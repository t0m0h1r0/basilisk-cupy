## 0. 要約
1. **誤差の場を 2 つに分ける（3 節）。** 同じ格子で CFL 数を c・c/2・c/4 にした 3 本から、時間刻み 0 の極限の場 `u⁰ = (u_c − 6u_{c/2} + 8u_{c/4})/3` を作る。`e_s = u⁰ − u_exact`（空間の誤差：高次化で減らせる分）、`e_τ = u_c − u⁰`（時間に結びついた分：時間積分を変えない限り残る。参照解なしで測れる）。固定の格子で Δt を変えた誤差のノルムの差では読まない。
2. **場所と源を混同しない。** 誤差を「帯」（界面から法線の距離 2.5 セル以内）と「内部」に分けたノルムは、誤差が**どこにあるか**で、**どこで作られたか**ではない（界面で作られた誤差は内部に広がる）。源は介入で読む。
3. **介入は場の要因分解で読む（4 節）。** 2 つの介入 X・Y の 4 本の誤差の場から、`δ_X`、`δ_Y`、相互作用 `δ_XY`、残り `e₁₁` を作り、4 つのノルムをそのまま表にする。寄与率（%）は書かない。`‖δ_XY‖` が小さい場合だけ「加法的」と書く。作れない組はベンチマークごとに明記する。
4. **CCD の利得は上限で判定する（5 節）。** 「内部の空間誤差を 0 にした場」`e_opt = e_τ + e_s·1_帯` のノルムの曲線と、基準の曲線から、同じ誤差に達する格子の粗さ G、同じ費用での加速率 S₁、**損益分岐の費用の比 `r_c* = S₁/1.5`** を出す。`r_c* < 1` のベンチマークは、高次化の費用が 0 でも目標に届かない＝「利得が見込めない」。
5. **GPU の時間は 2 種類（6 節）。** (P) 段ごとに同期を入れた割合の測定、(T) 同期を足さない総計算時間。比較に使うのは (T) だけ。

## 3. 時間誤差が空間の高次化の利得を制約する程度（要求仕様 1）
### 3.1 誤差の模型
要求仕様の形 `E ≈ C_s h^p + C_x hΔt + C_t Δt²` を、ノルムではなく**場**に対して置く【仮定 A0：滑らかな範囲で、誤差の場が h と Δt のべき乗に展開できる】：

```
e(h, Δt) = h^p e_s + Δt e_1 + hΔt e_x + Δt² e_t          （e_s, e_1, e_x, e_t は場。帯と内部で別の大きさ）
```

- `e_1`（h によらない 1 次の項）は、#153 の合格の条件 `O(h² + hΔt + Δt²)` を満たす構成では 0。#179 の分岐で c（時間 1 次のまま）を採った場合と、界面の帯（ノート117）では残る。
- CFL 数 `c = UΔt/h` を固定すると、`e = h^p e_s + c h (e_1/U) + c h² (e_x/U) + c² h² (e_t/U²)`。VOF 型の輸送の「CFL 数に依存する空間誤差 `h² f(c)`」（ノート112・113）は、`f(c) = f₀ + f₁c + f₂c²` の形でこの展開に入る。**固定の格子で Δt を小さくすると誤差が増えることがある**（ノート113 の 3 節）のは、`e_x`・`e_t` と `e_s` が逆符号の場合で、ノルムの差からは次数が読めない。

### 3.2 測る量：時間刻み 0 の極限の場
同じ格子 h で、CFL 数 c（運用の値、既定 0.5）・c/2・c/4 の 3 本を、同じ物理時刻で保存する。

```
u⁰  = (u_c − 6 u_{c/2} + 8 u_{c/4}) / 3        時間刻み 0 の極限（c の 2 次式の定数項【証明：174_breakeven.py】）
e_s = u⁰ − u_exact                              空間の誤差の場（参照解が要る）
e_τ = u_c − u⁰                                  時間に結びついた誤差の場（参照解が要らない）
a   = 2 (4 D₂ − D₁) / Δt,   b = 8 (D₁ − 2 D₂) / (3 Δt²),   D₁ = u_c − u_{c/2},  D₂ = u_{c/2} − u_{c/4}
```

- `a = e_1 + h e_x`、`b = e_t`（Δt は c の本の値）。`‖a‖` を 3 格子以上で読み、h によらない成分（`e_1`）と h に比例する成分（`e_x`）を分ける（ノート113 の 6 節の方法）。
- **3 本の妥当性の確認**（規約）：4 本目（c/8）を、最も粗い格子と最も細かい格子で 1 回ずつ足し、`u⁰` の 2 通りの外挿（(c, c/2, c/4) と (c/2, c/4, c/8)）の差が `‖e_s‖` の 10% 以下であること。超える場合は、その格子・ベンチマークの `e_s`・`e_τ` を「分離できない」と記録する（ノート117：非粘性の渦の中の液滴では、時間刻みの違う解が収束しなかった）。
- 界面のある問題では、f も同じ式で外挿せず、u・p だけを外挿する（f の線形結合は界面をにじませる）。f の誤差は 3 本それぞれの L1 を並べる。
- 毛管の制限で Δt が決まる問題（Δt ∝ h^{3/2}）では、c の代わりに時間刻みの倍率（1、1/2、1/4）を使う。式は同じ。

### 3.3 同じ誤差に達する格子がどこまで粗くできるか
【仮定 A1】高次化は `e_s` の内部で作られる分だけを変え、`e_τ` と帯で作られる分は変えない（時間積分と界面の扱いを変えない）。

- **固定の CFL**：基準の誤差を `E₀(h) = E_s + E_τ`（同じ次数 m の和の形で上から抑える）とし、高次化の後に残る誤差の次数を m（`e_1 ≠ 0` なら 1、そうでなければ 2）、`ρ_s = E_s/E_τ` とすると、空間誤差を全て消しても

  ```
  G_max = h′/h = (1 + ρ_s)^{1/m}
  加速率  S = G^{d + s} / r_c        （d = 2。s = 1：Δt ∝ h、s = 3/2：毛管の制限 Δt ∝ h^{3/2}。r_c は 1 ステップの費用の比）
  ```

  目標（計算時間が 2/3 以下、S ≥ 1.5）に要る `ρ_s ≥ (1.5 r_c)^{m/(d+s)} − 1`【証明：代数。174_breakeven.py】：

  | 残る誤差 | Δt | r_c = 1 | 1.5 | 2 | 3 |
  | --- | --- | --- | --- | --- | --- |
  | 1 次（m = 1） | ∝ h | 0.14 | 0.31 | 0.44 | 0.65 |
  | 2 次（m = 2） | ∝ h | 0.31 | 0.72 | 1.08 | 1.73 |
  | 2 次（m = 2） | ∝ h^{3/2} | 0.26 | 0.59 | 0.87 | 1.36 |

- **CFL を下げる場合**：`e_τ` が支配していて CFL を c → c/k にすると、`E_τ` は（1 次の項なら）1/k、ステップ数は k 倍になる。R1 では運用の CFL だけでなく c/2・c/4 の本があるので、(格子、CFL) の 12 点（4 格子 × 3）それぞれの誤差と (T) の時間を同じ図に置き、誤差ごとの最小の時間（下の包絡線）を基準の曲線とする。式の形で外挿しない。
- 実際の判定は、ノルムの和の上界ではなく、場から作る 5 節の `e_opt` で行う（符号の打ち消しを含む）。ここの式は、結果を読むための目安である。

## 4. 介入の試験の相互作用と識別可能性（要求仕様 2）
### 4.1 介入の定義（質量と運動量の流束の共通性を壊さない形だけ）
| 記号 | #142 の名前 | 何を差し替えるか | 流束との整合 |
| --- | --- | --- | --- |
| **A** | B3 界面の輸送 | VOF の面の体積の流束を、厳密な流れの写像による掃過体積（相 1 の分）にする。運動量の流束は、その体積 × 面の値 | 同じ体積の流束を質量と運動量が使う（D1・D2 と同じ要請）。セルの f を上書きしない |
| **G** | B1 界面の形 | 幾何学的な再構築（PLIC）の法線と、ポテンシャルが使う界面の位置を、厳密な界面のものにする。切片はセルの f に合わせる（体積は変えない） | 流束は同じ再構築から切り出すので整合する。f は数値解のまま |
| **K** | B2 曲率 | `φ = σκ` の κ を厳密な値にする（界面のセルで） | 流束に触れない |

- 面の密度・面の粘性に厳密な面の体積分率を使う形は、介入に入れない（セルの密度との関係が変わり、圧力を含む総運動量の保存〔ノート115：算術平均が条件〕を壊す。構成の軸として R0 で決める）。
- B123 は (A, G, K) = (1, 1, 1)。B0 は (0, 0, 0)。

### 4.2 読み方：場の要因分解
2 つの介入 X・Y（なし = 0、あり = 1）の 4 本の誤差の場 `e_xy` から

```
δ_X = e₀₀ − e₁₀,   δ_Y = e₀₀ − e₀₁,   δ_XY = e₀₀ − e₁₀ − e₀₁ + e₁₁
e₀₀ = e₁₁ + (e₁₀ − e₁₁) + (e₀₁ − e₁₁) + δ_XY                     【証明：恒等式】
```

- 表に書くのは、`‖e₀₀‖`、`‖e₁₀‖`、`‖e₀₁‖`、`‖e₁₁‖`、`‖δ_X‖`、`‖δ_Y‖`、`‖δ_XY‖`（帯・内部・全体、L2 と L∞）。**寄与率（%）や「X が誤差の何割」は書かない。**
- 規約（測定の前に固定）：`‖δ_XY‖ ≤ 0.2 min(‖δ_X‖, ‖δ_Y‖)` のときだけ「X と Y は加法的」と書く。それ以外は「相互作用あり：寄与は分けられない」と書き、4 本の値をそのまま結論に使う。
- 介入で誤差のノルムが**増える**場合（`‖e₁₀‖ > ‖e₀₀‖`）は、誤差の源どうしの打ち消しである（例：ノート113 の E2 と E3）。そのまま記録し、「X を除いても良くならない」とは読まず、打ち消しの相手を `δ` の場の形（どの介入の δ と逆符号か、内積 `⟨δ_X, δ_Y⟩/(‖δ_X‖‖δ_Y‖)`）で特定する。
- 3 つの介入（A・G・K）がそろうベンチマーク（6 の σ > 0）は 2³ = 8 本。τ は全ての水準に掛ける（3 本ずつ）ので、`e_s`・`e_τ` それぞれに同じ分解を行う。
- **B123 で残る誤差は診断値**である（ユーザー）。`e₁₁₁` には、介入が除かないもの（内部の離散化、圧力と粘性の界面での扱い、面の物性の平均）が全て入る。

### 4.4 介入そのものが新しい誤差を作らないことの確認（介入ごとに、本測定の前に）

## 5. 損益分岐点（要求仕様 3）

| 入力 | 出どころ |
| --- | --- |
| 基準の誤差の曲線 `E₀(h)`（ノルムごと、時刻ごと） | 2 節の誤差、運用の CFL。CFL を下げた点も含めた下の包絡線（3.3 節） |
| 上限の曲線 `E_opt(h) = ‖e_τ + e_s·1_帯‖` | 3.2 節の場。内部の空間誤差を、界面が原因の分も含めて全て 0 にした場合。内部だけを高次にする方式が達しうる誤差の**下限の目安**である【仮定 A2：内部の `e_s` と残す部分が打ち消し合っている場合、実際の方式の誤差はこれを上回りうる。厳密な下限ではない】 |
| 介入つきの上限 `E_opt^{AGK}(h)` | A・G・K が作れるベンチマークで、(1, 1, 1) の水準の `e_s` の内部の分を「内部で作られた空間誤差」の目安とし、`e₀₀₀` からそれだけを引いた場のノルム。相互作用が大きい場合（4.2 節の規約）は使わない |
| 1 ステップの時間 `t_step(h)`、段ごとの割合 | 6 節の (T) と (P) |
| ステップ数 | 実測（`T/Δt` の式ではなく、実行の記録） |

### 5.2 出力の式と表の形
誤差 ε ごとに（ε は、基準の 4 格子の誤差の範囲の中だけ。外挿しない）、`E₀(h₀) = ε`、`E_opt(h₁) = ε` を、対数の線形補間で解く。

```
G(ε)    = h₁ / h₀                                   必要な格子の削減率の上限
S₁(ε)   = [ステップ数(h₀) · t_step(h₀)] / [ステップ数(h₁) · t_step(h₁)]     費用の比が 1 のときの加速率の上限
r_c*(ε) = S₁(ε) / 1.5                               損益分岐の費用の比：1 ステップの費用がこれ以下なら、計算時間が 2/3 以下になりうる
r_c     = 1 + Σ_k w_k (ρ_k − 1)                     高次化する段 k の割合 w_k（(P)）と、その段の費用の倍率 ρ_k（R2・R3 で測る）
時間刻みの制約：高次の演算子の安定の上限が c′ < c なら、ステップ数(h₁) に c/c′ を掛ける（r_c* は c′/c 倍になる）
```

| ベンチマーク | ノルム・時刻 | ε | h₀ | h₁ | G | S₁ | r_c* | 判定 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| （R1 で埋める） | | | | | | | | |

- **判定の規約**（測定の前に固定）：ε の範囲の全てで `r_c* < 1` → 「利得が見込めない」。どこかで `r_c* ≥ 1` → 「上限では見込める。許容できる費用の比は r_c*」。`r_c* ≥ 1` でも、4.3 節で界面と内部の源が分けられないベンチマークは「場所による上限だけ」と書く。
- `S₁` は上限で、実際の利得ではない（R2・R3 で、実際の高次の方式の誤差の曲線に置き換える）。
- 計算は `174_breakeven.py` の `breakeven()`（合成のデータで自己点検済み：内部の空間 4 : 時間 1、帯つきで G = 1.93、S₁ = 7.2、r_c* = 4.8）。

### 6.2 フックの仕様（A が `cases/` に作る。ライブラリは変えない）
- **段の境**：`CenteredNS._run_hooks(stage)` の呼び出しの入口を境にする（包むだけ）。区間の名前：

| 区間 | 境（入口 → 次の入口） | 中身 |
| --- | --- | --- |
| dt | `set_dtmax` → `vof` | 時間刻み（CFL、毛管の制限） |
| transport | `vof` → `properties` | VOF と運動量の輸送（`tracer_advection`・`tracer_diffusion` を含む） |
| properties | `properties` → `advection_term` | 物性 |
| advection | `advection_term` → `viscous_term` | 非保存形の移流（予測 + 半ステップの射影）。保存形では 0 に近い |
| viscous | `viscous_term` → `acceleration` | 粘性の求解 |
| force | `acceleration` → `projection` | 曲率・ポテンシャル・面の速度 |
| projection | `projection` → `end_timestep` | 圧力の求解、セルの補正 |
| other | `end_timestep` → 次の `set_dtmax` | 出力など |

  #179 で半ステップの予測の段が入る構成では、その段の射影を `predict` として分ける。
- **記録**（JSON、1 本ごと）：GPU の型番、ドライバ、CUDA・CuPy の版、倍精度、格子、CFL、圧力・粘性の許容誤差と緩和の回数、ステップ数、Δt の最小・最大、各ステップの V サイクルの回数（`mgp.i`・`mgu.i`・`mgpf.i`）、測定の前後の `nvidia-smi` の使用率と他のプロセスの有無、捨てたステップ数、(P) の区間ごとの合計、(T) の時間。
- **捨てるステップ数**（監修 C-4 の 6）：本測定の前に、(格子、ベンチマーク) ごとに 1 回、(P) のモードで 60 ステップ走らせ、(i) CuPy のメモリプールの `total_bytes()` が 5 ステップ続けて変わらない、(ii) 1 ステップの時間が、その後の 20 ステップの中央値の ±10% に入る、の両方を満たす最初のステップを n₀ とする。n₀ を記録し、本測定では n₀ ステップを捨てる。満たさない場合は「落ち着かない」と記録して B に上げる。
- **(T) の区間**：n₀ ステップの後で同期して計時を始め、最終の物理時刻のステップの後で同期して止める。報告するのは、この区間の時間と、全ステップに換算した値（× 全ステップ数 / 測ったステップ数）の両方。
- **繰り返し**：3 回、中央値。`(最大 − 最小)/中央値 > 5%` なら、他のジョブの無い時間に測り直す（4 セッションが同じ機械を使う）。
- **先に記録する既知の非効率**（測るだけで直さない。A の案のとおり）：多重格子の緩和が Red–Black（V サイクルの回数）、`timestep` と `vof_advection` の CFL の戻り値の毎ステップの同期、許容誤差と V サイクルの回数の関係。

### 6.3 小さい格子での動作の確認（A。数値は R1 の結果に使わない）
N = 32・64 の 2 本（ベンチマーク 1 と 6）で：(P) の区間の合計が全体の ±2% に入る、(T) が (P) の合計以下である、n₀ が決まる、JSON の項目がそろう。
