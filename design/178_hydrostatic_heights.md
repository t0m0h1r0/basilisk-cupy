## 0. 要約
1. **前提の訂正（B・A・C へ）**：ノート120 の 4 節「壁の無い周期の帯でも、薄片で本物の界面のセルの位置が半周期まで飛ぶ（12 配置の全て）」は、**時間刻みの上限を設定していないことによる見かけ**である【再実行】。その測定は `ns.DT` が 1e30 のままで、時間刻みが雑音の速度（1e-16）の CFL で決まり、Δt = 5e12〜2e13、最終の時刻 1e15 になる。雑音の速度の CFL 数は 0.5〜0.6 に達し、**界面そのものが乱数の速度で運ばれて崩れる**（`max|f − f₀| = 1`）。`DT = 0.5/N`（静水圧の試験と同じ）にすると、同じ 40 ステップで薄片は 0 個、位置のずれは 1e-14 セル、`max|f − f₀|` は 4e-15 である。「(B) は壁から離れても起きる」ことの測定の根拠は、今は無い。
2. **機構 (B) の正体**：薄片（f = 1e-22 など）のセルは `0 < f < 1` で「界面のセル」と判定され、ポテンシャル φ を持つ。そのセルの高さは 1 セルより遠いので、位置は PLIC の重心（薄片のセルの中の点）に落ち、**界面の上にない**。面のポテンシャルは両側の平均なので、本物の界面のセルとの間の面（f の跳びが O(1)）に、誤った φ の半分が掛かる【証明：`position()` と `_interfacial_force` の式】。高さ関数の値そのものは、薄片でほとんど変わらない。**薄片が界面の隣にあれば、壁から離れていても力は出る**【静的な確認：周期の斜めの帯に薄片を入れると、面の力が 4e-15 → 0.02〜0.06（セルの単位）】。問題は「薄片がどこで生じるか」で、それは 1 の再実行では生じず、監修の測定（壁の近く、DT あり）では生じている。
3. **機構 (A) の正体**：壁を横切る列は、鏡像のゴーストセルでは正しく完成しない。高さが取れず（または 1 セルより遠く）、位置が PLIC の重心（法線は壁の鏡像で曲がる）に落ちる。ゴーストセルを定数延長に変えても、t = 0 の φ は変わらない【静的な確認】。**壁に浅い角度で接する界面では、壁の行のセルが 1/tanθ 個の程度に並び、どれも壁に垂直な列が壁を横切り、壁に沿った行の和も届かない**（監修の反例：θ = 5°、δ = −0.45、N = 32）。
4. **候補**（どれも f と輸送に触れない。reduced のポテンシャルの位置の作り方だけ）：
   - **B-1**：高さ・界面のセルの判定・位置に、`f ≤ ε → 0`、`f ≥ 1 − ε → 1`（ε = 1e-10）と丸めた**判定用の写し**を渡す。f は書き換えない。
   - B-2（2 つ目。相分率を書き換える）：輸送の後に `f ≤ ε₂`・`f ≥ 1 − ε₂`（ε₂ = 1e-14）を 0・1 にする。相の質量の変化を記録する。
   - **A-1（改訂）壁で閉じた列**：壁のゴーストセルを、鏡像ではなく「壁に接するセルの、壁の側の相」（0 か 1）で埋めて高さを作る。界面が壁と交わるセル（接触のセル）の、壁に垂直な向きの高さだけは、壁に沿った隣の列の高さの線形外挿で埋める。
   - A-2（改訂。2 つ目）高さの線の規則：それでも高さが 1 セルより遠い界面のセルで、PLIC の重心に落ちる前に、2.5 セル以内の高さとその傾きの直線をセルの中へ辿った点を使う（第 1 版の A-1）。

5. **第 1 版（9cd928e）の候補は、監修の走査で外れた**：定数延長 + 線の規則 + 隣の 2 列の外挿（旧 A-1+A-2）は、1794 配置のうち 56 配置で `max|φ| > 1e-8` が残った（現行は 364。残りの 52 は θ = 2.5〜22.5°、4 は 45°。42 配置で角から 2 セルより遠い）。第 1 版の「残りは 0 か、角の 1〜2 セルの少数」という予測は外れた。

## 1. 定式化（ライブラリの現行の形）
reduced の重力の力は、面の加速度 `a_f = α_f φ_f (f_r − f_l)/h`。

| 段 | 現行の規則（`interface/heights.py`、`two_phase._interfacial_force`。Basilisk の `heights.h`・`curvature.h`・`iforce.h` と同じ） |
| --- | --- |
| 界面のセル | `0 < f < 1`、または `f ≥ 1` で隣に `f ≤ 0` がある、またはその逆（`interfacial()`）。**厳密な比較** |
| 高さ | 軸ごとに、セルから ±4 セルの列の和（`_half_column`）。満・空の判定は `S > 0 && S < 1`、`c ≤ 0`、`c ≥ 1` の**厳密な比較**。壁のゴーストセルは f の鏡像 |
| 位置 | 界面のセルで、法線の大きい成分の軸の高さ（`|h| ≤ 1` のときだけ）→ もう一方の軸の高さ（同じ条件）→ どちらも無ければ **PLIC の線分の重心**（法線は `mycs`、3 × 3） |
| φ | `(ρ₂ − ρ₁) G·(x_I − Z)`。界面のセル以外は未定義 |
| 面の φ | 両側で定義されていれば平均、片側だけならその値、どちらも無ければ 0 |

平面が G に垂直で Z を通れば、`x_I` が平面の上にある限り φ ≡ 0 で、静止が離散の厳密解になる（ノート120 の A 節）。**崩れる必要十分の条件は、φ を持つセルの `x_I` が平面の上にないこと**である。

### 2.2 薄片が力になる経路【証明 + 静的な確認】
薄片のセル（`0 < f ≤ 1e-12` など）が、本物の界面のセルの隣にあるとする。
1. 薄片のセルは `interfacial()` が真で、φ が定義される。
2. そのセルから界面までの距離は、列の向きに 0.5〜1.5 セル。`|h| ≤ 1` を満たさなければ高さは使われず、PLIC の重心になる。重心は薄片のセルの中（界面に近い辺か角）にあり、平面からの距離は最大で 1 セル程度。
3. 本物の界面のセルとの間の面では、`φ_f = (φ_本物 + φ_薄片)/2`、`f_r − f_l = O(1)`。誤差 `φ_薄片/2` がそのまま力になる。**薄片の大きさによらない**（1e-30 でも 1e-12 でも同じ）。
4. 薄片が無ければ、隣のセルは `f = 0` で界面のセルではなく、`φ_f = φ_本物`。

静的な確認（周期の斜めの帯の厳密な f に、界面の隣の空・満のセルの半分へ 1e-22・1 − 1e-16 を入れる。G は単位法線）：

| n | N | 薄片なし | 薄片あり（ライブラリ） | 薄片あり（B-1） |
| --- | --- | --- | --- | --- |
| (1, 1) | 32 / 64 | 4e-15 / 6e-15 | 2.4e-2 / 1.7e-2 | 4e-15 / 6e-15 |
| (1, 2) | 32 / 64 | 3e-15 / 5e-15 | 5.9e-2 / 6.1e-2 | 3e-15 / 5e-15 |
| (2, 3) | 32 / 64 | 6e-15 / 1e-14 | 4.1e-2 / 4.6e-2 | 6e-15 / 1e-14 |

（面の力 `max|φ_f (f_r − f_l)|`、φ はセルの単位の距離。）

- 高さ関数の値そのもの（`|h| ≤ 1` の本物の界面のセル）は、薄片を入れても変わらない（高さの無いセルが数個増えるだけ）【静的な確認】。「列の和が変わって高さが飛ぶ」という説明は、少なくともこの配置では当たらない。
- 曲率（表面張力）への影響は、位置より小さいはずである：薄片のセルの曲率は、同じ界面の高さ（±5.5 セルまで届く）から作られ、PLIC の重心には落ちにくい【仮定：未検証。5 節の E-B2 で測る】。

### 2.3 候補
**B-1 判定用の写し（第一候補）**
```
c̃ = 0（f ≤ ε）、1（f ≥ 1 − ε）、f（それ以外）        ε = 1e-10
高さ・界面のセル・位置・（曲率）・PLIC の法線は c̃ から作る。面の力の (f_r − f_l) と、輸送・物性・運動量は f のまま
```
- **質量・自由流・局所の収支に触れない**【証明：f、輸送、物性のどれも変えない。変わるのは、力の中の φ（と曲率）だけ】。
- **薄片のセルは界面のセルでなくなり、φ を持たない**。2.2 節の 3 の経路が消える【証明】。薄片の側の面の `(f_r − f_l) = 1e-22` には、φ_f が未定義で 0 が掛かる。
- **精度への影響**：列の和が、1 列あたり最大 9ε（セルの単位）変わる。位置で `9εh`、曲率で `≈ 36ε/h`（3 点の 2 階差分）の変化で、ε = 1e-10、N ≤ 256 なら相対 1e-6 以下【証明：上界】。`ε < f < 1 − ε` のセルだけの計算では、高さは現行とビット一致する。本物の界面が ε より小さい体積だけ入ったセル（体積分率 `< 1e-10`）は「空」と読まれ、その界面は隣のセルの高さで表される。
- ε の選び方：`vof.h` が「相が無い」と判定する閾値（1e-10、D1 の修正と同じ値）に合わせる。丸めの薄片（1e-17〜1e-30）と、CFL の 2 乗の角の薄片より大きく、意味のある体積分率より小さい。**ε は 1 つの値で、走査しない**（感度の確認は 5 節の E-B3 の 1 回だけ）。
- 表面張力の曲率にも同じ写しを使うか：**使う**（高さ関数は 1 つで、判定が食い違うと φ と曲率で界面のセルの集合が変わる）。#178 の条件 3（曲率の精度を壊さない）は、5 節の E-B2・E-3 で確かめる。

**B-2 輸送の後の薄片の除去（2 つ目の候補。相分率を書き換える）**
```
輸送の後：f ≤ ε₂ → 0、f ≥ 1 − ε₂ → 1（ε₂ = 1e-14）。相ごとの運動量はそのまま
```
- 相の質量を 1 セルあたり最大 ε₂ 変える（記録する）。速度は `u = q/ρ(f)` なので、軽い相のセルから重い相の薄片を除くと、相対で `ε₂ (ρ₁/ρ₂ − 1) ≈ 1e-11` 変わる【証明】。自由流の閾値（1e-8）の内側だが、丸めではない。ε₂ を 1e-10 にすると 1e-7 になり、自由流を壊す。**ε₂ = 1e-14 より大きい薄片（CFL の 2 乗の角）は除けない。**
- B-1 が条件 1〜4 を満たせば、B-2 は実行しない。

## 3. 機構 (A)：壁
### 3.1 何が起きているか
- ゴーストセルを鏡像から定数延長に変えても、試した配置の t = 0 の φ は桁まで同じ（例：45°・δ = 0.0137・N = 32 で 6.3e-4 のまま）【静的な確認】。鏡像が作る「折れた界面」を列が読んでいるのではなく、**壁を横切る列が正しく完成しないこと**が原因である。
- 例 1（θ = 30°、δ = 0.40、N = 64。監修の不成立の配置）：φ ≠ 0 のセルは最上段の `f = 0.998` の 1 つ。y の列は壁を横切って高さが無い。x の高さは 1.28 で、`|h| ≤ 1` を満たさないので使われない。残る PLIC の重心は、鏡像を含む 3 × 3 の法線で作られ、平面から外れる。
- 例 2（θ = 5°、δ = −0.45、N = 32。**監修の反例**）：壁の行のセル (23, 0)、f = 0.94。y の列は壁で未完成。浅い角度なので、壁に沿った行の和（x の高さ）は ±4 セルでは届かない。隣の列も同じ状態で、**この状態のセルが壁に沿って 1/tanθ の程度で続く**。第 1 版の候補（自分の高さが要る線の規則、隣の 2 列の高さが要る外挿）は、どちらも使えなかった。
- **壁の行のセルの f は、それだけで、その列の界面の高さを厳密に与えている**：壁の側が相 1 で満たされ、界面がその列の幅の中で壁に達しないなら、`f = （界面の平均の高さ）/h`。列を壁で閉じれば（壁の外を相 1 と見なせば）、高さ関数はこの値を返す。鏡像は、壁の外に「部分的なセル」を置くので、列が閉じない。

### 3.2 候補
reduced のポテンシャルの位置を作るときだけに使う。表面張力の曲率の壁の条件（鏡像 = 90°）は変えない。

**A-1（改訂）壁で閉じた列（第一候補）**
1. **ゴーストセル**：壁のゴーストセルの全ての層を、壁に接するセルの「壁の側の相」`H ∈ {0, 1}` で埋める。壁に接するセルの値を `c₀`、その内側の隣を `c₁` として
   ```
   H = 1（c₀ ≥ 1）、0（c₀ ≤ 0）、1（0 < c₀ < 1 で c₁ < c₀：相 1 が壁の側）、0（c₁ > c₀）、round(c₀)（c₁ = c₀）
   ```
2. **接触のセル**：壁の行の部分的なセルで、壁に沿った両隣の H が違うもの（界面がそのセルの幅の中で壁に達する）と、箱の角の部分的なセル。ここでは、閉じた列の和は「壁で切られた界面」の平均で、界面の高さではない。**壁に垂直な向きの高さを捨てる。**
3. **外挿**：捨てた高さ（と、もともと無い高さ）を、同じ向きの、壁に沿った隣の 2 列の高さから `h = 2h₁ − h₂` で埋める。埋めた値は次の列の外挿に使う（片側から順に）。
4. その後は現行の規則（`|h| ≤ 1` の高さ → もう一方の軸 → PLIC の重心）。

- **平面で厳密**【証明】：(i) 界面が列の幅の中で壁に達しない列では、壁の側は一方の相で満たされているので、H はその相で、閉じた列の和は界面の平均の高さになる（直線の界面では、列の中心での高さに等しい）。(ii) 接触のセルでは、(i) の列の高さは壁に沿った座標の 1 次式なので、線形外挿は界面の（壁の外へ延ばした）高さを厳密に与える。(iii) したがって、高さを持つ全ての界面のセルで、点 `(x_c, y_c + h·Δ)` は平面の上にあり、`G·(x_I − Z) = 0`。外挿に使える隣の列が 2 つ無い場合（箱の角で、両方の壁の接触のセルが重なる場合など）は、この証明の外である。
- H の規則が正しい条件：壁に接するセルの中で、界面が壁に垂直な向きに単調（相 1 が壁の側か反対側のどちらかに寄っている）。平面と、壁の近くで曲率半径がセルより十分大きい界面では成り立つ。壁に接する薄い膜や、1 セルより小さい液滴では成り立たない【仮定：その場合は現行と同じく PLIC の重心に落ちるはずだが、未検証】。
- 界面が壁に 90° で接する配置（壁に垂直な向きの列と界面が平行）：壁の側だけ閉じても、列の反対の端が完成しないので、高さは現行と同じく「無し」になる【証明：列の完成には両端が要る】。
- 接触のセルの外挿した点は、セルの外（壁の外）に出ることがある（`|h| ≤ 1` なら使う）。曲がった界面では、界面から `O(κh²)`【証明：Taylor。係数は未検証】。

**A-2（改訂）高さの線の規則（2 つ目の候補。A-1 で残る配置がある場合だけ）**
A-1 の後でも標準の規則で高さが取れない界面のセルで、重心の前に次を試す。軸 a の高さ `h_a`（`|h_a| ≤ 2.5`）と、傾き `s`（同じ軸の高さの、もう一方の軸 t の向きの差）から、セルの座標で直線 `ξ = h_a + sτ` を作り、`τ ∈ [−1/2, 1/2] ∩ {|h_a + sτ| ≤ 1/2}` が空でなければ、その中点を界面の点とする。平面で厳密【証明：完成した列の高さとその差は、直線の位置と傾きを厳密に与える】。15 配置の静的な確認では、A-1 だけで足り、A-2 が働く配置は無かった。

**第 1 版の候補（記録）**：定数延長のゴーストセル + 線の規則 + 隣の 2 列の外挿。監修の走査で 56 配置が残った（0 節の 5）。定数延長は列を未完成にするだけで、壁の行のセルが持つ高さの情報（3.1 節の最後）を使っていなかった。
