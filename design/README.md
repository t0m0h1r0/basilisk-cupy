# design/：数学的な定式化と設計の仕様（D 設計）

運用の規約は `docs/operations.md`。ここには、タスクの Issue ごとに、定式化・候補の比較・主張と導出・判定の基準・反証の方法・最小の実験の仕様を置く。測定の記録は書かない（`docs/notes/` に A が書き、ここを参照で引く）。文書の名前は Issue の番号で始める。記号計算などの小さい確認は `checks/`（sympy・numpy だけで動く）。

主張には区別を付ける：証明、模型（線形の模型で確かめただけ）、引用（ノート・監修の測定）、仮定、未検証。
