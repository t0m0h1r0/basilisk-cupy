## 0. 要約
1. **x に一様な状態は、離散の 1 ステップの厳密な不動点である【証明、1 節】。** 方式の不整合で定常解が無いのではない。崩れるのは、x に一様でない微小な擾乱（丸め・求解の許容誤差）が**線形に増幅する**ためである。
2. **線形の模型は、監修の切り分けを全て再現する【模型、2 節】**：面の上・密度比 1000 で増幅（時間刻みを小さくすると 1 ステップの倍率は下がるが、1 を超えたまま）、粘度比によらない、密度比 10 では増幅しない、力が無ければ（Couette）増幅しない、界面を 0.3 セルずらすと増幅しない。粘性を外しても増幅する。
3. **帰還の材料は 2 つ【模型：スイッチで確認】**：
   - (i) **力の加速度 `F/ρ(f)` の、f への感度**。純粋な軽い相のセル（f = 0）では `∂(F/ρ)/∂f = −F(ρ_H − ρ_L)/ρ_L²`（密度比 1000 で 1e9）。重い相がわずかに入るだけで、加速度が大きく変わる。部分的なセル（f = 0.3）では 1e4 で、5 桁小さい。**力を基底の密度で作ると、増幅は消える。**
   - (ii) **界面の面の法線の速度を、両側のセルの速度の算術平均で作ること**（`uf = I_f(u) + Δt a`）。軽い相のセルの法線の速度（圧力の応答が `α_L = 1/ρ_L` で入る）が、界面の面に半分そのまま乗り、界面を動かす。**この補間を質量加重にすると、増幅は大きく下がる**（時間刻みの小さい側では消える）。
4. 粘性は帰還に入らない：力の加速度は粘性の段の**後**に、面の速度とセルの速度に陽的に入る（centered.h の順）。基底の流れによる移流、VOF の上流の切り替え、D1・D2 も、模型には入れていないのに増幅が出るので、必要ではない。
5. **模型と合わない点**：密度比 100 は、模型では時間刻みの大きい側（Δt N ≥ 0.29）で増幅する（1.45〜2.19）。監修の測定では t = 0.3 まで崩れていない。模型の省略（上流の切り替え、基底の流れ）か、測定の時間の短さかは分からない（実験 P4）。
6. **切り分けの実験は 5 本**（3 節）。P1（力を初期の密度で作る）と P2（界面の面の補間を質量加重に）が、模型の 2 つの材料の反証になる。

## 1. x に一様な 1 ステップは厳密な不動点【証明】
配置：x は周期、y = 0・1 は粘着壁。相 1（ρ_H、μ_H）が y < 1/2、相 2（ρ_L、μ_L）が上。体積力 F が x 向きで、面の加速度として `a_x = F α_x`（`α_x = 1/ρ(x の面)`）。界面は行 j0 − 1 と j0 の間の面の上で、混合セルは無い（f は厳密に 1 と 0）。

x に一様な状態（`u = (U_j, 0)`、f は上のとおり、p は定数）での centered.h の 1 ステップ：
1. VOF：面の速度は `uf = (U_j, 0)`。y の面の速度が 0 で、x の面の流束は x に一様なので、f は変わらない。
2. 物性：変わらない。x の面の密度は行ごとに ρ_H か ρ_L。界面の y の面は `ρ((1 + 0)/2) = (ρ_H + ρ_L)/2`。
3. 粘性：`U ← V(U + Δt g) − Δt g`、`g_j = F/ρ_j`（前のステップのセルの加速度）。x に一様で、y の成分は 0 のまま。
4. 力と射影：`uf_x = U_j + Δt F/ρ_j` は x に一様、`uf_y = 0`。発散は 0 で、圧力は定数。`g = C(a) = F/ρ_j`。
5. したがって `U^{n+1} = V(Uⁿ + Δt F/ρ)` で、これは 1 次元の `ρ U_t = F + (μ U_y)_y` の後退 Euler（力は陽的）である。定常解は離散の厳密な不動点で、界面は動かない。

**x に一様な状態を保つ限り、どのステップにも不整合は無い。** 密度比にも、界面が面の上にあることにもよらない。

## 2. 擾乱の線形の模型【模型】
x の Fourier モード `exp(ikx)` の擾乱について、同じ 1 ステップを線形に書き下す（y は N 行をそのまま持つ）。入れたもの：VOF（界面の面の速度による界面の変位）、物性（セル・x の面・y の面の密度）、粘性の後退 Euler（新しい密度 × 古い加速度の項 `δρ g⁰` を含む）、力 `δa = −F δρ_面/ρ⁰²`、面の速度と射影、セルの補正。入れていないもの：基底の流れによる移流、粘性の係数の擾乱、VOF の上流の切り替え。

- 面の上・密度比 1000 では、4 つの時間刻みの全てで 1 を超える。1 ステップの倍率は Δt とともに下がるが、**時間あたりの成長率 `ln(倍率)/Δt` はおよそ 260〜430 で、Δt にあまりよらない**。時間刻みを小さくしても消えない、という監修の測定（DT 0.02/N でも t = 1 までに崩れる）と同じ性格である。
- 粘度比 1 でも同じ値。粘性の段を外しても増幅する。**粘性は原因でも、歯止めでもない。**
- 力なし、密度比 10、界面を 0.3 セルずらした配置は、増幅しない（1.000）。
- N への依存（Δt N = 0.1）：N = 16・32・64 で 5.4・3.9・2.5。

### 2.2 帰還の経路（模型のスイッチから）
1. 軽い相の行 j0 のセルに、重い相が φ だけ入る（界面の面の上向きの速度による）。
2. そのセルの密度が `ρ_L(1 + (ρ_H/ρ_L − 1)φ)` になる。力の加速度 `F/ρ` が、x に一様でなくなる：`δa = −F(ρ_H − ρ_L)φ/ρ_L²`。密度比 1000 で `1e9 φ`。**φ = 1e-12 で、加速度の差は 1e-3 になる。**
3. x に一様でない x の加速度は発散を持ち、射影が圧力で打ち消す。その圧力の勾配は、軽い相の中では `α_L = 1/ρ_L` 倍で速度になるので、行 j0 のセルの法線の速度に大きく入る（界面の面は `α = 2/(ρ_H + ρ_L)` で、ほとんど動かない）。
4. 次のステップの界面の面の速度は、両側のセルの法線の速度の**算術平均**から作る。行 j0 のセルの大きい法線の速度の半分が、界面の面に乗る。射影は、界面の面の α が小さいので、これをほとんど直さない。
5. 界面の面の速度が界面を動かし、1 に戻る。

- **なぜ界面が面の上のときだけか**：2 の感度が、純粋な軽い相のセル（f = 0）で最大になるため。部分的なセル（f = 0.3）では密度が ρ_H の程度で、感度は `F(ρ_H − ρ_L)/ρ(0.3)² ≈ 1e4`。界面を 0.3 セルずらすと、界面の両側の面はどちらも部分的なセルに接し、純粋な軽い相のセルに重い相が入るのは、界面が 1 セル動いた後になる。
- **なぜ密度比か**：感度は `ρ_H/ρ_L²`、3 の倍率は `1/ρ_L`、4 の「直さない」は `α_界面/α_L = 2ρ_L/(ρ_H + ρ_L)`。積は、およそ `F Δt²/(ρ_L h)` の型になる。
- **なぜ Couette では出ないか**：F = 0 で 2 が無い。
- セルの力の加速度の不整合（`C(F/ρ_面)` と `F/ρ_セル` の差。x の面の密度は両隣のセルの平均なので、`F(ρ_H − ρ_L)φ sin²(kh/2)/ρ_L²` だけ違う）は、**時間刻みの最も小さい所（Δt N = 0.02）の増幅だけを決めている**（セルの密度で作ると 1.19 → 1.000）。大きい時間刻みでは効かない。粘性の段の「新しい密度 × 古い加速度」の項は、効かない。
- まとめると、時間刻みの大きい側は「面の力の加速度の変化 → 射影 → 界面の面への算術平均の補間」（Δt とともに強くなる）、小さい側は「セルと面の力の加速度の不整合」（Δt によらない成分）が支えている。**どちらも (i) を通る。**

### 2.3 模型の限界
- 上流の切り替え（下向きの面の速度は、f = 0 のセルから何も運ばない）を入れていない。実際の増幅は、上向きの部分だけで起きる。
- 基底の流れ（軽い相で 1 の程度）による擾乱の移流を入れていない。
- 基底を準定常と置いた（始動の過渡を入れていない）。
- したがって、**倍率の値は目安**で、合うと期待するのは、増幅の有無と、パラメータへの依存の向きである。密度比 100 の食い違い（0 節の 5）は、この限界の中かもしれない。

## 4. B への材料（原因が確かめられた場合）
- この不安定は、**密度比の大きい二相で、体積力を「面の加速度 `F/ρ_面`」として入れ、界面がセルの面に揃う**ときの、元の方式（centered.h + two-phase.h）の性質である。重力を reduced の形（界面のポテンシャル）で入れる場合は、力が密度で割られた体積力として入らないので、この経路は無い【証明：2.2 節の 2 が無い】。R0 の試験で、体積力を面の加速度として入れるのは、R10 の Poiseuille だけである（静水圧・上昇気泡は reduced）。
- 直す場合に触る所は、(i) 体積力の入れ方（Poiseuille の駆動を、圧力勾配 = 密度で割らない力として運動量に入れる形）か、(ii) 界面の面の法線の速度の作り方、のどちらかになる。(ii) は射影と自由流に関わる。どちらも新しい方式で、この Issue では設計しない。
- 既知の制約とする場合の範囲：「体積力を面の加速度で入れる二相の流れで、界面がセルの面に揃う配置」。界面をセルの中に置けば起きない、というのは模型と監修の測定の両方の結果だが、界面が動いて面に揃った時点で同じことが起きうる【未検証】。
