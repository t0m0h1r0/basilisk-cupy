# 36 連成反復の収束判定・加速・格子依存・コスト（#49 の続き）

## ねらい
35（#49）では、`coupled_tolerance` で外側反復を収束させると、密度比 100 でも人工粘性なしで安定になることを示した。
この安定化を手法として完成させる前に、レビューで指摘された次の点を測定で確かめる。

- 収束判定が連成方程式の残差になっていない。
- 反復が上限回数で止まったとき、黙って次のステップへ進む。
- 圧力の遅れによる残留と、交換子との関係。
- Jacobian の基準状態、摂動幅、Ritz 残差。
- 格子依存性と密度比 1000。
- 計算コスト。

条件：静止液滴または振動する液滴（R = 0.25(1 + 0.05 cos 2θ)）、σ = 1、μ₁ = μ₂ = 0.1、ρ₁ = 1、壁、CLS + GFM。
刻みは tension.h の上限 √(ρ_m h³/(πσ)) の f 倍で表す。

## 1. 収束判定と残差（`cases/coupled_residuals.py`）
### 停止したときの運動量残差
反復 k の後で止めると、ステップの終わりの速度は u = w_k − Δt g_k + Δt g_{k+1} になる。
ここで w_k は (I − Δt/ρ L)w_k = u_adv + Δt g_k の解である。

この u の連成運動方程式の残差は、厳密に次の式になる。

    r_m = u_adv + Δt g_{k+1} − (I − Δt/ρ L) u = (Δt²/ρ) L (g_{k+1} − g_k)

- r_m は、判定に使っている変化量 Δt|Δg| に粘性演算子 Δt/ρ L を掛けたものである。
- 差分では最大で 8νΔt/h² 倍になる。気相の ν = μ/ρ が大きい高密度比では、この倍率が大きい（N = 32 で νΔt/h² = 35〜353）。
- 粘性の解演算子 B = (I − Δt/ρ L)⁻¹ で前処理すると B r_m = Δt(I − B)Δg になる。I − B のノルムは 1 以下と見込まれ、そうであれば |B r_m| ≤ Δt|Δg| となる。変化量による判定は、前処理した残差（速度の補正量）を抑えることと同じである。

外側反復が収束率 c で縮小するなら、真の解との誤差は |u_k − u*| ≤ c/(1 − c) · 変化量 で抑えられる。

### 測定
振動する液滴を 40 ステップ（収束まで反復）進めた状態から 1 ステップ進め、外側反復ごとの量を測った（N = 32、1.6 倍）。

| 反復 k | 密度比 1：変化量 / 残差 / 誤差 | 密度比 100 | 密度比 1000 |
| --- | --- | --- | --- |
| 1 | 8.6e-4 / 2.1e-3 / 4.4e-4 | 1.4e-1 / 6.1e-1 / 8.4e-2 | 3.8e-1 / 1.6 / 2.2e-1 |
| 4 | 2.9e-5 / 5.1e-5 / 9.7e-6 | 4.8e-3 / 2.9e-2 / 2.7e-3 | 1.3e-2 / 8.6e-2 / 7.4e-3 |
| 8 | 6.3e-7 / 1.2e-6 / 2.2e-7 | 3.5e-4 / 3.0e-3 / 1.5e-4 | 1.1e-3 / 1.2e-2 / 4.8e-4 |
| 12 | 1.9e-8 / 3.9e-8 / 7.4e-9 | 5.7e-5 / 1.1e-3 / 2.6e-5 | 2.0e-4 / 5.7e-3 / 9.5e-5 |

（max\|u\| は約 0.1）

- **誤差と変化量：** 誤差は変化量の 0.4〜0.6 倍で、変化量に沿って減る。c/(1 − c) の上限（c = 0.64 で 1.8）の内側にある。
- **密度比 1 の残差：** 変化量の 2〜2.5 倍で、一緒に減る。
- **高密度比の残差：** 変化量の 4〜28 倍あり、反復が進むほどこの比が開く。指摘どおり、変化量が小さくても運動量残差は大きいことがある。
  - 誤差（速度のずれ）は小さいので、この残差は主に粘性の硬い気相のセルの不釣り合いと見られる。
  - 密度比 1000、N = 64 では、残差が 7e-5 付近で止まる。その間も誤差は 6e-7 まで減る。粘性ソルバー自身の残差の床と見られ、残差による判定はこの値より下に設定できない。
- **収束率：** 1 回あたり、密度比 1 で約 0.4。高密度比では後半に 0.6〜0.7 まで悪化する。
- **発散：** 面の発散 Δt|D_f u_f| は全反復で 1e-14 程度。セル速度の発散 Δt|D interp(u)| は 4e-5（密度比 1）〜2.6e-4（密度比 1000）で止まり、反復しても下がらない（近似射影の床）。
- **N = 64、密度比 100 の注意：** あるステップでは 1 回目の変化量が 9.5（max|u| = 0.1）に達し、誤差は 6.3 だった。sharp 形の圧力ジャンプが新しいセルへ移ると、前ステップの圧力が初期値として大きく外れるためと見られる（4 節）。

### 実装（`CenteredNS`、既定は変更なし）
| 引数 | 意味 |
| --- | --- |
| `coupled_criterion="change"` / `"residual"` | 判定に使う量：変化量 Δt\|Δg\|、または運動量残差 r_m（Basilisk の `viscosity()` のみ） |
| `coupled_tolerance` | 絶対の許容値 |
| `coupled_rtol` | 1 回目の値に対する相対の許容値（無次元）。両方指定したときは大きい方を使う |
| `coupled_on_failure="warn"` / `"raise"` / `"ignore"` | 上限回数に達しても許容値を満たさないときの扱い |
| `coupled_failures`、`coupled_info` | 失敗したステップの数。直近ステップの反復回数・収束したか・変化量 |
| `momentum_residual()`、`divergence_residuals()` | 上の残差と、面・セルの発散を測る関数 |

絶対の許容値 1e-10 は、静止液滴では 3〜5 回で満たされる。振動する液滴（max|u| = 0.1）では 30 回でも届かなかった（5 節）。許容値は流れの速度に合わせる必要があるので、`coupled_rtol` を加えた。

## 2. 圧力の遅れによる残留の分解（`cases/operator_commutator.py split`）
w = Δt face_to_cell(α∇q) とすると、恒等式 P(B − I)w = [P, B]w + (B − I)Pw が成り立つ。

- 第1項は交換子の寄与。
- 第2項は、セルの近似射影が、面勾配をセルへ平均したものを消せない寄与（Pw ≠ 0）。

いずれも |Δt ∇q| で割った値で示す。

| | 交換子 [P,B]w | 近似射影 (B−I)Pw | 合計 | \|Pw\|/\|w\| | \|w\|/\|Δt∇q\| |
| --- | --- | --- | --- | --- | --- |
| A：密度比 1 | 1.9e-13 | 0.039 | 0.039 | 0.082 | 1.0 |
| 密度比 10 | 0.18 | 0.68 | 0.70 | 0.099 | 8.3 |
| B：密度比 100 | 4.2 | 6.9 | 8.1 | 0.12 | 58 |
| C：密度比 100、動粘性をそろえる | 0.36 | 2.9 | 2.8 | 0.12 | 58 |
| D：密度比 1、粘性比 100 | 2.4e-3 | 1.3e-3 | 2.6e-3 | 0.082 | 1.0 |
| E：密度比 1000 | 14.5 | 43.7 | 46.5 | 0.14 | 305 |

（q = x² − y²、N = 32）

Jacobian の不安定モードの圧力で同じ分解をすると、次のとおり（密度比 100、K = 1、1.6 倍）。

- 交換子 0.044、近似射影 0.974、合計 0.975。
- \|Pw\|/\|w\| = 0.67：格子規模の圧力の勾配は、セルの射影でほとんど消えない。

**わかったこと**

- 定数係数では交換子は 0（1e-13）になる。それでも残留が出るのは、セルの近似射影が厳密な射影でないためである。
- 不安定モードでは、残留の 96 % が近似射影の項である。35 で「交換子では説明できない」とした結論は、「ランダムな速度場での交換子の大きさでは説明できない」に限って正しかった。正確には、遅れた圧力勾配のうちセルの射影で消えない部分を、粘性が勾配でない形に変えることが原因である。交換子の項もあるが、主ではない。
- 密度比への依存は比例ではない。|w|/|Δt∇q| は 8.3 / 58 / 305（密度比 10 / 100 / 1000）である。これは気相の α と、圧力勾配が気相にある割合で決まる。粘性演算子 B も ρ を含む。そのため「密度比に強く依存する」と表すにとどめる。合計値 / 密度比は 0.039 / 0.070 / 0.081 / 0.047 だった。

## 5. 反復の加速（`cases/coupled_acceleration.py`）
振動する液滴、密度比 100、1.6 倍、20 ステップ。各ステップは `coupled_rtol = 1e-3`（1 回目の変化量の 1e-3 倍）で止め、1 ステップあたりの平均反復回数を測った。
誤差は 20 ステップ後の max\|u − u_ref\|/max\|u_ref\| で、基準は素の反復を 1e-13（上限 40 回）まで回したもの。

| 方式 | N = 32 sharp | N = 32 smooth | N = 64 sharp | N = 64 smooth |
| --- | --- | --- | --- | --- |
| 素の反復 | 11.6（2.4e-5） | 13.0（4.6e-6） | 18.7（3.9e-3、上限 3 回） | 12.6（4.2e-6） |
| 線形外挿 2pⁿ − pⁿ⁻¹ | 13.3（4.4e-4） | 12.3（1.4e-6） | 21.4（2.0e-3） | 10.2（7.5e-6） |
| Anderson m = 1 | 8.3（1.7e-5） | 9.3（3.1e-6） | 11.4（4.8e-3） | 9.1（5.2e-6） |
| Anderson m = 2 | 7.6（2.4e-5） | 8.8（3.7e-6） | 10.5（4.4e-3） | 8.5（5.4e-6） |
| Anderson m = 3 | 7.6（2.5e-5） | 8.7（3.5e-6） | 9.8（3.5e-3） | 8.3（5.1e-6） |
| 外挿 + Anderson m = 2 | 8.2（2.4e-4） | 8.2（1.0e-6） | 10.6（2.8e-3） | 7.2（4.2e-6） |

（反復回数/ステップ。括弧内は誤差）

### Anderson 加速
- 実装は圧力の反復列に対する type II（減衰なし）。最後の反復は通常の射影なので、面速度の発散は 0 のまま。
- 反復回数は 35〜50 % 減る。N = 64 の sharp でも上限に達しなくなる。
- 線形・アフィンな反復では、Anderson は GMRES と同値である（Walker & Ni）。そのため GMRES は別に試していない。
- GPU で増えるのは、1 反復あたり最大 m 本の内積と、小さな最小二乗だけ（未測定）。

### 圧力の外挿
- sharp 形（ジャンプを含む圧力）を外挿すると、反復回数も誤差も悪化した（誤差は 10〜20 倍）。動くジャンプを外挿するためで、指摘どおりである。
- smooth 形（`TwoPhaseCLS(jump_mode="smooth")`、ns.p = p̃ = p − H j_ext）では、外挿は滑らかな成分だけにかかる。ジャンプは新しい界面から加速度 a として作り直される。これは指摘された p_init = 2p̃ⁿ − p̃ⁿ⁻¹ + H^{n+1} j^{n+1} そのものである。
  - 反復回数は 0〜20 % 減り、誤差は 1/3 以下になる。Anderson と組み合わせると、素の反復の 0.57〜0.63 倍の回数で済む。
- 2 点の面勾配（FD2）では、smooth と sharp で速度の解は同じになる。圧力の表し方が H j_ext だけ違い、射影と g の両方で打ち消し合うため。基準解の D も 7 桁一致した。
  - 違うのは外側反復の初期値だけである。smooth では、外挿なしでも前ステップのジャンプが外れ、新しいジャンプが入る。
  - N = 64 の素の反復で smooth が sharp より速いのは、このためと見られる。1 節の N = 64 で 1 回目の変化量が大きかったのも、同じ理由と見られる。

## 6. 一定の物理時間あたりのコスト（`cases/coupled_cost.py`）
振動する液滴、N = 32、密度比 100、t = 0.3 まで（CPU、1 スレッド）。
誤差は、変形量 D(t) = ∫ψ(x² − y²) の、0.25 倍・収束反復の基準解との相対差。

| 方式 | 刻み | ステップ数 | 反復の合計 | 時間 | D の誤差 |
| --- | --- | --- | --- | --- | --- |
| K = 0（Basilisk の分割） | 0.95 倍 | 153 | 153 | 9.3 s | 1.6e-2 |
| K = 2 | 1.6 倍 | 95 | 190 | 12.8 s | 8.0e-2 |
| 絶対 1e-10 | 1.7 倍 | 90 | 2700（毎回 30 回） | 118 s | 3.0e-2 |
| rtol 1e-2 | 1.7 倍 | 90 | 589 | 30.8 s | 3.6e-2 |
| rtol 1e-2 + Anderson 2 | 1.7 倍 | 90 | 472 | 25.0 s | 2.6e-2 |
| smooth、rtol 1e-2 | 1.7 倍 | 90 | 575 | 29.4 s | 3.0e-2 |
| smooth、rtol 1e-2 + 外挿 + Anderson 2 | 1.7 倍 | 90 | 438 | 22.3 s | 3.0e-2 |

- この条件（N = 32、刻みの大きさで誤差が決まる領域）では、連成反復で刻みを 1.8 倍にしても、計算時間は 2.4 倍以上かかる。誤差も K = 0 の 2 倍になる。
- 1 ステップあたり 4.9〜6.5 回の粘性求解と射影が必要で、刻みの増分（1.8 倍）を上回る。
- K = 2 は 1.6 倍でも D の誤差が 8.0e-2 で、精度の面で使えない。
- 連成反復が時間短縮につながるのは、精度より安定性で刻みが決まる場合に限られる。この条件では、反復を 2 回程度まで減らす必要がある。この試験だけでは、そのような場合を確認できていない。

## まとめ
| 課題 | 結果 |
| --- | --- |
| 収束判定 | 変化量は誤差を抑える（誤差 ≈ 0.5 × 変化量）。運動量残差は気相の粘性で 4〜28 倍に増幅される。どちらで判定するかは選べるようにし、相対判定 `coupled_rtol` を加えた |
| 上限回数での打ち切り | `coupled_on_failure` と `coupled_failures` で扱いを決め、数えるようにした（既定は警告） |
| 遅れた圧力の残留 | 主因は近似射影の項（不安定モードで 96 %）。交換子は従 |
| Jacobian | 基準状態の残差（3e-7〜8e-5）に対して固有値は 0.2 % 以内で変わらない。反復回数が変わる場合は、許容値を摂動より細かくする必要がある |
| 格子依存 | 収束させれば境目はほぼ一定（1.7〜1.9 / 2.1〜2.3）。K = 1 は高密度比で N とともに下がる |
| 密度比 1000 | 収束させれば密度比 100 と同等 |
| 加速 | Anderson で反復回数 −35〜50 %。smooth 形と外挿の組み合わせで −40 % |
| コスト | N = 32 の振動液滴では、K = 0 の方が速く、精度も高い |

既定（K = 0）は変えない。

## 残り
- K = 1 の境目が N とともに下がる理由。
- 境目の係数 C_h の理論式。
- 反復を 2〜3 回で済ませる方法。近似射影の項を減らす面ベースの補正が候補。
- 精度より安定性で刻みが決まる条件での、コストの比較。
- GPU での時間、内積と同期の回数。
- layered 形の粘性のエネルギー増大（33）。
