# 71 運動量保存形の VOF（`conserving.h`）と、壁の圧力の境界条件（PR #81）

## 1. 実装：`TwoPhase(conserving=True)`
Basilisk の `navier-stokes/conserving.h` の移植。一様な格子では次の 4 点だけ：

- 中心ソルバーの移流を止める（`stokes = true`）。予測と半ステップの射影も飛ぶので、VOF は前のステップの終わりに射影した面の速度で運ばれる。
- 刻みは `stability` で `timestep(uf, dtmax)`（CFL）を取り直す（`stokes` のとき中心ソルバーは CFL を見ないため）。
- 相ごとの運動量 `q1 = f ρ1 u`、`q2 = (1 − f) ρ2 u`（`q2` は `1 − f` に付く）を、f の VOF の濃度として同じ流束で運ぶ。勾配は u と同じ（既定は中心差分）。
- 運んだ後、`u = (q1 + q2)/ρ(f)`。

`q` のゴーストは、Basilisk の `boundary_q1_x` などと同じく、ゴーストの f と u から `f ρ u` で作る（`two_phase._MomentumField`）。適合格子のための細分・集約の関数は、一様な格子では不要なので移植していない。

## 2. 移植の漏れ：`centered.h` の壁の圧力
照合の途中で、`centered.h` の壁の圧力の境界条件が移植されていないことが分かった：

```
p[top] = neumann (a.n fm.n / alpha.n)   （ほかの壁も同様）
```

これは、壁の面の正味の加速度 `a − α ∇p` をちょうど 0 にする。こちらは圧力を `Neumann(0)` のままにしていたので、壁に垂直な加速度（重力 `a[]`）があると、壁の面に `a` が残り、それがセル中心の補正 `g` を通じて壁の際のセルの速度に入っていた。これまでの照合（`gravity.c`、`capwave.c`、静止液滴）は、縮約重力や表面張力で壁に垂直な `a` がなかったので表に出なかった。

修正：`CenteredNS.centered_gradient` で、圧力が Neumann の壁の面の正味の加速度を 0 にする（圧力の境界条件そのものは `Neumann(0)` のまま。射影の Poisson は壁の面の速度が 0 で決まるので変わらない）。IMEX の経路も同じ関数を使うので、同じく直る。

- 重力のかかった静止流体（16²、壁、20 ステップ）：修正前は壁の際で速度が増え、修正後は 1e-10 以下（`tests/test_conserving.py`）。

## 3. Basilisk の C 版との照合（`cases/conserving_compare.py`）
`src/test/rt.c`（Rayleigh–Taylor、`conserving.h`、ρ1 = 1.225 / ρ2 = 0.1694、μ = 0.00313、重力 `a[] = {0, −9.81}`）を、一様な 64² で適合なし（`tools/basilisk/rt_conserving.c`、`qcc`）にして、t = 0.1 と 0.4 の場を比べた。こちらは Basilisk の CPU 版と同じ辞書式の緩和。

| t | f の最大のずれ | u.x | u.y | p（平均を除く） | 最大速度 |
| --- | --- | --- | --- | --- | --- |
| 0.1（31 ステップ） | 5.7e-6 | 1.4e-5 | 2.6e-5 | 2.0e-5 | 0.226 |
| 0.4（92 ステップ） | 7.3e-4 | 6.2e-4 | 1.5e-3 | 1.8e-3 | 1.354 |
| （参考）0.4、`conserving.h` なし | 3.2e-2 | 9.4e-2 | 1.4e-1 | 7.9e-2 | |

- ステップ数（92）と刻みの列は、C 版と一致する。
- t = 0.1 で 1e-5 の一致。t = 0.4 のずれは、不安定が成長する流れでソルバーの許容誤差（1e-6）の差が増幅されたもの。`conserving.h` を使わない計算は 0.4 で 3e-2〜0.14 ずれ、照合が保存形の再現を区別できていることを示す。
- テスト：`test_rayleigh_taylor_against_basilisk`（t = 0.1 の最大 u.y 0.2258136、運動エネルギー 0.0101207、f の総和）。
