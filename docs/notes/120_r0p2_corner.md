# 120 A-2（R0-P2）：静水圧の角の近くの不成立（ノート115 の 9 条件）の原因は、高さ関数のゴーストセル。滑り壁の対称の条件が f を鏡像にする（接触角 90° を暗に仮定する）ので、斜めの平面が壁に達する点の近くで高さがずれ、界面のポテンシャル φ が 0 でなくなる。角の近くだけで起きるのは、そこでは使う高さの列が壁を横切るため。平面をそのままゴーストセルに延ばすと、t = 20 まで丸めで釣り合う

## 結論の要約
- **原因（確認した）**：reduced.h の力は φ = (ρ₂ − ρ₁)G·(x_I − Z) の界面での跳びで、x_I は高さ関数から取る界面の位置。重力の向きに垂直で Z を通る平面では、**φ は厳密に 0** で、静止の状態に力は掛からない。不成立の配置では、壁の角のセルとその隣（2〜4 セル）で高さが平面からずれ、φ が 2.4e-4〜6.3e-4（(ρ₂ − ρ₁)G で割った値）になる。
- **予測と照合**（予測は測定の前に書いた）：ノート115 の 24 の配置の全てで、「t = 0 に φ ≠ 0 のセルがある」と「静水圧が不成立」が一致した（3 配置は両方、21 配置はどちらでもない。φ は 5e-16 以下）。
- **ずれの出どころ（確認した）**：高さ関数の列が使う壁の外のゴーストセル。滑り壁の対称の条件（Neumann(0)）は f を鏡像にするので、壁と 90° で交わる界面を仮定している。この試験の平面は、壁と 90° − θ で交わる。平面そのものをゴーストセルに延ばすと φ は丸め（4e-16 以下）に戻る。**角のブロックだけを直しても変わらない**（角のゴーストセルそのものではない）。
- **角の近くだけで起きる理由（仮定つきの説明。数値と矛盾しない）**：高さの列は法線の大きい成分の向きに取る。界面が壁に達する点の近くで、その列が壁を横切ると、鏡像の部分的なセルが列の和に入る。箱の中の平面では、主たる列の向きは、界面が接する壁とふつう平行（壁を横切らない）で、横切るのは接点が直交する壁から 1 セル以内のとき、すなわち角の近くだけである。φ ≠ 0 のセルは全て、使う列が壁を横切るセルだった（45° の (0, 31) は x の列で左の壁、(31, 0) は y の列で下の壁、26.565° の (0, 30)・(0, 31) は y の列で上の壁）。
- **完全なソルバーで確認**：高さ関数のゴーストセルだけを平面に置き換える（フック）と、3 配置とも t = 1 で速度 2e-10 以下（許容誤差の水準）。**長時間**：45°・δ = 0.0137・N = 32 は、元の方式で t = 20 に 1.3e-2 まで育つ（ノート115 と同じ）が、置き換えると 5.8e-14。
- **セルの速度と面の流束の差**（B の (iii)、静水圧で分かる範囲）：不成立の配置ではセルと面の速度は同じ大きさ（比 0.8〜1.1）で一緒に育ち、置き換えると両方が許容誤差の水準。静水圧の配置では、差の累積は寄生流そのものと区別できない。最終の判定は A-4（粘性のある斜めの二層せん断流）で行う。
- **含意**：これはソルバーの不具合ではなく、**壁の上の f の境界条件（接触角 90°）と試験の幾何（接触角 90° − θ）の不整合**である。斜めの層を壁のある箱で静止させる試験は、接触角の境界条件（ゴーストセルの f を指定の角度で延ばす、Basilisk の `contact.h` に当たる）が無い限り、角の近くでは成り立たない。

## 定式化と理論的根拠
### A. reduced.h の形で平面の静止が厳密になる条件（構成から）
重力を `−∇(ρG·x)` と書き換え、圧力に `ρG·x` を含めると、運動量の式に残るのは界面の力 `φδ_s n`、`φ = (ρ₂ − ρ₁)G·(x_I − Z)`。平面が G に垂直で Z を通れば `G·(x_I − Z) = 0` なので φ ≡ 0 で、u ≡ 0 が離散の解である。ただし離散の x_I は高さ関数（または PLIC の重心）から取るので、x_I が平面の上にあるときに限る。

### B. 高さ関数とゴーストセル
高さ `h = Σ c − (セルの数の半分)` を、法線の大きい成分の向きの列（7 セル、`heights()` は上下に 2 セルずつ 2 回）で取る。壁の外のセルはゴーストセルで、滑り壁では `c_ghost(−k) = c(k − 1)`（鏡像）。界面が壁に角度 β で交わると、鏡像の界面は 180° − 2β で折れる。β = 90° のときだけ平面のまま続く。列が壁を横切り、横切った先に部分的なセル（折れた界面）があると、列の和は平面の高さにならない。

### C. 予測（測定の前に固定）
1. φ ≠ 0 のセルは、不成立の配置にだけ、角の近くにある。
2. ゴーストセルを平面の延長にすれば φ = 0（丸め）になり、完全なソルバーでも釣り合う。
3. 角のブロック（2 × 2 のゴーストセル 4 つ）だけを平面にしても直らない（列は角を通らず、辺のゴーストセルを使うので）。

3 つとも当たった（3 は「角のゴーストセルが原因」という別の仮説を否定するために足した）。

## 自己点検（試験が成立しやすい条件に寄っていないか）
- 照合は、ノート115 の 24 の配置の全てで行った（後から選んでいない）。
- 平面の延長は「正解のゴーストセル」を外から与えたもので、静止の試験でしか使えない。ソルバーの修正ではない。
- 「角の近くだけ」の説明は、平面の箱の中での列の向きの議論で、曲がった界面や、壁に急な角度で接する界面（液滴が壁に付く場合など）では、角から離れていても同じことが起きうる（未検証）。

## 検証済みと未検証
- 確認した：原因（3 つの予測が全て当たった）、完全なソルバーでの釣り合いの回復、長時間。
- 仮定つき：角の近くだけで起きる理由（列の向きの議論。φ ≠ 0 のセルが全て壁を横切る列を使うことは確認）。
- 未検証：接触角の境界条件を入れた場合（ライブラリに無い）、曲がった界面・動く界面での同じ誤差、壁のある R0 の試験（Couette・Poiseuille）への影響（界面は壁に 90° で接するので、この誤差は出ないはず）。

## B に求める判断
1. 扱い：これは解法の不具合ではなく、試験の幾何と壁の f の境界条件の不整合なので、**直さずに「壁と 90° でない角度で接する界面は、接触角の境界条件が無い限り、壁の近くで高さがずれる」と R0 の条件の注記に記録する**ことを提案する。R0 の必須の試験（斜めの二層せん断流は周期、Couette・Poiseuille は界面が壁に 90°）には影響しない見込み。
2. 静水圧の要件は「接触角が 90° の配置、または壁から離れた界面で釣り合う」と読む（63 / 72 → 原因の除かれた配置では 72 / 72）。
