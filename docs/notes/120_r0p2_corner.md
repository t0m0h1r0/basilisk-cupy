## 結論の要約
- reduced.h の力は φ = (ρ₂ − ρ₁)G·(x_I − Z) の界面での跳びで、x_I は高さ関数から取る界面の位置。重力の向きに垂直で Z を通る平面では、**連続の問題でも離散でも φ ≡ 0 が厳密な静止解**（壁との角度によらない。表面張力が無いので接触角は意味を持たない：監修の指摘 3）。崩れるのは、離散の x_I が平面からずれるときで、その原因が少なくとも 2 つある。
- **(A) 滑り壁の鏡像のゴーストセル**（確認した）：対称の条件は f を壁で鏡像にする。壁と斜めに交わる平面の鏡像は折れるので、高さの列が壁を横切り、その先に部分的なセル（折れた界面）があると、高さが平面からずれる。平面そのものをゴーストセルに延ばすと φ は丸めに戻る（不成立の 3 配置で 4e-16 以下、完全なソルバーで t = 20 まで 6e-14）。**角の近くに限らない**（訂正）：主たる法線の向きの列は、θ < 45° の平面が上下の壁に接するとき壁を横切る。監修の走査では、φ ≠ 0 の 364 配置のうち 245 配置で接点が角から 2 セルより遠い（最大 28 セル）。ノート115 の 24 配置で角の近くだけに見えたのは、その配置の取り方による。
- **(B) 丸めの薄片**（監修が壁の近くで見つけた機構。**訂正 2（#193）：下の「壁の無い周期の帯で…飛んだ」は見かけ**で、時間刻みの上限 `DT` を与えなかったため、雑音の速度 1e-16 に対する CFL の刻みが 4e13 まで伸び、雑音の速度の CFL 数が 1/2 を超えていた。`DT = 0.5/N` を与えると 1000 ステップでも薄片は出ず、位置のずれは 1.5e-13 以下（4 節）。壁の近くの薄片〔監修の `sliver_probe.py`、DT あり〕の結論は変わらない）：丸めの速度（1e-16）が、f = 1e-22〜1e-30 や 1 − 1e-17 の薄片を作る。高さ関数は f の 0・1 を**厳密に**判定する（`S > 0 && S < 1`。Basilisk の `heights.h` も同じ）ので、薄片を含む列の和が変わり、**本物の界面のセルの位置が飛ぶ**。壁の無い周期の斜めの帯（力なし、1e-16 の雑音）で、2〜3 ステップ目に薄片が現れ、本物の界面のセル（1e-6 < f < 1 − 1e-6）の位置が**界面の間の中央（半周期、3.6〜8.9 セル）まで飛んだ**（12 配置の全て）。雑音 0 では薄片も位置のずれも出ない。重力（reduced）や表面張力（高さ関数の曲率）では、この飛びが力になる（監修：壁に近い配置で φ が 0 → 2.6e-3 に跳び、寄生流が育つ）。
- **ノート115 の 24 配置の照合**（初版）：その範囲では「t = 0 に φ ≠ 0 ⇔ 不成立」が一致したが、(B) があるので**一般には成り立たない**（監修の反例：θ = 37.5°・δ = 0、θ = 40°・δ = 0.0137 は φ(t = 0) = 0 で崩れ、平面のゴーストセルでも崩れる）。
- **含意**：試験の配置の誤りではなく、**壁に斜めに接する界面、および丸めの薄片に対する、reduced（と高さ関数の曲率）の離散化の制約**である。直すか、基準ソルバーの既知の制約として記録するかは B の判断。~~(B) は壁と無関係なので、影響の範囲は静水圧の試験より広い可能性がある~~（訂正 2：壁から離れた周期の帯の根拠は見かけだった。壁から離れた場所で (B) が起きるかは、時間刻みの上限のある計算では確かめられていない）。

## 定式化と理論的根拠
### A. reduced.h の形で平面の静止が厳密になる条件（構成から）
重力を `−∇(ρG·x)` と書き換えると、運動量の式に残るのは界面の力 `φδ_s n`。平面が G に垂直で Z を通れば `G·(x_I − Z) = 0` なので φ ≡ 0、u ≡ 0 が離散の解である（x_I が平面の上にある限り）。壁との角度は条件に入らない。

### B. 機構 (A)：鏡像のゴーストセル
高さ `h = Σc − (半分)` を、法線の大きい成分の向きの列（7 セル）で取る。滑り壁では `c_ghost(−k) = c(k − 1)`。壁と角度 β で交わる平面の鏡像は 180° − 2β で折れ、β = 90° のときだけ平面のまま続く。列が壁を横切り、その先に部分的なセルがあると、列の和は平面の高さにならない。列の向きは法線の大きい成分の向きなので、例えば θ < 45°（法線が y に近い）の平面が上下の壁に接すると、y の列が壁を横切る。

### C. 機構 (B)：薄片と厳密な判定
`_half_column` は、列を延ばすかどうかを `S > 0 && S < 1`、終わりを `c ≤ 0`・`c ≥ 1` で判定する。f = 1 − 1e-17 のセルは「部分的」と判定され、列はそこで止まらずに延び、本来は完結していた列の和と高さが変わる（または別の界面に達する）。丸めの速度で VOF が 1e-17 の f を動かすだけで起きるので、静止の問題でも 1 ステップ目から起こりうる。許容誤差を入れた判定（例：`S > ε && S < 1 − ε`）や薄片の除去は、ライブラリの変更（B の判断）。

### D. 予測と照合（初版の測定）
初版の予測：(1) φ ≠ 0 のセルは不成立の配置だけ、(2) 平面のゴーストセルで φ = 0 と釣り合いの回復、(3) 角のブロックだけでは直らない。ノート115 の 24 配置では 3 つとも当たったが、(1) は配置の取り方に依存していた（監修の走査）。
