## 2. 実用上の推奨構成（本移植）
| 層 | 推奨 | 理由 |
| --- | --- | --- |
| 時間積分 | SBDF2（`IMEXMultistepNS` の既定） | 安定限界が高く（静止液滴で tension.h の 1.41 倍）、費用が小さい |
| ψ を運ぶ速度 | `transport="ab2"` | 論文の u_f^n の 1 次の誤差を除く（毛管波で −18.8% → −12.0%）。水–空気では、u_f^n だと増幅する |
| CN 系を使う場合 | `force_weights="scheme"` | ジャンプの時刻を合わせないと 1 次になる |
| 再初期化 | ξ-SDF を 10 ステップごと（`reinit_every=10`） | 移動界面の不安定を止める（50 ステップごとでも安定）。圧縮・拡散は減衰しすぎる |
| 曲率 | 閉じた界面では高さ関数（`curvature_kw={"method": "heights", "heights_method": "fd2"}`） | ψ の CCD 曲率は再初期化の凹凸を増幅し、振動液滴の振幅が増える |
| 面の演算子 | fd2（GFM） | 密度比によらず 2 次で安定。FCCD は等密度に限る（相ごとの CCD は試作段階） |
| 刻み | tension.h の上限 × √(5/12) | 静止液滴は 1.2〜1.4 倍まで安定。ARS(2,2,2) は密度比 1000 で 0.60 倍が限界なので避ける |
| 解法の許容値（次元つきの問題） | `volume_tolerance=True`、1e-8 | 絶対値の 1e-3 は、m・s の単位では緩すぎる（毛管波の振幅比が 0.956 対 0.899） |
| 精度が要るとき | 格子を細かくする | 1 波長 16 点では周波数が −9%。32 点で −4%（ノート49 の結論と同じ） |

## 3. 本移植で見つけた方式ごとの性質（論文と独立）
- Basilisk 型の VOF は、水–空気の毛管波・振動液滴・上昇気泡・RT のすべてで、再初期化なしで安定。周波数の誤差は CLS の 1/2〜1/3。減衰は N = 32 で物理の 2.5 倍、N = 64 で 1.3 倍。
- CLS の欠点は二つ：輸送が格子規模の毛管波を散逸させないこと（再初期化が必要）と、再初期化が曲率に雑音を入れること（高さ関数の曲率で回避できる）。
- 1 波長 16 点では、CLS + GFM の周波数の誤差が VOF の約 2.3 倍（−9.3% 対 −4.0%）。

## 4. 残る課題
- 相ごとの CCD の射影（`PhaseCCDFaces`）をライブラリに入れる（壁の線、GPU、毎ステップの射影、帯の外で 0 になる曲率のジャンプの補間）。
- IMEX-RK と CN 系の段の中でのジャンプの時刻（1 次の刻み依存が残る）。
- 振動液滴の減衰（高さ関数の曲率で物理の 3〜4 倍）と、周波数の誤差（−3.4%）。
- 上昇気泡の論文との差（17%）：論文の界面適合格子（α = 2）を再現して比べる。
- 論文の実装（TwoPhaseFlow）そのものを同じ条件で動かして比べる（未実施）。
