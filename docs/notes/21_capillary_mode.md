# 21 CLS で安定の境目が N とともに下がる原因（PR #36）

## 問い
20 で、CLS＋GFM の静止液滴の安定の境目（tension.h の上限の何倍か）が N とともに下がることが分かった。VOF では下がらない。その原因を探る。

## 増大するモード（N = 64、密度比 100、μ = 0.1、係数 1.0）
- 速度は、界面をはさむ2セル幅の帯に集中する。
  - 帯の外（ψ < 0.01、ψ > 0.99）の速度は帯の中の 1/500 以下。
- 界面に沿って1セルごとに符号が反転する（波長 2Δ の毛管波）。
- 界面全体ではなく、界面の階段状の折れ目の1か所に局在する（r = 0.26）。
- ψ の変化は 1e-5 程度。

## 候補の切り分け（N = 128、密度比 100、μ = 0.1、係数 0.95 と 1.05。何も変えなければ 0.95 で不安定）
| 変えた点 | 0.95 倍 | 1.05 倍 |
| --- | --- | --- |
| なし | 不安定 | 不安定 |
| 補正した発散＋6次の面値（18） | 不安定（増大が速い） | 不安定 |
| ε = 2Δ | 不安定（増大が速い） | 不安定 |
| 曲率の帯 ψ_min = 1e-4 | 不安定 | 不安定 |
| 質量補正なし | 不安定 | 不安定 |
| clipping なし | 不安定 | 不安定 |
| 界面の移流を止める | 安定 | 安定 |
| 圧縮・拡散（4 擬似ステップ）を 10 ステップごと | 不安定 | 不安定 |
| 圧縮・拡散（4 擬似ステップ）を毎ステップ | 安定 | 安定 |

- 移流を正確にすると（散逸が減ると）かえって不安定になる。

## 毎ステップの圧縮・拡散での境目（密度比 100、μ = 0.1）
| N | 32 | 64 | 128 | 256 |
| --- | --- | --- | --- | --- |
| 再初期化なし（20） | 1.05〜1.1 | 0.95〜1.0 | 0.91〜0.95 | 0.85〜0.88 |
| 毎ステップ、4 擬似ステップ | ≥ 1.6 | ≥ 1.6 | ≥ 1.6 | ≥ 1.4 |
| 毎ステップ、1 擬似ステップ | — | 1.2〜1.6 | 1.0〜1.2 | — |
| VOF（20） | — | 1.2〜1.4 | — | 1.2〜1.4 |

- 毎ステップの圧縮・拡散で、境目は N とともに下がらなくなり、VOF と同等以上になる。
- 代償：
  - 静止液滴の寄生流が減衰しなくなる。800 ステップ後で 1.2e-3 / 6.8e-5 / 1.6e-5 / 2.0e-5（N = 32 / 64 / 128 / 256）。再初期化なし（安定な係数）では減衰し続ける（N = 64、係数 0.9 で 1.0e-7）。
  - 反転渦で細い糸を削る（17：0.171 / 0.137 / 0.0687）。

## 解釈
- 増大するのは界面の格子規模の毛管波。
- CLS の移流（FCCD の中心型）は、格子規模の界面の乱れを減衰させない。そのため、このモードを抑えるのは粘性だけになる。
- VOF の幾何的な移流や、圧縮・拡散の拡散項は、格子規模の乱れを減衰させる。その分だけ境目が上がり、N に依存しなくなる。
- N 依存の候補：切断面の実効密度 θρ_L + (1−θ)ρ_R の最小値は N とともに下がる（0.110 / 0.066 / 0.034 / 0.040、N = 32 / 64 / 128 / 256、密度比 100）。軽い側に寄った切断面では、ジャンプ j が小さな慣性にかかる。ただし、増大モードの位置（N = 64）は最小の面とは一致しなかった。**確定はしていない。**
- 粘性が大きいほど境目が下がる理由も未解明。

## 結論
- 境目が N とともに下がるのは、CLS の移流が格子規模で散逸を持たないことによる。
- 毎ステップの圧縮・拡散（4 擬似ステップ）で解消するが、寄生流の減衰と細い糸の保持を犠牲にする。
- 時間刻みの係数は √(5/12) のまま（測定した範囲で安定側。20）。毎ステップの圧縮・拡散を使うなら、1 に戻してよい（N = 256 まで 1.4 倍で安定）。
