## 定式化と理論的根拠
### A. 最小粘性エネルギー再構築（ユーザー）
質量加重平均 q を厳密に満たす連続な速度のうち、粘性散逸が最小のもの：

```
R_ν q = argmin { ½ ∫μ|v'|² dx : A_ρ v = q }
```

Euler–Lagrange の式 `−(μv')' = λ_iρ`（セル K_i）から、応力 τ = μv' はセルの質量座標 s_i について線形になる：`τ_h = (1 − s_i)τ_{i−1} + s_iτ_i`。

これはノート99 の応力の再構築そのもので、`Hτ = Dq`（H = ∫ψψ/μ）。速度はセルごとに次のとおり：

```
v(x) = q_i + w(x) − ⟨w⟩_{ρ,i},   w(x) = ∫_{x_i}^x τ_h/μ
G_ν = R_ν*R_ν（ρ の重み）,   K_ν = DᵀH⁻¹D,   G_ν q̇ = −K_ν q（Ritz–Galerkin）
```

- **構成上の性質**：`G_ν ⪰ M`（平均を保つ、ノート96 C 節）、`G_ν1 = m`、`K_ν1 = 0`、`d/dt(½qᵀG_νq) = −qᵀK_νq ≤ 0`。
- **再構築の粘性エネルギーは qᵀK_νq**：`∫τ_h²/μ = τᵀHτ = qᵀDᵀH⁻¹Dq`。
- **非定常で 4 次になる理由（ユーザーの見積もり）**：Stokes の固有モードでは `dτ/ds_i = −λm_iu`。u は界面で連続なので、応力は質量座標で 1 階まで連続になり、物理座標での勾配の跳びが消える。`Hτ_h = Dq` は、厳密な応力の 1/μ で重みを付けた直交射影なので `‖τ − τ_h‖ = O(h²)`。Ritz の固有値の誤差はエネルギーの誤差の二乗なので `O(h⁴)`。
  - 物性比を固定したときの近似の理論で、定数が物性比によらないことは示していない。

### B. コンパクトな形
`w_f` を、面 f の単位の応力に対するセル内の平均を引いた速度とする。`Q_fg = ∫ρw_fw_g`（三重対角）とすると、

```
G_ν = M + DᵀH⁻¹QH⁻¹D
```

補助の未知数を残せば `Hτ = Dq`、`Hη = Dq̇`、`Hξ = Qη`、`Mq̇ = −Dᵀ(τ + ξ)` となり、密行列は不要（ユーザー）。

### C. V4：移流と粘性の内積
移流の PCCD（部分セルの相分離、ノート97）の Gram を `G_A = R_A*R_A` とする。比べる方式：

| 方式 | 半離散の式 | 構成上のエネルギー |
| --- | --- | --- |
| A | `M q̇ = −K₄q` | M |
| B | `G_A q̇ = −K₄q` | G_A |
| C | `G_ν q̇ = −K_νq` | G_ν |
| D | `G_A q̇ = −K_νq` | G_A |
| E | `G_A q̇ = −PᵀK_νPq`、`P = G_ν⁻¹R_ν*R_A` | G_A、`PᵀG_νP ⪯ G_A` |

- D と E は G_A のエネルギーが減る。
- 総運動量：`1ᵀG_Aq = mᵀq`（G_A1 = m）、`1ᵀK_ν = 0`。

## まとめ
- **粘性の第一候補**：最小粘性エネルギー再構築（C、`G_ν q̇ = −K_νq`）。密度と粘度が跳ぶ二相の非定常 Stokes で 4 次。保存・散逸は構成上成り立つ。
- **移流との統合の第一候補**：D（`G_A q̇ = −K_νq`）。共通の G_A のエネルギーで安定で、減衰率は 4 次、時間発展は 3.2〜4.1 次。
- **課題**：
  - G_ν の Gram は、粘度一定の高密度比で最大 9.6 万（上界なし）。D では G_A を使うので、この悪条件は直接は効かない（G_A は ≤ 20.5、ノート97）。
  - D の剛性は、粘度一定・水空気では ≤ 10.4 だが、動粘度一定（粘度比も 1e6）の薄片では 479 まで増える（5 節）。
- H₃ の対称化と DG 型の追加研究は保留（ユーザーの判断）。
