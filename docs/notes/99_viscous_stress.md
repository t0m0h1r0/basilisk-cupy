## 定式化と理論的根拠
### A. 質量加重平均と応力の厳密な関係（ユーザー）
セル `K_i = [x_i, x_{i+1}]`、質量加重平均 ū_i、質量 m_i、面 f = x_{f+1}（セル f の右）とする。質量の累積で、K_f で 0 → 1、K_{f+1} で 1 → 0 と変わる関数を ψ_f とする：

```
ψ_f = (1/m_f)∫_{x_f}^x ρ   (K_f),      (1/m_{f+1})∫_x^{x_{f+2}} ρ   (K_{f+1})
```

部分積分で、厳密に次が成り立つ（密度と粘度の跳びは、両方とも ψ と 1/μ に入る）：

```
ū_{f+1} − ū_f = ∫ψ_f u' dx = ∫ψ_f τ/μ dx
```

### B. 方式（V1）
各セルで Σ_g ψ_g = 1 なので、面の応力 τ_g から `τ_h = Σψ_gτ_g` と再構築すると、`Dū = Hτ`、`H_fg = ∫ψ_fψ_g/μ`（対称正定値、周期の三重対角）。

```
H_L = diag(H1),   H₄ = (H + H_L)/2,   K = DᵀH₄⁻¹D,   M dū/dt = −Kū
```

- 一定の ρ、μ、一様な格子では `H₄ = (h/μ)·tridiag(1/12, 5/6, 1/12)`。これは 4 次のコンパクトな関係 `(τ_{f−1} + 10τ_f + τ_{f+1})/12 = μ(ū_{f+1} − ū_f)/h`。記号は `−ν k²(1 − (kh)⁴/240 + …)`。
- **構成上の性質**：
  - エネルギー：`d/dt (½ūᵀMū) = −τᵀH₄τ ≤ 0`。
  - 総運動量：`1ᵀDᵀ = 0`。
  - 一様な速度は不変。
  - 一定の応力を厳密に再現：H₄1 = H1 なので、`H₄(τ₀1) = Dū`。
  - 面の応力の三重対角の連立で、Red-Black は不要。
- **剛性の一様な上界**（ユーザーの導出）：`d_f = (H1)_f ≥ (ℓ_H² + ℓ_L²)/(2m_iν_max) ≥ h²/(4m_iν_max)`、`H₄ ⪰ H_L/2` から、`λ_max(M^{−1/2}KM^{−1/2}) ≤ 32ν_max/h²`。密度比と切断セルの体積分率によらない。
  - ノート97 の定理（移流の再構築の連続性との両立は不可能）とは矛盾しない。この演算子は、連続な速度の再構築を微分したものではないからである。

### C. V3 の試作：行ごとに 2 次まで厳密な H₃
一様な格子の H₄ の行 (1/12, 5/6, 1/12) は、「三重対角の行が、2 次の多項式の応力に対して厳密」という条件から一意に出る（3 次は対称性で厳密になり、4 次の精度になる）。

そこで、各行 f の 3 個の係数を、応力 `τ ∈ {1, x, x²}`（面のまわり）に対して `Σ_g (H₃)_fg τ(x_g) = ∫ψ_f τ/μ` が厳密になるように決める（`H₃`）。

- 一様な格子では H₄ に一致する（測定で一致）。
- 密度や粘度が跳ぶ所では非対称になる。エネルギーの散逸には、対称部分が正定値であればよい（`wᵀH₃⁻¹w = yᵀH₃y`、y = H₃⁻¹w）。ただし、それは構成上は保証されない（下の測定で破れる場合がある）。
- 一定の応力の厳密さ（行和）、総運動量は保つ。
- **限界（見積もり）**：応力が界面で滑らかなとき（定常・強制のある定常、Couette・Poiseuille の型）だけ厳密さが効く。非定常では `τ' = ρu_t − f` なので、密度が跳ぶと応力そのものが界面で折れる。滑らかな多項式への厳密さでは表せない。

### D. 移流とのエネルギー内積の不一致（V4、未測定）
PCCD–Galerkin の移流は `E_G = ½uᵀGu` で、この粘性は `E_M = ½uᵀMu` でエネルギーが減る。組み合わせたときの共通の安定性は保証されない（ユーザー）。比べる方式は次の 3 つ：

- `M u̇ = −Ku`（有限体積として自然）
- `G u̇ = −Ku`（G のエネルギーで安定。精度が落ちる可能性）
- `G u̇ = −K_G u`（G 内積に整合した高次の粘性、本命の候補）

圧力の射影にも共通する問題なので、粘性の段階で見通しを立てる。

### E. 厳密解（V0）
- **周期の定常の二層流**：`τ = sin 2πx + τ_c`（連続で滑らか）、`u = ∫τ/μ`（連続で勾配が跳ぶ）。τ_c は u が周期になるように選ぶ。強制 `F_i = −(τ(x_{i+1}) − τ(x_i))`。
- **二層 Stokes の固有モード**：ρ、μ が層ごとに一定なら、`[u; τ]` の伝達行列 `[[cos kL, sin kL/(μk)], [−μk sin kL, cos kL]]`（`k = √(λρ/μ)`）の積の跡が 2 になる λ が、周期の減衰率である。離散の一般化固有値（K, M）の最も近いものと比べる。
- 壁のある Couette・Poiseuille（非周期）は次の段階。一定の応力の厳密な再現は、周期の内部の面で直接確かめた。
