# 57 水–空気の毛管波で CLS が不安定になる：原因は密度比ではなく、格子規模の毛管波（フェーズ3 の前提）

## 経緯
論文の 4 ベンチマーク（14 章の条件、`cases/paper_benchmarks.py`）を `TwoPhaseIMEX` の既定で流すと、界面が動く三つがいずれも不安定になった（GPU）。

| ケース | 結果 |
| --- | --- |
| 毛管波（水–空気、32²、5 周期） | 約 3.5 周期で発散（最大速度が 0.03 → 270 m/s、刻みが 1e-6 まで縮む） |
| 振動液滴（2 周期） | 2 周期後の変形量が 0.109 で、初期の 0.1 を上回る。最大速度 0.23 m/s（振動から見積もる約 0.03 m/s の 8 倍） |
| 上昇気泡 | t = 0.035 s で発散（論文は「t ≃ 0.04 s 以降に形状が破綻」） |
| RT | t = 5.79 で発散（論文は T = 7 まで流している） |

## 1. 刻みと方式（毛管波、水–空気、`cases/capwave_water_air.py`）
刻みは、tension.h の上限 √(ρ_m h³/(πσ)) = 7.3e-4 s の f 倍。5 周期まで流し、各周期の最大速度を見た。

| 方式 | f = 1 / 0.645 / 0.5 / 0.35 / 0.25 |
| --- | --- |
| TwoPhaseIMEX（既定） | 3.5 / 3.6 / 4.2 / 4.5 / 4.3 周期で発散 |
| + ab2 | 5.0 周期で発散 / 安定（5 周期目 0.43）/ 4.8 / 4.9 / 安定（0.87） |
| IMEX-RK ARS(2,2,2) | 4.9 / 安定（0.19）/ 5.0 / 4.8 / 4.6 |
| CenteredNS + CLS/GFM | すべて発散しないが、5 周期目に 0.19〜0.91 |
| 同、連成反復 | 4.6 / 安定（0.27〜0.64） |
| **Basilisk 型の VOF** | **すべて安定。0.0276 → 0.0199 と物理的に減衰** |

（物理的な最大速度は約 0.02〜0.03 m/s。法線モードの減衰は 5 周期で exp(−0.803 × 0.234) = 0.83 倍。）

- **刻みを 1/4 にしても治らない。** 時間刻みの不安定ではなく、CLS を使う方式に共通する空間の離散化の問題である。
- VOF は同じ格子・刻みで安定なので、NS の部分（射影、粘性）の問題でもない。

## 2. 原因の切り分け（CenteredNS + CLS/GFM、f = √(5/12)）
| 変えたもの | 各周期の最大速度（5 周期） |
| --- | --- |
| 密度比 1 | 0.019 / 0.020 / 0.019 / 0.064 / 0.087（**等密度でも増える**） |
| 密度比 10 / 100 | 5 周期目 0.28 / 0.25 |
| 曲率を高さ関数（fd2）に | 4.0 周期で発散 |
| 表面張力を CSF に | 0.043 / 0.068 / 0.068 / 0.033 / 0.051 |
| 10 ステップごとの再初期化（圧縮・拡散） | 0.029 / 0.019 / 0.014 / 0.0092 / 0.0058（安定、減衰） |
| 高さ関数 + 再初期化 | 0.028 / 0.018 / 0.013 / 0.0080 / 0.0050 |
| 参考：VOF（密度比 1 / 10 / 100） | 0.017 → 0.013 / 0.025 → 0.021 / 0.028 → 0.024 |

- **密度比の問題ではない。** 等密度でも 3〜4 周期目から増える。密度比があると増え方が大きい。
- **再初期化（圧縮・拡散）で止まる。** ノート21 の「CLS の輸送は格子規模の毛管波を散逸させない。毎ステップの圧縮・拡散で解消」と同じ機構が、長い時間で表に出たと考えられる（未確認：格子規模の成分を直接見ていない）。
- ただし再初期化を入れると、減衰しすぎる（5 周期で 0.2 倍。物理的には約 0.83 倍、VOF は 0.72 倍）。
- 曲率の方法（ψ の CCD か高さ関数か）は、安定性を決めない。

## 3. 再初期化の方法と頻度（CenteredNS + CLS/GFM、密度比 829、f = √(5/12)）
各周期の最大速度（1 → 5 周期）：

| 方法 | 1 ステップごと | 5 | 10 | 50 |
| --- | --- | --- | --- | --- |
| 圧縮・拡散 | 0.032 → 0.016 | 0.030 → 0.0060 | 0.029 → 0.0058 | 0.028 → 0.018 |
| **ξ-SDF（論文の標準）** | **0.0292 → 0.0249** | **0.0293 → 0.0251** | **0.0294 → 0.0254** | **0.0301 → 0.0249** |

- **論文の標準の再初期化（ξ-SDF）は、50 ステップごとでも不安定を抑える。** 5 周期の減衰（約 0.85 倍）は、法線モードの見積もり（0.83 倍）に近く、VOF（0.72 倍）より物理に近い。
- 圧縮・拡散は、どの頻度でも減衰しすぎる（50 ステップごとで 0.64 倍、10 ステップごとで 0.20 倍）。
- **ノート54 との対比：** ξ-SDF は静止液滴のジャンプを +13% ずらす（曲率に雑音を入れる）が、動く界面では安定化に欠かせない。
- 最大速度は振幅と寄生流を合わせた粗い指標である。減衰率と周波数の評価は、界面の振幅の時系列で行う（フェーズ3）。

## 判定（論文の主張）
| 主張 | 判定 | 根拠 |
| --- | --- | --- |
| 標準経路は、移動界面・水–空気で 1 周期を超えて安定（14 章） | 条件付き：再初期化が必須 | 再初期化なしでは、すべての CLS の方式が 3〜5 周期で不安定。ξ-SDF を 50 ステップごとに入れると安定 |
| 再初期化の頻度は設定ごとに明示する（11b1） | 記載の不足 | ベンチマークの頻度が書かれていない。安定性を決める設定である |

## 論文との関係
- 論文の標準経路は Ridge–Eikonal の再初期化（ξ-SDF）を前提にしている（11b1 第2段）。ただし頻度は「各検証設定として明示」とあるだけで、ベンチマーク（14 章）の設定は書かれていない。また、14a の毛管波は CLS ではなく swept-volume 輸送を使っている（ノート10）。
- 上昇気泡が論文の報告（t ≃ 0.04 s 以降の破綻）とほぼ同じ時刻（0.035 s）に発散したのは、同じ機構による可能性がある（未確認）。
