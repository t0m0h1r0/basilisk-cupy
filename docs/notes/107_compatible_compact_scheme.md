## 1. 研究の目的と適用の範囲
- **最終目標**（ノート98）：CCD・FCCD・PCCD を中核にした、高次精度・保存型・コンパクト・GPU 向けの二相 Navier–Stokes のソルバー。
- **方針の変更**（ユーザー）：移流・粘性・圧力射影を別々に作って後から整合させる進め方をやめる。全演算子が満たすべき構造を先に定め、共通の再構築空間から各演算子を導く。
- **CCD の位置づけ**（ユーザー）：CCD を保存性・安定性の根拠にはしない。整合した離散化を、高次かつ狭い陰的なステンシルで実現する手段とする。CCD を中心に据える方針は変えない。
- **このノートの範囲**：二次元、周期、粘性流（界面で速度は連続、速度勾配が跳ぶ）、非圧縮、鋭い界面。密度比は 1、1e3、1e6（1e6 はストレス試験、ノート98）。
- **範囲外**：壁の境界、三次元、接線速度が跳ぶ非粘性の界面、完全離散の時間積分の安定性、GPU の実装。

| --- | --- | --- |

## 3. 可換な再構築（支柱 I）
### 3.1 目標の恒等式（ユーザー）
再構築 R₀、R₁、R₂（頂点・面・セルの自由度から連続の場へ）について：

```
R₁ C_h = curl R₀
∇·R₁   = R₂ B_h
```

- 補足（単相での実現）：ノート105 の MAC–PCCD は `u_h = (R_F,x ⊗ R_C,y) u_f`、`v_h = (R_C,x ⊗ R_F,y) v_f` で、`∂R_F = R_C D` から 2 行目が演算子の恒等式として成り立つ（ノート105 の 1 節、単相・周期、N = 32 の一次元と N = 12 の二次元の全行列で丸めの水準）。
- 補足（1 行目）：`R₀ = R_F,x ⊗ R_F,y` と置くと、`∂R_F = R_C D` を各方向に使って 1 行目も成り立つ（導出。行列での確認はしていない）。

### 定理 1：発散の整合（ユーザー）
- **仮定**：`∇·R₁ = R₂ B_h` が演算子の恒等式として成り立つ。
- **主張**：`B_h f = 0` なら `∇·(R₁ f) = 0`（各点）。
- **証明**：恒等式に f を代入する。
- **適用の範囲**：再構築した速度で界面を運ぶと、連続の流れの写像は十分な正則性の下で体積を保つ。数値の流れの写像の体積保存までは言えない（ノート105）。
- **未解決**：二相でこの恒等式を満たす R₁ が存在するか（3.3 節）。

### 3.2 流れ関数型の hinge 基底（ユーザー）
直線の界面からの符号付き距離を ξ、接線方向の座標を η、`ξ₊ = max(ξ, 0)` とする。

```
ψ_h(ξ, η) = P₅(ξ, η) + ξ₊² Q₃(ξ, η),   u_h = curl ψ_h
```

P₅、Q₃ は全次数 5 以下、3 以下の多項式。

### 定理 2：直線の界面での完全な表現（ユーザー）
- **仮定**：界面は 1 本の直線。領域は局所的に単連結。
- **主張**：界面で連続な、区分 4 次以下の発散 0 の速度場の全体は、`curl(P₅ + ξ₊² Q₃)` の全体に等しい。
- **証明**：
  - （⊂）各相で発散 0 の 4 次以下の速度は、5 次以下の流れ関数 ψ^± を持つ。速度が界面で連続なら ∇ψ が連続なので、`[ψ]_Γ` は界面に沿って定数である。片側の定数を調整して `[ψ]_Γ = 0`、`[∂_ξ ψ]_Γ = 0` にできる。`ψ⁺ − ψ⁻` は ξ = 0 で 2 位の零点を持つ多項式なので ξ² で割り切れ、商は 3 次以下である。
  - （⊃、補足）`P₅ + ξ₊² Q₃` は界面で C¹ なので速度は連続で、curl なので発散は 0、各相で 4 次以下である。
- **自由度**：`dim P₅ + dim Q₃ = 21 + 10 = 31`。ψ の定数を除いて、速度の自由度は 30。
- **表せるもの**：`[∂_ξξ ψ]_Γ = 2Q₃(0, η)` なので、接線速度の法線方向の勾配の跳びを表せる。法線速度の法線方向の勾配 `∂_ξ u_ξ = −∂_η u_η` は連続である（非圧縮から）。
- **適用の範囲外**：曲線の界面、1 つのパッチに界面が 2 本ある配置（薄膜）、相の消滅。これらは縮退で扱う（10 節）。
- **未解決**：局所のデータ（頂点の ψ、面の平均）から 30 個の自由度が決まるか。自由度の数が足りることと、階数が足りることは別である（ユーザー）。

### hinge 基底の役割（ユーザーの判断、2026-11-27）
- この基底は**再構築が再現すべき関数空間の定義**である。広いパッチへの当てはめを最終の方式にするという意味ではない。
- 7×7 などの広いパッチは **Oracle** に限る。広い最小二乗 Galerkin（ノート80〜90、ノート98 で参照解法）を本命に戻さない。
- 本命は、CCD の基準の再構築 + 必要最小限のコンパクトな界面の補正で、同じ再現の能力を狭い陰的なステンシルで得ることである。
- 段階：(a) 基底が理論どおりに再現するか、(b) Oracle のパッチで必要な情報が取れるか、(c) CCD の基準の再構築が再現できない部分はどれか、(d) その部分だけをコンパクトな補正で再現できるか。
- (b) で階数の不足や著しい悪条件が出るなら、コンパクトな端の条件の設計には進まない。情報の不足という原理の問題を先に調べる。

### 3.3 面の速度を保つ curl の補正（ユーザー）
単相の MAC–PCCD を R₁⁽⁰⁾ とする。

```
R₁^Γ f = R₁⁽⁰⁾ f + curl χ_Γ(f),   全ての格子の頂点で χ_Γ = 0
```

- **証明（χ_Γ が大域的に連続な場合）**：面 F の端の頂点を a、b とすると `∫_F curl χ·n ds = χ(b) − χ(a) = 0`。面の平均は変わらない。`∇·curl χ = 0` なので `∇·R₁^Γ f = ∇·R₁⁽⁰⁾ f = R₂ B_h f`。可換性は二相でも保たれる。
- 補足（訂正、ユーザーのレビュー）：χ_Γ の大域の連続は**十分条件**である。厳密に必要なのは、面をまたぐ**法線トレースの整合**（面の両側で `curl χ·n = ∂_t χ` が一致すること）である。頂点で 0 と合わせれば、面上のトレースの共有で満たせる。
- 補足（訂正、ユーザーのレビュー）：7 節の移流の行列 A は `u_h·∇φ_j` を含む。接線速度が固定の面で跳ぶと、A の定義に面の項が要る。大域の C¹ はこれを避ける**十分条件**で、必要条件とは限らない。弱微分・区分的な正則性（面の項を A に含める形）も許容できる。
- 補足：定数の速度 c について `χ_Γ(c) = 0`（または curl が 0）であることが、自由流の再現に要る。
- **仮説**：頂点で 0・トレースの共有・hinge 空間の再現を同時に満たす、コンパクトで線形な χ_Γ(f) が存在する。

### 3.4 curl の補正が及ぶ範囲（ユーザー）
hinge 基底が完全に表すのは発散 0 の速度である。射影の前の任意の面の速度を全て表すという意味ではない。

```
f = C_h ψ + f_harm + f_div
```

| 成分 | 役割 |
| --- | --- |
| C_h ψ | 発散 0 の回転の成分 |
| f_harm | 周期領域の平均流などの調和成分 |
| f_div | 発散を持つ成分 |

- 発散 0 の成分に hinge 型の補正を使い、発散を持つ成分にも定義された再構築を用意する。
- この分解のために、毎ステップ大域の Poisson の求解を足すことは望ましくない。最初は Oracle として扱い、コンパクトな局所の補正で済むかを判定する。
- **未証明**：f_div に対する補正を局所に定義でき、f について線形で、かつ 4 節の Gram の条件を壊さないこと。

### 3.5 固定した発散の再構築の下での curl の補正の限界（ユーザーの定理、2026-11-27）
3.3 節の形 `R₁^Γ f = R₁⁽⁰⁾ f + curl χ_Γ(f)` は、発散の再構築を単相の R₂⁽⁰⁾ に固定する。この構成では、法線方向の速度の再構築に密度適合性を持たせられないモードがある。

- **設定**：密度が y だけに依存する層の二相、x は周期（長さ L_x）。x に一様な法線速度のデータ `f = (0, f_y(y))`。
- **証明**：curl の補正の法線成分は `δv = −∂_x χ`。周期なので `∫₀^{L_x} δv dx = 0`。そのため、どの curl の補正でも、法線速度の x 方向の平均は変わらない：`(1/L_x)∫ v_h dx = v₀(y)`（v₀ は単相 MAC–PCCD の再構築）。Cauchy–Schwarz から `∫|v_h|² dx ≥ L_x |v₀(y)|²`。よって

```
fᵀ G_Γ f ≥ ρ_H L_x ∫_{Ω_H^y} |v₀(y)|² dy
```

- **帰結**：単相 PCCD の法線方向の再構築が重い相に漏れていれば、curl の補正だけではそのエネルギーの漏れを除けない。補正の次数・パッチの幅・最適化の方法によらない。
- **ユーザーの独立の数値**（周期 32 セル、h = 1、重い相がセル 0〜15、軽い相が 16〜31。軽い相の面の自由度を 1、他を 0 とした密度加重のエネルギーを、その面の双対の制御体積の軽い相の質量で割る。Gram の最大固有値の下界）：

| 界面からの距離 | 密度比 1 | 1e3 | 1e6 |
| --- | --- | --- | --- |
| 1 セル | 0.924 | 20.4 | 19,536 |
| 2 セル | 0.924 | 4.49 | 3,567 |
| 3 セル | 0.924 | 1.65 | 728 |
| 4 セル | 0.924 | 1.07 | 151 |
| 5 セル | 0.924 | 0.955 | 32.1 |

- **切断セルが 1 つもない、格子の面に一致した界面でも悪条件になる**。開発側の再現は T1（ノート108）で行う。
- 補足：このモード（x に一様で y に変わる法線速度）は、定数でない限り離散の発散を持つ。発散 0 の部分空間の中の話ではないが、`L_Γ = B_h G_Γ⁻¹ B_hᵀ` は全速度空間の G_Γ で決まるので、射影の頑健性（定理 3 の仮定）に直接効く。
- 上の表はユーザーの計算で、開発側では未再現である。

### 3.6 新しい設計の候補：R₁ と R₂ を整合して密度適合させる（ユーザー）
必要なのは `∇·R₁^Γ = R₂^Γ B_h` で、R₂ を単相に固定する必要はない。R₂^Γ 自体を界面に適合させても、可換性が保たれる限り、非圧縮の条件は失われない（定理 1 は R₂ の形によらない）。

```
R₁^Γ = R₁⁽⁰⁾ + Z_Γ + curl χ,   ∇·Z_Γ = (R₂^Γ − R₂⁽⁰⁾) B_h
```

- Z_Γ は発散の再構築の違いを補う演算子で、面の平均の保存も要求する。
- 純相の領域では CCD を使い、界面の近くでは発散の再構築も含めて整合した補正をする。
- **層の二相での試作**（ユーザー）：一次元の**体積平均**を保つ密度適合の再構築 R_C^Γ を定義し、

```
d_i = (f_{i+1} − f_i)/h,   (R_F^Γ f)(x) = f_i + ∫_{x_i}^x (R_C^Γ d)(ξ) dξ
```

  とする。R_C^Γ が体積平均を保つ限り `∂_x R_F^Γ = R_C^Γ D` が成り立ち（**証明**、ノート105 の A 節と同じ）、可換性を密度適合型に拡張できる。
- 従来の相分離 PCCD（ノート97）は質量加重の平均の保存を目的としているので、そのまま流用しない。ここで要るのは体積平均の保存である。
- **未検証**：R_C^Γ、R_F^Γ の具体的な構成と成立性（T1-D）。
- **方針**：単相 PCCD に対する curl の補正だけの最適化は続けない。発散の再構築も含めた密度適合性を、まず一次元・層の二相で確立する。

## 4. 密度適合の Gram（支柱 II）
### 4.1 定義（ユーザー）
```
u_h = R₁ f,   E_k = ½ ∫ρ|u_h|² dV = ½ fᵀ G_Γ f,   G_Γ = R₁* ρ R₁
```

- 移流・粘性・圧力射影で同じ G_Γ を使うことを原則とする。
- 粘性の剛性の行列 K だけは、別の補助の再構築から作ることを許す（6 節）。

### 4.2 正定値と一様な同値は別である（ユーザー、補足）
- 補足（証明）：R₁ が面の平均を再現するなら R₁ は単射で、ρ > 0 なら `G_Γ ≻ 0` である。MAC の B_h は再構築を含まないので、`L_Γ = B_h G_Γ⁻¹ B_hᵀ` の零空間は B_hᵀ の零空間（周期の連結領域では定数）だけである。ノート104 の偽の零空間（面の値が混合セルの平均に依存しない。N = 32・64、密度比 1e3・1e6 で混合セルの列が 1e-15 以下）は、この構成では生じない。
- ユーザー：しかし `G_Γ ≻ 0` と、下の一様な同値は全く別である。問題は零空間から Gram の同値性に移っただけである。

```
c_G M_F ⪯ G_Γ ⪯ C_G M_F
```

- M_F は、物理的に適切な低次の MAC の速度の内積。
- c_G、C_G が、密度比・切断セルの体積分率・切断面の面積分率・界面の角度・格子の解像度に依存して極端に悪化しないことを目指す（**仮説**）。
- 切断面の M_F は、密度を適当に平均して決めない。低次の界面適合の再構築か、区間の抵抗（直列の移動度）に基づいて定める（ユーザー。ノート104 の 3 節・監修 #117 の追記と同じ要求）。
- 条件数 10 以下のような単独の閾値は必須にしない（ユーザー、ノート98）。
- **M_F の基準は方向で異なる**（ユーザーのレビュー）：

| 方向 | 基準となる物理量 |
| --- | --- |
| 法線方向（層をまたぐ） | 圧力の評価点の間の区間で積分した密度に基づく直列の移動度 `β_n = h/∫_I ρ dy` |
| 接線方向（層に平行） | 面の中で平均した逆密度に基づく移動度 `β_t = (1/h)∫_I (1/ρ) dy` |
| エネルギーの比較 | 双対の制御体積の密度の積分、低次の再構築の Gram |

- 全ての速度成分に同じ密度の平均を使わない。M_F を後から調整して条件数を良く見せることは認めない。物理的な根拠を先に定義する。
- **固定した単相の発散の再構築では、curl の補正で除けない漏れがある**（3.5 節）。一様な同値を目指すには、R₂ も密度適合させる（3.6 節）。

### 定理 3：射影の頑健性（ユーザー）
- **仮定**：`c_G M_F ⪯ G_Γ ⪯ C_G M_F`、`M_F ≻ 0`。
- **主張**：`L_ref = B_h M_F⁻¹ B_hᵀ` として `(1/C_G) L_ref ⪯ L_Γ ⪯ (1/c_G) L_ref`。
- **証明**：正定値の行列の逆は大小を反転する。`(1/C_G) M_F⁻¹ ⪯ G_Γ⁻¹ ⪯ (1/c_G) M_F⁻¹` を B_h で挟む。
- **適用の範囲**：零空間と条件数。圧力勾配の精度（界面を横切る整合性）は、同値性からは出ない（補足）。
- **未解決**：c_G、C_G の一様性。M_F の定義。

### 4.3 密度による悪条件の必要条件（ユーザー）
- 軽い相を代表する面の自由度の基底を φ_j とすると `(G_Γ)_jj ≥ ρ_H ∫_{Ω_H} |φ_j|² dV`。
- 基準の質量が軽い相の密度に比例するなら、重い相への漏れが一定量あるだけで、正規化した Gram の固有値は密度比 r に比例して増える。必要なのは、軽い相から重い相への正規化した L² の漏れが `O(r^{−1/2})` であること（導出）。
- **下界（証明、古典的な結果）**：端で値 1 を取る次数 p の多項式は `∫₀^h |u|² dx ≥ h/(p + 1)²`。重い相の純相のセルの端で面の速度を 1 に固定し、セル内を多項式で連続に再構築すれば、この質量は必ず生じる。
- **帰結**：面の速度を状態変数にしても、密度比の問題は自動では消えない。その面の自由度の基準の質量を軽い相だけで決めれば、密度比に比例する悪条件は避けられない。
- 密度比 1e6 の薄片では、Gram の最大固有値だけでなく最小固有値も測る（ユーザー）。

## 5. 質量・運動量・エネルギーの保存（支柱 III）
### 5.1 保存性の区別（ユーザー）
| 保存性 | 意味 |
| --- | --- |
| 質量 | 各相の質量が保たれる |
| 総運動量 | 領域全体の運動量が保たれる |
| 局所の運動量 | 各制御体積で、共通の面の流束による収支が成り立つ |

### 定理 4：一般の再構築空間での保存型の輸送（ユーザー）
- **仮定**：体積を保つ厳密な写像 Φ で密度を運ぶ（`ρ_{n+1} = ρ_n∘Φ⁻¹`）。積分は厳密。
- **構成**：`U_Φ u = u∘Φ⁻¹`、`C = R_{n+1}* ρ_{n+1} U_Φ R_n`、`G_{n+1} f_{n+1} = C f_n`。
- **主張**：`Cᵀ G_{n+1}⁻¹ C ⪯ G_n`（エネルギー非増加）。新しい再構築空間が定数の速度を含めば総運動量が保たれ、両方の空間が定数を再現すれば自由流が保たれる。
- **証明**：U_Φ は密度加重の内積の等長写像で、f_{n+1} は `U_Φ R_n f_n` の、新しい空間への直交射影である。射影はノルムを増やさず、定数との内積を変えない。
- **適用の範囲**：セル中心型・MAC 型のどちらにも使える。Galerkin 輸送の理論（ノート91〜97）は、状態変数を変えても捨てなくてよい。
- **未解決**：局所の運動量保存はこの定理から出ない。MAC 型では輸送後の f_{n+1} は一般に `B_h f ≠ 0` で、射影と組み合わせた精度は未検証（補足）。

### VOF との整合：質量の移動を共有する（ユーザー）
- 旧位置 x と新位置 y の間の質量の移動を、非負の測度 π(x, y) で表す。周辺は `∫π(dx, ·) = ρ_{n+1} dy`、`∫π(·, dy) = ρ_n dx`。相ごとに同じ条件を課す。
- `C = ∫ R_{n+1}(y)ᵀ R_n(x) dπ(x, y)` とすると、Cauchy–Schwarz から同じエネルギー非増加が出る（**証明**、π が存在する場合）。
- **未解決**：実際の PLIC に対して、非負で局所の π を高次で構成できるか。

### 5.2 局所の運動量保存は必須（ユーザーの判断、2026-11-27）
最終のソルバーでは、局所の運動量保存を必須とする。従来のセル中心の制御体積でなくてもよく、MAC 型では速度の成分ごとの双対の制御体積 V*_i（面を中心とする）での保存を認める。

```
p*_i = ∫_{V*_i} ρ u_α dV
dp*_i/dt = −Σ_{F ⊂ ∂V*_i} 𝓕_{p,F} + 𝓕_{stress,i} + 𝓕_{ext,i}
```

- 内部の面では、隣り合う制御体積が同じ流束を逆符号で使う。
- 一様な速度 U について `𝓕_p = U 𝓕_m`（質量の流束と整合）。これで、密度の界面を運んでも自由流が保たれる。
- 総運動量が保たれることや、代数的に差分の形へ書き換えられることだけでは、局所保存が成立したとは判定しない。
- **圧力射影だけ成立しても、運動量を保存できない状態変数は採用しない。**

### 5.3 MAC 型に固有の問題（ユーザー）
セルの運動量への変換を `(P_Γ f)_i = ∫_{K_i} ρ R₁ f dV` とする。

- **証明（単相・一次元・周期・N が偶数）**：交互の面の速度 `f_i = (−1)^i` に対する MAC–PCCD の再構築は、各セルの中央について反対称である（セルの中央での反転は f を −f に移し、方式は反転で不変）。各セルの平均は 0 で、P_Γ に零空間がある。
- 帰結：`P_Γ f^{n+1} = p*`（幾何学的な輸送で得たセルの運動量）は、任意の p* に対して解を持たない。セルの運動量保存型の VOF に、MAC–PCCD をそのままは接続できない。圧力の checkerboard とは別の問題である。
- 双対の制御体積への変換 `(P*_Γ f)_i = ∫_{V*_i} ρ R₁ f dV` の階数と条件数は**未測定**である。

### 定理 7：局所の運動量の変換の上界（ユーザー、2026-11-27）
P*_Γ は運動量の次元を持つので、最小特異値をそのまま密度比について比べるのは適切でない。双対の制御体積の質量 `M_⋆ = diag(∫_{V*_i} ρ dV)` で無次元化する：

```
Q_⋆ = M_⋆^{−1/2} P*_Γ G_Γ^{−1/2}
```

- **仮定**：各速度成分の双対の制御体積が領域を分割する。
- **主張**：`(P*_Γ)ᵀ M_⋆⁻¹ P*_Γ ⪯ G_Γ`、すなわち `0 ≤ σ_j(Q_⋆) ≤ 1`。
- **証明**：Cauchy–Schwarz から `(∫_{V*_i} ρ u_α dV)² / ∫_{V*_i} ρ dV ≤ ∫_{V*_i} ρ u_α² dV`。全ての制御体積・速度成分について足す。
- **使い方**（T4 の検証の条件）：
  - 最大特異値が 1 を超えたら、積分・正規化・双対の制御体積の構成を疑う。
  - 最小特異値が 0 なら、独立な局所の運動量の座標としては使えない。
  - 最小特異値が密度比とともに 0 に近づくなら、運動量から速度への復元が悪条件になる。
- **零空間がある場合の判断**：P*_Γ に零空間があることだけから、MAC 型で局所の運動量保存が原理的に不可能とは断定しない。否定されるのは、任意の双対セルの運動量を面の速度と一対一に対応させる方式である。運動量が特定の部分空間に制約される方式や、補助モーメントを持つ方式は残る。

| 評価 | 意味 |
| --- | --- |
| 全速度空間の階数 | 任意の仮の速度・運動量への適用 |
| 発散 0 の部分空間への制限 | 非圧縮の速度としての情報量 |
| 正規化した最小特異値 | 密度比への頑健性 |
| 局所の流束の構成 | 実際の局所の運動量保存（Gate 1-C で検証） |

T4 が合格しても、局所の運動量保存が完成したとは扱わない。

| 対策の候補（ユーザー） | 特徴 |
| --- | --- |
| MAC の双対の制御体積の運動量 | 面の速度に自然。界面の輸送の再設計が要る |
| Galerkin の運動量の輸送 | 総運動量とエネルギーは定理 4。局所の収支は別に設計する |
| 面の速度 + 局所の補助モーメント | 情報を補えるが、自由度と求解の費用が増える |

## 6. 粘性・圧力・界面エネルギー（支柱 IV）
### 6.1 粘性（ユーザー）
```
𝒟_μ = ∫ 2μ ε(u):ε(u) dV,   K_Γ = ∫ 2μ B_εᵀ B_ε dV,   G_Γ ḟ = −K_Γ f
```

- **証明**：`K_Γ = K_Γᵀ ⪰ 0` なので、固定の界面で `dE_k/dt = −fᵀ K_Γ f ≤ 0`。B_ε をどの再構築から作っても成り立つ。
- 移流の再構築をそのまま微分すると、薄片で剛性が発散する（ノート97 の D 節と 3 節。不採用、ノート98）。粘性専用の応力の再構築を使う方針を保つ。
- 補足（訂正、ユーザーのレビュー）：`G_Γ ḟ = −K_Γ f`（共通の Gram + 別の再構築の K）は D 方式と同じ構造である。既存の D は最大誤差で 2.4〜3.3 次（ノート103 の 1 節：二層 Stokes の第 1 モード、N = 32〜256 の 13 点、界面の位置 3 通りの最悪値、4 つの物性と単相）。エネルギーは定理で言えるが、**精度は言えない**。ただし、新しい状態変数・再構築でも必ず 2.4〜3.3 次になるとは言えない（次数は G と K の再構築の組で決まる）。測り直しが要る。
- D を 4 次にする局所の最適化は、再構築空間が決まるまで保留する（ユーザー）。

| 既存の技術 | この体系での役割（ユーザー） |
| --- | --- |
| C 方式 | 高次の粘性の Oracle |
| D 方式 | 共通の Gram による散逸の実証 |
| コンパクトな応力 H₄ | 低剛性・安定な基準の方式 |
| H₃ | 非対称な高次化の失敗例 |

### 6.2 圧力は制約のラグランジュ乗数（ユーザー）
```
f^{n+1} = argmin_{B_h f = 0} ½ (f − f*)ᵀ G_Γ (f − f*)
Π_Γ = I − G_Γ⁻¹ B_hᵀ (B_h G_Γ⁻¹ B_hᵀ)⁺ B_h,   Π_Γᵀ G_Γ Π_Γ ⪯ G_Γ
```

- **証明**：Π_Γ は G_Γ 内積の直交射影（ノート104 の A 節、ノート105 の 1 節で行列でも確認済み、単相）。
- 定数の速度が離散の発散 0 なら、周期領域で総運動量も保たれる。
- **圧力の自由度の意味**（ユーザー）：物理的な圧力をセル平均から R₂ p と再構築し、その重みなしの Gram を H_p とすると、圧力による加速度（負の圧力勾配）は `G_Γ a_p = +B_hᵀ H_p p`（`−∫w·∇p = ∫p ∇·w` から）。物理的なセル平均 p と、射影で解く双対変数 H_p p を区別する。
- 記録の訂正：ノート105 の C 節には `G_F a = −Bᵀ H_p p` とあるが、`cases/mac_pccd.py` の `pressure_gradient` は正の符号で `−p'` と比べている。ノートの側の誤りで、#127 の記録の訂正として別の PR で直す（このノートでは直さない）。

### 6.3 表面張力（ユーザー）
```
E_σ = σ|Γ|,   Ẋ = J f,   F_σ = −Jᵀ ∇_X E_σ   ⇒   fᵀ F_σ = −dE_σ/dt
```

- **証明**：`Ẋ = J f` が離散で成り立つなら恒等式。
- これだけでは balanced-force は出ない。静止液滴には `F_σ ∈ range(B_hᵀ)` が要る。測る量は `‖Π_Γ G_Γ⁻¹ F_σ‖_{G_Γ}`（圧力で打ち消せない成分）。
- **仮説**：VOF・PLIC の幾何学的な自由度 X に対して、J と ∇_X E_σ を構成できる。
- 関連：毛管波の研究で問題になった、表面張力と界面の運動学が随伴でないこと（凍結中、PR #62・#63）の理論の土台になりうる。再開は Gate 3 以降。

## 7. 統合した半離散方程式（支柱 I〜IV のまとめ）
### 7.1 移動する空間での移流（ユーザー）
`u_h(x, t) = Σ_j φ_j(x, t) f_j(t)` とし、密度と界面はこの速度で運ばれるとする。

```
A_ij = ∫ ρ φ_i · (∂_t + u_h·∇) φ_j dV   ⇒   A + Aᵀ = Ġ
```

- **証明**：`A_ij + A_ji = ∫ρ D_t(φ_i·φ_j)`。質量保存 `∂_t ρ + ∇·(ρ u_h) = 0` と Reynolds の輸送定理（周期）から `= d/dt ∫ρ φ_i·φ_j`。
- **仮定**：密度が u_h で厳密に運ばれる。基底が時間について微分でき、`u_h·∇φ_j` が面で特異にならない（3.3 節の補足）。
- 固定の界面・一定の密度では `A + Aᵀ = 0`（通常の反対称の形）に戻る。

### 7.2 方程式と構造の条件（ユーザー）
```
G_Γ ḟ + A_Γ f + K_Γ f − B_hᵀ λ = F_σ + F_ext
B_h f = 0
Ẋ = J_Γ f

∇·R₁ = R₂ B_h,   c_G M_F ⪯ G_Γ ⪯ C_G M_F,   A_Γ + A_Γᵀ = Ġ_Γ,
K_Γ = K_Γᵀ ⪰ 0,   F_σ = −J_Γᵀ ∇_X E_σ
```

### 定理 5：総エネルギーの収支（ユーザー）
- **仮定**：上の構造の条件が全て成り立つ演算子が存在する。
- **主張**：`E_total = ½ fᵀ G_Γ f + E_σ` について `dE_total/dt = −fᵀ K_Γ f + fᵀ F_ext`。外力がなければ非増加。
- **証明**：運動方程式に fᵀ を掛ける。`fᵀ B_hᵀ λ = 0`。`−fᵀ A f + ½ fᵀ Ġ f = 0`。`fᵀ F_σ = −Ė_σ`。
- **総運動量**：定数の速度を表す c について `R₁ c` が一定、`B_h c = 0`、`K_Γ c = 0`、`A_Γ c = 0` で、E_σ が並進で不変なら、周期領域で `cᵀ G_Γ f` が保たれる。
- **未証明**（ユーザー）：任意の切断の界面でこの演算子が実在すること。局所の運動量保存。高次の精度。完全離散の時間積分での安定性。

## 8. 移動する再構築空間と随伴補正（支柱 V）
### 8.1 比べる対象（ユーザー）
- 厳密な質量の輸送で、各時刻の再構築空間を共通の Hilbert 空間に引き戻す。その正規直交基底を W(t)（`W*W = I`）とする。
- 再構築空間の中の速度を W(t)z(t) と書き、移動する空間での射影された時間発展を `W* d/dt (Wz) = 0`、すなわち `ż = −W*Ẇ z` と定める。時間の精度は、この方程式の厳密解に対して測る。
- 一ステップの Galerkin 輸送は `T = W(t + Δt)* W(t)`。随伴補正は `T_c = T[I + ½(I − T*T)]`。

### 定理 6：随伴補正による時間の高次化（ユーザー）
- **仮定**：
  - 厳密な密度の輸送で、共通の Hilbert 空間へ等長に引き戻せる。
  - 再構築空間の次元が一定。
  - W(t) が時間について十分に滑らか（例えば C³）。
  - Galerkin 射影と随伴を厳密に評価する。
- **主張**：通常の Galerkin 輸送は、射影された時間発展に対して一般に時間 1 次。随伴補正つきは 2 次以上。どちらもエネルギー非増加。
- **証明**：
  - `W*Ẇ` は反対称なので、時間に依存する直交変換で `W*Ẇ = 0`（平行移動のゲージ）にできる。このゲージでは `ż = 0` で、厳密な一ステップの写像は I である。
  - `Ẇ*W = 0` を微分して `Ẅ*W = −Ẇ*Ẇ`。`L = Ẇ*Ẇ ⪰ 0` と置く（このゲージでは `Ẇ*(I − WW*)Ẇ` に等しい）。
  - `T = I − (Δt²/2) L + O(Δt³)`。局所誤差が 2 次なので、決まった時刻で一般に 1 次。
  - `T*T = I − Δt² L + O(Δt³)` から `T_c = (I − (Δt²/2)L)(I + (Δt²/2)L) + O(Δt³) = I + O(Δt³)`。
  - T の特異値 s ∈ [0, 1] は `s_c = (3s − s³)/2 ≤ 1` に移るので、T_c は縮小的である。局所 3 次と合わせて、決まった時刻で O(Δt²)。
  - 補足：ゲージの変換 `W → WQ(t)` で `T → Q(t + Δt)* T Q(t)`、T_c も同じ形で変換するので、結果は基底の選び方によらない。

| 対象 | 判定（ユーザー） |
| --- | --- |
| 滑らかな移動空間での射影された時間発展 | 2 次を証明 |
| エネルギー非増加 | 証明 |
| 相の消滅・ステンシルの切り替え | 未証明（次元が変わる、W が不連続） |
| PLIC の再構築の誤差を含む輸送 | 未証明 |
| 非線形の Navier–Stokes 全体 | 未証明 |
| ノート103 の、粘性との連成での時間の次数の低下の解消 | 未検証 |

- **帰結**（ユーザー）：幾何学的な連続性は、再構築の品質の指標であるだけでなく、高次の時間積分が成り立つための条件である。
- 監修 #127 の指摘どおり、純粋な Galerkin 輸送の時間 1 次（この定理の対象）と、粘性との連成で見えた時間刻みへの依存（ノート103 の 2 節）は、**別の現象**として扱う。
- この定理の数値の検証はしていない。

### ノート104 の補足の次数についての注意（ユーザー、#127 に関連）
- 監修の訂正（格子に平行な界面で、法線成分への高階差分の補正の局所誤差は O(h²)）は、`∂_n u_n = −∇_t·u_t` が連続であることから妥当である。
- ただし、補正への入力が質量加重のセル平均なら、滑らかな線形の速度でも `ū_ρ − ū_volume = u'(x̄_ρ − x̄_volume)` で、混合セルの重心の差は一般に O(h) である。法線速度の勾配が連続でも、O(h) の誤差が出うる。
- ノート104 の訂正（#127）では、体積平均と質量加重の平均の違いも含めて評価する。

## 10. 再構築の候補の設計
### 10.1 CCD + 局所の拘束つき補正（ユーザー）
基準の再構築の係数を a₀、局所の多項式の係数を a とする。

```
min_a ½ (a − a₀)ᵀ H_ρ (a − a₀)   subject to   L a = b
a = a₀ + H_ρ⁻¹ Lᵀ (L H_ρ⁻¹ Lᵀ)⁺ (b − L a₀)
```

- L は面の平均・セルの平均・界面の接続などの拘束。H_ρ は密度加重の局所のエネルギーの行列。
- **証明**（`H_ρ ≻ 0`、拘束が整合する場合）：解の公式。
- **未証明**：密度比に一様な有界性。この形だけでは出ない（ユーザー）。
- **判定の順序**（ユーザー。最適化から始めない）：
  1. 多項式の再現に必要な拘束を導く。
  2. 拘束の整合性・階数を確かめる。
  3. 密度加重の拘束の Schur 補行列 `L H_ρ⁻¹ Lᵀ` のスペクトルを測る。
  4. 再構築の演算子全体の増幅率を測る。
  5. コンパクトな実装に落とせるかを判定する。

### 10.2 短い相の領域の縮退（ユーザー）
| 状態 | 対応 |
| --- | --- |
| 十分な純相のセル | 通常の高次の CCD |
| 近くに少数の純相のセル | 多次元のパッチで情報を補う |
| 極端に短い相の領域 | 低い次数の界面適合の再構築 |
| 解像できない薄膜 | 保存性・有界性を優先する |
| 相の消滅 | 単相の再構築へ連続に移る |

- 補正の速度を直接混ぜず、流れ関数の段階で混ぜる：`χ_Γ = Σ_j w_j χ_j`、`u_h = u₀ + curl χ_Γ`。
- **証明**：重み w_j が空間に依存しても、curl なので補正の発散は 0。各 χ_j が頂点で 0 なら χ_Γ も頂点で 0。
- 面のトレースの共有は、重みを含めて満たす必要がある（設計の条件）。
- ノート98 の縮退の形 `R_ω q = Jq + ω(R_H q − Jq)` と、ノート106 の SplitShort は、セル中心型での対応物である。

### 10.3 Gate 1-B の比較の候補（ノート98 の 0 節。D は 3.6 節で改訂）
A：セル平均 + 相分離 PCCD（+ SplitShort）。B：セル平均 + CCD + 多次元の補正。C：MAC–PCCD（補正なし）。D：MAC–PCCD + 密度適合型の可換な補正（R₁ と R₂ を整合して設計、3.6 節。curl の補正だけの形は限界の確認用）。Oracle：hinge 空間への広いパッチの当てはめ、多次元の最小二乗。

### S2・S3 の判定（ユーザーのレビュー、2026-11-27）
密度比に対する両対数の傾きは、発散の傾向を見つける指標として使う。ただし、傾きだけでは合否を決めない（最小 0.001・最大 1000 でも傾きは 0 になる）。次を併記する：

- 一般化固有値の最小・最大・条件数。
- 全ての密度比 {1, 1e1, …, 1e6} での対数回帰の傾き。
- 高密度比側（1e3〜1e6）だけの傾き。
- 隣り合う密度比の間の局所の傾き。
- 界面の位置ごとの値と、全ての位置の最悪値。

| 判定 | 条件 |
| --- | --- |
| 有望 | 傾きの絶対値が 0.1 以下で、固有値の絶対値も実用的 |
| 条件つき | 傾き 0.1〜0.5、または絶対的な悪条件がある |
| 不成立の強い証拠 | 傾き 0.5 以上の悪化が高密度比側でも続く |
| 構造的に不成立 | 厳密な零空間、発散の整合や平均の保存の破綻 |

- **有限の範囲の走査は、一様な有界性の証明ではない**。合格しても「走査した条件で有望」と記録し、理論上の一様な有界性は未証明のままとする。
- 薄片は、体積分率 c だけでなく `ζ = rc/(1 − c)` で走査する。`ζ ≈ 1`（`c ≈ 1/r`、密度比 1e6 では c ≈ 1e-6）は、重い相と軽い相の質量の寄与が同程度になる領域である。
- T1 では、まず低い次数でもよいので、次の 4 つを同時に満たす再構築が存在するかを判定する（T1-D）。成立してから CCD で高次化する。
  1. 体積平均・面の平均の厳密な再現。
  2. 微分と再構築の可換性。
  3. 定数の速度の厳密な再現。
  4. 密度比に対する Gram の頑健性。

### 11.3 分岐
- **S4 が不成立**：T5（コンパクトな補正）は中止。情報の不足の原因（パッチの形、データの種類、界面の位置）を調べるタスクに進む。
- **S2 または S3 が不成立**：その再構築と基準の内積の組は不採用とする。**個別の候補の不成立と、MAC 型全体の不成立は区別する**（ユーザーのレビュー）。T1-A〜D の全てが不成立のときに、補助の自由度か、セル中心型で混合セルの平均を面に入れる変形（ノート104 の「次」）を検討する。
- **S5 が不成立**（最小特異値が 0）：任意の双対セルの運動量を面の速度と一対一に対応させる方式は不採用。運動量が部分空間に制約される方式と、補助モーメントつきの方式は残る（定理 7 の後の表）。
- **S2〜S5 が全て成立**：T3 の結果で T5 に進む候補を選ぶ。その後、Gate 1-A3 の残り（圧力勾配・跳びの精度、balanced-force）、Gate 1-C、Gate 1-D の詳細のタスクを作る。
