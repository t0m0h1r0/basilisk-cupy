# 06 粘性の欠陥補正：split 形

- A_H は CCD の全応力、A_L は Basilisk の fd2 粘性マルチグリッド、GCR で加速する。
- 論文どおりの layered 形（CCD 勾配 → 応力 → CCD 発散）は、κ = νdt/h² ≥ 10 で停滞した。
  - 理由：CCD の1階微分はナイキストモードで記号が 0（θ = π で消える）。D1·D1 はグリッドスケールのモードを素通しにするが、A_L はそれを最も強く減衰させる。補正演算子とのずれが最大になる。
- split 形：同じ軸の項を ∂_b(μ∂_b u) = μD₂u + (D₁μ)(D₁u) とし、交差項だけ layered にする。可変 μ でも全応力のまま。
  - 補正回数（N = 64、壁、白色雑音）：κ = 0.1〜1000 で 13〜23（layered は κ = 10 で 213、それ以上は 300 で未収束）。
- split 形は Basilisk にはない（Basilisk は fd2 の応力のみ）。

## 定式化と理論的根拠
- **欠陥補正の反復と、停滞の理由**：反復の行列は `I − A_L⁻¹A_H`。高次の演算子 A_H と低次の A_L が、すべての波数で近いとき収束が速い。layered 形の D1·D1 は、kh = π で記号が 0（CCD の D1 は中心型で 0）なので、`A_H = I − κD1D1 ≈ I`（格子規模を減衰させない）。A_L（fd2）は格子規模を `1 + 4κ` 倍で最も強く減衰させる。そのモードの反復の行列の値は `1 − 1/(1 + 4κ)`。κ が大きいと 1 に近づき、停滞する（κ = 10 で 0.976）。
- **split 形の導出**：同じ軸の項は、積の微分で `∂_b(μ∂_b u) = μ ∂_bb u + (∂_b μ)(∂_b u)`。第 1 項を CCD の 2 階微分 D2 で取れば、格子規模の記号は 9.6（ノート19）で A_L に近く、反復が収束する。可変の μ でも全応力の式は変わらない（恒等式の書き換え）。
