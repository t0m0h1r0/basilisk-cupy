# 06 粘性の欠陥補正：split 形

- A_H は CCD の全応力、A_L は Basilisk の fd2 粘性マルチグリッド、GCR で加速する。
- 論文どおりの layered 形（CCD 勾配 → 応力 → CCD 発散）は、κ = νdt/h² ≥ 10 で停滞した。
  - 理由：CCD の1階微分はナイキストモードで記号が 0（θ = π で消える）。D1·D1 はグリッドスケールのモードを素通しにするが、A_L はそれを最も強く減衰させる。補正演算子とのずれが最大になる。
- split 形：同じ軸の項を ∂_b(μ∂_b u) = μD₂u + (D₁μ)(D₁u) とし、交差項だけ layered にする。可変 μ でも全応力のまま。
  - 補正回数（N = 64、壁、白色雑音）：κ = 0.1〜1000 で 13〜23（layered は κ = 10 で 213、それ以上は 300 で未収束）。
- split 形は Basilisk にはない（Basilisk は fd2 の応力のみ）。
