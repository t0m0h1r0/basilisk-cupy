# 07 写像格子

- 計量は、同じ CCD/FCCD 演算子で座標そのものを微分して作る → dx/dx = 1 が丸め誤差の精度で成り立つ（GCL）。面の計量は演算子の次数ごとに作る（04）。
- Neumann の壁データは、写像の厳密な dx/dξ で ξ 空間に変換する。FCCD の4次の面計量を使うと、CCD の壁の行が1〜2次落ちる。
- FCCD の Neumann 壁面はデータをそのまま返す。そうしないと4次の面計量が純 Neumann 問題の両立条件を崩し、欠陥補正が 5e-3 で停滞した。
- MonitorMapping はモニタ関数を Boole 則で積分し、エルミート補間で逆写像を作る。論文の台形則では写像が O(Δξ²) で頭打ちになる。
- マルチグリッド：残差の制限は体積重み付き。伸びたセルでは点 red/black が停滞する（tanh β = 2 の 64² で 52 サイクル）ので、壁の軸に沿ったゼブラ線 Gauss–Seidel にした（10 サイクル）。
- 粗いレベル（n < 6）は CCD の計量が作れないので、写像の厳密な微分を使う。
