# 07 写像格子

- 計量は、同じ CCD/FCCD 演算子で座標そのものを微分して作る → dx/dx = 1 が丸め誤差の精度で成り立つ（GCL）。面の計量は演算子の次数ごとに作る（04）。
- Neumann の壁データは、写像の厳密な dx/dξ で ξ 空間に変換する。FCCD の4次の面計量を使うと、CCD の壁の行が1〜2次落ちる。
- FCCD の Neumann 壁面はデータをそのまま返す。そうしないと4次の面計量が純 Neumann 問題の両立条件を崩し、欠陥補正が 5e-3 で停滞した。
- MonitorMapping はモニタ関数を Boole 則で積分し、エルミート補間で逆写像を作る。論文の台形則では写像が O(Δξ²) で頭打ちになる。
- マルチグリッド：残差の制限は体積重み付き。伸びたセルでは点 red/black が停滞する（tanh β = 2 の 64² で 52 サイクル）ので、壁の軸に沿ったゼブラ線 Gauss–Seidel にした（10 サイクル）。
- 粗いレベル（n < 6）は CCD の計量が作れないので、写像の厳密な微分を使う。

## 定式化と理論的根拠
- **GCL（幾何学的保存則）**：計量 x_ξ を、場の微分と同じ演算子で座標 x を微分して作ると、一様な場（u = x の一次関数）の微分が `(∂_ξ x)/x_ξ = 1` で厳密になる。演算子は一次関数を厳密に微分するので、丸め誤差まで成り立つ。
- **Boole 則と台形則**：写像は、モニタ関数の積分 `ξ(x) ∝ ∫ w dx` で作る。台形則は 2 次（誤差 O(Δξ²)）で、写像の計量の精度がそこで頭打ちになる。Boole 則は 6 次。
- **伸びたセルで点の緩和が停滞する理由**：異方的な問題（片方向の格子が細かい）では、細かい方向の結合が強く、点ごとの緩和はその方向の誤差を滑らかにしない（平滑化の係数が 1 に近づく）。強く結合した方向の線ごとに解く（ゼブラ線の Gauss–Seidel）と、その方向が厳密に解かれ、平滑化が回復する。
- **Neumann の壁データをそのまま返す理由**：純 Neumann 問題の両立条件（右辺の積分 = 境界の流束の積分）は、境界の流束を厳密に保つ必要がある。4 次の面計量で変換すると、流束が O(h⁴) だけ変わり、両立条件が崩れて欠陥補正が停滞する（5e-3）。
