# 40. 粘性のジャンプ補正（IIM 型）の試行：採用しない

> **追記（41）：** 4 節の「高さ関数の曲率で減衰誤差が下がる」は、曲率が正確になったためではない。厳密な線形曲率でも ψ 曲率と同じ不足が出る。高さ関数の曲率の余分な数値減衰が、運動学の不足を打ち消していた。

38 で、毛管波の減衰不足は界面での渦度の尖りがセル中心に乗らないためと分かった。等しい粘性の 2 流体では [∂²ₙu_τ] = ∂_τ j/μ（j は GFM のジャンプ）である。
この既知の跳びを差し引いて粘性演算子を補正する方法（IIM 型のジャンプ補正）を試した。**採用しない**。仮説と異なる結果として記録する。

- スクリプト：`cases/jump_viscous.py`（補正）、`cases/jump_frozen_layer.py`（固定界面）、`cases/jump_correction_figures.py`
- 図：`docs/figures/jump_correction.png`

## 方法
- 折れ目を J = H·J⁺ と書く。H は液相の指示関数（ψ > ½）である。
  - J⁺ = ∇⊥Ψ⁺、Ψ⁺ = −A χ d³/6、A = τ·∇j/μ、χ = exp(−(d/2h)²)、d は CLS の符号付き距離（液相で正）。
  - J は発散ゼロで、接線成分は A d²/2 になる。そのため [∂²ₙJ_τ] = A を持つ。
  - d = 0 で Ψ⁺ = O(d³) なので、∇⊥ の H の微分からデルタ関数の項は出ない。
- 補正した演算子は L_h(u − J) + L(J) で、L(J) = H·L(J⁺) である。陰的粘性の右辺に、dt/ρ·S を足す。ここで S = μ(H·L_h(J⁺) − L_h(H·J⁺)) である。
- 最初は接線成分だけの J（発散ゼロでない）にした。これでは、全応力の交差項が J の発散を拾い、法線成分の誤差が増えた（fd2：0.017 → 0.095）。そこで流れ関数の形にした。

## 1. 演算子としては合っている
厳密なモードの折れ目を CLS の界面 y = η に合わせた場（F(x, y − η)、N = 32、δ/h = 0.92）で、界面の近く（3 セル以内）の誤差 |L_h u − μ∇²u| を測った。

| | 接線成分（\|μ∇²u\| = 0.66） | 法線成分（0.089） |
| --- | --- | --- |
| fd2 | 0.307 → **0.068** | 0.017 → 0.081 |
| CCD split | 0.132 → 0.131 | 0.038 → 0.059 |

- 係数 A は厳密な跳びと一致する（−129、成分にして +129、厳密 [u_yy] = 131）。
- fd2 の接線成分は 1/4.5 になる。

## 2. 固定した界面：δ/h ≈ 1 では悪化する
平らな界面を固定し、既知のジャンプ j = 0.08 cos kx sin 10t で駆動した Stokes 層（t = 0.9）を、N = 256 と比べた。

| N | δ/h | 補正なし | 補正あり |
| --- | --- | --- | --- |
| 32 | 0.92 | 9.1e-4 | 1.6e-3（悪化） |
| 64 | 1.83 | 6.5e-4 | **3.5e-4** |

- IIM の補正は、折れ目を除いた ũ = u − J が格子で解像されていることを前提とする。
- δ/h ≈ 1 では渦層そのものが 1 セル程度しかなく、この前提が成り立たない。界面の隣のセルの速度は、0.01083 から 0.00892 になり（基準 0.01047）、補正が効きすぎる。

## 3. 界面が動く毛管波：不安定
法線モードから始め、高さ関数の曲率を使った（ψ 曲率でも同じ）。

| N | 補正なし | 補正あり |
| --- | --- | --- |
| 32 | −11.4% | 発散 |
| 64 | −0.6% | 発散（−246%） |
| 32、Δt/4、Δt/16 | −11.6% | 発散 |

- 刻みを 1/16 にしても発散するので、陽的な時間積分の安定限界の問題ではない。補正を入れた半離散系に増大モードがある。
- 補正の大きさを c 倍にすると（N = 32）：c = 1、0.5 で発散・増大、0.25 で −18.4%（悪化）、−0.5 で −7.7%、−1 で発散。
  - 負の向きで良くなるのは、補正の導出とは逆である。物理的な根拠がないので使わない。
- 増大は格子規模の振動として現れる（図 b）。
  - 補正 S は曲率の接線微分 ∂_τ(σκ) を含む。そのため、曲率の格子規模の雑音を 1/h で増幅し、毛管ループに陽的に戻す。
  - 固定界面（2）ではこの帰還がなく、N = 64 で改善した。

## 4. 副産物：曲率の方法で減衰誤差が大きく変わる
38 はすべて ψ 曲率（ψ の CCD 微分）だった。高さ関数の曲率（25）に変えると、次のようになった。

| N、粘性 | δ/h | ψ 曲率（38） | 高さ関数の曲率 |
| --- | --- | --- | --- |
| 32、×0.5 | 0.65 | −27.8% | −22.9% |
| 32、×1 | 0.92 | −16.4% | −11.4% |
| 32、×2 | 1.30 | −9.1% | −5.1% |
| 64、×0.5 | 1.30 | −7.4% | −2.6% |
| 64、×1 | 1.83 | −3.8% | −0.6% |
| 64、×2 | 2.59 | −2.0% | −0.2% |
| 128、×1 | 3.66 | +0.5% | +1.5% |

- 高さ関数の曲率では、同じ δ/h = 1.30 でも N = 32 と 64 で −5.1% と −2.6% になり、δ/h だけでは決まらない。
- **38 の「δ/h だけで決まる」は、ψ 曲率のときの観察である。** 誤差には、渦層の解像度（δ/h）と、曲率の精度（1 波長の点数）の 2 つの源がある。38 の測定では、ψ 曲率の誤差が δ/h とたまたま同じように並んでいた可能性がある。
- 38 の「減衰率の比 ≈ 格子で採った厳密解のエンストロフィーの比」は ψ 曲率の結果である。高さ関数の曲率では、一致しなくなるかもしれない（未確認）。
- N = 128 では高さ関数の曲率で +1.5% と、減衰しすぎの側に出る。

## 結論
- 粘性演算子のジャンプ補正は、演算子としては折れ目の誤差を取り除く（fd2 の接線成分で 1/4.5）。
- しかし、δ/h ≈ 1 では渦層そのものが解像されず、効きすぎる。界面が動くと、曲率の雑音を増幅して不安定になる。**採用しない。** 既定値は変えていない（補正は `cases/` の中だけにある）。
- 減衰精度に効く、より安い手段は曲率の方法だった（N = 64 で −3.8% → −0.6%）。既定の曲率は論文どおり ψ 曲率のままにした。高さ関数の曲率の副作用（静止液滴、密度比、斜めの界面）を定量してから判断する。

## 残り
- 高さ関数の曲率で、38 の診断（エンストロフィーとの一致、CSF との比較）をやり直す。
- 高さ関数の曲率の副作用の定量（静止液滴の寄生流、密度比、斜めの界面、写像格子）。
- ジャンプ補正を続けるなら、A を曲率の微分ではなく GFM の面のジャンプから滑らかに作る（雑音を増幅しない）必要がある。そのうえで、陰的に扱うかエネルギー的に整合させる必要がある。
