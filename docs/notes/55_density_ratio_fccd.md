# 55 密度比のある FCCD の射影：製造解による下調べ（フェーズ1 の残り、PR #69）

## ねらい
論文は高密度比で分相 PPE と HFE を「必須」とする（09c）。実装の前に、既存の形で代替できるかを測る（計画どおり）。

## 製造解（`cases/split_ppe_check.py`）
- 周期の単位正方形、中心に半径 0.25 の液滴、密度 ρ₁（内）/ ρ₂ = 1。
- 任意の滑らかな s に対し、p_k = ρ_k s + j₀ H とすると次が成り立つ。
  - α∇p = ∇s（両相で同じ）なので、法線方向の流束 [α∂ₙp] は連続。
  - ジャンプ [p] = (ρ₁ − ρ₂)s + j₀ は、界面に沿って変化する。
  - div(α∇p) = Δs。
- s = cos 2πx cos 4πy（kx ≠ ky）、j₀ = 4。
- 射影は D_f(α_f G_f p) = D_f u* を解く。u* = α_f B(j) + w_f（w_f は s の厳密な面法線微分）、刻みは 1。射影後の u_f = w_f − α_f(G_f p − B(j)) は厳密には 0 なので、残った |u_f| が「ジャンプを補正した圧力勾配の誤差」＝この問題の寄生流になる。

## 結果（残った面速度の最大値）
| 方式 | 密度比 | N = 32 | 64 | 128 | 次数 |
| --- | --- | --- | --- | --- | --- |
| fd2 の GFM（既定） | 1 | 2.38e-2 | 6.03e-3 | 1.51e-3 | 2.0 |
| | 10 | 4.15e-2 | 1.04e-2 | 2.93e-3 | 1.9 |
| | 1000 | 5.40e-2 | 1.42e-2 | 3.65e-3 | 1.9 |
| FCCD、滑らかな形 p − H j_ext（ノート32） | 1 | 1.33e-4 | 8.47e-6 | 5.31e-7 | **4.0** |
| | 10 | 0.81 | 0.84 | 1.21 | 収束しない |
| | 1000 | 42.6 | 39.1 | 62.1 | 収束しない |
| FCCD、鋭い形（界面越し） | 1 | 4.96 | 9.79 | 20.3 | 発散（∝ 1/h） |
| | 1000 | 665 | 1415 | 3169 | 発散 |

圧力の最大誤差（平均を引いた値）：fd2 は密度比 1 / 1000 で 5.3e-3 → 3.4e-4 / 6.9 → 0.44（2 次。圧力の大きさは 5 / 1000）。FCCD の滑らかな形は、密度比 1 で 2.3e-5 → 9.2e-8（4 次）、密度比 10 では 0.38〜0.45 で止まる。

## わかったこと
- **等密度なら、FCCD の滑らかな形は 4 次で、fd2 の GFM より 180〜2800 倍正確**（N = 32〜128）。
- **密度比が 10 でもう収束しない。** 滑らかな形の p̃ = p − H j_ext は、[α∂ₙp] = 0 のもとで法線微分が (ρ₁/ρ₂ − 1)∂ₙp₂ だけ跳ぶ。その折れ目を、FCCD の大域的な面勾配が界面越しに微分するためと考えられる（密度比 1 では折れ目がなく 4 次）。
- **fd2 の GFM は、密度比によらず 2 次**（面の 2 点の差しか使わず、切断面の係数で [α∂ₙp] = 0 を満たす）。
- **論文の主張（09c：高密度比では界面越しの場の延長が必須）は、FCCD を使う限り成立する。** 滑らかな形（HFE の最低次の延長）では代替できない。

## 次の段（設計の候補）
| 案 | 内容 | 予想される性質 |
| --- | --- | --- |
| A：相ごとの FCCD + GFM の面 | 相の内部の面は FCCD、切断面とその近くの面は fd2 の GFM。FCCD の行列を相ごとに閉じる（界面で片側の閉包） | 内部は高次、界面は 2 次の局所誤差。HFE は不要 |
| B：論文の分相 PPE + HFE | 各相の p を界面越しに Hermite 延長し、相ごとの FCCD の欠陥補正を繰り返す | 論文どおり。延長の精度と反復の収束が課題 |
| C：滑らかな形に密度比の補正 | p̃ の折れ目 [∂ₙp̃] を延長場で差し引く（[α∂ₙp] から法線勾配のジャンプを推定） | 簡単だが、ジャンプの推定に ∂ₙp₂ が要る（反復） |

### 案 A の単純な形の試作（`HybridFaces`、`hyb<m>-sharp` / `hyb<m>-smooth`）
切断面とその m 面以内の面勾配だけを fd2 の 2 点差（GFM）に替え、それ以外の面と発散は FCCD のままにした。N = 32、残った面速度：

| 方式 | m | 密度比 1 | 密度比 1000 |
| --- | --- | --- | --- |
| 鋭い形 | 0 / 2 | 5.34 / 0.618 | 737 / 118 |
| 滑らかな形 | 0 / 2 / 4 | 1.50e-2 / 2.19e-2 / 2.80e-2 | 44.6 / 18.2 / 3.88 |
| （参考）fd2 の GFM | — | 2.38e-2 | 5.40e-2 |
| （参考）FCCD の滑らかな形 | — | 1.33e-4 | 42.6 |

- **単純な面の切り替えは使えない。** 密度比 1000 では、m = 4 でも 3.9 残る（fd2 の 70 倍）。等密度でも、FCCD 単独より 100 倍以上悪い。
- 原因の候補（未確認）：
  - FCCD の面勾配は陰的な（大域的な）演算子で、界面の向こうの値の影響が切り替えた面の外まで届く（m を増やすと減る）。
  - 面ごとに勾配を混ぜると、FCCD の発散と組んだ D_f α G_f が、切り替えの境目で整合しない（等密度での悪化）。
- したがって案 A は、CCD の線の連立方程式を相ごとに閉じる形（界面を内部境界とする片側の閉包）でなければ成り立たない。これは HFE（片側の滑らかなデータ）と同じ問題を、別の手段で解くことになる。

次は、A'（相ごとの片側の閉包を CCD の線の解法に入れる）と B（論文の HFE）を比べる。どちらも本体のコードに手が入るので、設計の確認をとってから進める。

## 再現
`python -m cases.split_ppe_check [--jobs N]`（27 条件、並列、約 1 分）。

### 案 C（ジャンプを高い次数まで差し引く）の試作：使えない
滑らかな形の p̃ = p − H j_ext に対し、ジャンプの延長の作り方と、差し引く次数を変えた。N = 32 / 64 / 128 の残った面速度：

| 方式 | 密度比 1 | 密度比 10 | 密度比 1000 |
| --- | --- | --- | --- |
| 滑らかな形（最も近い交点の値で延長） | 1.3e-4 / 8.5e-6 / 5.3e-7 | 0.81 / 0.84 / 1.21 | 42.6 / 39.1 / 62.1 |
| 同上、発散を単純な面の差に | 同上 | 0.83 / 0.85 / 1.23 | 74 / 76 / 106 |
| 厳密な延長（円の最近点の j、法線方向に一定） | 同上 | 0.34 / 0.58 / 1.15 | 27.0 / 27.8 / 36.8 |
| 案 C：厳密な延長 + 法線微分のジャンプも差し引く（C¹） | 同上 | 0.31 / 0.65 / 1.34 | 4.5 / 4.8 / 2.5 |

- 当初の三つの見立ては、すべて否定された：「折れ目（法線微分のジャンプ）が原因」「FCCD の発散の補正項が原因」「延長が階段状なのが原因」。どれを直しても収束しない。
- **構造：** p_k = ρ_k s + … では、界面での 2 階以上の微分のジャンプもすべて (ρ₁ − ρ₂) に比例する。差し引きで C¹ にしても、2 階微分のジャンプ（密度比 × s″）が残る。FCCD は大域的な高次の演算子なので、これを界面の近くの O(h² × ジャンプ) の誤差に変える。密度比 1000 では h = 1/32 で h²·1000·(2π)² ≈ 40 で、観測（27〜37）と同じ大きさ。C¹ にすると一桁下がる（4.5）のも、この見積もりと合う。
- **結論：** ジャンプを有限の次数まで差し引く方法では足りない。各相の圧力を界面越しに滑らかに延長する（論文の HFE：片側のデータだけから作る）か、相ごとに演算子を閉じる必要がある。論文 09c の「HFE が必須」を、より強く裏づける。

## 案 A′：相ごとの CCD + 高次の GFM 流束（`PhaseCCDFaces`、試作、ユーザーの選択）
「ステンシルを広げない」原則に沿う形として選んだ（ユーザーの判断）。

**演算子（各軸の線ごと）：**
1. 線を切断面で区間に分ける。6 セル以上の区間は、外挿の閉包つきの CCD で f″ を作り、区間の内部の面では FCCD の面勾配を使う（界面の向こうの値に触れない）。5 セル以下の区間は fd2 で、f″ は 2 階差分で作る。
2. 切断面の流束：両側のデータを界面の位置まで Taylor で延ばし、[p] = j と流束の連続を課すと、界面の位置での流束が得られる。

   F_Γ = α_eff (p_R − p_L + j − ((1−θ)h)² f″_R/2 + (θh)² f″_L/2)/h

   2 次の項を落とすと既存の GFM の式になる。
3. 発散が必要とするのは**面の中心の流束**なので、F(x_f) = F_Γ + (½ − θ)h (α p″)_side で補正する（side は面の中心を含む相）。この補正がないと、等密度でも 1 次の誤差が残った（0.90 → 0.52）。
4. **交点のジャンプ j_Γ：** セルの値の線形補間では、誤差 O(h² j″) が密度比に比例して残り、全体を 1 次に落とした。線に沿った CCD のデータ (j, j′, j″) による 5 次の Hermite 補間（コンパクト）にした。

外挿の閉包の精度（端のセル）：f′ が 3 次、f″ が 2 次。

**結果（製造解、圧力の誤差 / 残った面速度、N = 32 / 64 / 128）：**

| 方式 | 密度比 1 | 密度比 10 | 密度比 1000 |
| --- | --- | --- | --- |
| fd2 の GFM（線形補間） | 5.3e-3 / 1.4e-3 / 3.4e-4、u 2.4e-2 → 1.5e-3 | 0.068 / 0.017 / 4.3e-3 | 6.9 / 1.8 / 0.44、u 5.4e-2 → 3.7e-3 |
| fd2 の GFM（Hermite 補間） | 同上 | 0.137 / 0.037 / 9.5e-3 | 15.9 / 4.3 / 1.1、u 0.44 → 0.11 |
| A′ + 線形補間 | 3.9e-4 / 7.1e-5 / 6.8e-6 | 0.13 / 0.034 / 8.8e-3 | 16.4 / 4.2 / 1.1 |
| **A′ + Hermite 補間** | 3.9e-4 / 7.1e-5 / 6.8e-6 | **9.7e-3 / 7.6e-4 / 4.8e-5** | **1.18 / 0.089 / 0.0068** |

（A′ + Hermite の残った面速度は、密度比 10 で 5.8e-2 → 3.5e-3、密度比 1000 で 0.10 → 7.2e-3。厳密なジャンプを与えた場合と同じ値になった。）

- **A′ + Hermite 補間で、圧力は密度比によらず約 3.7 次で収束する。** N = 128 で fd2 の GFM より 160〜200 倍正確。
- 残った面速度（切断面の流束）は 2 次。Taylor の 3 階の項を落としているためと見られる（次の改善点）。
- **fd2 の GFM の良い結果には、打ち消し合いが含まれていた：** 交点のジャンプを正確にすると、かえって悪くなる（密度比 1000 で 0.054 → 0.44）。線形補間の誤差と、2 点差の流束の誤差が打ち消し合っていた。
- まだ試作（周期の線のみ、numpy の線ごとのループ）。壁の線、GPU、毎ステップの射影への組み込み、実際の曲率（帯の外で 0 になる j）でのジャンプの補間が残る。

## 設計案（確認待ち）：B を既存の部品で組む
論文 09b1 の分相 PPE は、各相で ∇²p_k = ρ_k q を解き、界面で [p] = J_p と [ρ⁻¹∂ₙp] = J_n（保存的な離散化では 0）で二つの相をつなぐ。HFE は、CCD のステンシルが不連続に触れないように、片側のデータを界面越しに延長する。

既存の部品で組むなら、欠陥補正の形にする。

| 部分 | 中身 | 既存の部品 |
| --- | --- | --- |
| 低次の演算子（前処理） | fd2 の GFM（切断面の係数）。密度比によらず 2 次で収束 | `project` / マルチグリッド（そのまま） |
| 高次の残差 | 相 k のセルでは、相 k の圧力を界面越しに延長した場 p_k^ext から、D_f^FCCD(ρ_k⁻¹ G_f^FCCD p_k^ext) − q を評価する | FCCD の演算子（相ごとに 2 回） |
| 延長（HFE） | 界面の交点の値（隣の相の p にジャンプを足したもの）と、相 k の側の法線微分から、法線方向の Hermite（3 次以上）で延長する | 新規。最も近い交点は `extend_jump` と同じ探索で作れる |
| 反復 | 欠陥補正。収束の判定は、高次の残差で行う | `defect_correction` を一般化 |

確かめる順：
1. 製造解で延長の精度（次数）を測る。
2. 欠陥補正の収束を測る。
3. 残った面速度の次数（目標は密度比によらず 4 次）を測る。
4. 静止液滴と毛管波で比べる。
