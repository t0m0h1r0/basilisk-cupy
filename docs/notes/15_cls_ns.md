# 15 CLS の二相 NS への組み込み（PR #30）

## 方法
`TwoPhaseCLS(ns, cls, ...)` は VOF 版 `TwoPhase`（two-phase.h＋iforce.h の移植）と同じ結合で、体積率 f を ψ に置き換えたもの。VOF 版との差は界面の表し方だけ。

| 項目 | 内容 |
| --- | --- |
| 輸送 | `cls.advect(ns.uf, dt)`（段階 A、B）。ステップの最初に前の dt で行う（Basilisk の `vof(i++, first)` と同じ）。`reinit_every` で再初期化 |
| 物性 | ρ = ρ₂ + (ρ₁ − ρ₂)ψ。面では ψ の算術平均から α = 1/ρ と μ を作る（論文 06d も CLS では算術平均が基準） |
| 表面張力 | CSF σκ∇ψ（論文 02b、09）。iforce.h の面形式 α_f σκ_f (ψ_R − ψ_L)/Δ で balanced force。κ は 14 の ψ 曲率（界面帯の外は 0）、κ_f は面平均 |
| 換算重力 | φ = [ρ]G·(x − Z) をセル中心で評価（∇ψ が界面に局在させる） |

## 静止液滴（R = 0.25、σ = 1、μ = 0.1、10 ステップ）
圧力ジャンプ（理論 σ/R = 4）と寄生流の最大値：

| N | 64 | 128 | 256 |
| --- | --- | --- | --- |
| VOF（高さ関数） | 4.0138 / 4.2e-3 | 4.0043 / 2.0e-3 | — |
| CLS、ψ_min = 0.01（論文） | 4.0230 / 3.2e-4 | 3.9410 / 1.7e-4 | 3.9228 / 1.3e-4 |
| CLS、ψ_min = 1e-4 | 4.1299 / 5.2e-5 | 4.0298 / 1.4e-5 | 4.0067 / 4.7e-6 |

- ψ_min = 0.01 では、界面帯の外の ∇ψ（両側 1% ずつ）に κ が乗らないので、ジャンプは 2% 小さい値（0.98 × 4 = 3.92）に収束する。論文は「この閾値選択に対するロバスト性は高い」としている。
- ψ_min = 1e-4 なら 2次で 4 に近づく。差は CSF のモデル誤差（拡散した力を 1/r で重み付けするため O((ε/R)²)）。
- 寄生流は VOF より1桁以上小さい。ただし VOF は時間とともに減衰する（400 ステップで 6.1e-8）のに対して、CLS は残る（N = 64 で 2.4e-4）。
- ξ-SDF を 10 ステップごとにかけると、寄生流が 3.8e-2 になる（100 倍）。圧縮・拡散なら 4.1e-4。
- 密度比 10（ρ₂ = 0.1）でもジャンプは同じ。
- 質量は丸め誤差まで保たれる。

## 毛管波（Basilisk capwave.c、Prosperetti の解との相対 RMS 誤差）
振幅は ψ = 1/2 の交差の最大値。

| 1波長の点数 | 8 | 16 | 32 |
| --- | --- | --- | --- |
| VOF | 0.1386 | 0.0242 | 0.0064 |
| CLS（ψ_min = 0.01） | 0.355 | 0.315 | 0.236 |
| CLS（ψ_min = 1e-4） | 0.356 | 0.317 | 0.238 |
| CLS（圧縮・拡散、10 ステップごと） | 0.264 | 0.263 | 0.217 |
| CLS（ξ-SDF、10 ステップごと） | 0.290 | 0.264 | 0.194 |

- 原因は周波数のずれ。CLS の波は遅い。半周期（ω₀t）は 4.79 / 4.05 / 3.70 で、Prosperetti の解は 3.456（+39% / +17% / +7.1%、kε = 0.59 / 0.29 / 0.15）。
- 1波長 32 点で ε を変えても、ずれは kε だけで決まる：ε/Δ = 0.75 / 1.0 / 1.5 / 3.0 で半周期 3.76 / 3.84 / 4.05 / 4.72。1波長 64 点・ε = 1.5Δ（kε = 0.15）の 3.70 は ε = 0.75Δ の 3.76 とほぼ同じ。
- つまり、CSF で力を幅 ε に広げたこと自体のモデル誤差である。表面張力が界面から離れたところに働くので、復元力が実効的に弱くなる。
- 次数は kε についておよそ 1.2 次。論文（02b）の「O(ε²)」より低い。
- 鋭い圧力ジャンプ（分相 PPE＋GFM、次の段）が必要になる理由。
