# 63 相ごとの CCD：静止液滴の精度の床は曲率、毛管波の減衰の要因（PR #74）

## 定式化と理論的根拠
### 跳びが一定ならどの面の演算子でも厳密に釣り合う理由（1 節のオラクル）
面の加速度は `α_F (G p − B(j))`、`B(j) = j (H_R − H_L)/Δ`（ノート61）。j が一定（j₀ = 4σ）なら、`p = j₀ H + 定数` で、すべての面で次が成り立つ：

```
G p = j₀ (H_R − H_L)/Δ = B(j₀)
```

面の加速度は 0、u = 0 が定常解になる。α_F の取り方にも、`phase-ccd` の Taylor の項（相ごとに一定の p では 0）にもよらない。測定の丸め誤差（4.0000000000001、寄生流 1.8e-13）はこの帰結。

したがって、静止液滴の誤差は、界面に沿った j の変化（曲率の誤差）だけから来る。

### φ（ロジット）の曲率が頭打ちしない理由
CLS の ψ は幅 ε（= 1.5h、h に比例）の tanh 型の分布。格子を細かくしても、分布を表すセルの数は一定なので、ψ の微分の相対的な打ち切り誤差は h とともに減らない。曲率 `κ = ∇·(∇ψ/|∇ψ|)` は、この誤差を受け継ぐ（ノート14）。

ロジット `φ = ε ln(ψ/(1 − ψ))` は、ψ が厳密な tanh 型なら符号付き距離そのもの（界面を横切って線形）。CCD は線形の関数を厳密に微分するので、法線方向の分布の誤差が消え、曲率の誤差は界面の形の近似だけになる。N とともに減り続けたこと（2.2 次）と整合する。ψ が tanh 型からずれる（輸送・再初期化の後）と、この利点は弱まる。動く界面で効かなかったこと（5 節）は、これと矛盾しない。

### 射影の検査（5 節の `--projection`）の論理
射影 `u ← u − α_F G p`、`D(u − α_F G p) = 0` は、G が発散 D の負の随伴（ρ で重み付けた内積について `Gᵀ = −D` の形）なら、ρ で重み付けた運動エネルギーのノルムでの直交射影になる。

- 直交射影なら、エネルギーは増えない。
- 2 回かけても変わらない（冪等）。

乱数の面速度で、エネルギーが減り（0.53〜0.62 倍）、2 回目でほぼ変わらない（1.00015 倍以内）ことは、直交射影に近いことを示す。随伴でないことによる増幅は、射影だけでは起きていない。ただし、これは 1 つの界面の形での数値的な確認で、一般の証明ではない。

### 未解明の点
- 毛管波の減衰が `phase-ccd` で増える理由。
- 振動液滴で `phase-ccd` が密度比の大きいときに発散する理由。

どちらも理論的な説明はない（本文の候補は仮説）。

## 1. 静止液滴の精度の床は曲率の誤差
厳密な曲率（帯の中で κ = 4 を与えるオラクル）にすると、`phase-ccd` の静止液滴（密度比 1000、N = 32）は、ジャンプ 4.0000000000001、寄生流 1.8e-13 で、丸め誤差の範囲で釣り合った。ジャンプが一定なら、圧力は相ごとに一定になり、射影はどの方式でも厳密になる。

- **静止液滴のジャンプの誤差と寄生流は、すべて曲率の誤差から来る。** ノート61 の「N = 128 の頭打ちは曲率の誤差が床」を確かめた。
- 面の演算子の違いは、曲率の誤差（界面に沿って変わるジャンプ）にどう反応するかの違いにすぎない。

### 曲率の方法ごとの比較（静止液滴、密度比 1000、t = 0.5、`cases/phase_ccd_check.py --curvature-scan`）
ジャンプの誤差（4 からの相対）：

| 曲率 | 面の演算子 | N = 32 | 64 | 128 | 寄生流の最大（N = 128） | 時間（N = 128、CPU） |
| --- | --- | --- | --- | --- | --- | --- |
| ψ の CCD（既定） | fd2 | +2.63e-3 | +7.54e-4 | +2.66e-4 | 3.3e-5 | 710 秒 |
| ψ の CCD | phase-ccd | +5.38e-4 | +2.14e-4 | +1.68e-4（頭打ち） | 6.1e-5 | 1843 秒 |
| φ（ロジット）の CCD | fd2 | +2.59e-3 | +6.38e-4 | +1.52e-4 | 1.6e-5 | 666 秒 |
| **φ（ロジット）の CCD** | **phase-ccd** | **+4.90e-4** | **+4.66e-5** | **+9.95e-6** | **1.7e-5** | 1567 秒 |
| 高さ関数（fd2） | fd2 | +3.25e-3 | +8.16e-4 | +2.07e-4 | 2.5e-5 | 610 秒 |
| 高さ関数（fd2） | phase-ccd | +4.22e-3 | +1.95e-3 | −2.13e-3 | 1.1e-3 | 5811 秒 |
| 高さ関数（CCD） | fd2 | +2.14e-4 | −3.78e-4 | −4.48e-5 | 9.8e-6（N = 32 は 4.8e-3） | 2027 秒 |
| 高さ関数（CCD） | phase-ccd | +2.93e-3 | −1.35e-3 | −9.84e-4 | 3.1e-4 | 5567 秒 |
| 厳密（オラクル） | fd2 / phase-ccd | 丸め誤差 | | | 6.5e-14 / 5.7e-9 | |

- **φ（ロジット）の曲率と phase-ccd の組み合わせで、頭打ちが消える。** N = 128 でジャンプの誤差は 9.95e-6 で、既定（ψ + fd2）の 27 倍正確。次数は 3.4 → 2.2。寄生流も 1.7e-5 と小さい。
- φ の曲率は fd2 の面でも 2 次で、既定よりやや良い。
- 高さ関数の曲率は phase-ccd と相性が悪い（ジャンプが振動し、寄生流が 1e-3）。CCD の高さ関数は fd2 の面でも、粗い格子で寄生流が大きい（N = 32 で 4.8e-3）。
- 演算子の精度を活かすには、曲率も同じ次数で滑らかでなければならない。ψ の曲率（ε = 1.5h で O(h⁻¹) 型の誤差、ノート14）は φ の曲率より精度が落ちる。

## 2. 毛管波の減衰が大きくなる要因（`cases/phase_ccd_factors.py`）
論文の毛管波（水–空気、32²、輸送 ab2、ξ-SDF を 10 ステップごと）。法線モードは β = −0.803 s⁻¹。

| 面の演算子 | CLS の発散 | ジャンプの補間 | β（物理の倍率） | ω の誤差 |
| --- | --- | --- | --- | --- |
| fd2 | fccd | 線形 | −0.40（0.50 倍） | −9.30% |
| fd2 | fccd | Hermite | −1.50（1.87 倍） | −9.45% |
| fd2 | full | 線形 | −0.15（0.19 倍） | −9.10% |
| fd2 | full | Hermite | −1.35（1.68 倍） | −9.22% |
| phase-ccd | fccd | 線形 | −3.15（3.92 倍） | −8.26% |
| phase-ccd | fccd | Hermite | −4.45（5.54 倍） | −8.63% |
| phase-ccd | full | 線形 | −3.00（3.74 倍） | −7.95% |
| phase-ccd | full | Hermite | −4.35（5.42 倍） | −8.41% |

- **最も大きい要因は、面の演算子そのもの**（fd2 → phase-ccd で β が −2.6〜−3.0 増える）。
- 次が交点のジャンプの Hermite 補間（−1.1〜−1.4）。曲率は帯の外で 0 なので、帯の端の値で一定に延ばしてから CCD をかけている。その延長の不連続な微分が雑音になっている可能性がある（未確認）。
- CLS の輸送の発散（fccd と full）の違いは小さい（±0.25）。
- 周波数は、phase-ccd で約 1 ポイント良くなる。
- 面の演算子がなぜ減衰を増やすのかは、まだ分からない（候補：切断面の Taylor の項が、時間とともに動く界面で雑音を増幅する）。

`TwoPhaseIMEX` に、CLS の発散（`cls_divergence`）とジャンプの補間（`jump_interp`）を指定する引数を加えた（既定は従来どおり）。

## 3. 振動液滴の格子の収束（`cases/phase3_drop_convergence.py`）
基準は 2 次元の粘性つきのモード β = −0.179 s⁻¹、ω = 59.555 s⁻¹（ノート62）。2 周期、β の当てはめの刻みは 0.05 s⁻¹。

| 方式 | N = 32：β / ω の誤差 | N = 64 | N = 128 |
| --- | --- | --- | --- |
| VOF | +0.05 / −1.71% | 0.00 / −1.04% | −0.10 / −0.71% |
| CLS（ab2 + ξ-SDF 10 ステップごと + 高さ関数の曲率） | −0.45 / −5.13% | −0.70 / −3.38% | −0.70 / −2.46% |

- 周波数は、どちらも格子とともに縮む（約 0.5〜0.6 次）。VOF の方が 2〜3 倍正確。
- VOF の減衰は基準（−0.179）に近づく。**CLS の減衰は N = 64・128 で −0.70（物理の 3.9 倍）のまま縮まない。**

### 再初期化の回数は主因ではない
「10 ステップごとの再初期化は、格子を細かくすると同じ時間あたりの回数が増え、そのたびに減衰を足す」という見立てを確かめた。

| N | 再初期化の間隔（ステップ） | β（物理の倍率） | ω の誤差 |
| --- | --- | --- | --- |
| 64 | 10 / 20 / 60 | −0.70 / −0.65 / −0.50（3.9 / 3.6 / 2.8 倍） | −3.38 / −3.46 / −3.55% |
| 128 | 10 / 60（N = 32 の 10 と同じ物理時間の間隔） | −0.70 / −0.70 | −2.46 / −2.38% |

- N = 64 では回数を減らすと減衰が少し下がるが、N = 128 では変わらない。**見立ては否定された。** 細かい格子で残る過大な減衰の原因は未解明（候補：高さ関数の曲率、CLS の輸送）。

### 要因の切り分け（N = 64、`cases/phase3_drop_factors.py`）
| 輸送 | 高さ関数の差分 | 再初期化 | β（物理の倍率） | ω の誤差 |
| --- | --- | --- | --- | --- |
| ab2 | fd2 / CCD | ξ-SDF 10 | −0.70 / −0.70（3.9 倍） | −3.38 / −3.46% |
| frozen | fd2 / CCD | ξ-SDF 10 | −0.55 / −0.55（3.1 倍） | −3.46 / −3.46% |
| ab2・frozen | fd2・CCD | なし | 4 条件すべて発散 | — |

- 高さ関数の差分（fd2 か CCD か）は影響しない。
- 輸送の ab2 は、frozen より減衰を増やす（−0.55 → −0.70）。
- 再初期化なしでは、高さ関数の曲率でも発散する（ノート57 と同じ）。
- どの組み合わせでも物理の約 3 倍の減衰が残り、原因は特定できていない。VOF（同じ N で −0.10 から 0.00）との違いは、界面の表し方そのものにある可能性が高い。

## 4. 上昇気泡の論文との差は、格子でも方式でも説明できない（`cases/phase3_bubble128.py`）
t = 0.03 s の泡の重心（初期 5 mm）：

| 方式 | N = 32 | 64 | 128 |
| --- | --- | --- | --- |
| CLS（ab2 + ξ-SDF 10） | 6.933 mm | 7.028 | 7.026 |
| VOF | 6.989 mm | 6.999 | 7.003 |
| 論文（32 × 64、α = 2 の界面適合格子） | 7.350 mm | | |

N = 128 の平均上昇速度は CLS 0.0675、VOF 0.0668 m/s、変形量 D は 0.304 / 0.273（GPU で 67 / 51 秒）。

- 本移植の重心は、格子（N = 32〜128）と方式（CLS・VOF）について 7.00〜7.03 mm に収束している。論文の 7.350 mm は、そこから 0.33 mm（上昇距離の約 16%）離れ、格子の解像度では説明できない。
- 壁の条件も逆向き：本移植は滑り（Basilisk の既定）、論文の設定は滑りなし（`wall_condition: no_slip`）で、滑りなしなら上昇は小さくなるはず。
- 論文の値は、自身の重心と平均上昇速度とも整合しない（ノート59）。**論文の数値に誤りがある可能性が高い。** 論文の実装は 14 章の設定で動かないので、直接は確かめられない（ノート62）。

## 5. φ の曲率は動く界面では効かない（`cases/phi_curvature_dynamics.py`）
静止液滴で最良だった φ（ロジット）の曲率を、論文の毛管波（5 周期）と振動液滴（2 周期）で試した（水–空気、輸送 ab2、ξ-SDF を 10 ステップごと）。

| 面 / 曲率 | 毛管波 N = 32：β（倍率）/ ω の誤差 | N = 64 | 液滴 N = 32 | N = 64 |
| --- | --- | --- | --- | --- |
| fd2 / ψ（既定） | −0.40（0.50 倍）/ −9.30% | −1.15（1.43 倍）/ −4.22% | +0.80（増幅）/ −2.55% | +1.60（増幅）/ −1.38% |
| fd2 / φ | −0.40 / −9.30% | −1.15 / −4.22% | +1.10（増幅）/ −3.38% | +3.55（増幅）/ −2.55% |
| phase-ccd / φ | −4.35（5.4 倍）/ −8.45% | −1.90（2.4 倍）/ −3.48% | 発散（91 ステップ） | 発散（197 ステップ） |

- 毛管波では、ψ と φ の曲率は表示の桁まで一致する。初期の帯の中で曲率の差は最大 0.014（曲率 91 に対して）で、ほぼ平らな界面では両者は同じ。
- 液滴では、φ の曲率でも振幅が増える（ノート59 の ψ の曲率と同じ）。静止液滴の精度の改善は、動く界面の安定には結びつかない。
- **phase-ccd は、水–空気の振動液滴で発散する。**

### phase-ccd の発散の切り分け（液滴、N = 32、φ の曲率、`cases/phase_ccd_drop_stability.py`）
半周期までの最大速度：

| 変えたもの | 結果 |
| --- | --- |
| なし（密度比 830） | 73 ステップ（0.28 周期）で発散 |
| 密度比 1 / 10 | 0.5 周期まで安定（最大速度 0.05 / 0.07） |
| 毛管の刻み × 0.25（N = 32 / 64） | 117 / 286 ステップ（0.18 / 0.17 周期）で発散 |
| 圧力の許容誤差 1e-8 → 1e-10 | 変わらない（73 ステップで発散） |
| 輸送 frozen | 55 ステップで発散 |
| 曲率 ψ / 高さ関数（fd2） | ψ は 0.37 周期で発散、高さ関数は 0.5 周期まで持つが最大速度 0.25（fd2 の面の約 2.5 倍） |
| 再初期化を毎ステップ（ψ / φ / 高さ関数） | 0.19 / 0.13 / 0.32 周期で発散（10 ステップごとより早い） |

- **発散は密度比で起き、曲率・刻み・許容誤差・輸送では止まらない。** 刻みを小さくしても止まらないので、時間積分の安定条件ではない。
- 静止液滴（密度比 1000）と、ほぼ平らな毛管波では安定なので、**閉じた界面が動いて切断面の構造が変わること**と密度比の組み合わせで起きている（原因の特定は未完）。
- 面の射影だけでは増幅しない：20 ステップ進めた液滴の界面で、乱数の面速度に射影を当てると、ρ で重みづけた運動エネルギーは 0.53〜0.62 倍に減り（fd2 は 0.51〜0.56 倍）、2 回目の射影でのエネルギーの変化は 1.00015 倍以内だった（`--projection`）。**面の勾配が発散の随伴でないことによる増幅、という見立ては、この検査では支持されない。** セル中心の速度の補正（近似射影）やジャンプとの結合が残る候補。
- 実用上：phase-ccd は、密度比の大きい動く閉じた界面には使えない。既定の fd2 のまま。
