## 定式化と理論的根拠
### A. 次数の読み方
界面の位置 a が固定でも、セル内の位置 `aN − ⌊aN⌋` は N ごとに変わる。界面の近くの誤差の定数はこの位置に依存するので、3 点の傾きは偶然に左右される（例：粘度一定・1e3、D の最大誤差は N = 40 で 7.0e-6、48 で 1.8e-5）。そのため、多くの N と複数の界面の位置で測り、位置について最悪の値の最小二乗の傾きを読む。

### B. 可換な問題では分割の誤差が出ない（監修 #120、ユーザー）
Galilean boost の解では、共動座標で並進と粘性が可換である。粘性の半ステップは時間について厳密に積分しているので、連続の水準の分割の誤差は 0 である。

離散では、Galerkin の移流は射影を含み、`T_{Δt/2}² ≠ T_{Δt}` である。粘性の写像 `exp(−Δt G_A⁻¹K_ν)` も、界面の移動で G_A と K_ν が変わるので、移流と可換ではない。この試験で時間刻みに依存して出る差は、こうした離散の非可換性による（未確認の解釈）。

一般の時間精度は、移流と拡散が可換でない問題で測る必要がある。例：`A = −U(y)∂_x`、`B = νΔ` では `[A, B] = ν(U''∂_x + 2U'∂_xy) ≠ 0`（ユーザー）。

### C. 始動流の厳密解
壁の間（u = 0）で、静止から一定の体積力を加える。壁のモード φ_k は ρ の重みで直交するので：

```
u(x, t) = u_s(x) − Σ_k c_k e^{−λ_k t} φ_k(x),   c_k = ∫ρ u_s φ_k / ∫ρ φ_k²
```

u_s は定常解（ノート101）。モードは `e^{−λ_k t} < 1e-26` になるまで取る（水・空気・密度比 1 では 160 個）。

- 最初の実装は、モードを 40 個で打ち切っていた。軽い相の粘度が小さい条件（水・空気・密度比 1）では打ち切りの誤差が残り、最も細かい格子で次数が見かけ上落ちた。モードの数を増やすと直った（監修 #115 の「参照解の精度を確かめよ」に対応）。
- 離散は C（`G_ν q̇ = −K_ν q + F_eff`）で、補正なし（`F_eff = F`）と補正あり（`F_eff = F + D_bᵀH⁻¹d`、ノート102）を比べる。

### D. 固有ベクトルの混合（ユーザーの P0）
単相の二次元の記号では、微分の記号 c が純虚数なので、K は実対称になり、固有ベクトルは振幅 (α, β) の実の方向である。遅い（発散 0 の）固有ベクトルと k̂ の内積を、横波から縦波への漏れとして測る。

## まとめ
- **D は 4 次の粘性の方式ではない**（最大誤差 2.4〜3.3 次、残差 1 次）。監修の測定と一致した。D は暫定の方式、C は高次の参照解法、P1-A は未完了（ユーザーの判断）。
- **移流と粘性の統合**（boost）は、エネルギー・運動量・Gram の一致を（最後の更新と周期の境目を含めて）保つ。次数は D に支配されて 2.7〜3.3 次。
- **時間刻み**：この可換な問題でも、時間刻みを細かくした解との差は 1 次程度でしか縮まない。連続の分割の誤差ではない。一般の時間精度は未検証。
- **体積力の補正**は、非定常の始動流でも約 4 次（補正なしは 2 次）。

## 未検証・次
- 時間刻みの差の原因（離散の非可換性の内訳）。非可換なせん断流 + 拡散での分割の誤差（Gate 1-C）。
- D の精度の低下の原因の切り分け：セル単位の Gram の混合 `G_mix = Σ_i [(1 − χ_i)G_A,i + χ_iG_ν,i]` で、界面から 0、1、3、6 セル、全体を置き換える。セル数で固定した距離と、物理的な距離を分けて測る（ユーザー、Gate 1-D）。
- 始動流の動粘度一定の、界面の位置への強い依存。
