# 67 VOF + 相ごとの CCD（段階 C）、phase-ccd の発散と過大な減衰の原因（PR #76）

## 定式化と理論的根拠
### VOF の輸送のためにもう一度射影する理由
vof.h の掃過は、面の速度の fd2 の発散 `Σ_F u_F·n_F h = 0` を前提にする。分割の各掃過で c は `c ← c + Δt[(F_lo − F_hi) + cc·div u]/h` で変わる（ノート77）。発散が 0 なら、2 方向の掃過の後に `cc·div u` の項が打ち消し合い、体積が保存される。

phase-ccd の射影は FCCD の発散を 0 にするので、fd2 の発散は O(h^p) で 0 にならない。そのまま運ぶと、体積の保存が崩れる。fd2 の GFM の演算子で同じ面の速度を射影し直せば、fd2 の発散が（Poisson の許容誤差まで）0 になる。そのため、体積の変化は許容誤差の大きさになる（測定 3e-12〜5e-12）。

運動量の射影を phase-ccd のまま残すのは、高次の圧力の勾配を運動量の側で使うため。輸送の速度と運動量の射影の速度は、許容誤差を越えて O(h^p) だけ異なる。その影響は評価していない。

### `"cut"` の係数が発散を止める理由（解釈）
ノート65 の機構（切断面の GFM の係数を軽い側のセルに配ると、セルの速度が面の速度と食い違う）が、phase-ccd の大きな面の勾配と組み合わさって、陽的な帰還が増幅になっている、と解釈した。切断面だけ平均の係数にすると止まることが根拠で、帰還の増幅率は解析していない。

### Taylor の項が散逸を生む機構
**未解明。** 確かめたのは次の 3 つ：

- 密度比 1 では起きない。
- 受け渡し（`transfer`）を fd2 にしても直らない。
- Taylor の項（切断面での 2 階・3 階の項と面の中心への移動）を外すと消える。

候補は、次の 2 つの組み合わせ：
- 密度で割った高階の Taylor の項が、界面が動くたびに切断面の構造が変わる（1 セル単位で飛ぶ）ことで、時間的に不連続な力を入れる。
- 跳びのない相の側の勾配が、密度比で増幅される。

どちらも確かめていない。静止の精度（製造解の 3 次）と動く界面の散逸の取り引きは、測定の事実として記録する。

## 1. VOF-GFM と phase-ccd の組み合わせ
- `TwoPhaseIMEX(interface="vof-gfm", faces="phase-ccd")` を使えるようにした。phase-ccd の CCD の区間は、鋭いジャンプの切断面で閉じるので、切断面を持たない CSF（`interface="vof"`）とは組み合わせない（`NotImplementedError`）。
- phase-ccd の射影は FCCD の発散を 0 にするので、面の速度の fd2 の発散は 0 にならない。vof.h の輸送は fd2 の発散が 0 であることを前提にする（体積の保存）。そこで、**VOF の輸送に使う面の速度だけ、fd2 の GFM の演算子でもう一度射影する**（`TwoPhaseIMEX._fd2_project`、Poisson の解 1 回分の追加）。運動量の射影は phase-ccd のまま。
- 静止液滴（N = 32、t = 0.1、`tests/test_two_phase_imex.py`）：

| 面 | 密度比 | ジャンプ | 寄生流（終わり / 最大） | 質量の相対変化 |
| --- | --- | --- | --- | --- |
| fd2 | 1 | 4.04090 | 2.91e-4 / 4.82e-3 | 4e-15 |
| fd2 | 1000 | 4.04072 | 2.19e-4 / 7.33e-3 | 7e-16 |
| phase-ccd | 1 | 4.04095 | 2.95e-4 / 5.31e-3 | 5e-12 |
| phase-ccd | 1000 | 4.04357 | 1.19e-3 / 8.00e-3 | 3e-12 |

- 密度比 1000 まで安定。質量の変化は、もう一度の射影の許容誤差（1e-8）の大きさ。
- ジャンプの誤差は fd2 と同程度：静止液滴の誤差は曲率で決まる（ノート63）。

| N | `"gfm"`（既定） | `"cut"`（切断面だけ平均の係数） | `"mean"`（全部の面） |
| --- | --- | --- | --- |
| 32 | 94 ステップ（0.24 周期）で発散 | **0.5 周期まで安定（0.058）** | 安定だが 0.39 |
| 64 | 96 ステップ（0.09 周期）で発散 | **0.5 周期まで安定（0.15）** | 256 ステップで発散 |

- **phase-ccd + `"cut"` + 高さ関数の曲率は、液滴を 2 周期まで安定に解き、N = 64 で周波数の誤差 −0.88%（VOF の −1.04% より小さい）、CLS の過大な減衰（3.9 倍）も出ない**（液滴の β は ±0.5 ぶれるので、減衰の評価は粗い）。ただし最大速度は 0.11 で、fd2 の約 3 倍。
- φ の曲率とでは N = 64 で発散する（1001 ステップ）。`"cut"` で安定になるのは高さ関数の曲率とのときだけ。
- 毛管波では `"cut"` と `"gfm"` はほぼ同じ。`"cut"` は発散を止めるが、phase-ccd の毛管波の過大な減衰は直さない。

### phase-ccd の過大な減衰の切り分け
- **セルと面の受け渡しを fd2 にしても直らない**：`interp_f`・`face_to_cell` を fd2 の 2 点平均にした phase-ccd（`PhaseCCDFaces(transfer="fd2")`）は、毛管波 N = 32 で 6.79 倍 / −10.30%（FCCD の受け渡しで 5.42 倍 / −8.45%）。密度で跳ぶ g を高次で補間する振動、という見立ては否定された。
- **密度比 1 では過大な減衰は出ない**（CLS、φ の曲率、毛管波、`cases/cls_cell_coefficient.py --ratio1`、基準 β = −2.269）：

| 面 | N = 32：β 倍率 / ω の誤差 | N = 64 |
| --- | --- | --- |
| fd2 | 0.20 倍 / −7.34% | 0.55 倍 / −2.34% |
| phase-ccd | 1.08 倍 / −6.78% | 0.75 倍 / −1.55% |

  密度比 1 では phase-ccd の方が fd2 より正確。過大な減衰は密度比と phase-ccd の組み合わせで出る。VOF + phase-ccd はセル中心の補正がすでに平均の係数（ノート65）なので、残る候補は phase-ccd の切断面の勾配（密度で割る Taylor の項）。
- **原因は切断面の Taylor の項だった**：切断面の勾配から、両側の 2 階・3 階の Taylor の項と面の中心への移動（ノート55・61 で静止液滴の製造解の 3 次のために入れたもの）を外し、GFM の差だけにした（`PhaseCCDFaces.taylor = False`、区間の中の CCD はそのまま）。VOF-GFM の毛管波：

| 面 | N = 32：β 倍率 / ω の誤差 | N = 64 |
| --- | --- | --- |
| fd2（ノート65） | 0.25 倍 / −4.91% | 0.37 倍 / −1.44% |
| phase-ccd（Taylor の項あり） | 10.1 倍 / −10.02% | 10.0 倍 / −5.30% |
| **phase-ccd（Taylor の項なし）** | 0.12 倍 / **−1.63%** | 0.50 倍 / **−0.48%** |
| （参考）VOF on IMEX、CSF | 2.05 倍 / −3.98% | 1.18 倍 / −1.33% |

  過大な減衰は消え、**周波数の誤差はこれまでのどの構成よりも小さい**（N = 64 で −0.48%）。Taylor の項は、密度比のある動く界面で O(1) の散逸を生んでいた。

| VOF、CSF、fd2 の面（ノート64） | 2.05 倍 / −3.98% | 1.18 倍 / −1.33% | / −1.54% | / −1.04% |

- **毛管波・液滴とも、これまでで最も正確**。液滴の減衰も物理に近い（0.84 倍、ただし ±0.5 のぶれ）。最大速度 0.035〜0.040（fd2 と同じ）。

### 静止液滴（φ の曲率の CLS、密度比 1000、t = 0.5、`phase_ccd_check.drop(taylor=False)`）

- Taylor の項は静止液滴の精度を 4 倍上げていた（製造解で 3 次にするための項）。外しても fd2 よりは正確で、厳密な曲率なら丸め誤差で釣り合う。**静止の精度と、動く界面の散逸の取り引き**になっている。

## 4. CLS の振動液滴の過大な減衰と、ぼやけた粘性（`cases/cls_drop_viscosity.py`）
ノート63 の CLS の液滴の過大な減衰（物理の 3.9 倍）が、帯の中でぼやけた粘性 μ(ψ)（水–空気で 55 倍の比）から来るかを試した。面の粘性を、切断面の判定で決まる鋭い値（`mu1`・`mu2`、切断面は両側の平均）に置き換えた（ab2、ξ-SDF 10、高さ関数の曲率、fd2 の面）。

| 粘性の演算子 / μ | N = 32：β 倍率 / ω の誤差 | N = 64 |
| --- | --- | --- |
| CCD / ぼやけた μ(ψ)（既定） | 2.51 倍 / −5.13% | 3.90 倍 / −3.38% |
| fd2 / ぼやけた μ(ψ) | 2.23 倍 / −5.05% | 3.90 倍 / −3.38% |
| fd2 / 鋭い μ | 1.67 倍 / −5.05% | 3.07 倍 / −3.29% |

- 鋭い μ で減衰は減るが、N = 64 でも物理の 3.1 倍が残る。**ぼやけた粘性は過大な減衰の一部（N = 64 で約 2 割）で、主因ではない。**
- 同じ IMEX の経路の VOF（鋭い μ）は液滴の減衰がほぼ物理どおり（ノート64）なので、残りは CLS の界面の表し方（輸送・再初期化・曲率のどれか）にある。
