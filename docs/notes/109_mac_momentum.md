## 定式化と理論的根拠
### A. 変換と定理 7（ユーザー、ノート107 の 5.3 節）
```
(P f)_i = ∫_{V_i} ρ R₁ f dV,   M = diag(∫_{V_i} ρ dV),   Q = M^{−1/2} P G^{−1/2}
```

各速度成分の制御体積が領域を分割すれば、`0 ≤ σ(Q) ≤ 1`（定理 7）。

- 最大特異値が 1 を超えたら、構成の誤り。
- 最小特異値が 0 に近づくなら、制御体積の運動量から面の速度を復元できない。

### B. 2 通りの制御体積（どちらも領域を分割するので、定理 7 が使える）
| 名前 | 法線の速度（y の面 j） | 接線の速度（y のセル j） |
| --- | --- | --- |
| **dual**（通常の MAC） | 双対セル `[y_j − h/2, y_j + h/2]` | セル j（× x の双対の区間） |
| **phase**（相を区別、この段階で加えた） | 切断セルで、移動度（長さ / 密度）の大きい相は最も近い面へ。他方の相は、その相が接している面へ | 切断セルで、移動度の大きい相は自分のセルへ。他方の相は、隣の純粋なセルへ |

- phase は、再構築 D0m（ノート108）の割り当てと同じである。D0m では、切断セルの「他方の相」の部分は、その相の側の面・セルのデータだけで決まる。そこで、その部分の質量と運動量を、同じ面・セルの制御体積に入れる。
- 純粋なセルでは、dual と phase は同じ。面が界面にちょうど一致する場合も同じになる。
- phase の定義は、密度と幾何だけで決まる（結果を見て調整していない）。ただし、指定の基準（dual）とは別の割り当てなので、採否はユーザーの判断による。

### C. x 方向の因子と、発散 0 の部分空間
x は Fourier の記号で扱う。接線成分には `p_Fx/√g_Fx`（低次の再構築では `(3 + cos θ)/4 / √((2 + cos θ)/3)`、最小 0.866）、法線成分には `1/√g_Cx` が掛かる。

発散 0 の部分空間への制限は、θx ごとに離散の発散 `B = [b_x I, D_y/h]` の零空間 Z を取り、`M^{−1/2} P Z (ZᴴGZ)^{−1/2}` の特異値を測る。

## 1. ユーザーの予備の値との照合（c = 0.75、密度比 1 / 1e3 / 1e6、dual、全ての θx の最小）
| 候補 | 開発側 | ユーザー |
| --- | --- | --- |
| A（低次の MAC の再構築） | 0.866 / 0.807 / 0.807 | 0.866 / 0.810 / 0.810 |
| B（単相 PCCD） | 0.641 / 0.133 / 0.00429（界面が面に一致する配置では 0.00221） | 0.641 / 0.0697 / 0.00221 |
| D（密度適合型） | 0.671 / 0.0120 / 0.000378（D0m） | 0.701 / 0.0437 / 0.00138 |

- A は 2 桁目まで一致した。
- B は、密度比 1 で一致、界面が面に一致する配置で 0.00221（ユーザーの値と同じ）。c = 0.75 では約 2 倍の差がある（配置の違いと考えられる、未照合）。
- D は、密度比に対する減り方（1e3 → 1e6 で約 1/31.6 = r^{−1/2}）が同じ。大きさの差（約 3.6 倍）は、低次の D の形の違いと考えられる（未照合）。

## 2. 走査（N = 32、密度比 {1, …, 1e6}、10 通りの界面の位置と、薄い重い相・薄い軽い相の ζ = 1e-4〜1e4 の最悪値。全ての θx）
### 正規化した最小特異値（全速度空間 / 発散 0 の部分空間、密度比 1 → 1e3 → 1e6）
| 候補・制御体積 | 全速度空間 | 傾き（全体 / 1e3〜1e6） | 発散 0 の部分空間 |
| --- | --- | --- | --- |
| A・dual | 0.866 → 0.126 → **4.0e-3** | −0.41 / −0.50 | 0.869 → 0.703 → 0.701 |
| B・dual | 0.641 → 0.068 → **2.2e-3** | −0.43 / −0.50 | 0.643 → 0.099 → 0.015 |
| D0m・dual | 0.500 → 6.1e-4 → **6.1e-6** | −0.88 / −0.70 | 0.579 → 0.013 → 4.0e-3 |
| A・phase | 0.500 → 6.1e-4 → 6.1e-6 | −0.88 / −0.70 | 0.582 → 0.068 → 0.015 |
| B・phase | 0.453 → 4.6e-4 → 4.6e-6 | −0.89 / −0.70 | 0.575 → 0.072 → 6.6e-3 |
| **D0m・phase** | **0.671 → 0.796 → 0.796** | **+0.01 / 0.00** | **0.768 → 0.816 → 0.816** |

- **最大特異値は、全ての場合で 1.000 以下**（定理 7 のとおり）。空の制御体積は無い。
- **dual では、全ての候補で最小特異値が密度比とともに 0 に近づく**。ユーザーの予備の結果（単相 PCCD と密度適合型で悪条件が残る、低次の MAC も別の界面の位置で 0.0115 まで下がる）と同じである。
  - A・dual は、発散 0 の部分空間では 0.70 で止まる。全速度空間では r^{−1/2} で下がる。
- **再構築と制御体積の割り当てが合っている組（D0m・phase）だけが、密度比・薄片によらず一定**（0.67〜0.80、発散 0 では 0.77〜0.82）。割り当てが合わない組（D0m・dual、A・phase、B・phase）は、どれも下がる。
- N = 64 でも、D0m・phase は同じ値（0.671、0.768）。

### Gram と制御体積の質量の同値（一般化固有値の最小〜最大、密度比 1e6 まで）
| 候補・制御体積 | 法線 (G_F, M) | 傾き（最大、1e3〜1e6） |
| --- | --- | --- |
| A・dual | 0.286〜4.2e4 | +1.00 |
| B・dual | 0.017〜9.1e4 | +1.00 |
| D0m・dual | 5.8e-7〜2.9 | 最小が −1.00 |
| **D0m・phase** | **0.331〜2.06** | **0.00** |

- **D0m の法線の Gram は、相を区別した制御体積の質量と一様に同値**である（0.33〜2.06、密度比・薄片によらない）。ノート108 の「D0m の最小固有値 1/r は、基準 M_n の対角との食い違い」を、具体的な割り当てで確かめた形になる。
- 接線の Gram は、相を区別した制御体積の質量とは同値にならない（最大 1e10）。接線の自由度はセル全体の体積平均で、薄い軽い相の速度を `1/(1 − c)` 倍して表すからである（自由度のスケールの問題）。接線の基準は、調和平均の M_t のままでよい（ノート108：(G_C, M_t) ∈ [1, 4.0]）。運動量への変換の特異値は、この影響を受けない（上の表）。

## まとめ
- **S5 の判定（指定の dual の制御体積）**：A・B・D0m の全てで、正規化した最小特異値が密度比とともに 0 に近づく。任意の双対セルの運動量を面の速度と一対一に対応させる方式は、これらの再構築では成り立たない（ユーザーの予備の結果と一致）。
- **新しい観察**：再構築 D0m と同じ割り当ての制御体積（phase）を使えば、変換は密度比・薄片によらず良条件（σ ∈ [0.67, 1.00]）で、法線の Gram も制御体積の質量と一様に同値になる。層の二相では、「密度適合型の可換な再構築 + それと整合した相を区別した制御体積」という 1 つの組が、Gram・Schur 補行列（ノート108、対角のスケール）・射影の精度（ノート108）・運動量への変換の 4 つで頑健である。
- 補助モーメントは、この組では必要なかった（層の二相、走査した条件で）。

## 未検証・次（ユーザーの判断が必要）
- **制御体積の扱い**：phase は指定の基準（dual）と別の割り当てである。採るかどうかは、ノート108 の基準の内積の判断と同じ問題である。
- **局所の運動量保存そのものは未検証**（定理 7 の後の表の 4 行目）。相を区別した制御体積は界面とともに動き、移動度の大小が入れ替わる所で割り当てが不連続に変わる。その流束の構成と連続化は、Gate 1-C の課題である。T4 が良条件でも、局所保存が成立したとは扱わない。
- 斜めの界面・曲線の界面での、相を区別した制御体積の定義（#135）。
- 高次の再構築（#136）で、同じ割り当てが成り立つか。
- B の c = 0.75、D の大きさについての、ユーザーの値との差の原因。
