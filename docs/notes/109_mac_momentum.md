## 定式化と理論的根拠
### A. 変換と定理 7（ユーザー、ノート107 の 5.3 節）
```
(P f)_i = ∫ ρ χ_i R₁ f dV,   M⋆ = diag(∫ ρ χ_i dV),   Q = M⋆^{−1/2} P G^{−1/2}
```

制御体積の重み χ_i（0 ≤ χ_i ≤ 1、Σχ_i = 1）が領域を分割すれば、`0 ≤ σ(Q) ≤ 1`（定理 7）。

### B. 制御体積
| 名前 | 法線の速度（y の面 j） | 接線の速度（y のセル j） |
| --- | --- | --- |
| **dual**（通常の MAC） | 双対セル `[y_j − h/2, y_j + h/2]` | セル j |
| **phase**（相を区別、D0m の硬い規則） | 切断セルで、移動度（長さ / 密度）の大きい相は最も近い面へ。他方の相は、接している面へ | 移動度の大きい相は自分のセルへ。他方の相は、隣の純粋なセルへ |
| **blend**（重みつき、ユーザーの方式 C） | 「軽い相が埋める」規則と「重い相が埋める」規則を、D0b の再構築と同じ重みで混ぜる | 同じ |

- ユーザーの判断（2026-11-27）：相を区別した制御体積を新しい主候補とする。旧基準（dual）に対する不成立の結果は保つ。MAC 型の最終の採用は未決定。

### C. D0m の接線成分が等長になる理由（ユーザー）
D0m の接線の再構築は、相別の制御体積の上で区分定数である。制御体積の速度を `w = J_Γ f` とすると `p = M⋆ J_Γ f`、`G_Γ = J_Γᵀ M⋆ J_Γ`。よって `P⋆ᵀ M⋆⁻¹ P⋆ = G_Γ` で、J_Γ が可逆なら `σ_j(Q⋆) = 1`。良条件は偶然ではなく、再構築と運動量の積分領域を一致させた構造による。法線の区分線形・高次の PCCD では、等号にはならない。

**代償**（ユーザー）：薄い軽い相（割合 ℓ）が体積平均の補正を引き受けると `G_ii ∼ ρ_L h/ℓ`、`(M⋆)_ii = ρ_L h ℓ` で、比は `1/ℓ²`。移動度が等しくなる付近（ℓ ∼ 1/r）では O(r²) になる。

### D. 運動量から導く基準（定理 8、ユーザー）
`σ_min(Q⋆) ≥ s₀ > 0` なら、運動量の座標のエネルギー `H⋆ = P⋆^{−T} G P⋆^{−1}` は `M⋆⁻¹ ⪯ H⋆ ⪯ s₀⁻² M⋆⁻¹`。面の速度の座標では、基準を `M̂ = P⋆ᵀ M⋆⁻¹ P⋆` として `M̂ ⪯ G ⪯ s₀⁻² M̂`。つまり (G, M̂) の一般化固有値は `[1, 1/σ_min²]` にある。下の表の「最小特異値」は、この同値の定数でもある。

- **最大特異値は、全ての場合で 1.000 以下**（定理 7）。空の制御体積は無い。
- **dual では、全ての再構築で密度比とともに 0 に近づく**（旧基準に対する不成立、ユーザーの予備の結果と一致）。
- **硬い切り替えの D0m・phase だけが、低次で密度比によらず良条件**（法線 0.71〜0.79、接線は C 節のとおり等長）。
- **連続化（D0b）は、運動量への変換の頑健性を引き継がない**（ユーザーの指摘のとおり）。硬い相別の制御体積では法線が 3.0e-3（傾き −0.49）まで、再構築と同じ重みで混ぜた制御体積では接線が 0.016 まで下がる。
- **高次の D5m・phase は、密度比によらないが小さい**（0.09〜0.11）。定理 8 の同値の定数 `1/σ²` は約 110、運動量を厳密に保つ再構築の最悪のエネルギー増幅率（ユーザーの 8.1 節）も同じ値になる。D5b は D0b と同じく下がる。

- **接線の Gram と相別の質量の比は、移動度の切り替えの近くで r² に比例して増える**（C 節の代償、ユーザーの追加の計算と一致）。面の速度の自由度（セルの体積平均）と、薄い軽い相の物理的な速度の対応が、密度比に頑健でない。
- 定理 8 の基準 M̂ に対しては、(G, M̂) ∈ [1, 1/σ_min²] である（D 節）。D0m・phase では法線 [1, 1.98]、接線は 1 に一致する。r² の増大は、D0m については座標の選び方（面の速度か運動量か）による部分である（ユーザーの 6 節）。

## まとめ
- **S5（旧基準 dual）**：全ての再構築で不成立（維持）。
- **相を区別した制御体積 + D0m**：運動量への変換は良条件（法線 0.71〜0.79、接線は等長、発散 0 で 0.79 以上）。法線の Gram は M⋆ と一様に同値。接線は、運動量の座標（M̂）では同値、面の速度の座標では r² の食い違いがある。
- **連続化と高次化は、そのままでは運動量への変換の頑健性を保たない**：D0b は 3.0e-3（phase）または 0.016（blend）、D5m は 0.09〜0.11、D5b は 3.3e-3 / 4.2e-3。
- 補助モーメントの要否は、動く界面での保存とエネルギーの比較（ノート110）の後に決める（ユーザー）。

## 未検証・次
- **局所の運動量保存そのもの**：相別の制御体積は界面とともに動き、移動度の切り替えで所属が不連続に変わる（割り当ての質量の比は r²）。共通の質量輸送の測度による移管と、運動量 Remap・Galerkin の比較はノート110 で行う。
- 連続で、かつ運動量への変換が頑健な制御体積と再構築の組（D0b の代わり）。
- 高次の再構築で特異値を上げる方法（相ごとの小領域のモーメントを Oracle に使う。区分線形の速度を相の区間の半分ずつの平均で測ると、最小特異値に √(3/4) の下界がある、ユーザー）。
- 短い相の領域（隣に純粋なセルが無い場合）：D0m の「他方の相」は値 0 になり、定数を再現しない。この走査には含まれていない。
- 斜め・曲線の界面での制御体積の定義（#135）。
