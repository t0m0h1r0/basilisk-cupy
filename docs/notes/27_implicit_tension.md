# 27 表面張力の半陰的化（PR #41）

## ねらい
21 の不安定（格子規模の毛管波。陽的な表面張力の時間刻み上限が N とともに下がる）を、表面張力の半陰的化（Hysing 2006 型、dt·σΔ_s u）で抑える。

## 試した形
| 形 | 結果（GFM 静止液滴、密度比 100、μ = 0.1、N = 64、tension.h の刻み＝係数 1） |
| --- | --- |
| ① 予測段の粘性の陰解法に表面粘性 c·dt·σ·|∇ψ| を足す（`surface_viscosity`） | 不安定のまま（c = 0.5〜1、係数 1〜8 すべて） |
| ② 射影の前の面速度を (1/α)u − ∇·(θdt²σ|∇ψ|∇u) = u*/α で平滑化 | 密度比 100 では不安定、密度比 1 では発散は止まるが寄生流が 0.1 |
| ③ 射影の後の面速度（ψ を運ぶ速度）を同じ式で平滑化し、射影し直す（`implicit_tension=θ`） | **安定** |

- **①が効かない理由：** 表面張力（ジャンプの加速度）は粘性の段の後に加わるので、陰的な減衰がその時刻の衝撃にかからない。
- **②が効かない理由：** 面速度にはジャンプの加速度 dt·α·j/h が含まれていて、射影で圧力勾配と打ち消し合う。射影の前に平滑化すると、この釣り合いが崩れる。
- **③の実装：**
  - 面速度の各成分を、その成分の面の格子で解く。壁の面はゼロ、それ以外の壁は鏡像、周期軸は巻き戻し。
  - 演算子は対称・正定値（単体で確認）なので、共役勾配法で相対残差 1e-10 まで解く。
  - その後、別の圧力で射影し直して発散ゼロに戻す。
  - セル中心の速度（運動量）は変えない。ψ を運ぶ速度だけを平滑化する。

## ③の測定
安定の境目（tension.h の上限の何倍まで安定か、密度比 100、800 ステップ。N = 256 は 600〜800 ステップ）：

| | N = 64 | 128 | 256 |
| --- | --- | --- | --- |
| θ = 0（20） | 0.95〜1.0 | 0.91〜0.95 | 0.85〜0.88 |
| θ = 1 | 1.0〜2.0 | 1.0〜1.5 | < 1.0（1.0 でゆっくり増大、+0.006/ステップ） |
| θ = 4 | 1.0〜2.0 | 1.5〜2.0 | 1.0〜1.5 |
| θ = 16 | ≥ 2.0 | ≥ 2.0 | ≥ 1.0 |

- θ を固定すると、境目は N とともに下がる（21 の N 依存は残る）。θ = 4 なら、N = 64〜256 で係数 1（Basilisk と同じ刻み）が安定。
- N = 64、係数 1、θ = 1：寄生流は 800 ステップで 1.0e-10 まで減衰（θ = 4：4.2e-10、θ = 16：1.3e-7）。ジャンプは 4.0030。
- 密度比 1、係数 1.6：θ = 1 は不安定、θ = 4 は安定（1.7e-9）。

毛管波（GFM、補正した発散＋6次の面値、係数 √(5/12)、相対 RMS 誤差）：

| 1波長の点数 | 8 | 16 | 32 | 64 |
| --- | --- | --- | --- | --- |
| θ = 0 | 0.188 | 0.0639 | 0.0109 | 0.00213 |
| θ = 1 | 0.188 | 0.0660 | 0.0123 | 0.00250 |
| θ = 4 | 0.189 | 0.0718 | 0.0162 | — |
| θ = 4、係数 1.5 | 0.189 | 0.0718 | 0.0296 | — |

- 平滑化は、ψ を運ぶ速度と運動量の速度の間に O(dt²σk²) の不整合を入れる。そのため、θ と刻みを大きくするほど毛管波の誤差が増える（振幅の減衰が弱まる、図の右）。
- 図：`docs/figures/implicit_tension.png`（静止液滴の寄生流の時間変化、θ = 1 の速度と圧力、毛管波の振幅）。

## 結論
- 表面張力の陰的な項は、「ψ を運ぶ速度」にかけないと効かない（①②は失敗）。
- ③は格子規模の毛管波を抑え、係数 1 の刻みを密度比 100・N = 256 まで安定にする（θ = 4）。
- ただし θ は N とともに大きくする必要があり、毛管波の精度は落ちる。1ステップあたり共役勾配法と射影が1回ずつ増える。
- 既定は θ = 0（使わない）のまま。
