## 結論の要約
- **圧力を含む総運動量は、現行の方式で保存する（条件つき）**。保存形の輸送（`conserving=True`）で、セルの補正に使う面の密度が算術平均なら（**smooth は `filtered=False` に限る**。訂正、監修の PR #157 の指摘 2）、周期・外力なしの二相（密度比 1000、渦の中の液滴、t = 1）で相対変化は **1.1e-12 以下（smooth）、1.8e-11 以下（mean）**。必須の基準 1e-9 を満たす。
  - **`filtered=True`（two-phase.h の FILTERED：面の密度を頂点平均した f から作る）では保存しない**：t = 1 で 1.4e-2〜2.3e-2（N = 32〜128。緩やかには減るが、1e-9 の基準には格子を細かくしても届かない：監修の PR #157 の軽微の指摘）。運動量は f そのものの密度で数えるのに、面の密度が「両側のセルの密度の算術平均」でなくなる（B 節の条件が崩れる）。
  - GFM の係数をセルにも使う（gfm）と **3.5e-2〜0.27**、非保存形の輸送では **3e-2〜2**（N = 128 では t = 0.80 で発散）。どちらも不合格。
  - 一次元の恒等式（B 節）は丸めまで確かめた：算術平均 0、調和平均 649、GFM（θ = 0.3）1.53（式と一致）。
- **静水圧は、重力の入れ方で決まる**（面の密度の選択にはよらない）。
  - **reduced（界面のポテンシャル）：斜めの界面でも丸め〜求解の許容誤差の水準（2e-10 以下）で釣り合い、育たない**。θ = 0°、10°、26.565°、45°、界面の位置 3 通り、N = 32〜128、3 つの面の密度の、のべ 72 条件のうち 63 条件（訂正：初版は 66。監修の PR #157 の指摘 1）。
  - **不成立の 9 条件（3 配置 × 3 つの面の密度）は全て、界面が壁の角から 1 セル以内を通る配置**（45°・δ = 0.0137 の N = 32・64 と、26.565°・δ = 0.2313 の N = 32。速度は 3e-4〜6e-3）。訂正：初版は「6 条件」と書いたが、4 節の表の「3 つとも」の 3 配置で 9 条件である。同じ配置で格子を細かくして角から 1 セルより離れると、丸めに戻る。
  - **plain（面の加速度）：斜めの界面では釣り合わない**。θ = 10°・26.565° で速度が t = 1 までに 0.05〜0.2（√(GL) = 1 に対して）に育ち、界面が動く（体積分率の変化 0.03〜0.5）。**格子を細かくしても減らない**。密度比 10 でも同じ。釣り合うのは、θ = 0°（全て）と、θ = 45° の smooth（x と y の対称性で面の密度が離散の勾配になる）だけ。密度比 1 では釣り合う。
- **セルの速度と面の流束の差**（渦の中の液滴、保存形）：RMS は格子を倍にするとほぼ半分（smooth：t = 0.5 で 5.7e-3 / 3.2e-3 / 1.8e-3）で、時間とともに単調には増えない（t = 0.25〜0.5 で最大になり、t = 1 では減る）。**最大値は格子を細かくしても減らない**（0.03〜0.1、界面に局在）。非粘性で界面に接線方向の速度差ができる流れなので、最大値では判定できない（3 節）。
- **含意（B の判断の材料）**：#141 の R0-P2 の「共通の面の圧力による、セルの運動量の補正（流束の形）」は、**総運動量の保存のためには要らない**（算術平均の係数で足りる）。ノート111 の 4 節の「固定 MAC への移行の条件」のうち、ここで測った 2 つ（圧力を含む総運動量、静水圧）は、現行のセル中心の方式（smooth、または mean）+ 保存形の輸送 + reduced の重力で満たす。満たさないのは、(i) 界面のポテンシャルで書けない体積力を斜めの界面に掛ける場合、(ii) 界面が壁の角の 1 セル以内を通る粗い格子、である。
- 未検証：近似射影による時間誤差（二相）、静止液滴の balanced-force、粘性あり、斜めの界面で流れのある問題（R0 の表）。

## 定式化と理論的根拠
### A. 3 つの面の密度の選択（どれも既存のライブラリの選択肢）
圧力射影は面の速度を `u_f ← u_f − Δt α_f (Δp)_f/h` で直し、セルの速度を、両側の面の加速度の平均 `g_i = ½ Σ (a_f − α_f(Δp)_f/h)` で直す（`centered.h`）。

| 記号 | 面の速度の係数 α_f | セルの補正の係数 | クラス |
| --- | --- | --- | --- |
| smooth | `1/ρ(f̄)`、f̄ は両側のセルの体積分率の平均（密度の算術平均） | 同じ | `TwoPhase`（two-phase.h） |
| mean | 切断面で GFM の `1/(θρ_L + (1 − θ)ρ_R)` | 面の力 `a_f − α_f Δp/h` を算術平均の係数に付け替える（ノート65） | `TwoPhaseVOFJump(cell_coefficient="mean")`（このクラスの既定） |
| gfm | GFM | GFM のまま | `TwoPhaseVOFJump(cell_coefficient="gfm")` |

### B. 総運動量の保存の条件（導出：監修の第 7 回の報告、ノート111 の 4 節。ここでは行列の恒等式として確かめた）
一次元・周期で、セルの運動量の変化の総和は

```
dP/dt = Σ_i ρ_i g_i = −Σ_f [(ρ_L + ρ_R)/(2ρ_f)] (Δp)_f / h
```

任意の圧力で 0 になるのは、セルの補正に使う面の密度 ρ_f が両側のセルの密度の算術平均のときだけである。面の速度の係数は条件に入らない（mean が成り立つ理由）。二次元でも、方向ごとに同じ式である。移流の側は、保存形の輸送（`conserving=True`、相ごとの運動量を VOF の質量の流束で運ぶ）なら流束の形で、総和は変わらない。

### C. 静水圧の釣り合い（ノート111 の 4 節、ユーザーの補足）
静止した 2 層で `∇p = ρ g`。圧力が界面で連続であるためには `[ρ] g·t = 0`、つまり重力が界面に垂直でなければならない。**斜めの界面では、重力を界面の法線の向きに回した**（`g = −G n`、n は軽い側を向く単位法線、G = 1）。

- 重力の入れ方は 2 つ。
  - **plain**：面の加速度 `a_f = g·e_f` を、内部の全ての面に与える（壁の面は 0。壁の法線方向の面の速度は 0 で、ライブラリは壁の面の正味の加速度を 0 として扱う）。釣り合いの条件は `α_f (Δp)_f/h = g·e_f`、つまり `(Δp)_f = h g·e_f ρ_f`。**右辺が離散の勾配であること**（x の面と y の面の `ρ_f g·e_f` の離散の回転が 0）が要る。格子に平行な界面では成り立つ。斜めの界面では、面の密度が体積分率から作られるので、一般に成り立たない（仮定つきの主張：数値で確かめた。3 節）。
  - **reduced**：`reduced.h` の形。圧力を `p = p' + ρ G·(x − Z)` と置き、重力を界面の跳び `[ρ] G·(x − Z)` として入れる（`add_reduced_gravity`）。界面の位置は高さ関数から取る。平らな界面が重力に垂直なら、`G·(x − Z)` は界面の上で一定で、跳びは定数になり、p' = 定数 が厳密な離散解である（面の密度の作り方によらない）。
- 厳密な静水圧 `p(s) = p₀ − G ∫ρ ds`（s は法線方向の座標）では、セルの力の残差 `r_i = m_i g − Σ p̄_F n_F|F|` は発散定理で 0 である。ここで測るのは、離散の方式が静止を保つかどうか（セルの速度と面の速度）である。

### D. 設定と、合否の読み方（測定の前に固定した）
- **総運動量**：周期の [0, 1]²、外力・粘性・表面張力なし。液滴（半径 0.15、中心 (0.5, 0.3)、密度比 1000）を Taylor–Green の渦 + 一様流 (0.5, 0.2) の中に置く（ノート114 の 4 節と同じ）。`Σρu` の相対変化の、t = 1 までの最大。**合格：1e-9 以下**（ノート111 の 1 節の暫定の基準）。N = 32、64、128。3 つの面の密度 × 輸送 2 通り。
- **静水圧**：閉じた箱 [0, 1]²（滑り壁）、密度比 1000、表面張力・粘性なし、保存形の輸送。界面は点 (0.5, 0.5 + δ) を通る平面で、x 軸に対する角度 θ = 0°、10°、26.565°（tan θ = 1/2）、45°。δ = 0.0137。θ = 26.565°・45° は δ = 0.1171、0.2313 も（界面の位置 3 通り）。体積分率は一次関数から厳密。Δt = 0.5h、t = 1 まで（重力の時間の尺度 √(L/G) = 1）。N = 32、64、128。3 つの面の密度 × 重力の入れ方 2 通り。**合格：セルと面の速度が求解の許容誤差の水準（1e-10 の許容誤差に対して 1e-8 以下）にとどまり、時間とともに育たないこと**。密度比 1・10 と非保存形は θ = 26.565°・N = 64 で比較。
- **セルの速度と面の流束の差**：総運動量と同じ計算で、`max|u_f − (セルの速度の面への平均)|` と RMS を t = 0.05、0.25、0.5、1 で記録。#141 の条件は「格子を細かくすると減り、時間とともに累積して増えない」。
- 基準を書く前に、N = 32 の予備の実行（総運動量 t = 0.25、静水圧 θ = 0°・26.565°、t = 0.25）を見ている。合格の閾値（1e-9、1e-8）はノート111 の値と求解の許容誤差から決めたもので、予備の結果で動かしてはいない。

## 5. 追加（B の指示、PR #157 のコメント）：壁の圧力の力を含む収支、長時間の静水圧
### 壁の圧力の力を含む運動量の収支（閉じた箱・滑り壁、外力なし、Taylor–Green の渦の中の液滴、密度比 1000、保存形、t = 0.5）
セルは両側の面の力の平均を受け、壁の面の力は 0 なので、セルの補正の面の密度が算術平均なら、総和は壁に接するセルの圧力に畳み込まれる（導出：2 節の恒等式を、壁のある列に当てたもの）：

```
d/dt Σ ρ u_x h² = h Σ_j (p[0, j] − p[n−1, j]),    d/dt Σ ρ u_y h² = h Σ_i (p[i, 0] − p[i, n−1])
```

右辺を「離散の壁の力」（壁の圧力を、壁に接するセルの圧力で読む）として、収支の残差 `|P(t) − P(0) − ΣΔt F_wall|` の最大を、初期の `Σρ|u|h²` で割った値：

| 面の密度 | N = 32 | N = 64 | 壁の力積の大きさ（同じ正規化） |
| --- | --- | --- | --- |
| smooth | 3.2e-13 | 1.4e-12 | 1.9e-2 / 2.1e-2 |
| mean | 2.4e-12 | 5.9e-13 | 1.9e-2 / 1.9e-2 |
| gfm | **0.18** | **4.2e-2** | 1.4e-2 / 1.6e-2 |

- smooth・mean では、壁の力（0.02 の大きさ）を含めて収支が丸めまで閉じる。gfm では閉じない。
- この「壁の力」は、壁の圧力を隣のセルの値で読む定義で、方式の恒等式である。壁の上の圧力の値そのものの精度（外挿の次数）は、ここでは問うていない。

## まとめ
- 総運動量（圧力を含む）と静水圧の 2 つについて、現行のセル中心の方式には、**条件を満たす既存の組み合わせがある**：保存形の輸送 + セルの補正の面の密度が算術平均（smooth〔`filtered=False`〕または mean）+ 重力は reduced の形。
- 新しい圧力の補正の方式（共通の面の圧力の流束の形）や固定 MAC への移行を、この 2 つの結果からは求められない。
- 残る弱点は 2 つ：界面のポテンシャルで書けない体積力は斜めの界面で釣り合わない（plain の結果）、界面が壁の角の近くを通ると粗い格子で釣り合いが崩れる。

## 自己点検（試験が成立しやすい条件に寄っていないか）
- **総運動量は 1 つの流れ**（渦の中の液滴）だけ。周期と、滑り壁の閉じた箱（5 節、壁の力は隣のセルの圧力で読む定義）。厳密解が無い。
- **静水圧は平らな界面だけ**（曲がった界面では、重力に垂直でないので静止解にならない）。表面張力なし。**静止の釣り合いだけで、動く界面での釣り合いは見ていない**。reduced の形は、界面の位置を高さ関数から取るので、平らな界面で厳密になるのは構成による（成立しやすい条件である）。曲がった界面・動く界面での誤差は、この試験からは分からない。
- 界面の位置は、θ = 26.565°・45° で 3 通り、θ = 0°・10° は 1 通り。
- 密度比は主に 1000（θ = 26.565°・N = 64 だけ 1・10 も）。1e6 は測っていない。監修の記録（PR #157、未検証）：密度比 1e6 で粘性（μ = 1e-2）を入れると、`filtered=False` でも総運動量が 1.7e-3 変わる（N = 32、t = 0.05、圧力の許容誤差によらない。密度比 1000 では 1e-13）。原因は調べていない。密度比 1e6 は方式の完成後のストレス試験なので、今は追わない（B の指示）。
- 時間は t = 1 まで（5 節の 7 条件だけ t = 20 まで）。
- セルと面の速度の差は、条件の判定に向かない流れで測った（3 節）。

1. R0-P2 の「共通の面の圧力による、セルの運動量の補正（流束の形）」を、**作らない**（総運動量の保存には要らない）としてよいか。局所の（セルごとの）圧力の運動量の収支を流束の形にすることは、ノート111 の要件の表（「圧力を含む総運動量の保存」）には入っていない。
