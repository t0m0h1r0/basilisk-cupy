# 68 CLS の振動液滴の過大な減衰は、粘性の解のぼやけたセル密度（PR #79）

ノート63 で、CLS の振動液滴（水–空気、論文の設定）の減衰は、物理（2 次元の粘性モード β = −0.179 s⁻¹）の約 3.9 倍で、格子を細かくしても縮まなかった。再初期化の回数・高さ関数の差分・輸送の速度では説明できず、ぼやけた粘性 μ(ψ) も約 2 割にとどまった（ノート67）。

## 1. 粘性の解のセル密度を鋭くすると、過大な減衰が消える（`cases/cls_drop_viscosity.py`）
陰的な粘性の解 `(I − τ/ρ V) u = u*` は、セル中心の密度 ρ で割る。CLS（two-phase.h と同じ形）では ρ = ρ(ψ) で、帯（約 3 セル）の中でぼやけている。これを ψ = 1/2 で切った鋭い値（`ψ > 1/2` で ρ1、それ以外で ρ2）にした。面の粘性は切断面の判定で鋭くした（切断面は両側の平均）。CLS（ab2、ξ-SDF 10、高さ関数の曲率、fd2 の面）。

| 粘性の演算子 / μ / 粘性の解の ρ | N = 32：β 倍率 / ω の誤差 | N = 64 |
| --- | --- | --- |
| CCD / ぼやけ / ぼやけ（既定） | 2.51 倍 / −5.13% | 3.90 倍 / −3.38% |
| fd2 / ぼやけ / ぼやけ | 2.23 倍 / −5.05% | 3.90 倍 / −3.38% |
| fd2 / 鋭い / ぼやけ | 1.67 倍 / −5.05% | 3.07 倍 / −3.29% |
| **fd2 / 鋭い / 鋭い** | 1.67 倍 / **−1.79%** | **0.84 倍 / −1.13%** |
| （参考）VOF on IMEX（ノート64） | / −1.54% | / −1.04% |

- **N = 64 で減衰はほぼ物理どおり（0.84 倍、ただし液滴の β は ±0.5 ぶれる）、周波数の誤差は VOF 並み**。最大速度 0.036〜0.042（既定と同じ）。

### 効いているのは粘性の解のセル密度だけ（`--only fd2:rho ccd:rho ccd:sharp+rho`、`--case capwave`）
| 粘性の演算子 / μ / ρ | 毛管波（ψ 曲率）N = 32 | N = 64 | 液滴（高さ関数）N = 32 | N = 64 |
| --- | --- | --- | --- | --- |
| CCD / ぼやけ / ぼやけ（既定） | 0.50 倍 / −9.30% | 1.43 倍 / −4.22% | 2.51 倍 / −5.13% | 3.90 倍 / −3.38% |
| fd2 / ぼやけ / 鋭い | | | 2.51 倍 / −2.55% | 0.84 倍 / −1.38% |
| **CCD / ぼやけ / 鋭い** | 0.31 倍 / −4.83% | **0.75 倍 / −1.26%** | 2.51 倍 / −2.38% | **0.84 倍 / −1.38%** |
| fd2 / 鋭い / 鋭い | 0.68 倍 / −4.76% | 1.00 倍 / −1.33% | 1.67 倍 / −1.79% | 0.84 倍 / −1.13% |
| CCD / 鋭い / 鋭い | | | 発散しかける（最大速度 2.5） | 発散 |
| （参考）VOF on IMEX、CSF | 2.05 倍 / −3.98% | 1.18 倍 / −1.33% | / −1.54% | / −1.04% |

- **粘性の解のセル密度を鋭くするだけで、液滴の過大な減衰が消え、毛管波・液滴とも周波数の誤差が VOF 並みになる**（N = 64：毛管波 −4.22% → −1.26%、液滴 −3.38% → −1.38%）。μ と粘性の演算子は既定（ぼやけた μ(ψ)、CCD）のままでよい。
- μ も鋭くするのは、CCD の粘性とは組み合わせられない（不連続な係数、ノート64 と同じ）。fd2 の粘性なら安定だが、改善はわずか。
- 解釈：陰的な粘性の解は運動量の拡散を `τ/ρ` で重みづける。帯の中で ρ(ψ) をぼかすと、界面の空気側のセルに水の密度が混ざり、そのセルの粘性による運動量の交換が実際と変わる。毛管波・液滴は界面の近くの境界層で散逸が決まるので、この差が O(1) の誤差になる（機構の解釈は直接測っていない）。

ライブラリ：`TwoPhaseCLS(cell_density="sharp")`、`TwoPhaseIMEX(cell_density="sharp")`（既定は `"diffuse"` のまま。ノート69 で `"sharp"` に変えた）。

### ライブラリの選択肢での確認（`cases/cls_cell_density.py`、既定の CCD の粘性とぼやけた μ）
| 問題 | `"diffuse"`（既定）N = 32 | N = 64 | `"sharp"` N = 32 | N = 64 |
| --- | --- | --- | --- | --- |
| 毛管波（ψ 曲率） | 0.50 倍 / −9.30% | 1.43 倍 / −4.22% | 0.31 倍 / −4.83% | **0.75 倍 / −1.26%** |
| 液滴（高さ関数） | 2.51 倍 / −5.13% | 3.90 倍 / −3.38% | 2.51 倍 / −2.38% | **0.84 倍 / −1.38%** |
| 液滴（ψ 曲率） | 増幅 / −2.55%（0.10） | 増幅 / −1.38%（0.28） | 1.11 倍 / +1.87%（0.07） | 増幅 / −0.13%（0.21） |
| 上昇気泡の重心 | 6.933 mm | 7.028 mm | 6.976 mm | 7.046 mm |

- フックでの試験と同じ値（毛管波・高さ関数の液滴）。
- ψ の曲率の液滴の振幅の増加（ノート59）は、鋭い密度でも N = 64 では残る（N = 32 で止まって見えたのは一時的）。これは曲率の問題のまま。
- 上昇気泡の重心は、VOF（6.99〜7.01 mm）に近づくかどうかが格子でまちまち（N = 32 で近づき、N = 64 で離れる）。

## 3. VOF の静止液滴：列の CCD 曲率でジャンプの誤差が 1/8（GPU、`cases/vof_static_curvature.py`）
厳密な初期化、密度比 1000、t = 0.5、N = 64（ノート66 の続き）：

| 曲率 | CSF：ジャンプの誤差 / 最大速度 | GFM |
| --- | --- | --- |
| tension.h | +7.54e-3 / 4.9e-4 | +7.58e-3 / 1.0e-3 |
| 列の CCD | **−9.07e-4** / 5.9e-4 | **−9.37e-4** / 6.4e-4 |

- 円の曲率の rms では、N = 64 の列の CCD は tension.h より悪かった（ノート66）が、ジャンプ（曲率の平均）は 1/8 になる。tension.h の曲率には符号のそろった偏りがあり、列の CCD はそれが小さい。
