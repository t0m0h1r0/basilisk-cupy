# 10 TwoPhaseFlow 論文・実装で見つかった誤りと抜け

論文には誤り・抜け・計算ミス・前提の誤りがありうる、という前提で検証した結果。

| 箇所 | 内容 |
| --- | --- |
| 面の発散 `face_divergence` | 点値に素の面差分を使っており2次。kx = ky の検証では見えない（03） |
| FUCCD の記号（式 fuccd_periodic_symbol） | (1 + ω₂²/24) を1回しか含まない。4次の発散と組み合わせると2乗になる（03） |
| FCCD のスペクトル | 負の実部を持つと書かれているが、中央流束は純虚数（非散逸） |
| UCCD6 の時間積分 | §4.5 は陰的（CN）扱いが必要と書くが、NS では陽的 EXT2 で積分している |
| UCCD6 の CFL の docstring | σ ≲ √3·h/(8500·max\|u\|) は dt が抜けており、軸の上限も誤り |
| C_adv | 値が示されていない |
| モニタ写像 | 台形則の構成では写像が O(Δξ²) で頭打ち（07） |
| 面状態 | 論文 §11b2 は面速度を状態とするが、実装の `face_native_predictor_state` は既定で無効 |
| CLS の再初期化 | 論文（5b）は標準を Ridge–Eikonal とし、圧縮・拡散型は「非採用」。実装の既定は圧縮・拡散型の分割スキーム（`reinit_method = "split"`）で、頻度の既定は 0（13） |
| ξ-SDF 再初期化（05a 命題1） | 零交差の保存は連続の距離関数での性質。セル中心の点集合距離では斜めの界面で φ が最大 √2 倍になり、正確なプロファイルでも ψ が 4.5e-2 動く（解像度によらない）。交差を結ぶ折れ線までの距離なら1次で収束（13） |
| Eikonal 再初期化の有効性（05a） | 「受動移流で形状復元を満たす」とするが、反転渦では再初期化なしより悪化（13） |
| ξ-SDF の実装 | 交差検出前の ±2ε クリップと質量シフト後の符号保持（CHK-140）は論文に記載がない（13） |
| ψ 曲率の精度（03c） | 「CCD で O(h⁶)」とするが、ε = 1.5h では ψ の幅が常に3セルで、正確なプロファイルでも誤差は O(h⁻¹)（N = 64→512 で 6.3e-4→4.8e-3）。φ（ロジット）からなら 4.9e-7（N = 128）（14） |
| ψ 曲率の DCCD フィルタ | 論文は後置フィルタを標準経路で使わないが、実装の既定は ε_d = 0.05 で、誤差を約10倍にする（14） |
| 曲率の界面帯の閾値（03c） | 「閾値選択に対するロバスト性は高い」とするが、ψ_min = 0.01 では帯の外の ∇ψ に κ が乗らず、静止液滴の圧力ジャンプが 2% 小さい値に収束する（15） |
| CSF のモデル誤差（02b） | 「O(ε²)」とするが、毛管波の周波数のずれは kε についておよそ 1.2 次（kε = 0.59 / 0.29 / 0.15 で +39% / +17% / +7.1%）（15） |
| CLS 移流の面差分（06b） | FCCD の面値は4次でも、その単純な差 D_f は点値に対して2次。ε = 1.5h では誤差 −h²ψ‴/24 が ψ′ の一定割合（ψ = ½ で −0.93%）になり、界面が移動距離の約 0.9% ずつ遅れて収束しない（18） |
| CLS 移流の DCCD（15 章のまとめ） | 結論の章は ψ に「DCCD ε_d = 0.05 併用」とするが、06b の現行の方式は FCCD のみ（DCCD は旧ラベル） |
| 表面張力の時間刻み（07d 式 dt_sigma） | √((ρ_l+ρ_g)h³/(2πσ)) は連続の k = π/h から導いたもの。2次差分の曲率なら約 1.6 倍の余裕があるが、論文の CCD 曲率（格子規模の波に 9.6/h²）ではほぼ限界ちょうどで、密度比 100・1000 の静止液滴（N = 64）が発散した。√(5/12) を掛けると安定（19） |

## 二相全体の精度と 14 章のベンチマーク（B の知見と 14 章の読み込み、PR #64）
B（38〜49）の測定は本移植の組み合わせ（`CenteredNS` + `TwoPhaseCLS`、CLS の輸送 + GFM）で得たもので、論文の経路そのものではない。論文の主張との関係は、確かめた範囲だけを書く。

| 箇所 | 内容 |
| --- | --- |
| 部品の高次精度と二相全体の精度（04、06、09 の O(h⁶) 等の主張） | 部品の次数は二相全体の精度を保証しない。毛管波の減衰誤差は、粘性・面演算子を fd2 から CCD / FCCD にしてもほとんど変わらず（31、32、38）、支配していたのは CLS の輸送による界面の運動学（交点が ±h で平均した速度で動く）だった（41） |
| 二相の実効時間次数の帰属（11b1 第5段） | 論文は「ψ ≃ 0.5 の界面帯で毛管圧力ジャンプ / FCCD 射影が作る低正則性誤差に律速される」とする。本移植では、時間次数を隠していたのはコロケート格子の近似射影（面速度を毎ステップセル中心から作り直すこと）で、セル中心の厳密射影なら 2 次になった（47、48）。論文の経路で同じ機構が効くかは未確認 |
| 毛管波の解像度（14a） | 1 波長 16 点（32²、λ = 10 mm、h = 0.625 mm）では、液相の渦層の厚さ δ = √(2ν/ω) = 0.122 mm が δ/h = 0.20（α = 2 の細分でも最大で約 0.4）。本移植の測定では減衰誤差は δ/h で決まり、1% 以内には δ/h ≳ 2.5 が要った（30、49）。この条件では減衰の精度は議論できない |
| 毛管波の振幅比 0.793553（14a） | 粘性の弱減衰の見積もり exp(−2νk²T) = 0.964（液相 ν、T = 0.04674 s）に対し、減衰率は約 6.2 倍（−ln 0.7936 = 0.231 対 0.037）。論文は「散逸的 benchmark」とだけ書き、物理の減衰との比較がない。B の CLS の運動学が生むのは減衰の**不足**で向きが逆なので、この過大な減衰の説明にはならない。原因は未確認（フェーズ3 で Prosperetti の解と比べる） |
| 14 章の経路と 11b1 の標準経路の不一致 | 11b1 の第1段は CLS の TVD-RK3 だが、14a の毛管波は q セル分率の幾何 swept-volume 輸送（`geometric_swept_volume`）と PCG の active projection で、CLS を使っていない。14 章の共通構成は α = 2 の界面適合格子を毎ステップ作り直すが、11b1 にはこの段がない。14 章の結果は 11b1 の手順の検証として読めない |
| 振動液滴（14b） | NS を解いていない。Rayleigh–Lamb の 2 次モードの線形変分系を閉曲線チャートで積分したもので、論文自身が「力連成 未採用」（`force_admissible=0`）と書く。振幅誤差 2.5e-10 は線形系の時間積分の精度であり、14e の総括表の ✓ は二相 NS のベンチマークとしての合格ではない |
| Rayleigh–Taylor（14d） | 「線形増幅と整合する」とするが、成長率の当てはめ値・誤差が示されていない。基準の γ = √(At g k) = 1.778 は表面張力と粘性を含まない（σk³/(ρ₁ + ρ₂) を入れると 1.766、−0.65%） |
| 上昇気泡（14c） | t ≃ 0.04 s 以降の形状の破綻を「保存すべき不変量の取り違え」とするが、手法と実装のどちらの問題かは切り分けられていない（フェーズ3 で確かめる） |
| 密度比の掃引 V6（13d） | 「密度比 833 までブローアップしない」の根拠は各 8 ステップの計算。本移植の GFM では、密度比 1000 の静止液滴は 100 ステップまで寄生流 1.2e-5 で、400 ステップで発散した（16、刻みは tension.h の上限）。8 ステップは安定性の判定にならない |
| V6 の N = 32 の行（13d） | 全密度比で u∞ = 0.000、体積変化 0.000 が厳密に 0（N = 24 は 1e-12〜1e-9）。静止液滴の寄生流が厳密に 0 になる離散化は考えにくく、計算が進んでいない可能性がある（理由は未確認）。補正圧の比も N = 24 で 0.74〜0.76、N = 32 で 1.00 と格子で大きく変わる |
