## 結論の要約
- **規則**：ステップの開始時の体積分率から、界面のセル（0 < f < 1）と、そこから w セル以内のセル（(2w + 1)² の範囲）で、面の値の源の項に使う g を 0 にする。w = 1 と 2 の 2 通り。面の値の源の項（流束の形）のままなので、総運動量の保存は構成上保たれる。
- **5 条件は全て合格**（1 節）。液滴・気泡・斜めの帯、密度比 1e3・1e6、N = 32・64、2000 ステップで、max|u − U| は源の項なしの形と同じ水準（増幅なし）。渦の中の液滴の総運動量は t = 1 まで 7e-13 以下。界面の無い計算（Taylor–Green）は、切り替えなしの面の値の源の項と**ビット単位で一致**（場の差 0）。w = 1 と 2 で判定は同じ。
- **二相での時間の次数は読めなかった**（記録だけ、合否に入れない。2 節）。同じ格子・同じ時刻の数値解の場の差から測った「Δt に比例する項の係数」は、源の項なし・帯の 2 つ・加速度の形の**どれでも、格子を細かくすると大きくなる**（N = 64 → 128 で 8 → 14〜17）。界面から離れたセルだけで測っても同じ。この流れ（非粘性・表面張力なし・密度比 1000 の渦の中の液滴）は、時間刻みの違う解が収束しない（界面のせん断の不安定と考えられる）ので、時間の次数の判定に使えない。**帯の外を時間中心化した効果は、この流れでは見えない**。
- **判定**：案 4 は、B の条件では合格。「面の値の源の項（ノート112）+ 界面の帯で切る」は、単相の 2 次（ノート112・113）をそのまま保ち、二相で安定・保存する最小の修正である。二相での精度の利得は未確認で、R1 の誤差予算（適切な二相の問題）で測る必要がある。

## 定式化と理論的根拠
### A. 規則と、安定になる理由（ノート114 の式から）
ノート114 の式 (F)：`u⋆_i − U = (Δt/2)[m_in ĝ_in − m_out ĝ_out]/m'_i`。危険なのは `m_out/m'` が大きいセル、つまり重い相が 1 ステップで抜けるセルである。CFL ≤ 1/2 では界面は 1 ステップに 1 セル未満しか動かないので、**質量が大きく変わるセルは、ステップの開始時に界面のセルであるか、その隣**である。

- そのセルの全ての面で `ĝ = 0` なら、(F) の右辺は 0 で、跳びは起きない。ライブラリは面の `ĝ` を両側のセルの g の平均で作るので、あるセルの全ての面で 0 にするには、そのセルと面で接する全てのセルの g を 0 にする。掃過は 2 方向なので、1 回目の掃過で界面のセルになった隣のセル（斜めの位置を含む）も覆うよう、(2w + 1)² の範囲にした。
- w = 1：界面のセルと、その周りの 8 セル。界面のセルの全ての面で `ĝ = 0`。その隣のセル（純相）の外側の面は `ĝ = g/2` だが、純相のセルが 1 ステップで失う質量は高々 CFL 程度の割合なので `m_out/m'` は有界（重い純相のセルが半分抜けても `m/m' ≤ 2`）。
- w = 2：余裕を 1 セル足したもの。
- 上の議論は、界面が 1 ステップに 1 セル未満しか動かないこと（CFL ≤ 1/2）に依存する（仮定つきの主張。数値で確かめたのは 1 節の範囲）。

### B. 保存・自由流・単相との一致（構成による）
- 源の項は面の流束の中にだけ入る。同じ面の流束を両側のセルが逆符号で使うので、g をどう切っても、輸送は総運動量を変えない（証明：流束の形）。
- 一様な流れでは厳密解の g は 0 で、切り替えの有無は丸め誤差の育ち方だけに関わる（条件 1・3）。
- 界面が無ければ、帯は空で、g は変わらない。切り替えなしの方式と同じ演算になる（条件 4）。

### C. 合格の条件（B が結果の前に固定、PR #158 のコメント）
| # | 条件 |
| --- | --- |
| 1 | 自由流：密度比 1000 と 1e6 で、一様流の中の液滴・気泡・斜めの帯の速度が丸めの水準（源の項なしと同じ） |
| 2 | 保存：圧力を含む総運動量の正規化した誤差 1e-9 以下（渦の中の液滴） |
| 3 | 安定：同じ形状で増幅が無い（2000 ステップ程度） |
| 4 | 単相：界面の無い計算では、切り替えなしの結果と一致する |
| 5 | 閾値への依存：2 通りの閾値で 1〜3 の合否が変わらない |

記録だけ（合否に入れない）：二相での時間の次数（同じ物理時刻の数値解の場の差、渦の中の液滴）。

- 測り方（A が全ケースの前に決めた）：条件 1・3 は一様流 (1, 0.37)、N = 32・64、2000 ステップの max|u − U|（1e-3 に達したら不安定。「同じ水準」は、源の項なしの 10 倍以内）。条件 2 は t = 1 までの最大。条件 4 は定常の Taylor–Green（t = 0.5）の最後の速度の場の差。
- 正直な記録：全ケースの前に、N = 32・300 ステップの予備の実行（液滴・斜めの帯、渦、単相）で、安定・保存・一致を見ている。規則と閾値はその後で変えていない。

## 2. 記録：二相での時間の次数（渦の中の液滴、密度比 1000、t = 0.25。合否に入れない）
`a₁ = |u(Δt) − u(Δt/2)|_RMS / (Δt − Δt/2)`（ノート113 の 6 節と同じ読み方）。CFL の組 (0.5, 0.25) / (0.25, 0.125)。「離れた」は、両方の計算で 5×5 の範囲に界面のセルが無いセルだけの RMS。

| 形 | N | 全体 | 界面から離れたセル | 界面の近く（全体の 12% / 6%） |
| --- | --- | --- | --- | --- |
| 源の項なし | 64 | 7.9 / 9.1 | 4.5 / 5.1 | 20 / 22 |
| 源の項なし | 128 | 13.5 / 17.5 | 8.3 / 10.8 | 44 / 58 |
| w = 1 | 64 | 7.2 / 9.4 | 4.1 / 4.7 | 18 / 24 |
| w = 1 | 128 | 12.8 / 16.7 | 7.7 / 9.8 | 42 / 56 |
| w = 2 | 64 | 7.6 / 9.7 | 4.8 / 5.2 | 18 / 25 |
| w = 2 | 128 | 14.2 / 17.0 | 8.8 / 10.6 | 47 / 56 |
| 加速度の形（参考、非保存） | 64 | 6.7 / 9.5 | 3.8 / 4.6 | 17 / 25 |
| 加速度の形 | 128 | 14.4 / 20.8 | 9.0 / 11.6 | 47 / 71 |

- **どの形でも、係数 a₁ は格子を細かくすると大きくなり、Δt を小さくしても大きくなる**。単相（ノート113 の 6 節）では、同じ量が h に比例して小さくなった。この流れでは、時間刻みの違う 2 つの解の差が、時間の離散化の誤差として収束していない。
- 界面から離れたセルだけで測っても同じである（界面で生じた差が、圧力を通じて全体に及ぶ）。
- 考えられる理由（未検証）：非粘性・表面張力なしで、密度比 1000 の界面にせん断がかかる（Kelvin–Helmholtz 型の不安定で、連続の問題として短い波長ほど速く育つ）。時間刻みの違いが界面の小さな凹凸の違いになり、育つ。
- **帯の外の時間中心化（w = 1・2）による改善は、この測定では見えない**（源の項なしとの差は、係数のばらつきの範囲）。時間の次数と、界面の近くに残る時間 1 次の大きさを測るには、解が時間刻みについて収束する二相の問題（粘性か表面張力のある問題）が要る。R1 の誤差予算の材料として残すはずだった値は、**得られていない**。

## 自己点検（試験が成立しやすい条件に寄っていないか）
- **CFL 0.5 だけ**。A 節の議論は「界面が 1 ステップに 1 セル未満しか動かない」ことに依存する。保存形の CFL の上限は 0.5（`TwoPhase` が `ns.cfl` を 0.5 以下にする）だが、外挿した面の速度（ノート113 の E1）と組み合わせると、実効の CFL が上がりうる。未検証。
- **形状は 3 つ**（液滴・気泡・斜めの帯）、周期、一様流。薄い膜、分裂、壁に接する界面、界面どうしが近い配置（帯が領域の大半を覆う）は見ていない。界面が多いと、帯が領域の大半を覆い、時間中心化が効く範囲がほとんど無くなる。
- 安定の判定は 2000 ステップ、N ≤ 64。
- 条件 4 は周期の Taylor–Green だけ（界面の無い計算では演算が同じ、という構成上の性質の確認）。
- **粘性・表面張力・外力なし**。ノート113 の修正（E1 の外挿、E2 の粘性の源の項、E3）との組み合わせは測っていない。E2 の粘性の加速度も同じ面の値の源の項に入るので、同じ帯で切ることになる（未検証）。
- **二相での精度の利得は確認できていない**（2 節）。合格したのは「入れても壊さない」ことで、「入れると二相で良くなる」ことではない。

## B に求める判断
1. 案 4 を「最小の修正で安定性を達成できた」と判定してよいか（保存型の中点法・RK2 には進まない）。
2. 二相での時間の次数を測る問題の選定。候補：(a) 粘性のある渦の中の液滴（同じ設定に粘性を足す。自己収束で読む）、(b) R0 の必須の試験の斜めの二層せん断流 + boost（圧力勾配が無いので、源の項の効果は出ない。B の指摘のとおり）、(c) 毛管波（表面張力あり、厳密解あり）。A の見方：(a) を小さく測り、利得が見えなければ「二相では源の項は安定のためだけに切り、利得は単相の領域に限る」と記録する。
3. ライブラリへの導入の形（ノート112 の源の項 + この帯 + ノート113 の E1〜E3）は、2 の後に B が決める（PR #152 の B のコメントの条件 (ii) が、この結果で満たされる）。
