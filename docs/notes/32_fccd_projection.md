# 32 FCCD の射影とジャンプ補正付き面勾配（論文の閉包、PR #46）

## 方法
論文 09b1 の G_Γ(p; j) = G(p) − B(j) を、滑らかな圧力を解く形で実装した。

- **分解：** p = p̃ + H·j_ext。
  - H は液相の指示関数（ψ > ½）。
  - j_ext は界面のジャンプ j = σκ を、最も近い交差点の値で延長したもの（法線方向に一定。HFE の最も低次の形）。
  - 交差点の j は、隣り合うセルの σκ を θ で補間した値（16 と同じ）。
- **p̃ の性質：** 等しい密度では、p̃ は界面で値も法線方向の勾配も連続（[p] = j、[∂ₙp] = 0、∂ₙj_ext = 0 のため）。そのため FCCD の面勾配を界面越しに使える。
- **面の加速度：** 射影は p̃ を解き、面の加速度は α_f (B(j) − D_f(H j_ext))。
  - B(j) = j_Γ(H_R − H_L)/Δ、D_f(H j_ext) = (H_R j_R − H_L j_L)/Δ。
  - 射影・速度補正・セル中心の勾配は、すべて同じ G_Γ を使う。
- `TwoPhaseCLS(..., jump_mode="smooth")`。圧力ジャンプを含む圧力は `full_pressure(ns)`。
- **組み合わせ：** `CenteredNS(ops=FCCDFaceComplex(), viscous=CCDViscosity())`（31）と、CLS の `divergence="full"`。
  - `"full"` は FCCD の補正流束全体の差分。FCCD の射影では、この発散がゼロになるので ψ ≡ 1 が保たれる。
- **対象外：** 密度比のある場合（[∂ₙp] ≠ 0 で p̃ に折れ目が残る）と、Hermite による高次の延長。

## 静止液滴（等密度、R = 0.25、σ = 1、μ = 0.1、10 ステップ）
ジャンプ / 寄生流の最大値（速度成分）：

| | N = 32 | 64 |
| --- | --- | --- |
| 2次の面演算子、鋭いジャンプ（16） | 4.00896 / 2.82e-4 | 4.00267 / 4.39e-5 |
| 2次の面演算子、滑らかな形 | 4.00899 / 2.82e-4 | 4.00267 / 4.38e-5 |
| FCCD、鋭いジャンプ | 4.00694 / 6.93e-3 | 3.99987 / 3.99e-3 |
| FCCD、滑らかな形 | 4.00897 / 2.80e-4 | 4.00267 / 4.10e-5 |

- 2次の面演算子では、2つの形はジャンプの丸め誤差の範囲で一致する（分解が正しい）。
- FCCD で跳びをまたぐと、寄生流が 25〜90 倍になる。滑らかな形なら 2次と同じ水準。
- FCCD・滑らかな形は、N = 128 で 7.4e-6、N = 64・400 ステップで 5.3e-7 まで減衰（安定）。
- 解いた p̃ には液滴内部に ±1.5e-3 の十字状の模様がある。曲率の小さなノイズ（ψ 曲率）を一定に延長した H j_ext を、p̃ が打ち消しているため。
