# 41. 毛管波の離散分散関係：減衰不足の主因は界面の運動学

38〜40 は、時間積分の測定を積み重ねて「渦層の解像度（δ/h）が原因」と解釈してきた。
ここでは理論から見直した。スキーム全体を線形化して離散固有値を直接求め、演算子を一つずつ厳密なものに差し替えて、誤差を項ごとに帰属させた。
**結論は、38 の解釈を訂正する。** 減衰不足の主因は渦層の粘性の解像ではない。CLS の輸送が界面を「界面の近くの数面で平均した速度」で動かすこと（運動学）が主因である。

- スクリプト：`cases/capwave_jacobian.py`（離散分散関係）、`cases/capwave_kinematic_theory.py`（修正分散関係）、`cases/capwave_theory_figures.py`
- 図：`docs/figures/capwave_theory.png`

## 定式化と理論的根拠（本文 1・4 節の式の導出）
### 散逸の恒等式 D = μ∫|ω|²
一定の μ（両相で同じ、本文の線形モデル）、非圧縮で、粘性の散逸は `D = 2μ∫ 𝖣:𝖣`（𝖣 は変形速度テンソル）。恒等式 `2𝖣:𝖣 = |ω|² + 2∇·((u·∇)u)`（∇·u = 0 を使う）を積分すると、発散の項は境界の積分になる。速度が遠方で減衰するか周期なら、それは 0。速度は界面で連続なので、界面の上の跳びの項も出ない。したがって `D = μ∫|ω|²`。

減衰率は、`dE/dt = −D`、モードでは `E ∝ e^{2Re(s)t}` から `−Re(s) = D/(2E)`。

### 運動学の誤差の展開
CLS の交点の速度は `V_h = Σ_f w_f v(y_f)`（y_f は界面からの面の距離）。v を界面のまわりで展開すると：

```
V_h = (Σw) v(0) + M₁ v′(0) + ½ M₂ v″(0) + …,   M_k = Σ_f w_f y_f^k
```

測った重みでは、Σw = 0.982、M₁ = 0、M₂ = 0.331h²。v は界面に幅 δ の山（渦層、極大）を持つので `v″ ≈ −v/δ²`。相対誤差は次のとおり：

```
(V_h − v(0))/v(0) ≈ (Σw − 1) − ½ M₂/δ² = −0.018 − 0.17 (h/δ)²
```

これが本文の「誤差は M₂(h/δ)² に比例」の式。重みは面の間隔 h で決まり、ε にも演算子の次数にもよらない。界面は山の頂点より遅い平均の速度で動く（本文の 0.101 に対して 0.094）。δ/h = 0.92 では第 2 項が約 −0.2 で、減衰の誤差（−17%）と同じ符号・同じ桁。符号と大きさの詳細は、本文 4 節の修正分散関係を自己無撞着に解いて求めた。

## 1. 理論の枠組み
- **散逸の恒等式：** 速度は界面で連続で、遠方で減衰するので、全散逸は D = μ∫|ω|²（エンストロフィー）である。
  - 減衰率は γ = D/(2E)。法線モードで検算した（D/2E = 0.7977、−Re s = 0.7978、×0.5）。
  - 渦度は渦層にしかないので、この流れの散逸はすべて渦層の散逸である。38 の「減衰率 ≈ 格子で採ったエンストロフィー」は、この恒等式から来る。
- **1 次元の Stokes 層モデル：** 階段状の力 F·H(y)e^{iωt} に対する離散の応答では、離散の層はむしろ多めに散逸する（δ/h = 0.92 で FD2 +14%、CCD +10%）。
  - したがって、「層の粘性応答が足りない」は減衰不足の説明にならない。38 の読みはここで崩れた。
- **離散分散関係：** 平らな界面で静止した状態（厳密に定常）のまわりで、1 ステップの Jacobian を作った（状態 ψ, u, uf, p, g の中心差分）。
  - x 方向は一様格子で鏡像の壁なので、各場を「x 方向は cos kx / sin kx、y 方向は各セル」の基底（N = 32 で 257 本）に制限すると、ほぼ閉じる（残差 2e-5）。
  - その密行列の固有値から s_h = log λ / Δt を出す。
  - 注意：Basilisk の CFL の平滑化は t = 0 で刻みを 1/11 にするので、写像は t ≠ 0 から始める必要があった。
- **検算：** N = 32、×1 で、Jacobian の値は減衰 −16.4%、周波数 −3.6%。時間積分の当てはめ（38：−16.35%、−3.37%）と一致した。

## 2. 帰属（N = 32、×1、δ/h = 0.92 の固有値）
| 変えたもの | 減衰誤差 | 周波数の誤差 |
| --- | --- | --- |
| 既定（ψ 曲率） | −16.4% | −3.6% |
| 高さ関数の曲率 | −11.8% | −2.3% |
| **厳密な線形曲率**（交点の η(x) を余弦級数で −η''） | −16.6% | −4.5% |
| 厳密な曲率、Δt/2、Δt/4 | −16.8%、−17.0% | |
| 厳密な曲率、CCD 粘性 | −16.8% | −4.9% |
| 厳密な曲率、CCD + FCCD（smooth） | −13.4% | −3.5% |
| **厳密な曲率、鋭い運動学**（η_t = 面の速度を η で補間） | **+3.8%** | −1.1% |
| 厳密な曲率、CLS の重みを運動学に使う | −16.8% | −5.4% |

- **曲率は原因でない。** 厳密な線形曲率でも同じ不足が出る。高さ関数の曲率で減衰誤差が小さくなるのは、より正確だからではない。余分な数値減衰が、運動学の不足を打ち消しているためである。40 の副産物の解釈は訂正する。
- 時間刻み、粘性演算子の次数、面演算子は、ほとんど効かない。
- **運動学を鋭くすると不足が消える。** CLS の輸送の代わりに、界面の位置 η(x) を面の速度 uf_y を η で補間した値で進め、ψ = H_ε(y − η) を作り直した。
  - η は logit の逆写像で正確に取り出す。交点の線形補間で測り直すと偏りが入り、減衰が 3.8 倍になる誤った結果が出た。

## 3. CLS の運動学の重み
- CLS の保存形の輸送では、ψ = ½ の交点の速度は、交点の両側のセルの ψ_t で決まる。それは界面のまわりの面の速度の線形結合 η_t = Σ w_f v(y_f) である。
- 発散ゼロの cos kx モードを各面に置き、`cls._rhs` から重みを直接求めた（`kinematic_weights`）。
  - 界面の面で 0.569、±h で 0.228、±2h で −0.029、さらに外側に符号の交互する小さな尾（FCCD の補間）がある。
  - 和は 0.982、1 次モーメントは 0、2 次モーメントは M₂ = 0.331h²。格子幅で無次元化すると N によらない。
- 連続系では、ψ = ½ の等値線は v(η) で動く。離散系では、±h の範囲で平均した v で動く。
- **その重みで界面を動かす版**は、CLS の輸送の固有値をほぼ再現する。

| N、粘性 | δ/h | CLS の輸送 | CLS の重みで運動学 | 鋭い運動学 |
| --- | --- | --- | --- | --- |
| 32、×0.5 | 0.65 | −28.8% | −28.9% | −1.3% |
| 32、×1 | 0.92 | −16.6% | −16.8% | +3.8% |
| 32、×2 | 1.30 | −9.2% | −9.5% | +2.7% |
| 64、×0.5 | 1.30 | −8.7% | | +7.0% |
| 64、×1 | 1.83 | −4.7% | −5.0% | +3.3% |
| 64、×2 | 2.59 | −2.9% | −3.2% | +0.9% |

（すべて厳密な線形曲率）

## 4. 修正分散関係（連続の Navier–Stokes ＋ 離散の運動学）
法線モードの運動学条件 sη = v(0) を、sη = Σ w_f v(y_f) に置き換えて解いた（`cases/capwave_kinematic_theory.py`。v(y) は固有ベクトルによるので Newton 法で自己無撞着に解く）。

| N、粘性 | δ/h | 理論 | スキーム（CLS、厳密な曲率） |
| --- | --- | --- | --- |
| 32、×0.5 | 0.65 | −26.8% | −28.8% |
| 32、×1 | 0.92 | −17.0% | −16.6% |
| 32、×2 | 1.30 | −9.6% | −9.2% |
| 64、×0.5 | 1.30 | −11.4% | −8.7% |
| 64、×1 | 1.83 | −6.3% | −4.7% |
| 64、×2 | 2.59 | −3.3% | −2.9% |

- 重みを δ 関数にすると、厳密な s に戻る（差 1e-16）。
- N = 32 では理論とスキームが 2 ポイント以内で一致する。N = 64 では 2〜3 ポイントずれる。鋭い運動学でも残る、運動学以外の部分の誤差（+1〜+7%、減衰しすぎの側）が加わるためと考えられる。
- **機構：** V_h ≈ v(0) + ½M₂ v''(0) + …。v は界面で幅 δ の山を持ち（図 c）、その v'' は v/δ² の大きさである。そのため運動学の誤差は M₂(h/δ)² に比例する。38 で見た (h/δ)² の振る舞い、ε によらないこと（28、38：重みは ε でなく h の面の間隔で決まる）、演算子の次数によらないこと（31、32）を、一つの機構で説明する。
- N = 32、×1 では、v の山の頂点 0.101 に対して、重み付き平均は 0.094（虚部）である。

## 結論
- 毛管波の減衰不足の主因は、CLS の輸送による界面の運動学である。界面が、±h の範囲で平均した速度で動く。粘性項・曲率・面演算子・時間刻みは主因でない。
- 38 の「渦層の粘性の解像不足」の解釈と、40 の「高さ関数の曲率で良くなる」の解釈は、ここで訂正する。
- 39 の写像格子が効いたのは、h を δ より小さくして運動学の平均を狭めたためと解釈できる（M₂h² が小さくなる）。
- 既定値は変えていない。

## 次の段（候補）
- **速度の延長（velocity extension）による輸送：** 界面の速度を法線方向に一定に延長した速度で ψ を動かす。運動学が鋭くなる。保存形でなくなるので、質量は段階 B の補正で閉じる。鋭い運動学の版で、不足は −1〜+4% に下がった。
- **輸送の重みを鋭くする：** 保存形を保ったまま、交点の速度の重みの 2 次モーメントを 0 にする補正（重みの和と 1 次モーメントを保つ）。
- 運動学以外の部分の誤差（N = 64 で +3〜+7%）の帰属。
