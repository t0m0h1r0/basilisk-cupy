# 04 6次の面演算子

## D2 を2回かけない
- f′′′′ = D2(D2 f) は、関係式の幅は3点のままだが、2段目に壁データがない（f″ の壁値は未知）。外挿のクロージャに頼ることになり、合成の性質も保証されない（02 を参照）。
- 未知の高階微分を段数で稼ぐので、情報の使い方は広いステンシルと同じ性格 → 採らない（Tomo さんの指摘）。

## セルのジェットのエルミート補間
CCD は1回の解法で (f, f′, f″) を6次で出している。いまの FCCD は f′ を捨てていた。両隣2セルのジェットで5次のエルミート補間を作り、面で評価する（sympy で検証）。

- 面の値 = (f_L+f_R)/2 + (5h/32)(f′_L − f′_R) + (h²/64)(f″_L + f″_R)　→ 最初の誤差は x⁶（6次）
- 面の勾配 = (15/8)(f_R−f_L)/h − (7/16)(f′_L + f′_R) + (h/32)(f″_R − f″_L)　→ 最初の誤差は x⁷（6次）
- ステンシルは2セル幅のまま。追加の解法は不要。`FCCDFaceComplex(order=6)`。

## 実測（PR #19）
| | 4次 | 6次 |
| --- | --- | --- |
| 面の勾配 / 値、周期、N = 128 | 2.1e-8 / 7.6e-8 | 3.8e-12 / 3.0e-13 |
| 壁あり | 4次 | 壁面は4次（クロージャは同じ）、内部は6次 |
| TG kx = ky、面状態、N = 16 / 32 / 64 | 1.95e-4 / 1.26e-5 / 8.01e-7 | 8.71e-7 / 6.77e-8 / 7.90e-9 |
| TG kx ≠ ky、面状態、N = 16 / 32 / 64 | 1.39e-3 / 1.25e-4 / 8.49e-6 | 8.41e-4 / 6.81e-5 / 4.49e-6 |

- kx = ky では約 1/100。N = 64 で次数が 3.1 に落ちるのは時間誤差と考えられる（未確認）。
- kx ≠ ky では約 1/2 にとどまる。**床は4次の発散**。一般の流れで6次の効果を出すには6次の発散が要る。
- 既定は4次のまま（`order=6` で選ぶ）。発散が6次になってから既定を見直す。

## 計量
- 写像格子の J_face は、同じ次数の面勾配で座標を微分して作る（`J_face_for(order)`）。4次の J_face のままだと勾配が4次に止まり（N = 128 で 4.31）、6次の J_face を4次の勾配と組み合わせると GCL（dx/dx = 1）が崩れる。

## 発散：エルミート微分（案 a）の調査結果
- 面の並び上のジェット (F, F′, F″) に5次エルミートの中点微分を使う：(15/8)(F_R−F_L)/h − (7/16)(F′_L + F′_R) + (h/32)(F″_R − F″_L)。
- 周期：6次。全セルの和は 1e-15 で 0（保存形の流束が存在する）。
- 壁あり：壁セルで4次（4次の補正版と同じ）、内部は6次以上。全体の和に内部の値が入る構造も4次版と同じ（03 の「未解決」と同じ問題を持つ）。
- NS（a ≠ b、面状態、N = 16 / 32 / 64）：
  - 周期：2.86e-4 / 5.22e-6 / 2.32e-7（4次の発散 8.49e-6 の約 1/37）。
  - 自由すべり箱：6.51e-4 / 5.61e-5 / 2.32e-6（改善なし）。床は壁のクロージャ（壁セルで4次・3次）。コンパクト化で受け入れた次数の低下が最大ノルムに出ている。
- 案 (b)（拡張 CCD で F′′′′）は、周期では (a) で足り、壁では床がクロージャなので、今は不要。
