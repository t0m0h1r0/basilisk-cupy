# 78 エネルギー整合の陰的な運動量の輸送：小規模な行列での検証（P0-3、P0-4a、P0-4b）

ノート77 で、Basilisk の運動量保存形（`conserving.h`）が界面のない Taylor–Green でも時間 1 次で、演算子を継ぎ足す修正（源の項など）では直らず、源の項は密度比 1000 で不安定になることがわかった。ユーザーの提案に従い、方針を「**保存則と安定性を満たす離散演算子を先に定義し、その制約の中で CCD による高次化を行う**」に転換する。最初に、流れの解法も VOF も使わない小規模な行列で、設計の原理が成り立つかを確かめた（`python -m cases.energy_transport`、一次元・周期）。

## 1. 定式化（ユーザーの設計）
セルの質量 mⁿ > 0、1 ステップに面 f を通る質量 M_f、`mⁿ⁺¹ = mⁿ − D M`。質量の平方根で重み付けた時間平均

```
w_i = (√m_iⁿ⁺¹ u_iⁿ⁺¹ + √m_iⁿ u_iⁿ) / (√m_iⁿ⁺¹ + √m_iⁿ)
```

で、各セルで厳密に `ΔE_i = w_i Δp_i − |w_i|² Δm_i / 2`。セル i と j の間の質量の移動 M_ij（= −M_ji）に対して、運動量を

```
P_ij = M_ij (w_i + w_j)/2 − |M_ij| λ_ij (w_j − w_i)/2,   λ_ij ≥ 0
```

で運ぶと `ΔE = −½ Σ |M_ij| λ_ij |w_j − w_i|² ≤ 0`。1 ステップは `(B₊ + L) w = B₋ uⁿ`（`B₊ = diag(mⁿ⁺¹ + √(mⁿ⁺¹mⁿ))`、`B₋ = diag(mⁿ + √(mⁿ⁺¹mⁿ))`）。

対の構造は 2 つ：
- `pair2`：面の流束を隣どうしの対で運ぶ（空間 2 次）。
- `pair4`：ユーザーの再配分。2 つ離れたセルの対に `b_i = −(M_{i+1/2} + M_{i+3/2})/12` を置き、隣の対を、各面を通る質量の合計が M_f のままになるよう調整する（一定の流束では 4/3 と −1/6、4 次の中心差分）。質量の変化は VOF の Δm と厳密に同じ。

（エネルギー収支は、実際の ΔE と `−½ Σ|M|λ|Δw|²` の差の E に対する比。増幅率は `‖(Mⁿ⁺¹)^{1/2} R (Mⁿ)^{−1/2}‖₂`、R は uⁿ → uⁿ⁺¹ の行列。一様な速度の方向で 1 になる。）

- **運動量保存、エネルギー収支、自由流保存が丸め誤差で成り立ち、連立の行列の対称部は正定値、質量で重み付けた増幅率は 1 以下**（非正規による過渡的な増幅も含めて）。λ = 0 でエネルギーは丸め誤差で保存、λ > 0 で減るだけ。
- **4 次の対の構造（負の結合を含む）でも、エネルギーの構造は保たれる。**

## 4. 時間の誤差を除いた空間の次数（P0-4a、`--semi`）

## 5. 変形と逆変形（P0-4b、`--shear`）：保存するエネルギーの次数
ユーザーの指摘：保存しているのはセル平均の運動エネルギー `E₂ = ½ Σ m q̄²` で、厳密な運動エネルギーとはセル内の変動の分 `(ρh²/24)∫|∇u|²` だけ違う。セル内の変動が変形で変わると、厳密解でも E₂ は変わるので、E₂ を厳密に保存する方式は高次になれない。

試験（ユーザーの設計）：一定の密度、`u_x = a′(t) sin 2πy`、`a = A sin²πt`（A = 0.25、t = 1/2 で最も変形、t = 1 で戻る）、`q = sin 2π(x − a sin 2πy)`（厳密解）。pair 輸送を行ごとに x 方向に（行 j の面の質量の流束は a′(t) × 行の sin 2πy の平均）。

| | N = 16 | 32 | 64 | 128 | 次数 |
| --- | --- | --- | --- | --- | --- |
| 厳密なセル平均の E₂ の変化（t = 0 → 1/2） | −1.56e-2 | −3.95e-3 | −9.90e-4 | −2.48e-4 | 2.0 |
| **厳密なセル平均の E₄ = E₂ + ½ Σ m h²/12 \|D q̄\|² の変化** | −5.31e-4 | −3.42e-5 | −2.15e-6 | −1.35e-7 | **4.0** |
| 方式の E₂（pair2・pair4） | 丸め誤差で一定 | 同 | 同 | | |
| pair2 の t = 1/2 の最大誤差 | 3.83e-2 | 9.96e-3 | 2.51e-3 | | 2.0 |
| **pair4 の t = 1/2 の最大誤差** | 1.49e-2 | 3.90e-3 | **9.87e-4** | | **2.0** |

（D は E₄ の診断のためのスペクトル微分（CCD の代わり）。t = 1 ではどちらも丸め誤差に戻るが、行ごとの輸送が時間対称な線形写像で厳密に元に戻るためで、情報はない。）

- **一次元で 4 次だった pair4 が、ここでは 2 次に落ちる。** 誤差は厳密な E₂ の減り（N = 64 で 9.9e-4）と同じ大きさ。E₂ を厳密に保存する方式は、少なくともこの減りの分だけ厳密解から離れる、というユーザーの議論と数値が合う。ただしこの試験は行ごとの輸送（行の中のずれを表せない構造）の限界も含むので、原因がエネルギーの保存そのものだけかは、まだ分けられていない。
- **E₄ は厳密解で O(h⁴) まで保たれる。** 高次にするなら、保存するエネルギーを E₄ に高次化する（ユーザーの提案 `M̃ = M + h²/12 Dᵀ M D`）、という方向を支持する。

## まとめ
- ユーザーの設計（質量の平方根で重み付けた時間平均、対の流束、陰的な連立）は、変密度（1000:1）の任意の正の質量と整合した質量の流束の上で、運動量保存・自由流保存・エネルギーの単調な減少（λ = 0 で保存）・連立の可解性・質量で重み付けた非増幅を、構造として満たすことを数値で確かめた。
- 4 次の対の構造でも構造は保たれ、一定の密度で空間 4 次が出る（変速度では 2 次、ノート79 で訂正）。
- ただし、セル平均の運動エネルギー E₂ を厳密に保存する方式は、変形と逆変形の試験で 2 次に落ちた（pair4 も）。厳密解でも E₂ は O(h²) 変わり、セル内の変動を含めた E₄ は O(h⁴) まで保たれる。**高次化の前に、保存するエネルギーを E₄ に高次化する必要がある**（ユーザーの指摘を数値で確認）。

## 次
- E₄（`M̃ = M + h²/12 D_CCDᵀ M D_CCD`）を保存する輸送の構成と、変形と逆変形の試験での次数。
- 高次の補正 `K = BᵀQB`（Q 歪対称）でコンパクトな 4 次・6 次への一般化（ユーザーの提案）。
- 時間の高次化（w の定義を保ったまま、または多段の陰的な段で）。
- 対の構造をコンパクト（CCD 型、有理関数の記号）に一般化し、`L + Lᵀ = −diag(Δm) + 2 HᵀWH` の制約の中で修正波数を最適化する。
- 二次元、VOF の質量の流束（方向分割の掃過ごと、または輸送行列 T_ij）と組み合わせ、密度比 1000 の界面で確かめる。
