# 66 VOF の曲率：初期化の誤差と、列の高さの CCD 微分（PR #76）

VOF の静止液滴の誤差は、ジャンプも寄生流もすべて曲率から来る（ノート63・64）。tension.h の曲率（高さ関数を 3 点の差分で微分）を、CCD で精度を上げられるかを調べた。その途中で、初期化の誤差が大きいことが分かった。

## 1. `fraction()` の初期化は、曲率に収束しない誤差を残す（`cases/vof_curvature_ccd.py`）
円（R = 0.25、曲率 4、中心をずらして 8 通り）の、tension.h の曲率の相対誤差：

| 初期化 | N = 32 | 64 | 128 | 256 |
| --- | --- | --- | --- | --- |
| `fraction()`（頂点の水準関数を辺で線形補間） | rms 5.5e-2、max 1.3e-1 | 5.2e-2、1.3e-1 | 5.4e-2、1.3e-1 | 5.5e-2、1.3e-1 |
| 厳密な面積率 | 8.3e-3、1.8e-2 | 2.0e-3、3.3e-3 | 4.9e-4、7.7e-4 | 1.2e-4、1.9e-4 |

- `fraction()` は、辺の上の水準関数の線形補間で界面の位置を O(h²) ずらす。このずれはセルごとに違うので、高さを 2 階微分すると O(1) の曲率の誤差になり、**格子を細かくしても 5% から減らない**。
- 厳密な面積率なら、tension.h の曲率は 2 次で収束する。
- 対策として `fraction(grid, func, refine=k)` を加えた：各セルを k × k の小セルに分け、小セルの `fraction()` を平均する。f の誤差は 1/k² になる（N = 64 で 1.5e-2 → 3.6e-3 / 8.7e-4 / 2.1e-4、k = 2 / 4 / 8）。曲率の rms は N = 128、k = 8 で 5.9e-4（厳密で 4.9e-4）。`TwoPhaseIMEX(vof_refine=k)` で使える。既定は k = 1（Basilisk と同じ）。

### 静止液滴への影響（密度比 1000、μ = 0.1、t = 0.5）
| N | 初期化 | ジャンプの誤差（CSF / GFM） | 寄生流の最大（CSF / GFM） |
| --- | --- | --- | --- |
| 32 | `fraction()` | +3.60e-2 / +3.60e-2 | 1.42e-2 / 1.69e-2 |
| 32 | 厳密 | +3.13e-2 / +3.13e-2 | 1.23e-3 / 1.24e-3 |
| 64 | `fraction()` | +1.15e-2 / （測れず） | 9.04e-3 / （測れず） |
| 64 | 厳密 | +7.54e-3 / +7.58e-3 | 4.57e-4 / 1.14e-3 |

- **寄生流の最大の大部分は、初期化の誤差から来ていた**（厳密にすると N = 32 で 1/12、N = 64 で 1/20）。
- ジャンプの誤差への影響は小さい。厳密な初期化では、N = 32 → 64 で 4.1 倍減る（2 次）。
- N = 64 の `fraction()` + GFM は 2 時間で終わらず（刻みが極端に小さくなったとみられる、原因は未調査）、N = 128 は測れなかった。

## 2. 列の高さの CCD 微分（`basilisk_cupy/interface/vof_curvature.py`）
### 窓の中の列和を CCD で微分しても、次数は上がらない
CLS 用の `height_curvature(heights="sum")` を VOF に使った（行ごとの 7 セルの窓の列和を、列の並びに沿って CCD で微分、`vof_height_curvature`）。円の誤差は rms 4.0e-4（N = 128、tension.h 4.9e-4）で、2 次のまま。CCD が使えたセルだけで測っても同じだった。列和は列の幅で平均した高さなので、点の値に直す補正 `η − h²η″/24` も入れたが、変わらない。原因は run の短さ：行ごとの窓で高さを取るので、45° 付近の run は 10 列ほどしかなく、CCD の端の閉包の精度が支配する。

### 列ごとの界面の絶対位置を CCD で微分する（`ccd_curvature`）
Basilisk の高さ（セル中心から界面までの距離）から、列ごと・向きごとに界面の絶対位置 `P = i + h` を作る。隣の列との差が 1.5 セル以内なら同じ run とし、run に沿って CCD で微分する（平均から点の値への補正つき）。セルは、法線の大きい方の軸の列の値を取る。

| 方法 | N = 32 | 64 | 128 | 256 |
| --- | --- | --- | --- | --- |
| tension.h | rms 8.3e-3、max 1.8e-2 | 2.0e-3、3.3e-3 | 4.9e-4、7.7e-4 | 1.2e-4、1.9e-4 |
| 窓の列和 + CCD | 9.3e-3、3.3e-2 | 1.6e-3、3.3e-3 | 3.9e-4、7.7e-4 | 9.7e-5、1.9e-4 |
| **列の絶対位置 + CCD** | 2.5e-2、1.0e-1 | 3.0e-3、1.2e-2 | 1.8e-4、9.4e-4 | **2.3e-6、1.6e-5** |

- **細かい格子では大きく良くなる**：N = 256 で rms 2.3e-6、tension.h の 1/54。N = 128 → 256 で約 80 倍。
- **粗い格子（N ≤ 64）では tension.h より悪い**。誤差は 45° 付近に集中する（N = 64：0〜10° で 4e-5、40〜50° で 1.2e-2）。45° のセルは、どちらの軸の run でも端に近い。
- run をつなぐ段差の上限を広げると（1.5 → 2.0 / 2.5 / 3.5 セル）、45° は run の内側に入るが、急な部分の高さが入って悪くなる（N = 64 の rms 3.0e-3 → 4.2e-3 / 5.8e-3 / 9.5e-3）。

### 45° 付近の誤差は、列による表し方の特異点から来る
- 高さそのものは正確：N = 32 の円で、Basilisk の高さから作った P は、傾き 1.39 の列まで厳密な列平均と丸め誤差で一致した（傾き 2.69 の列には高さがない）。
- 列で見た円 `y = sqrt(R² − x²)` は、x = R（界面が垂直になる点）で特異になる。45° の点からこの特異点までは R(1 − 1/√2) ≈ 0.29R（N = 32 で 2.3 セル、64 で 4.7、128 で 9.4）。高階の微分がそこで急に大きくなるので、CCD のような高次の微分は、この距離が十分に長くないと効かない。tension.h の 3 点の差分は短いので影響されにくい。
- 試した対策（円、8 通りの平均）：

| 対策 | N = 32 rms | 64 | 128 | 256 |
| --- | --- | --- | --- | --- |
| なし（法線の大きい方の軸） | 2.5e-2 | 3.0e-3 | 1.8e-4 | 2.3e-6 |
| run の端から遠い方の軸を選ぶ（`choose="interior"`） | 2.8e-2 | 3.1e-3 | 1.9e-4 | 2.3e-6 |
| CCD は \|P′\| ≤ 0.6 の列だけ、ほかは tension.h（`max_slope`） | 1.0e-2 | 1.5e-3 | 3.5e-4 | 8.9e-5 |
| （tension.h） | 8.3e-3 | 2.0e-3 | 4.9e-4 | 1.2e-4 |

- どれも、粗い格子と細かい格子の間の取り引きになるだけ。**列の CCD 曲率が tension.h より良いのは、曲率半径がおよそ 30 セル以上のとき**（円では N ≥ 128）。
- 閉じていない、ほぼ平らな界面（毛管波）は、周期的な一本の run になり、端も特異点もない。ここが一番効くはず（次節）。

## 3. 動く界面（`cases/vof_imex_dynamics.py --variants ...+ccdk ...+r8`、ab2、fd2 の粘性）
### CCD の曲率は毛管の刻みを短くする必要がある
最初、GFM と列の CCD 曲率の組み合わせは、毛管波 N = 64 で寄生流が育った（最大速度 0.62、周波数 +9.95%）。CSF でも、刻みを tension.h の毛管の上限（2.58e-4）いっぱいにすると、最大速度は 0.08〜0.14 になる（出力時刻に合わせて刻みが約 10% 短くなる比較では 0.032 で、際どく安定していただけ）。CCD の 2 階微分は格子スケールで 3 点の差分の 12/5 倍の利得を持つので、CLS の CCD 曲率と同じく、毛管の刻みに √(5/12) をかけた（`TwoPhase._curvature_dt_factor`、`curvature_method="ccd"` のときだけ）。これで最大速度は 0.03 に戻った（GFM と CSF とも）。以下はこの刻みでの値。

| 方式 | 毛管波 N = 32：β 倍率 / ω の誤差 | N = 64 | 液滴 N = 32：ω の誤差 | N = 64 |
| --- | --- | --- | --- | --- |
| CSF、tension.h の曲率 | 2.05 倍 / −3.98% | 1.18 倍 / −1.33% | −1.54% | −1.04% |
| **CSF、列の CCD 曲率** | 2.05 倍 / **−3.02%** | 1.18 倍 / **−1.09%** | −1.46% | −1.13% |
| CSF、tension.h、初期化 k = 8 | 2.05 倍 / −3.98% | 1.18 倍 / −1.33% | −1.96% | −1.13% |
| GFM、tension.h の曲率（ノート65） | 0.25 倍 / −4.91% | 0.37 倍 / −1.44% | −2.38% | −1.04% |
| **GFM、列の CCD 曲率** | 0.25 倍 / **−3.98%** | 0.44 倍 / **−1.22%** | −2.29% | −1.21% |

- **毛管波では、列の CCD 曲率で周波数の誤差が縮む**（CSF：N = 32 で 0.96 ポイント、N = 64 で 0.24 ポイント；GFM も同程度）。減衰は変わらない。
- N = 128（GPU、`--backend cupy --n 128 --cases capwave`）：tension.h は 1.00 倍 / −0.55%、列の CCD は 1.00 倍 / −0.52%。縮む幅は 0.03 ポイントだけ。**細かい格子では、毛管波の周波数の誤差は曲率以外（時間積分・速度の離散化）で決まる。** 減衰は N = 128 で物理どおり。
- 振動液滴（半径 8〜16 セル）では差がない。円の試験どおり、この解像度では CCD の利点が出ない。
- 初期化の細分（k = 8）は、動く界面の結果をほとんど変えない（毛管波は同じ値）。初期化の誤差が効くのは、静止液滴の寄生流（1 節）。
