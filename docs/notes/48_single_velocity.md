# 48. 一つの速度場で閉じた半離散化：セル中心の厳密射影と MAC

47 で、CenteredNS は面速度を毎ステップ、セル中心の速度から作り直す（近似射影）ため、2 次の時間積分でも次数が上がらないと分かった。
ここでは、一つの速度場で閉じた半離散化が成り立つかを、小規模な線形系（行列）で判定した。

**結論：セル中心の厳密射影は、2 次で収束し、毛管波の誤差も改善する。** 同じ Δt で、fd2 の粘性では +7.7% → +3.2%、CCD では +4.4% → +1.1%。静止液滴のつり合いも保たれる。
注意点として、圧力演算子が checkerboard で変調されたモードを、最も滑らかなモードと同じ大きさでしか拾わない（コロケート格子に固有の問題）。MAC は、この組み合わせでは減衰しすぎた（+12.9%）。

- スクリプト：`cases/single_velocity.py`（行列の組み立て、半離散の固有値、CN・SDIRK2 の 1 ステップ）、`cases/single_velocity_figures.py`
- 図：`docs/figures/single_velocity.png`
- 共通の条件：線形（平らな界面のまわり）、密度比 1、壁（法線速度 0、接線方向はすべり）、厳密な線形曲率、帯の補正の運動学（44）。壁面は未知数から除いた。

## 定式化と理論的根拠
### セル中心の厳密射影が直交射影であること
`G_c = −D_cᵀ`（体積の内積で）なら、`Π_c = I − G_c(D_c G_c)⁺ D_c` は次を満たす：

- 対称：`(G_c(D_cG_c)⁺D_c)ᵀ = D_cᵀ((D_cG_c)⁺)ᵀ G_cᵀ = G_c(D_cG_c)⁺D_c`。`D_cG_c = −D_cD_cᵀ` が対称で、その擬似逆行列も対称なため。
- 冪等：`D_c G_c (D_cG_c)⁺ D_c = D_c`（D_c の値域の上で）から `Π_c² = Π_c`。

したがって、直交射影（エネルギーを増やさない）。測定の `Π² − Π` 2e-15、`Π − Πᵀ` 1e-15 はこの確認。

### checkerboard の圧力モードが弱い理由
`D_c = D_f I`（I はセルから面への平均）。一次元で、`(D_c u)_i = (u_{i+1} − u_{i−1})/(2h)`（間隔 2h の中心差分）。その記号は `i sin(kh)/h` で、kh = π（checkerboard）で 0 になる。

- 周期の領域では、checkerboard の圧力は `D_cᵀ` の核に入り、厳密な零モードになる。
- 壁があると厳密な零モードではなくなるが、最も滑らかなモードと同じ程度の小さな固有値しか持たない。測定（最小の非零固有値 2.459 の固有ベクトルの 71〜74% が checkerboard）はこれと一致する。
- MAC の `D_f D_fᵀ` は間隔 h の差分で、記号 `2i sin(kh/2)/h` は kh = π で最大。checkerboard を強く抑える。

### 毛管波の誤差が CenteredNS の Δt → 0 の値と一致する理由
CenteredNS の近似射影は、毎ステップの作り直し（ノート47）を除けば、同じセル中心の射影を 1 ステップずつ近似している。Δt → 0 でその近似の誤差は消え、厳密射影の半離散の値に近づく（+3.2%、+1.1% で一致）。

## 1. 二つの半離散化
| | セル中心の厳密射影 | MAC |
| --- | --- | --- |
| 未知数 | セル中心の速度 u_c（面速度 u_f = I u_c） | 面速度 u_f |
| 射影 | D_c = D_f I、G_c = −D_cᵀ、Π_c = 1 − G_c(D_c G_c)⁺D_c | Π_f = 1 − G_f(D_f G_f)⁺D_f、G_f = −D_fᵀ |
| 粘性 | セル中心の解法の全応力（fd2 または CCD） | 面の各成分の fd2 ラプラシアン |
| 表面張力 | Iᵀa（GFM の面加速度を補間の転置でセルへ） | a（面にそのまま） |
| 運動学 | ψ̇ = −T I u_c | ψ̇ = −T u_f |

半離散系 u̇ = Π(νLu + f(ψ))、ψ̇ = −T u_f の固有値から、時間刻みの誤差なしに減衰と周波数を求めた。

## 2. 射影の性質
- セル中心：Π_c² − Π_c の最大 2e-15、Π_c − Π_cᵀ の最大 1e-15（体積の内積について直交射影）。
- MAC：擬似逆行列の閾値を 1e-10 にして 3e-15（既定の閾値では、定数の零固有値を切れずに 3e-5 だった）。
- **圧力の零空間：** 壁があるので、厳密な零空間はどちらも定数の 1 つだけである。ただし、低い固有値の中身が違う。

| | 最小の非零固有値（N = 32） | その固有ベクトル |
| --- | --- | --- |
| セル中心 D_c D_cᵀ | 2.459（4 重） | 2 つが checkerboard で変調されたモード（固有ベクトルの 71%、74%） |
| MAC D_f D_fᵀ | 2.465（2 重） | 滑らかなモード（checkerboard の成分 0.1%） |

- セル中心の形では、checkerboard で変調された圧力モードが、最も滑らかなモードと同じ固有値しか持たない。広い間隔（2h）の中心差分であるため、圧力演算子は checkerboard の振動を滑らかな成分と区別できない。
- 周期境界なら、厳密な零モードになる。
- 速度の射影そのものは正確である。ただし、圧力場と GFM のジャンプの表現に checkerboard が出る可能性がある（未試験）。

## 3. 毛管波（半離散の固有値、N = 32）
| | 減衰誤差 | 周波数の誤差 |
| --- | --- | --- |
| CenteredNS の Δt → 0 の外挿（46、fd2） | +3.2% | −0.2% |
| セル中心の厳密射影、fd2 | +3.23% | −0.18% |
| セル中心の厳密射影、CCD | **+1.14%** | −1.11% |
| MAC、fd2 | +12.9% | +2.8% |

- セル中心の厳密射影の半離散値は、CenteredNS を Δt → 0 に外挿した値と一致する（fd2：+3.2%、CCD：+1.1%）。CenteredNS の近似射影は、この系の 1 次の近似になっている。
- MAC は、周波数は格子とともに収束する（×4 で N = 16 / 32：+5.2% / +0.7%）が、減衰しすぎる（×1 で −19.9% → +12.9%、×4 で +5.2% → +4.5%）。帯の補正の運動学は CenteredNS の面速度に合わせて作ったもので、MAC との相性は確かめていない（未解明）。
- セル中心（fd2）の格子依存：×4 で N = 16 / 32：−7.0% / +1.3%、×1 で −27.8% / +3.2%。

## 4. 時間積分の次数（セル中心の厳密射影、N = 32、×1）
| 方式 | Δt | Δt/2 | Δt/4 | 周波数（Δt） |
| --- | --- | --- | --- | --- |
| BE、fd2 | +16.1% | +9.7% | +6.5% | −0.58% |
| CN、fd2 | +3.203% | +3.221% | +3.226% | −0.19% |
| SDIRK2、fd2 | +3.215% | +3.224% | +3.226% | −0.19% |
| CN、CCD | +1.113% | +1.130% | +1.135% | −1.12% |
| SDIRK2、CCD | +1.125% | +1.133% | +1.136% | −1.11% |

- 厳密射影では、CN・SDIRK2 は 2 次で収束し（差の比 ≈ 0.25〜0.3）、既定の刻みですでに半離散の値に達する。
- 同じ刻みで、現行より 4.5 ポイント（fd2）、3.3 ポイント（CCD）良い。

## 5. 静止液滴のつり合い
円の界面（R = 0.25）の GFM の力のうち、射影で残る発散ゼロ成分の割合：

| | N = 32 | N = 64 |
| --- | --- | --- |
| 面（CenteredNS の u_f の射影） | 8.1e-4 | 1.9e-4 |
| セル中心の厳密射影（Iᵀa） | 8.6e-4 | 2.1e-4 |

- つり合いは、ほぼ同じに保たれる。

## 判定と次の段
| 判定基準 | 結果 |
| --- | --- |
| 2 次収束し、毛管波の誤差も改善 | **該当**（セル中心の厳密射影） |
| 構造的な問題 | checkerboard で変調された圧力モードが、最も滑らかなモードと同じ大きさでしか抑えられない（厳密な零空間ではない） |
| MAC | この組み合わせでは減衰しすぎる。運動学との相性が未確認 |

- セル中心方式を継続する。実装上の課題は次の三つ。
  - 厳密射影の圧力方程式 D_c D_cᵀ（間隔 2h の広いステンシル）のマルチグリッドの設計。周期境界では 4 つの部分格子に分かれる。
  - checkerboard 圧力の監視（GFM のジャンプと静止液滴の圧力場）。
  - 時間積分（SDIRK2 など）との組み合わせと費用。
- 既定値は変えていない（`cases/` のみ）。P0-4 は引き続き保留。
