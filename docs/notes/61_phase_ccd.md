# 61 相ごとの CCD の射影をライブラリに：`faces="phase-ccd"`（PR #72）

## 定式化と理論的根拠
### 跳びのある圧力の面勾配（GFM、Liu–Fedkiw–Kang 2000）
界面は、面の両側のセルの ψ が 1/2 を横切る点。面の中心間の線分の割合 `θ = (ψ_L − 1/2)/(ψ_L − ψ_R)` の位置にある。跳びの条件は次の 2 つ：

- 圧力：`[p] = j`、`j = σκ + [ρ] G·(x − Z)`（表面張力と、重力の縮約の項）。
- 加速度の連続：`[α ∂_n p] = 0`（α = 1/ρ）。

相ごとに p を一次とみなして、この 2 条件を課すと、面の加速度は次のとおり：

```
α_F (G p − B(j)),   B(j) = j (H_R − H_L)/Δ,   α_F = 1/(θ ρ_L + (1 − θ) ρ_R)
```

H = [ψ > 1/2]。α_F は、界面までの距離で重み付けた α の調和平均（区間 [L, Γ] と [Γ, R] の直列の抵抗）。これが fd2 の GFM（2 次）。

`phase-ccd` は、切断面で区切った区間ごとに CCD の (p, p′, p″) を作り、両側の 3 階までの Taylor の項で界面の値と勾配を合わせる。面の差の打ち切り誤差は O(h⁴) まで下がる（製造解の約 3.8 次）。

### 交点の跳びの Hermite 補間
線に沿った交点で必要な跳び j（=σκ）を、隣り合う 2 点の (j, j′, j″) で補間する。条件は 6 個なので、次数 5 の Hermite 多項式が一意に決まり、補間の誤差は O(h⁶)。曲率は帯の外で 0 に落ちるので、そのまま CCD をかけると帯の端で不連続になる。そのため、帯の端の値で延長してから微分する。

### 流れの中で精度が頭打ちになる理由（解釈）
ジャンプの誤差は、演算子の打ち切り誤差 `O(h^p)` と、与える跳び σκ の誤差 `σ δκ` の和。製造解では κ が厳密なので演算子の次数が見える。流れの中の κ は ψ の CCD から計算した曲率で、その誤差の次数が低ければ、細かい格子では `σ δκ` が床になる。N = 128 で fd2 との差が縮んだのは、この形と整合する。曲率を厳密にした比較をしていないので、確かめてはいない。

## 実装
- `basilisk_cupy/discretization/phase_ccd.py` の `PhaseCCDFaces`。ノート55 の案 A′ を、壁のある線にも対応させた。
  - 各線を切断面で区間に分ける。区間の閉包は、壁側が場の境界条件（圧力の増分は Neumann）、切断面側が外挿。
  - 6 セル以上の区間の内部の面には、FCCD の面勾配を使う。
  - 切断面では、両側の 3 階までの Taylor の項を加えた GFM の差にし、面の中心の値に移す。
  - 線ごとの計算はホストで行う。区間の構造は界面が動いたときだけ作り直し、同じ長さ・閉包の区間はまとめて一回の行列積で計算する（線ごとのループの版と 1e-11 で一致）。
- `hermite_at_crossings`：交点のジャンプを、線に沿った CCD のデータ (j, j′, j″) による 5 次の Hermite で補間する。曲率は帯の外で 0 なので、線に沿って帯の端の値で延長してから CCD をかける。`TwoPhaseCLS(jump_interp="hermite")`。
- `TwoPhaseIMEX(faces="phase-ccd")`（`TwoPhaseIMEXRK` も）：密度比を許す。交点のジャンプは Hermite、CLS の発散は FCCD に合わせて `"full"`。物性が決まった後に、毎ステップ切断面の情報を更新する。既定は fd2 のまま。
- 試作（ノート55）との一致：製造解で、残った面速度が試作と同じ値（密度比 1 / 1000 で 1.5236e-2 / 1.2072e-1）。この比較で、試作の検査の判定漏れ（発散が fd2 のまま）が見つかり、ノート55 を訂正した（結論は不変）。

## 1. 静止液滴（R = 0.25、σ = 1、μ = 0.1、壁、t = 0.5、`cases/phase_ccd_check.py`）
| 面の演算子 | 密度比 | ジャンプの誤差 N = 32 / 64 / 128 | 寄生流の最大 N = 32 / 64 / 128 | 時間 N = 128（CPU） |
| --- | --- | --- | --- | --- |
| fd2 の GFM | 1 | 2.57e-3 / 7.51e-4 / 2.67e-4 | 3.7e-4 / 5.7e-5 / 2.8e-5 | 164 秒 |
| fd2 の GFM | 1000 | 2.63e-3 / 7.54e-4 / 2.66e-4 | 6.8e-4 / 9.4e-5 / 3.3e-5 | 469 秒 |
| `phase-ccd` | 1 | **5.48e-4 / 2.17e-4 / 1.68e-4** | 1.7e-4 / 7.7e-5 / 5.1e-5 | 773 秒 |
| `phase-ccd` | 1000 | **5.38e-4 / 2.14e-4 / 1.68e-4** | 3.2e-4 / 1.0e-4 / 6.1e-5 | 1643 秒 |

- 密度比 1000 でも安定。t = 0.5 の寄生流は、どちらも 1e-9〜1e-8。
- **ジャンプの誤差は粗い格子で 3.5〜4.9 倍小さい。** ただし N = 128 では 1.7e-4 で頭打ちになり、fd2 との差は 1.6 倍に縮む。製造解の約 3.8 次は、流れの中では出ない。曲率（ψ の CCD）の誤差が床になっていると見られる（未確認：曲率を厳密にした比較はしていない）。
- **寄生流の最大は、N = 64・128 で fd2 の約 2 倍。**
- 費用は CPU で 2〜4 倍。時間のほとんどは、欠陥補正の前処理（GFM の係数の多重格子法、1 ステップに約 16 回）で、`phase-ccd` の面勾配そのものではない。

## 判定
- 相ごとの CCD は、製造解（与えたジャンプ）では密度比によらず高次になるが、流れの中では曲率の精度が先に効き、利点は粗い格子のジャンプの精度に限られる。毛管波の減衰と寄生流は、かえって悪くなる。
- **既定は fd2 の GFM のまま**とし、`faces="phase-ccd"` はオプションとして残す。
- 次の一手の候補：曲率の高次化（ψ でなく高さ関数や φ からの曲率、ノート25）と組み合わせて、ジャンプの精度の床が下がるかを確かめる。GPU 化（線ごとの計算をデバイスで）。
