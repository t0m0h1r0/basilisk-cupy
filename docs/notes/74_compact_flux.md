# 74 BCG 型の流束をコンパクトに：CFL 数に依存する右辺と固定の左辺（PR #82）

ノート72 の CCD-BCG の試作（BCG の勾配を CCD の微分に替える）を一歩進め、BCG の面の流束そのものをコンパクトな関係式で求める形を検討した（ユーザーの設計案による）。

## 1. 厳密な流束の演算子
一次元の定速移流 `q_t + u q_x = 0`、セル平均 `q̄`、CFL 数 `C = u Δt / h`、`D = h ∂x`。1 ステップに面を通る量の平均（風上のセルから）を与える厳密な演算子は

```
R_C(D) = (1 − e^{−C D}) / (C (1 − e^{−D}))
       = 1 + (1 − C)/2 · D + (1 − C)(1 − 2C)/12 · D² − C (1 − C)²/24 · D³ + …
```

BCG はこれを D の 1 次で打ち切ったもの。2 次まで取ると、セル平均を保つ放物線 `q̄ + q′ξ + q″/2 (ξ² − h²/12)` の掃過の平均になる。`R_1 = 1`（CFL 数 1 で厳密な平行移動）。

1 ステップの増幅率は `G(θ, C) = 1 − C (1 − e^{−iθ}) R`、厳密解は `e^{−iCθ}`。

## 2. ノート72 の `ccd2` の誤り
最初の試作の 2 次の項は `(h²/8)(1 − C)² q″`（面での、半ステップ先の点の値のテイラー展開）だった。有限体積の流束として正しいのは `(h²/12)(1 − C)(1 − 2C) q″`（上の展開）。線形の安定性（`cases/ccd_bcg_stability.py`、CCD の記号は実装の行列から）：

| 面の値 | 0 < C ≤ 1 |
| --- | --- |
| BCG（中心差分の勾配） | 安定 |
| CCD の勾配 | 安定 |
| CCD + (1 − C)²/8 q″（点の値、誤り） | C ≲ 0.33 で不安定（\|G\| − 1 最大 1.6e-2） |
| CCD + (1 − C)(1 − 2C)/12 q″（平均を保つ放物線） | 安定 |

直した `ccd2` は、二相のせん断層で、密度比 10 では 1.07〜1.12（誤った版は 5.5 倍・発散）になったが、密度比 100、N = 128 では発散した（t = 1.71）。線形には安定なので、残る不安定は界面（密度の跳び）から来る。線全体を一度に解くコンパクトな方式は、界面で速度の勾配が折れる影響を線全体に広げる。

## 3. 左辺を固定し、右辺だけ CFL 数に依存させるコンパクトな流束（`cases/compact_flux_theory.py`）
```
α r_{f−1} + r_f + α r_{f+1} = Σ_j a_j(C) q̄_{i+j}      （i は面 f の風上のセル）
```

左辺は CFL 数によらず固定（一度だけ分解でき、CFL 数がセルごとに違っても使える）。右辺の係数は、CFL 数ごとに、`R_C(D) (1 + α(e^D + e^{−D}))` のテイラー係数を、ステンシルが許す階数まで合わせて決める。`C = 1` では `a = (α, 1, α)` で `R_1 = 1` を表せる。

1 ステップの増幅率の、厳密解からのずれ（全 CFL 数 0.05〜1 での最大）：

| 方式 | 全 CFL 数で安定 | θ = π/4 | θ = π/2 |
| --- | --- | --- | --- |
| BCG | 安定 | 8.5e-3 | 0.12 |
| CCD の勾配 | 安定 | 3.9e-3 | 3.1e-2 |
| CCD の放物線 | 安定 | 9.8e-4 | 1.6e-2 |
| α = 0（陽的）、5 点 j = −2..2 | 安定 | 1.0e-3 | 5.0e-2 |
| α = 1/4、5 点 | 安定 | 2.4e-4 | 1.7e-2 |
| **α = 1/3、5 点** | **安定** | **5.5e-5** | **5.6e-3** |
| α = 1/3、3〜4 点 | 一部の C で不安定 | | |

（「次数」の欄も計算したが、小さい波数での傾きの粗い目安で信用できない値が出たので、次の節の実測で示す。）

## 4. 一次元の試作（`cases/compact_flux_1d.py`、周期、定速、FFT で左辺を解く）
正弦波を 1 周期運んだときの最大誤差：

| 方式 | CFL 0.5：N = 16 / 32 / 64 / 128 | 次数 | CFL 0.8：N = 128 | 次数 |
| --- | --- | --- | --- | --- |
| 1 次の風上 | 4.5e-1 / 2.6e-1 / 1.4e-1 / 7.4e-2 | 0.9 | 3.0e-2 | 1.0 |
| BCG | 1.7e-2 / 2.2e-3 / 2.8e-4 / 3.5e-5 | 3.0 | 1.5e-4 | 2.0 |
| α = 1/4、5 点 | 1.1e-4 / 3.6e-6 / 1.1e-7 / 3.5e-9 | **5.0** | 1.3e-9 | **5.0** |
| α = 1/3、5 点 | 2.3e-5 / 7.2e-7 / 2.2e-8 / 7.0e-10 | **5.0** | 1.7e-10 | **5.0** |

- **定速の移流で 5 次**。N = 128 で BCG の 1/10,000〜1/50,000 の誤差。
- 矩形波（N = 128、CFL 0.5）の行き過ぎ：BCG 5.2%、コンパクト 7.4〜7.5%（1 次の風上は 0）。不連続には流束の制限（FCT）が要る。
- 速度が場所で変わる一次元の試験は、どの方式も 1 次程度に落ちた。ただしこれは試験の誤り：一次元で速度が変わると発散が 0 でなく、BCG の予測子は発散のない速度を前提にする（`−q u_x Δt/2` の項がない）。非圧縮の流れで測るには、発散のない二次元の速度場が要る。

## 次
- 二次元の受動スカラーの移流（発散のない回転流・せん断流、CFL 数が場所で変わる）で、多次元の横方向の補正を含めた次数と安定性。
- FCT による流束の制限（不連続の行き過ぎ）。
- 二相流：相ごとの区間（界面で切る）で解く形で、運動量保存形の q の移流に入れる。
