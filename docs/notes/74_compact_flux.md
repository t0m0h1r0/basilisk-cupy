# 74 BCG 型の流束をコンパクトに：CFL 数に依存する右辺と固定の左辺（PR #82、二次元と FCT はノート75 の PR）

ノート72 の CCD-BCG の試作（BCG の勾配を CCD の微分に替える）を一歩進め、BCG の面の流束そのものをコンパクトな関係式で求める形を検討した（ユーザーの設計案による）。

## 定式化と理論的根拠
### 厳密な流束の演算子 R_C の導出
定速 u > 0 の厳密解は平行移動。1 ステップに面 `x_f = x_i + h/2` を通る量は、面の上流の長さ uΔt の区間の積分。1 セルの幅あたりにすると次の平均：

```
r_f = (1/C) ∫_{−C}^{0} q(x_f + h s) ds
```

Fourier の成分 `q = e^{ikx}`（D = ikh）では次のとおり：
- セル平均：`q̄_i = e^{ikx_i} (e^{D/2} − e^{−D/2})/D`。
- 掃過の平均：`r_f = e^{ikx_f} (1 − e^{−CD})/(CD)`。

比を取ると、セル平均から流束への記号が得られる：

```
R_C(D) = r_f / q̄_i = (1 − e^{−CD}) / (C (1 − e^{−D}))
```

Taylor 展開は本文の式。C = 1 では R = 1：上流のセルがちょうど 1 つ面を通り抜けるので、流束はそのセル平均そのもの。

更新 `q̄_i^{n+1} = q̄_i − C (r_f − r_{f−1})` の記号は `G = 1 − C(1 − e^{−iθ}) R`。R が厳密なら `G = e^{−iCθ}`（平行移動）。

### `ccd2` の誤り
BCG の面の値は、特性線を半ステップさかのぼった点の値 `q(x_f − uΔt/2)`。セルの中心からの距離は `(h/2)(1 − C)`。点の値の Taylor 展開は次のとおり：

```
q_i + (h/2)(1 − C) q′ + (h²/8)(1 − C)² q″
```

（1 次までは掃過の平均と一致し、2 次で一致しない。）有限体積の流束は掃過の平均で、正しい 2 次の係数は `(1 − C)(1 − 2C)/12`。誤った係数は、2 次の精度を壊すうえ、線形の増幅率を一部の C で 1 より大きくした（表）。

### コンパクトな流束の係数の決め方
`α r_{f−1} + r_f + α r_{f+1} = Σ_j a_j(C) q̄_{i+j}` の記号は次のとおり：

```
(1 + α(e^{D} + e^{−D})) R_C(D) = Σ_j a_j e^{jD}
```

右辺の Taylor 係数を左辺に、D の低い次数から合わせる。5 点（j = −2…2）なら 5 個の係数で D⁰〜D⁴ が合い、流束の誤差は O(D⁵)。更新は流束の差なので、1 ステップの誤差は `O(h⁵)·(差)`、時間で積み上がって 5 次（実測 5.0）。

C = 1 では R = 1 なので `a = (α, 1, α)`（j = −1, 0, 1）で厳密。α を大きく取ると、左辺が高い波数を抑え、分散誤差が減る（表で α = 1/3 が最小）。3〜4 点の右辺で一部の C が不安定になる理由は、係数を合わせた結果の記号の値の問題で、解析的な説明はしていない。

### 陰的な Padé の [1/2] が、独立の 2 階微分で不安定になる理由
実装の [1/2]（L 安定）は次の形：

```
G = (1 − Z/3) / (1 + 2Z/3 + Z²/6)
```

- 1 階微分の記号は `d₁ = iκ₁`、Z = C d₁。
- Z² を `d₁² = −κ₁²` で置くか、独立の CCD の 2 階微分 `d₂ = −κ₂` で置く。
- 実装の周期の CCD の記号は、全波数で実数（虚部 ≤ 5e-14）。また `κ₂ ≥ κ₁²` を満たす。1 階微分は高い波数で厳密な kh を下回り、2 階微分は (kh)² をよく近似するため。

すると次が成り立つ：

```
|分母|² − |分子|² = (C²/3)(κ₁² − κ₂) + C⁴κ₂²/36
```

- **d₁² で置く（κ₂ = κ₁²）**：差は `C⁴κ₁⁴/36 ≥ 0` なので |G| ≤ 1。どの C でも安定。
- **独立の d₂ で置く**：`κ₂ > κ₁²` の波数では、C が小さいと第 1 項（負）が勝って |G| > 1 になる。境目は `C² = 12(κ₂ − κ₁²)/κ₂²`。これより大きな C では安定。

表の「[1/2] を独立の d₂ で組むと C ≤ 1 で不安定」は、この式の帰結。L 安定性（Z → ∞ で G → 0）の議論は、Z² を Z の 2 乗として扱うことを前提にしており、独立の 2 階微分では成り立たない。

### 方向分割で 1 次に落ちる理由（解釈）
一方向の掃過の速度は発散が 0 でない。vof.h は掃過ごとに `q (u_{i+1/2} − u_{i−1/2})` の項で、これを打ち消すよう補正する。この補正と掃過の順序の交互の入れ替えでは、分割の誤差が `O(Δt)`（1 ステップあたり O(Δt²)）残る。面の値の精度をいくら上げても、この誤差より下には下がらない。

一様な並進では掃過の速度の発散が 0 で、分割の誤差もないので 5 次が残る。分割の誤差の次数そのものを、解析で導いてはいない。

## 1. 厳密な流束の演算子
一次元の定速移流 `q_t + u q_x = 0`、セル平均 `q̄`、CFL 数 `C = u Δt / h`、`D = h ∂x`。1 ステップに面を通る量の平均（風上のセルから）を与える厳密な演算子は

```
R_C(D) = (1 − e^{−C D}) / (C (1 − e^{−D}))
       = 1 + (1 − C)/2 · D + (1 − C)(1 − 2C)/12 · D² − C (1 − C)²/24 · D³ + …
```

BCG はこれを D の 1 次で打ち切ったもの。2 次まで取ると、セル平均を保つ放物線 `q̄ + q′ξ + q″/2 (ξ² − h²/12)` の掃過の平均になる。`R_1 = 1`（CFL 数 1 で厳密な平行移動）。

1 ステップの増幅率は `G(θ, C) = 1 − C (1 − e^{−iθ}) R`、厳密解は `e^{−iCθ}`。

## 2. ノート72 の `ccd2` の誤り
最初の試作の 2 次の項は `(h²/8)(1 − C)² q″`（面での、半ステップ先の点の値のテイラー展開）だった。有限体積の流束として正しいのは `(h²/12)(1 − C)(1 − 2C) q″`（上の展開）。線形の安定性（`cases/ccd_bcg_stability.py`、CCD の記号は実装の行列から）：

| 面の値 | 0 < C ≤ 1 |
| --- | --- |
| BCG（中心差分の勾配） | 安定 |
| CCD の勾配 | 安定 |
| CCD + (1 − C)²/8 q″（点の値、誤り） | C ≲ 0.33 で不安定（\|G\| − 1 最大 1.6e-2） |
| CCD + (1 − C)(1 − 2C)/12 q″（平均を保つ放物線） | 安定 |

直した `ccd2` は、二相のせん断層で、密度比 10 では 1.07〜1.12（誤った版は 5.5 倍・発散）になったが、密度比 100、N = 128 では発散した（t = 1.71）。線形には安定なので、残る不安定は界面（密度の跳び）から来る。線全体を一度に解くコンパクトな方式は、界面で速度の勾配が折れる影響を線全体に広げる。

## 3. 左辺を固定し、右辺だけ CFL 数に依存させるコンパクトな流束（`cases/compact_flux_theory.py`）
```
α r_{f−1} + r_f + α r_{f+1} = Σ_j a_j(C) q̄_{i+j}      （i は面 f の風上のセル）
```

左辺は CFL 数によらず固定（一度だけ分解でき、CFL 数がセルごとに違っても使える）。右辺の係数は、CFL 数ごとに、`R_C(D) (1 + α(e^D + e^{−D}))` のテイラー係数を、ステンシルが許す階数まで合わせて決める。`C = 1` では `a = (α, 1, α)` で `R_1 = 1` を表せる。

1 ステップの増幅率の、厳密解からのずれ（全 CFL 数 0.05〜1 での最大）：

| 方式 | 全 CFL 数で安定 | θ = π/4 | θ = π/2 |
| --- | --- | --- | --- |
| BCG | 安定 | 8.5e-3 | 0.12 |
| CCD の勾配 | 安定 | 3.9e-3 | 3.1e-2 |
| CCD の放物線 | 安定 | 9.8e-4 | 1.6e-2 |
| α = 0（陽的）、5 点 j = −2..2 | 安定 | 1.0e-3 | 5.0e-2 |
| α = 1/4、5 点 | 安定 | 2.4e-4 | 1.7e-2 |
| **α = 1/3、5 点** | **安定** | **5.5e-5** | **5.6e-3** |
| α = 1/3、3〜4 点 | 一部の C で不安定 | | |

（「次数」の欄も計算したが、小さい波数での傾きの粗い目安で信用できない値が出たので、次の節の実測で示す。）

## 4. 一次元の試作（`cases/compact_flux_1d.py`、周期、定速、FFT で左辺を解く）
正弦波を 1 周期運んだときの最大誤差：

| 方式 | CFL 0.5：N = 16 / 32 / 64 / 128 | 次数 | CFL 0.8：N = 128 | 次数 |
| --- | --- | --- | --- | --- |
| 1 次の風上 | 4.5e-1 / 2.6e-1 / 1.4e-1 / 7.4e-2 | 0.9 | 3.0e-2 | 1.0 |
| BCG | 1.7e-2 / 2.2e-3 / 2.8e-4 / 3.5e-5 | 3.0 | 1.5e-4 | 2.0 |
| α = 1/4、5 点 | 1.1e-4 / 3.6e-6 / 1.1e-7 / 3.5e-9 | **5.0** | 1.3e-9 | **5.0** |
| α = 1/3、5 点 | 2.3e-5 / 7.2e-7 / 2.2e-8 / 7.0e-10 | **5.0** | 1.7e-10 | **5.0** |

- **定速の移流で 5 次**。N = 128 で BCG の 1/10,000〜1/50,000 の誤差。
- 矩形波（N = 128、CFL 0.5）の行き過ぎ：BCG 5.2%、コンパクト 7.4〜7.5%（1 次の風上は 0）。不連続には流束の制限（FCT）が要る。
- 速度が場所で変わる一次元の試験は、どの方式も 1 次程度に落ちた。ただしこれは試験の誤り：一次元で速度が変わると発散が 0 でなく、BCG の予測子は発散のない速度を前提にする（`−q u_x Δt/2` の項がない）。非圧縮の流れで測るには、発散のない二次元の速度場が要る。

### FCT（Zalesak、`python -m cases.compact_flux_1d --fct`、1 次の風上を低次の流束に）
| 方式 | 正弦波 N = 16 / 32 / 64 / 128 | 次数 | 矩形波 N = 128：最小 / 最大 / L1 誤差 |
| --- | --- | --- | --- |
| コンパクト（α = 1/3） | 2.34e-5 / 7.20e-7 / 2.24e-8 / 7.00e-10 | 5.0 | −0.0748 / 1.0748 / 1.36e-2 |
| コンパクト + FCT | 3.31e-2 / 1.07e-2 / 3.36e-3 / 1.04e-3 | 1.6〜1.7 | 0 / 1 / 1.31e-2 |
| BCG + FCT | 4.32e-2 / 1.11e-2 / 3.14e-3 / 9.39e-4 | 1.7〜2.0 | 0 / 1 / 2.29e-2 |

FCT は行き過ぎを消し、矩形波の L1 誤差は BCG + FCT の 0.57 倍。ただし、なめらかな正弦波の極値でも流束を切るので、次数が 1.7 に落ちる（コンパクトの利点が消える）。使うなら、なめらかな極値を見分ける制限（極値の判定に 2 階微分を使う型）が要る。

## 5. 二次元の受動スカラー（`python -m cases.compact_flux_2d`、方向分割、発散のない面の速度）
| 試験 | 方式 | N = 32 / 64 / 128（/ 256） | 次数 |
| --- | --- | --- | --- |
| 一様な並進 (1, 0.5)、t = 2 | BCG | 1.08e-2 / 2.13e-3 / 4.89e-4 | 2.3、2.1 |
| | コンパクト | 2.22e-6 / 6.93e-8 / 2.16e-9 | **5.0、5.0** |
| 変形渦（T = 0.5、往復して元に戻る） | BCG | 1.06e-1 / 4.17e-2 / 1.71e-2 / 8.12e-3 | 1.35、1.28、1.08 |
| | コンパクト | 7.30e-2 / 3.45e-2 / 1.64e-2 / 8.10e-3 | 1.08、1.07、1.02 |

- 一様な並進（分割の誤差がない）では二次元でも 5 次。
- 速度が場所で変わる変形渦では、BCG もコンパクトも 1 次に落ち、N = 256 で同じ誤差。誤差は面の値ではなく、方向分割の掃過（各掃過の速度の発散と、`q (u_{i+1/2} − u_{i−1/2})` の項、vof.h と同じ形）で決まっている。高次にするには、分割をやめた多次元の流束（横方向の補正）か、高次の時間積分が要る。
- T = 2（N = 128 で解像できない細い筋になる）は、どちらも収束しない（N = 128 で BCG 0.46、コンパクト 0.18）。

## 6. 陰的な時空間 CCD（Padé 近似、`cases/implicit_ccd_theory.py`）
`e^{−Z}`（`Z = u Δt ∂x`）の Padé 近似で 1 ステップを陰的に進め、Z を `C d₁`、Z² を独立の CCD の 2 階微分 `C² d₂` または `C² d₁²` で置き換えた（d₁、d₂ は実装の CCD の記号）。全波数の \|G\| − 1 と、kh = π/2 の振幅 / 位相速度比：

| Padé | Z² | C ≤ 1 | C = 1 | C = 2 | C = 4 |
| --- | --- | --- | --- | --- | --- |
| [1/1]（CN） | どちらも | 安定 | 1.000 / 0.845 | 1.000 / 0.638 | 1.000 / 0.402 |
| [1/2]（L 安定） | **独立の d₂** | **不安定**（\|G\| − 1 最大 0.67） | 0.942 / 0.980 | 0.661 / 0.853 | 0.331 / −0.42 |
| [1/2] | d₁² | 安定 | 0.940 / 0.978 | 0.663 / 0.851 | 0.334 / −0.42 |
| [2/2] | どちらも | 安定 | 1.000 / 0.991 | 1.000 / 0.930 | 1.000 / −0.30 |

- [1/2] は、CCD が独立に求める 2 階微分で組むと C ≤ 1 で不安定。L 安定性は `Z² → d₁²` のときだけ保たれる。
- 陰解法でも、C ≳ 2 では位相が大きく狂う（C = 4 で逆向き）。精度を保てるのは C ≲ 1〜2。
- いまの二相流の刻みは表面張力で決まり、対流の CFL では決まらないので、陰解法の利点は効きにくい。陽的なコンパクトな流束（C ≤ 1 で 5 次）を本線とし、陰的な形は対流の CFL が刻みを決める問題のための選択肢として残す（採るなら [2/2]、または [1/2] を d₁² で）。
