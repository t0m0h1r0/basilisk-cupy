# 64 VOF + IMEX：VOF の界面を IMEX の時間積分と GFM のジャンプで使う（PR #74）

「CLS + CCD より VOF + CCD の方がうまくいくかもしれない」という方針で、VOF の界面を `TwoPhaseIMEX` に載せた。CLS の経路と同じ時間積分・同じ粘性（CCD）で、界面の表し方だけを入れ替えて比べられるようにする。

## 実装
- `TwoPhaseIMEX(interface=...)`：
  - `"cls"`（既定）：これまでの CLS + GFM。
  - `"vof"`（段階 A）：Basilisk の VOF（vof.h の PLIC 輸送、two-phase.h の物性、tension.h の高さ関数の曲率、iforce.h の CSF、reduced.h）を、そのまま IMEX の段に入れる。
  - `"vof-gfm"`（段階 B）：VOF の曲率を、CSF でなく鋭い圧力ジャンプ（GFM）で入れる。`basilisk_cupy/interface/vof_jump.py` の `TwoPhaseVOFJump`。
- VOF は面の速度が厳密に発散ゼロであることを前提にする（vof.h）。そのため面の演算子は fd2 に限り、それ以外は `NotImplementedError`。phase-ccd との組み合わせ（段階 C）は未実装。
- 輸送の速度（`transport`：frozen / ab2 など）は CLS と同じ仕組みで VOF にも効く。
- `TwoPhaseVOFJump` の切断面と交点：
  - 切断面：`H = [f > 1/2]` が面の両側で異なる面。
  - 交点：面の両側 3 セルずつの f の線和 S から（面に沿った方向の高さ関数）。下側が相 1 なら、交点は下側のセルの中心から `S − 2.5` セル、上側が相 1 なら `3.5 − S` セル。θ は [0, 1] に切る。CLS のように f を線形補間すると、VOF の f はセルの中で跳ぶので、交点が O(h) ずれる。
  - GFM の係数 `α_f = 1/(θ ρ_L + (1 − θ) ρ_R)`、ジャンプ `j = σκ + [ρ] G·(x − Z)` は、ポテンシャルが定義された（界面の）セルから θ で重みづけ。
- 交点の別法 `vof_crossing="plic"`：面の両側の界面セルの PLIC の直線（Basilisk の `mycs` の法線と α）が、セル中心を結ぶ線と交わる点。下側のセルの直線が [0, 1/2] に、上側のセルの直線が [1/2, 1] に交点を持てばそれを使い（両方なら平均）、どちらもなければ線和に戻る。既定は線和（`"sum"`）。
- 診断：`ns.cls` は f を ψ として持つ薄い入れ物（`mass`、`sharp_volume`）で、CLS の経路の診断がそのまま使える。

## 1. 静止液滴（R = 0.25、σ = 1、μ = 0.1、壁、N = 32、t = 0.1、`tests/test_two_phase_imex.py`）
VOF は fd2 の粘性（3 節の既定）、CLS は CCD の粘性。

| 界面 | 密度比 | ジャンプ | 寄生流（終わり / 最大） | ステップ |
| --- | --- | --- | --- | --- |
| CLS + GFM（既定） | 1 | 4.00977 | 1.07e-4 / 3.67e-4 | 60 |
| CLS + GFM | 1000 | 4.01030 | 1.17e-4 / 6.76e-4 | 81 |
| VOF（CSF） | 1 | 4.04118 | 2.79e-4 / 4.47e-3 | 42 |
| VOF（CSF） | 1000 | 4.04111 | 1.11e-4 / 5.75e-3 | 56 |
| VOF-GFM | 1 | 4.04090 | 2.91e-4 / 4.82e-3 | 42 |
| VOF-GFM（PLIC の交点） | 1 | 4.04093 | 2.66e-4 / 4.79e-3 | 42 |
| VOF-GFM | 1000 | 4.04122 | 4.37e-5 / 7.75e-3 | 56 |
| VOF-GFM（PLIC の交点） | 1000 | 4.04138 | 2.40e-4 / 7.30e-3 | 56 |

- VOF の二つとも、質量は丸め誤差（1e-15）で保存し、密度比 1000 で安定。
- ジャンプの誤差（+1%）は、どちらの VOF でも同じ。**誤差は高さ関数の曲率で決まり、力の入れ方（CSF か GFM か）にはよらない**（ノート63 と同じ構造：静止液滴の誤差は曲率から来る）。
- VOF のステップ数が少ないのは、tension.h の毛管の刻み（CCD 曲率の 12/5 倍の制約がない）による。

### 交点 θ の精度（初期の界面、`cases/vof_jump_crossing.py`）
厳密な界面（水平の線に沿った二分法）と比べた θ の誤差（最大 / 平均）。f > 1/2 では切断面だが厳密な符号は同じ面（液滴で各向き 4 面）は除いた。

| 界面 | 面の向き | 線和 | PLIC |
| --- | --- | --- | --- |
| 毛管波 N = 64 | x（界面とほぼ平行、8 面） | 0.432 / 0.432 | 0.030 / 0.030 |
| 毛管波 N = 64 | y（64 面） | 0.003 / 0.002 | 0.003 / 0.002 |
| 液滴 N = 32 | x / y | 0.159 / 0.058、0.364 / 0.069 | 0.078 / 0.044、0.095 / 0.037 |
| 液滴 N = 64 | x / y | 0.125 / 0.031、0.076 / 0.020 | 0.035 / 0.020、0.022 / 0.015 |

- 線和は、面の向きの線が界面とほぼ平行なとき（毛管波の x 向きの面）に大きく外れる。線の上の f が一様に近く、高さ関数として働かないため。PLIC は界面の向きによらない。
- 静止液滴（N = 32）では、PLIC にしてもジャンプはほとんど変わらない（1 節の表；曲率の誤差が支配）。

## 2. 動く界面：最初は CCD の粘性で（論文の毛管波・振動液滴、水–空気、`cases/vof_imex_dynamics.py`）
法線モード（毛管波 β = −0.803 s⁻¹、ω = 134.34）と 2 次元の粘性モード（液滴 β = −0.179、ω = 59.55）との比較。毛管波は 5 周期、液滴は 2 周期の当てはめ。

| 方式 | 毛管波 N = 32：β（倍率）/ ω の誤差 | N = 64 | 液滴 N = 32 | N = 64 |
| --- | --- | --- | --- | --- |
| VOF（`CenteredNS`、Basilisk） | −2.00（2.49 倍）/ −3.98% | −1.05（1.31 倍）/ −1.33% | +0.05 / −1.71% | +0.00 / −1.04% |
| VOF on IMEX（frozen、CCD の粘性） | +0.75（増幅）/ −4.26% | +0.20 / −3.37%（最大速度 1.04） | +0.60（増幅）/ −1.63% | +1.70 / −8.46%（最大速度 1.69） |
| VOF on IMEX（ab2、CCD の粘性） | −1.20（1.49 倍）/ −3.83% | +0.10 / −1.63%（最大速度 0.40） | +0.15 / −1.54% | +2.15 / −5.55%（最大速度 2.46） |
| VOF-GFM on IMEX（ab2、CCD の粘性） | +0.50 / −6.41% | −1.65 / +2.48%（最大速度 0.72） | −0.30（1.67 倍）/ −4.63% | 発散（514 ステップ） |

最大速度は、Basilisk の VOF で 0.03（毛管波・液滴とも）。

- **N = 32 では、IMEX 上の VOF（ab2）は Basilisk の VOF と同程度**（毛管波の減衰 1.49 倍、液滴の周波数 −1.5%）。輸送は CLS と同じく ab2 が必要（frozen は増幅）。
- **N = 64 では、IMEX 上の VOF は CSF でも GFM でも寄生流が育つ**（最大速度 0.4〜2.5、液滴の GFM は発散）。同じ格子の Basilisk の VOF は安定なので、VOF そのものではなく IMEX の経路との組み合わせの問題。原因の切り分けは次節。

注意：液滴の物理の減衰は 2 周期で振幅の 4% にすぎず、β の当てはめは ±0.5 程度ぶれる（符号が変わるのはこのため）。周波数の方が信頼できる。

## 3. N = 64 の寄生流の原因は、不連続な粘性係数にかけた CCD の粘性（`cases/vof_imex_stability.py`）
IMEX の既定の粘性は CCD（`CCDViscosity`）。VOF の粘性係数は面で `μ(f)` の算術平均で、界面で 1 セルの間に跳ぶ（水–空気で 55 倍）。CLS では ψ が 1.5h の幅で滑らかなので、係数も滑らか。

N = 64、1 周期までの最大速度（Basilisk の VOF は 0.03）：

| 変えたもの | 毛管波（VOF、CSF） | 液滴（VOF-GFM） |
| --- | --- | --- |
| なし（CCD の粘性） | 0.082 | 0.21 |
| 最大の刻みを半分（Δt = 1.2e-4） | 0.085 | 1.30 |
| SBDF1 | 0.087 | 1.95 |
| **fd2 の粘性（`FD2Viscosity`）** | **0.032** | **0.031** |

- **刻みを半分にしても、1 次の SBDF1 にしても寄生流は減らない**（液滴ではむしろ増える）ので、毛管の刻みの制約や時間積分の問題ではない。fd2 の粘性にすると、寄生流は Basilisk の VOF と同じ大きさになる。
- そこで、VOF の界面の既定の粘性を fd2 にした（`interface="vof" / "vof-gfm"` のときだけ；CLS は CCD のまま）。1 節の静止液滴の値はこの既定で測り直したもの。

## 4. fd2 の粘性での動く界面（`cases/vof_imex_dynamics.py --variants ...-fd2v`）
| 方式 | 毛管波 N = 32：β（倍率）/ ω の誤差 | N = 64 | 液滴 N = 32 | N = 64 |
| --- | --- | --- | --- | --- |
| VOF（`CenteredNS`、Basilisk） | −2.00（2.49 倍）/ −3.98% | −1.05（1.31 倍）/ −1.33% | +0.05 / −1.71% | +0.00 / −1.04% |
| **VOF on IMEX（ab2、CSF）** | −1.65（2.05 倍）/ −3.98% | **−0.95（1.18 倍）/ −1.33%** | +0.05 / −1.54% | **+0.00 / −1.04%** |
| VOF-GFM on IMEX（ab2、線和） | +0.45（増幅）/ −5.80% | +0.35（増幅）/ −2.33% | +0.10 / −3.79% | +0.25 / −1.88% |
| VOF-GFM on IMEX（ab2、PLIC） | +0.45 / −5.80% | +0.35 / −2.33% | −0.10 / −3.38% | +0.30 / −1.88% |
| （参考）CLS（ab2 + ξ-SDF 10、fd2 の面、ψ 曲率、ノート63） | −0.40（0.50 倍）/ −9.30% | −1.15（1.43 倍）/ −4.22% | +0.80（増幅）/ −2.55% | +1.60（増幅）/ −1.38% |

最大速度はすべて 0.029〜0.036。時間は N = 64 で 150〜180 秒（CCD の粘性の 770〜900 秒の約 1/5）。

- **IMEX 上の VOF（CSF）は、Basilisk の VOF とほぼ同じ精度**（N = 64 で周波数は同じ −1.33% / −1.04%、毛管波の減衰は 1.18 倍と 1.31 倍）。時間積分を SBDF2 + ab2 に替えても、VOF の精度は落ちない。
- **同じ格子で、VOF は CLS より周波数が 3 倍以上正確**（毛管波 −1.33% 対 −4.22%）で、液滴の振幅も増えない。「VOF + CCD」の土台として、VOF on IMEX は使える。
- **VOF-GFM は CSF より悪い**：毛管波の振幅が増え（β > 0）、周波数の誤差も大きい。交点を PLIC にしても毛管波は変わらない（ほぼ平らな界面では、x 向きの切断面は少なく、y 向きの面の θ は線和でも正確なため）。静止液滴では CSF と同じなので、動く界面でだけ現れる差。原因は未解明（候補：切断面の判定 `f > 1/2` が界面の移動で 1 セル単位で飛ぶこと、ジャンプの位置と高さ関数の曲率の位置のずれ）。
- 液滴の β は、上の注意のとおり ±0.5 のぶれがあり、ここでの差は判定に使わない。

## まとめと次
- VOF on IMEX（`interface="vof"`、ab2、fd2 の粘性）は、Basilisk の VOF と同じ精度で、CLS より正確。
- VOF に CCD の精度を足すには、不連続な係数を避ける必要がある：粘性は fd2 のまま、CCD は相ごとに（phase-ccd と同じ考え方）。
- 次の候補：VOF-GFM の動く界面での劣化の原因（→ ノート65：セル中心の補正の係数。`cell_coefficient="mean"` で CSF と同等に）；VOF + phase-ccd（段階 C、VOF の面速度は厳密に発散ゼロである必要がある）；VOF の曲率の精度（高さ関数の CCD 化）。
