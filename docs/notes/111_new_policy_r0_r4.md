## 1. 研究目的と要件（ユーザー）
> 固定格子上の質量・運動量保存型の二相流ソルバーを基盤とし、CCD によって純相領域の数値誤差を低減する。水・空気相当の物性比で頑健性を維持しながら、同一の物理量の誤差を達成する計算時間を、Basilisk 互換方式より短縮する。

最終目標は、全領域 4 次という形式的な次数ではなく、**物理量の精度と計算性能の改善**である。統合計算が改善した場合にだけ高次化を採用する。高次化しないという結論も成果とする。

| 要件 | 優先度 |
| --- | --- |
| 相の質量・移流の運動量の局所保存 | 必須 |
| 一様な速度の厳密な保存（自由流） | 必須 |
| 離散の体積流束の発散 0 | 必須 |
| 密度比 1000（水・空気相当）で安定 | 必須 |
| 圧力を含む総運動量の保存 | 必須（正規化した収支の誤差 1e-9 以下を暫定の基準） |
| 時間 2 次以上 | 開発目標（基準ソルバーでは R0 の合否の条件） |
| 純相内部の空間 4〜6 次 | 開発目標 |
| 界面の近くの高次精度 | 実測された必要性に応じて追求 |
| 共通の Gram、再構築した場の各点の発散 0 | 必須条件から除外 |
| 同じ精度での GPU の計算時間の短縮 | 最終の採用の条件 |

密度比 1e6 は、方式が完成してからのストレス試験とする。

## 3. R0-P1：保存型の運動量輸送の時間 1 次
### 背景（ノート77）
運動量保存形（`conserving.h` の移植）は、界面のない Taylor–Green でも時間 1 次である（N = 32 / 64 / 128 で 6.36e-2 / 3.39e-2 / 1.82e-2。C 版の Basilisk も同じ値）。面の値の半ステップの予測に圧力の源の項が無いことが約 1/6 を説明し、残りは未解明だった。

### 進め方（ユーザー、監修の第 8 回の報告）
1. ノート77 の結果を再現する。
2. 同じ厳密な初期条件から xy・yx の掃過を 1 ステップずつ行い、誤差の場を偶成分 `(e_xy + e_yx)/2` と奇成分 `(e_xy − e_yx)/2` に分ける。
3. 候補ごとの 1 ステップの局所誤差の主要項を先に書き、実測と照合する。空間誤差と時間誤差を混同しない（固定の格子で時間刻みを変える）。
4. 既存の方式の半ステップの予測を直す最小の修正を、中点法・RK2 より先に試す。
5. 実際の圧力の求解との連成、高密度比での帰還の安定性を確かめる。
6. 最小の修正で解決しない場合だけ、保存型の中点法・RK2 に進む。その場合、質量と運動量を共通の時間積分の段で更新する（質量だけ 1 段にすると自由流の条件が壊れる、監修）。

### 局所誤差の式（ユーザー、2026-11-27）
単相・一定密度・既知の定常な発散 0 の速度場で、`A = −u∂_x`、`B = −v∂_y`、`L_x = −∂_x(u·)`、`L_y = −∂_y(v·)`、`d = ∂_x u = −∂_y v`（`L_x = A − d`、`L_y = B + d`）。現在の VOF の濃度の輸送（方向別の保存形の流束 + 膨張の項、両方の掃過でステップの開始時の濃度を使う）を、空間の再構築が厳密として理想化すると：

```
x → y の順：e_xy = +(Δt²/2)([B, A] + d(A + B))q + O(Δt³)
y → x の順：e_yx = −(Δt²/2)([B, A] + d(A + B))q + O(Δt³)
```

- 交換子だけでなく、凍結した膨張の項による主要な誤差も、掃過の順序の反転で符号が変わる（奇成分）。
- したがって、方向分割と膨張の項の凍結だけでは、交互の掃過で残る時間 1 次を説明できない可能性がある。偶成分（源の項、時間のレベル、射影）を調べる。
- 現行のコードそのものについての証明ではない。実測との照合はノート112。

### 制約（ユーザー）
- ノート77 の源の項は、密度比 1000 で陽的な帰還の不安定（1 ステップに約 1.8 倍）を起こした。単相で時間 2 次になっても、そのまま二相に入れない。
- 時間・空間とも 2 次の基準方式が成立するまで、CCD を足さない。

## 4. R0-P2：圧力を含む運動量の保存
### 導出（監修の第 7 回、ユーザーが採用）
一次元・周期で、セルの速度を両側の面の加速度 `a_f = −(Δp)_f/(hρ_f)` の平均で補正すると、総運動量の変化は

```
ΔP = −Δt Σ_i [(ρ_i + ρ_{i+1})/(2ρ_{i+1/2})] (p_{i+1} − p_i)
```

任意の圧力でこれが 0 になるのは、係数が空間的に一定、すなわち面の密度が両側のセルの密度の算術平均のときだけである。鋭い GFM の面の密度は満たさない。求解の精度では直らない、離散化の問題である。

### 候補（ユーザー）
- 体積流束の補正：`u_f^{n+1} = u_f⋆ − Δt A_f G_f p`。
- セルの運動量の補正：`p_i^{n+1} = p_i⋆ − Δt Σ_{F⊂∂K_i} p_F n_F |F|`（p_F は面で共有する圧力）。内部の面で同じ圧力の応力を逆符号で使うので、周期では総運動量の保存が構成上成り立つ。
- 面の速度とセルの速度の不整合（近似射影）は、これでは解決しない。表面張力を含む場合の圧力の跳びは、表面張力なしで確かめた後に扱う。

### 静水圧の釣り合い（監修の第 8 回、ユーザーの補足）
- 表面張力なしの静水圧の平衡を、R0-P2 の必須の試験にする。密度比 1000、格子に平行な界面、次に斜めの界面。
- **斜めの界面では、重力も界面の法線方向に回転させる**（ユーザー）。静止流体では `∇p = ρg` で、圧力が界面で連続であるためには `[ρ] g·t = 0`、すなわち重力が界面に垂直でなければならない。鉛直の重力のままでは、斜めの平らな密度の界面は静水圧の平衡にならない。
- 厳密な静水圧：界面の法線の座標 s で `p(s) = p₀ + g_n ∫_{s₀}^s ρ(ξ)dξ`。
- 合否を判定する残差：`r_i = m_i g − Σ_{F⊂∂K_i} p̄_F n_F |F|`。厳密な面の平均の圧力では 0 になる。

| 評価の対象 | 必要な条件 |
| --- | --- |
| セルの運動量 | 圧力の応力と重力が釣り合う |
| 面の流束 | 圧力勾配と重力が釣り合う（GFM の側でも独立に） |
| 総運動量 | 境界の応力・外力を含む収支が閉じる |
| 静止の状態 | 長時間にわたって寄生流が育たない |

- セルの速度と面の流束の差は、厳密な 0 を求めない。空間の離散化の誤差として説明でき、格子を細かくすると減り、時間とともに累積して増えないことを求める。

### 固定 MAC への移行の条件（ユーザー）
| 項目 | 必須の条件 |
| --- | --- |
| 移流による局所の運動量保存 | 丸めの水準 |
| 圧力を含む総運動量の保存 | 正規化した誤差 1e-9 以下 |
| 離散の面の流束の非圧縮性 | 求解の許容誤差の水準 |
| 近似射影による時間誤差 | 時間 2 次の達成を妨げない |
| 静止液滴 | balanced-force を保つ |

セル中心の保存型の圧力補正がこれらを満たせなければ、固定の双対の制御体積の MAC 型に移る。セル中心の補正を際限なく最適化しない。動く相別の制御体積と共通の Gram は再導入しない。

## 5. R0：基準ソルバーの合否の条件（ユーザーの暫定の設計値。既存のソルバーが満たすことを確かめた値ではない）
状態変数の第一候補は、セル中心の質量・運動量と補助の面の流束（Basilisk 互換の格子、既存の VOF・GFM・粘性・GPU 実装を再利用）。代替は固定の MAC。

| 試験 | 条件 | 合格の条件の案 |
| --- | --- | --- |
| 単相の保存形 Taylor–Green | 界面なし | 空間・時間とも 2 次 |
| 一様流による液滴の並進 | 密度比 1000、表面張力なし、周期、10 周期 | 速度の誤差 1e-8 以下、相の質量の誤差 1e-10 以下 |
| 総運動量の保存 | 上と二相のせん断層 | 正規化した収支の誤差 1e-9 以下 |
| 離散の発散 | 全ての試験 | `h‖∇_h·u_f‖_∞/U_ref` が 1e-8 以下 |
| 静水圧の釣り合い | 密度比 1000、平行・斜めの界面 | 4 節 |
| 静止液滴・厳密な曲率 | 密度比 1000 | 寄生流が求解の許容誤差の水準 |
| 静止液滴・数値の曲率 | 密度比 1000、複数の解像度・界面の位置 | 既存の方式より悪化せず、細かくすると改善 |
| 二相のせん断層 | 密度比 1000、外力・表面張力なし | 発散せず、運動エネルギーの非物理的な増加が 1% 以内（時間刻みを小さくしたときの傾向も見る） |
| 毛管波 | 水・空気相当、10 周期 | 振動数・減衰率が既存の方式より悪化しない |
| 二層 Couette・Poiseuille | 密度・粘度比を変える | 厳密解に収束 |
| 上昇気泡 | 物理ベンチマーク | 質量の保存・形・重心の速度が参照解と整合 |

エネルギーは、移流・圧力・粘性の各ステップで、密度加重の物理的な運動エネルギーで測る。

## 6. 代表の二相の性能試験：斜めの二層せん断流 + Galilean boost（必須、ユーザー・監修）
```
z = a(x − U_x t) + b(y − U_y t),   t̂ = (−b, a)/√(a² + b²),   u(x, y, t) = U + t̂ w(z, t)
ρ = ρ(z),  μ = μ(z),   Dz/Dt = 0,   ρ ∂_t w = (a² + b²) ∂_z(μ ∂_z w)
```

- 界面の条件は `[w] = 0`、`[μ∂_z w] = 0`。一次元の参照解（非定常の粘性の固有モード）を座標変換して使える。
- boost なし：速度が界面に平行で界面は動かない。粘性・界面の条件の確認。
- boost あり：斜めの界面が格子を横切って動く。質量と運動量の流束の共通性・自由流・方向分割が働く。
- 最初の条件：界面は `ax + by` に沿う周期の帯、密度比 1000、粘度比は水・空気相当、表面張力なし。
- 連続の方程式では並進と粘性が可換なので、時間分割の誤差は測れない。時間積分の次数は、別の非可換な問題（非定常の Taylor–Green、液滴の近くを通る渦）でも測る。
- 格子に平行な界面だけで成功としない。最終の性能の達成の条件に、非整列の界面の問題を 1 件以上含める。

## 7. R1〜R4 の要点（ユーザー）
- **R1**：介入の試験 B0（通常）、B1（厳密な界面の形）、B2（厳密な曲率）、B3（厳密な界面の輸送）、B123（同時）、B4（時間刻みの細分化）。B123 で残る誤差は、改善の上限ではなく診断値として扱う。介入が VOF の質量の流束と不整合にならない方法を明記する。各処理の GPU の実行時間も測り、基準の側の既知の非効率（Red-Black の緩和など）を先に記録する。
- **R2**：運動量の流束 `P_F = P_F^L + θ_F(P_F^H − P_F^L)`（安定な低次の保存型の流束と、CCD で再構築した掃過領域の積分）。隣のセルが同じ面の流束を逆符号で使う限り、局所の保存は補正の係数によらない。低次の方式は、非負の質量の移動量 `m_ij`（流入・流出の両方の周辺の条件つき）でエネルギーが増えない。局所の速度の範囲の制限は安定化の候補にとどめ、エネルギーは別に測る（範囲を守ってもエネルギーは増えうる：ユーザーの反例、等質量の 4 セルで 1 → 2）。最初の Floquet の試験は 8 条件（密度比 1000、CFL 1/4・1/16、低次化の幅 0・2、端の式 2 種）。
- **R3**：粘性は H₄（ノート99）を第一候補に戻す（二次元の全応力・斜めの界面は未検証）。圧力は、発散の演算子を固定し、面の勾配だけを高次にする（`B G_H p = B u_f⋆/Δt`）。既存の GCR で加速した欠陥補正を使い、CCD の陰的な結合は必要なら界面で分離する。
- **R4**：同じ誤差の定義（物理量・ノルム・時刻）をベンチマークごとに測定の前に固定する。誤差と計算時間の曲線を 4 解像度以上で比べる。基準は R0 で確立した保存型のソルバー。少なくとも 2 種類の二相の問題で改善を示し、そのうち 1 つ以上は格子に平行でない界面を持つ。目標は同じ誤差での GPU の計算時間が基準の 2/3 以下（暫定）。
