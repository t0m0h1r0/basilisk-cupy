## 定式化と理論的根拠（ユーザー）
### A. 面の速度からの再構築
状態は面の法線方向の速度 f_i（面の平均、一次元では面の値）だけとする。セル中心の速度を第 2 の状態として持たない。圧力はセル中心である。周期では、自由度の数はセル中心型と同じ（速度 2N²、圧力 N²）。

```
d_i = (f_{i+1} − f_i)/h                          （微分のセル平均、微積分の基本定理で厳密）
(R_F f)(x) = f_i + ∫_{x_i}^x (R_C d)(ξ) dξ       （R_C はセル平均の PCCD 再構築）
```

R_C はセル平均を保つので、次が成り立つ：

- `R_F f(x_i) = f_i`、`R_F f(x_{i+1}) = f_{i+1}`（両方の面の値を再現する）。
- `∂_x R_F = R_C D`（演算子の恒等式）。
- R_C d は C¹ なので、R_F f は C²、セルごとに 5 次の多項式である。

### B. 二次元で発散が整合する
```
u_h = (R_F,x ⊗ R_C,y) u_f,   v_h = (R_C,x ⊗ R_F,y) v_f
∇·u_h = (R_C,x ⊗ R_C,y)(D_x u_f + D_y v_f)
```

そのため、離散の発散 `D_x u_f + D_y v_f = 0` なら、再構築した場は**各点で発散 0** である。

- セル中心型では、セル平均に非圧縮の条件を課しても、再構築した場の発散は 0 にならなかった。
- 厳密な流れの写像の体積保存と相性がよい（ただし、数値の流れの写像の体積保存までは保証しない）。

### C. 射影と圧力勾配
- エネルギーは `E = ½ u_fᵀ G_F u_f`。G_F は再構築の Gram で、二次元では `G_F,x ⊗ G_C,y` と `G_C,x ⊗ G_F,y`。
- 射影は `Π = I − G⁻¹Bᵀ(BG⁻¹Bᵀ)⁺B`（B は MAC の発散）。G 内積の直交射影である。
- 二次元の Schur の記号：`L̂ = 4 sin²(θx/2)/(g_F(θx)g_C(θy)) + 4 sin²(θy/2)/(g_C(θx)g_F(θy))`。
- **圧力勾配の弱形式**：圧力もセル平均の PCCD 再構築 R_C p で表す。`∫R_F(w) ∂_x p_h = −∫ ∂_x R_F(w) p_h = −(Dw/h)ᵀ H_p p` なので、面の加速度は `G_F a = −Bᵀ H_p p`（H_p は圧力の PCCD の Gram）。**訂正（2026-11-27、監修 #127 への対応で見つけたノートの側の誤り）**：符号が逆で、正しくは `G_F a = +Bᵀ H_p p`（B = D/h。`−∫R_F(w)∂_x p_h = +∫∂_x R_F(w) p_h = (Dw/h)ᵀH_p p`）。`cases/mac_pccd.py` の `pressure_gradient` は正の符号で `a = G_F⁻¹BᵀH_p p` を作り、`−p'` と比べている。数値は変わらない。
  - 圧力の双対変数（ラグランジュ乗数）と、物理的なセル平均を混同しない。
  - 二次元の y の因子は `G_C⁻¹H_p = I` になるので、x 面の x 方向の勾配は、一次元の演算子を各行に当てたものになる。

| --- | --- | --- | --- | --- | --- |

- **発散 0 の場の面の平均は、射影で丸めの誤差の水準しか変わらない**。面の平均の MAC の発散は、発散定理で厳密だからである。発散 0 の場は、厳密に離散の発散 0 の部分空間に入る。
- 勾配の波の残りは、0.8 → 0.4 で 2500 倍（約 11 次）。

- MAC–PCCD は 16 → 32 で 4400 倍（約 12 次）。N ≥ 48 は丸めの水準。古典的な MAC は 2 次である。**訂正（監修 #127 の 4）**：「約 12 次」は、次数を読める点が 3 点（N = 8〜32 のうち丸めに達する前）しかなく、収束の規約（格子 10 点以上）に合わない。次数としては主張しない。
- 単相・周期・滑らかなデータでの超収束（Galerkin の 9 次以上、ノート91 と同じ種類）と考えられる。一般の収束の次数は主張しない（ユーザーも同じ判断）。

## まとめ
- MAC–PCCD は単相・周期で、次の全てを満たした：
  - 面の値の再現と `∂R_F = R_C D`。
  - 離散の発散 0 から各点の発散 0。
  - 圧力の零空間は定数だけ（Schur の比の最小 0.656 / 0.429、古典的な MAC の 0.405 より良い）。
  - G 内積の直交射影（エネルギー非増加・運動量保存）。
  - 発散 0 の場を正確に保ち、圧力勾配は超収束する。**訂正（監修 #127 の 4）**：「発散 0 の場を正確に保つ」は、面の平均の MAC の恒等式（発散定理）で、古典的な 2 次の MAC でも同じ値になる。PCCD の精度の成果ではない。
- セル中心型の高階差分の補正（ノート104）と違い、射影の精度を落とす非対称の補正が要らない。

| 評価項目 | 必要な性質 |
| --- | --- |
| 切断面 | 重い相・軽い相を含む面の平均の正確な再構築 |
| 非圧縮性 | 二相でも離散の発散と再構築した場が整合すること |

| 圧力射影 | 二相で定数以外の零空間がなく、Schur 補行列が密度比に頑健であること |

| 粘性・移流（追記、監修 #127 の 4） | セル平均・質量加重の平均で確立した結果（粘性 D、Galerkin 輸送）は、面の平均の状態変数には引き継がれない。未検証 |
