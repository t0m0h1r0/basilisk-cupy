# 14 ψ 曲率（PR #29）

## 方法
- 論文の式（03c、11b1 の第4段）：κ = −(ψ_y²ψ_xx − 2ψ_xψ_yψ_xy + ψ_x²ψ_yy)/|∇ψ|³
  - ψ_x と ψ_xx は軸ごとに1回の CCD 解法で求める。ψ_xy は ψ_x を y 方向に CCD 微分して求める。
  - 界面帯 0.01 < ψ < 0.99 の外は κ = 0。
  - 液滴（ψ = 1 が内側）で κ > 0。Basilisk の `curvature()` と同じ向き。
- `CLSInterface.curvature()`（`interface/cls_curvature.py`）。
  - `source="phi"`：ロジットで φ に戻してから同じ式を当てる（論文では比較用）。
  - `code_variant=True`：実装にだけある DCCD フィルタを再現する。g + 0.05(2ψ−1)²(g₊ − 2g + g₋) を全微分・全軸に当て、壁セルは除く。論文は標準経路で後置フィルタを使わないとしている。

## 測定
円（R = 0.2、中心は格子からずらす）。|φ| < ε のセルでの最大誤差 |κ − 1/r|·R。各セルを通る等値線の曲率は 1/r。

正確なプロファイル ψ = H_ε(R − r)：

| N | 64 | 128 | 256 | 512 |
| --- | --- | --- | --- | --- |
| ψ から（論文） | 6.31e-4 | 1.21e-3 | 2.39e-3 | 4.78e-3 |
| φ から | 1.35e-4 | 4.9e-7 | 1.2e-6 | 2.4e-6 |
| ψ ＋ DCCD（実装） | 6.43e-3 | 1.25e-2 | 2.45e-2 | 4.82e-2 |

- ψ から求めると、N を倍にするたびに誤差が倍になる。
  - 原因：ε = 1.5h なので ψ の幅は常に3セルで、CCD の相対誤差は N によらず一定。曲率の誤差はそれに 1/ε を掛けた大きさになる。
  - 論文は「CCD で O(h⁶)」とするが、ε ∝ h のもとでは O(h⁻¹)。
- φ は滑らかなので、φ から求めれば1000倍以上正確（N = 128）。論文がロジットを省く理由に挙げる「飽和域の特異性」は、界面帯では影響しない。
- DCCD フィルタは誤差を約10倍に増やす（相対誤差 0.05(h/ε)² 程度が残るため）。
- 参考：Basilisk の高さ関数（正確な体積率から）の最大相対誤差は 3.7e-2 / 4.9e-3 / 1.2e-3（N = 32 / 64 / 128、12 の M4c）。

並進（周期、(1, 0.5)、t = 1）の後：

| N | 32 | 64 | 128 |
| --- | --- | --- | --- |
| 再初期化なし | 0.394 | 0.611 | 0.805 |
| ξ-SDF（点、10 ステップごと） | 4.12 | 11.2 | 33.6 |
| 圧縮・拡散（4 擬似ステップ、10 ステップごと） | 0.134 | 0.0372 | 0.0167 |

- 輸送後の ψ には接線方向の細かな乱れがあり、2階微分で 1/h² に増幅される。そのため、再初期化なしでは収束しない。
- ξ-SDF（論文の標準）の距離は折れた形になるので、曲率は O(10) になる。
- 論文が「非採用」とする圧縮・拡散型（実装の既定）なら収束する（およそ1〜2次）。
- φ から求めると、再初期化ありでは ψ からと同程度（ψ そのものの誤差が支配的）。再初期化なしでは 0.393 / 26.2 / 267 と悪化する（飽和域近くの ψ の乱れがロジットで拡大される）。
