# 65 VOF-GFM が動く界面で劣る原因は、セル中心の速度の補正の係数（PR #75）

ノート64 で、VOF の GFM（`interface="vof-gfm"`）は、静止液滴では CSF と同じだが、論文の毛管波・振動液滴（水–空気）で CSF より悪かった（毛管波の振幅が増え、周波数の誤差も大きい）。その原因を切り分けた。

## 定式化と理論的根拠
### セル中心の補正と、係数の倍率が釣り合いを崩さない理由
Basilisk の射影では、面の速度を `u_F ← u_F + Δt (a_F − α_F (∇p)_F)` で直し、セル中心の速度は面の正味の加速度をセルに平均した g で直す：

```
g_i = ½ Σ_{面 F ∈ ∂K_i, 軸ごと} (a_F − α_F (∇p)_F)
```

`cell_coefficient="mean"` は、各面の正味の加速度に `α_mean/α_gfm` を掛けてから平均する。

- **静止状態**：射影の結果、すべての面で `a_F − α_F(∇p)_F = 0`（面の速度が変わらない）。倍率を掛けても 0 のまま。したがって釣り合いの性質は変わらない。静止液滴の値がほとんど変わらなかったこと（4.04122 → 4.04072）と整合する。
- **密度比 1**：α_mean = α_gfm なので、倍率は 1 で完全に同じ。
- **面の速度**：射影そのものは GFM の係数のまま。そのため、面の速度の発散が 0 であること（VOF の前提）と、鋭い跳びは保たれる。

### 物理的な意味（2 節の解釈の式）
切断面の GFM の係数 `1/(θρ_L + (1 − θ)ρ_R)` は、面の上の 2 相の直列の質量に対する加速度。セル i の速度が受けるべき加速度は、セル i の流体の質量 ρ_i に対するもの。重い相の質量で決まった加速度を軽い相のセルに配ると、そのセルの加速度は `ρ_light/ρ_mix` 倍だけ小さすぎる。セルの速度と面の速度の食い違いは、次のステップの予測子に入る。`α_mean = 1/ρ(f_F)` は、セルの体積率から決まる質量に合わせる。

この食い違いを直接測ってはいない。1 節の切り分け（セル中心の補正だけを変えると劣化が消える）が根拠。

### CLS の混合の重み w
w は物理の量から導いたものではない。周波数の誤差を 0 にする w が格子とともに変わるので、他の誤差を打ち消す調整の値と判断した（理論的な裏付けはない）。

## 1. 要因の切り分け（毛管波、5 周期、ab2、fd2 の粘性、`cases/vof_gfm_factors.py`）
| 変種 | N = 32：β（基準）/ ω の誤差 | N = 64 |
| --- | --- | --- |
| CSF | −1.65（−0.803）/ −3.96% | −0.95 / −1.35% |
| GFM（ノート64） | **+0.45** / −5.81% | **+0.35** / −2.31% |
| GFM、ジャンプの重みを θ でなく 2 セルの平均（iforce.h と同じ） | +0.45 / −5.81% | +0.30 / −2.22% |
| GFM、面の係数を two-phase.h の 1/ρ(f_face)（ジャンプは鋭いまま） | −0.15 / −4.81% | −0.10 / −1.46% |
| GFM、面の射影は GFM の係数、**セル中心の補正だけ** 1/ρ(f_face) | −0.20 / −4.93% | −0.30 / −1.46% |
| 密度比 1：CSF | −1.35（−2.269）/ −4.55% | −1.55 / −1.28% |
| 密度比 1：GFM | −1.35 / −3.39% | −1.45 / **−0.39%** |

- ジャンプの重みは無関係。
- **密度比 1 では GFM の方が CSF より正確**（N = 64 の周波数 −0.39% 対 −1.28%）。劣化は密度比があるときだけ。
- 劣化は切断面の係数から来るが、**面の速度の射影に GFM の係数を使うことは問題でない**。セル中心の速度の補正だけを平均の係数に戻すと、劣化が消える。

## 2. 何が起きているか（解釈；1 節の切り分けと整合するが、機構そのものは直接測っていない）
セル中心の速度は、面の正味の加速度 `a − α ∇p` をセルに平均して補正する（Basilisk の `centered_gradient`）。切断面では GFM の係数 `α = 1/(θ ρ_L + (1 − θ) ρ_R)` が面の上の流体の質量を表すので、面の加速度は「面の上の混合物」に対する値になる。これを両側のセルにそのまま配ると、軽い側（空気）のセルは重い側の質量で決まった加速度を受け、セルの速度が面の速度と食い違う。食い違いは次のステップの予測子（セルの速度を面に補間）に入り、毛管波では振幅を増やす向きに働く。密度比 1 では α は面によらないので、この問題は起きない。

## 3. 修正：`cell_coefficient="mean"`
面の正味の加速度を、two-phase.h の係数に合わせてから平均する（倍率が 1 でないのは、切断面と、f が 0・1 でないセルに接する面）：

```
g = face_to_cell( (a − α_gfm ∇p) · α_mean / α_gfm ),   α_mean = 1/ρ(f_face)
```

- 面の速度の射影は GFM のまま（鋭いジャンプ、鋭い係数）。
- 静止状態では面の正味の加速度が 0 なので、倍率をかけても 0 のまま。**釣り合いは崩れない**：静止液滴（N = 32、密度比 1000）のジャンプ 4.04072、最大速度 7.3e-3（GFM の係数で 4.04122、7.8e-3）。密度比 1 では α_mean = α_gfm なので完全に同じ。
- 実装：`BasiliskCentered.centered_gradient` が `ns.g_scale`（各軸の面の倍率）を読む。`TwoPhaseVOFJump(cell_coefficient=...)`（既定 `"mean"`）、`TwoPhaseCLS(cell_coefficient=...)`（既定 `"gfm"`、既定は変えていない）、`TwoPhaseIMEX(cell_coefficient=...)`。

## 6. CLS では効き過ぎる（`cases/cls_cell_coefficient.py`）
CLS（ab2、ξ-SDF 10、fd2 の面）で同じ選択肢を試した。CLS では、切断面でない面の係数も GFM（相の密度そのもの）なので、`"mean"` は ψ の帯（約 3 セル）の全部の面で倍率をかける。`"cut"` は切断面だけにかける変種。

| セルの係数 | 毛管波（ψ 曲率）N = 32：β 倍率 / ω の誤差 | N = 64 | 液滴（高さ関数の曲率）N = 32 | N = 64 |
| --- | --- | --- | --- | --- |
| `"gfm"`（既定） | 0.50 倍 / −9.30% | 1.43 倍 / −4.22% | 2.51 倍 / −5.13% | 3.90 倍 / −3.38% |
| `"mean"` | 2.99 倍 / −0.63% | 5.48 倍 / **+3.37%** | 13.7 倍 / +4.29% | 9.2 倍 / +2.37% |
| `"cut"` | 0.50 倍 / −9.17% | 1.56 倍 / −4.26% | 2.51 倍 / −5.05% | 3.62 倍 / −2.79% |

（ψ 曲率の液滴は、どの係数でも振幅が増える：ノート59・63。）

- `"mean"` は周波数の誤差の符号を反転させ、減衰を 3〜14 倍にする。**CLS には使えない。CLS の既定は `"gfm"` のまま。**
- `"cut"` は `"gfm"` とほとんど同じ。CLS で周波数を動かしているのは、切断面ではなく帯の中の面の係数。
- 見方を変えると、**CLS の周波数の誤差（−9.3% / −4.2%）は、帯の中のセルが受ける密度の扱いで大きく動く**。GFM（鋭い）と ρ(ψ)（ぼやけた）の間に、誤差の小さい扱いがあるかもしれない（未検証）。

### 二つの係数の混合（`cases/cls_cell_coefficient.py --cells w0.1 w0.2 w0.35 w0.5 --no-psi-drop`）
セルの係数を `w α_mean + (1 − w) α_gfm` にした（診断用、ライブラリの選択肢にはしていない）。周波数の誤差：

| w | 毛管波（ψ 曲率）N = 32 | N = 64 | 液滴（高さ関数）N = 32 | N = 64 |
| --- | --- | --- | --- | --- |
| 0（`"gfm"`） | −9.30% | −4.22% | −5.13% | −3.38% |
| 0.1 | −7.87% | −2.83% | −3.71% | −2.38% |
| 0.2 | −6.56% | −1.52% | −2.29% | −1.38% |
| 0.35 | −4.67% | +0.37% | −0.38% | +0.04% |
| 0.5 | −2.98% | +2.10% | +1.54% | +1.37% |
| 1（`"mean"`） | −0.63% | +3.37% | +4.29% | +2.37% |

減衰：毛管波は w とともに増える（N = 64 で 1.43 → 1.56 / 1.68 / 1.81 / 1.99 倍）。液滴は w = 0〜0.5 で変わらない（3.90 倍）。

- 周波数の誤差は w にほぼ比例して動き、N = 64 では w ≈ 0.3 で両方の問題ともほぼ 0 になる。
- ただし、誤差が 0 になる w は格子で変わる（毛管波は N = 32 で約 0.6、N = 64 で約 0.3）。**w は物理の量ではなく、他の誤差を打ち消す調整の値になっている。** 既定にはしない。
- 液滴の過大な減衰（3.9 倍、ノート63）は、この係数とは無関係。

## まとめ
- VOF-GFM の劣化の原因は、セル中心の速度の補正で、切断面の GFM の係数を軽い側のセルにそのまま配っていたこと。密度比 1 では起きない。
- 修正 `cell_coefficient="mean"`（VOF-GFM の既定）で、静止状態の釣り合いを保ったまま、動く界面の精度が CSF と同等になる。
- CLS では同じ修正は効き過ぎる。CLS の周波数の誤差は帯の中のセルの密度の扱いで大きく動くが、誤差を 0 にする混合の重みは格子に依存し、調整の値にしかならない。液滴の過大な減衰はこの扱いと無関係。
