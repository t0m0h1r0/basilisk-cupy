# 01 原則と壁クロージャ（PR #16）

## 原則
- 精度は陰的に解く高階微分で上げる。片側に広いステンシルは取らない（Chu & Fan の CCD の考え方）。
- 壁の行も内部と同じ幅に収める。壁で1〜2次落ちることは受け入れる。
  - 根拠：境界の行が内部より1次低くても（2階微分なら2次低くても）全体の次数は保たれる（Gustafsson 1975）。
- 「幅」は陰的な関係式がつなぐ点の範囲と、そこに入るデータで数える。CCD の逆行列は密なので、陽的な依存範囲は最初から全域。

## 壁クロージャ
| | 旧（wide） | 新（compact） |
| --- | --- | --- |
| 読む範囲 | 壁データ＋4〜6セル | 壁データ＋2セル |
| 壁セルの次数 f′ / f″ | 6 / 5 | 4 / 3（外挿は 3 / 2） |
| 移流 −D1·h の固有値の最大実部（Dirichlet） | +0.096（増幅モード） | +1e-15 |
| N = 256 | 丸め誤差で精度低下 | 低下なし |

- FCCD の壁面は、壁際セルの CCD ジェット (f, f′, f″) から作る（4次）。
- 行 II（f″₀）は2セル幅では3次が上限。f′₁ を加えると行 I と同じ関係式になり、系が特異になる。
- Navier–Stokes（蓋付きキャビティ、Ghia、Taylor–Green）は 0.1% 以内で同じ。
- 悪化：数セルでしか解像していない境界層 8.6e-7 → 3.3e-5、補正なしの欠陥補正 165 → 461 サイクル（GCR は 17 → 18）。
