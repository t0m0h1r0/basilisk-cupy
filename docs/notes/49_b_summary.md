# 49. B（毛管波の減衰精度）の総括：区切りとして整理する

38〜48（PR #52〜#62）で、粗い格子の毛管波の減衰不足を出発点に、原因の特定と対策を順に試した。
一つを直すたびに別の構造的な問題が現れ、全面的に進めると新しいソルバーの設計に相当する規模になる。そこで、ここを区切りとし、開発は凍結する。
**打ち切るのは「すべての数値的な欠点を同時に解消する開発方針」であって、研究の成果は以下に保存する。**

- 図：`docs/figures/b_summary.png`（`cases/b_summary_figures.py`、すべて既存の測定値）

## 2. 確立した知見（数値実験の裏付けあり）
1. **CCD の高次精度だけでは、二相流全体の精度は保証されない。** 毛管波の減衰誤差は、粘性・面演算子を fd2 から CCD / FCCD にしても、ほとんど変わらなかった（31、32、38）。支配していたのは界面の運動学だった（41）。
2. **界面の運動学と表面張力の結合の幅が、毛管波の減衰を支配する。**
   - CLS の輸送は、交点を ±h で平均した速度（重み 0.23 / 0.57 / 0.23、2 次モーメント 0.33h²）で動かす。界面では v が幅 δ の山を持つので、運動学の誤差は (h/δ)² に比例する（41）。
   - 結合の幅が広いほど不足は大きい（鋭い +3.8%、~h で −16.8%〜−25.9%、~ε で −63.9%。43）。
3. **エネルギーの整合性と、物理の再現精度は別の性質である。**
   - 随伴型の表面張力はエネルギーを 1e-14 で整合させるが、精度は悪化した（43）。
   - 逆に、整合の破れの大きさは、基準のエネルギーを正しく選べば、減衰誤差を定量的に説明する（鋭い界面のエネルギーで、予測 −19.7% に対して実測 −16.6%。45）。
4. **波数だけでは、物理的な高波数成分と数値誤差を区別できない。** 渦層（y 方向の高波数で、散逸の担い手）を、高波数の減衰が削った（42：−16.4% → −18.9%）。
5. **コロケート格子の近似射影は、時間積分の高次化を妨げる。** 面速度を毎ステップセル中心から作り直すと、CN・SDIRK2 でも刻み依存は現行と同じだった（47）。セル中心の厳密射影なら 2 次になる（48）。
6. **散逸の恒等式 D = μ∫|ω|²**（速度が界面で連続なので）。等しい 2 流体の毛管波の散逸は、すべて渦層のエンストロフィーである（41）。

## 3. 否定・訂正した仮説
| 仮説 | 否定・訂正した測定 |
| --- | --- |
| 渦層の粘性の解像不足が主因（38） | 厳密な曲率・粘性の差し替えでも残り、運動学を鋭くすると消える（41） |
| 曲率（高さ関数）で減衰誤差が下がる（40） | 厳密な線形曲率でも同じ不足。高さ関数は余分な数値減衰による打ち消し（41） |
| 粘性の次数は効かない（31、41） | 運動学の誤差に隠れていた。運動学を直した後は効く（46：fd2 → CCD で −2.1〜−3.3） |
| エネルギー交換の吸収が補正後の減衰しすぎの原因（44） | 鋭い界面のエネルギーでは −2% で、原因ではない（45） |
| 残りの 4.5 ポイントは時間積分の 1 次誤差（46） | 2 次の積分法でも残る。近似射影の刻み依存（47） |
| 高波数の人工減衰は毛管波・密度比に効く（外部の提案） | どちらにも効かない（42） |
| 随伴化で精度が上がる（外部の提案） | エネルギーは整合するが精度は悪化（43） |

## 4. 実用上の指針（適用範囲）
**格子解像度と方式の比較（毛管波、×1、減衰誤差）：**
| 方法 | N = 32 | N = 64 | N = 128 | 備考 |
| --- | --- | --- | --- | --- |
| 既定（CLS の輸送、時間積分） | −16.4% | −3.8% | +0.5% | 本体の既定 |
| 帯の速度補正（44、`cases/`） | +3.4% | +3.5% | +2.0% | 粗い格子で有効、細かい格子では既定の方が良い |
| セル中心の厳密射影 + CN（48、線形、厳密な曲率） | +3.2%（CCD +1.1%） | | | 実装は未完 |
| 写像格子（39、32² で y を 8 倍） | −2.2% | | | CPU では一様 128² より遅い |

- **減衰を 1% 以内に収めたいなら、まず格子解像度を上げる。** δ/h ≳ 2.5（30）、すなわち 1 波長あたり 64 点程度で既定の方式でも達する（N = 128 で +0.5%）。
- 一様格子の費用は、ソルバーの構造を変えるより確実で安い（39：同じ精度で一様 128² の方が写像格子より速い）。
- 粗い格子が避けられない場合（δ/h ≲ 1.5）に限り、帯の速度補正（`cases/velocity_extension.py`）が使える。静止液滴の寄生流の減衰が約 10 倍遅い点に注意する。
- 周波数（周期）の誤差は、1 波長あたりの点数で決まる（30）。

## 6. 未解決の問題（記録）
- 帯の補正の後の静止液滴で、時間積分の max|u| の減衰が遅い理由（線形化した主要モードは遅くない。45）。
- 帯の補正の後に残る半離散の +1.1%（CCD）、周波数の −1.1%（CCD）。
- MAC が減衰しすぎる理由（帯の補正の運動学との相性か。48）。
- セル中心の厳密射影の checkerboard 変調の圧力モードが、GFM のジャンプと静止液滴の圧力場に及ぼす影響（48）。
- 写像格子の静止液滴で、寄生流が減衰しない理由（39）。
