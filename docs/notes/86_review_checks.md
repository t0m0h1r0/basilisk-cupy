## 1. ノート85 の訂正
- **失われたエネルギーの場所**：本文の「界面の軽いセルの飽和した損失」は不正確。shift では、小さな CFL（0.01）の最悪モードの残差は**界面のセルの重い相**に集中していた（密度比 1e6、A0 で 96.8%、B0 で 90.4%、ノート85 の表）。制約付きでは軽い相に出る場合もある。原因の入力モードと、残差の現れる場所は別に考える必要がある。
- **オラクル**：移流の後の空間だけに基底を足した（`V₀ → V₁ ⊕ W`）。失われたモードの数（小さな CFL でほぼ階数 1）を測るには適切だが、追加の自由度そのものを移流する方式（`V₀ ⊕ W₀ → V₁ ⊕ W₁`）の効果は示さない。両側に足した結果は 4 節。
- **粘性の剛性**：測ったのは、セルの中の微分の 2 乗の積分（セル境界の速度の跳びと応力を含まない）で、粘性の演算子全体ではない。質量座標の補正を不採用とする結論（剛性が 1e9 倍）は変わらないが、「補正なしの 9〜13 で粘性の項に問題がない」とは言えない。

## 2. 複数の界面が窓に入る場合（`cases/galerkin_multi.py`、N = 48、shift、α = 0.75、窓 +1 の 12 セル）
**見つけた誤り**：`Reconstruction._rows()` は、界面 zz の左右にそれぞれ一つの密度があると仮定していた。窓の中に別の界面があると、セルの質量と積分を誤る。

すべての界面で区間を切って、実際の密度で Gauss 積分するように直した。孤立した界面では結果は変わらない（試験と、ノート85 の値 11.5 を確認）。

## 3. 物理的なモードに限った損失（`physical_loss`）
### 定式化
物理的に意味のある速度の空間 Q（ユーザー）として、次のセル平均を取った：

- 全体で滑らかな sin・cos(2πk(x − s))（k ≤ N/8、波長 8 セル以上）
- 同じ関数に帯の中の山 `(z − A0)(B0 − z)` を掛けたもの（界面で連続、勾配が折れる）

一次元では、非圧縮の速度は一様なので、非圧縮の制約は意味を持たない。毛管波の固有モードは二次元の問題。

損失は `L_phys = Qᵀ(I − 𝒯ᵀ𝒯)Q` の最大固有値。

**注意（測定で見つけた）**：この 24 本の列はほぼ一次従属（G₀ の内積での特異値の比 5e-7）。そのまま一般化固有値問題を解くと、滑らかな関数を大きな係数で打ち消し合わせた残り（物理的でない格子規模の関数）が最悪になった。密度比 1・CFL 0.37 で 0.495 で、全状態の最悪（0.91）に近い。

エネルギーの内積で正規直交化し、相対特異値 1e-4 未満の方向（3〜10 本）を落として測った。

### 結果（N = 48、1 ステップの損失、[ ] は単位時間あたり）
| 適合 | β | 密度比・ζ・界面 | CFL 0.01：物理 / 全状態 | CFL 0.37：物理 / 全状態 |
| --- | --- | --- | --- | --- |
| shift | 0 | 1・1・A0 | 7.2e-4 [3.4] / 0.036 | 0.016 [2.1] / 0.91 |
| shift | 1/2 | 1・1・A0 | 1.2e-5 [0.06] / 1.0e-3 | 7.9e-3 [1.0] / 0.81 |
| shift | 0 | 1e3・10・A0 | 1.0e-3 [5.0] / 0.88 | 0.013 [1.7] / 1.00 |
| shift | 1/2 | 1e3・10・A0 | 6.3e-4 [3.0] / 0.76 | 5.8e-3 [0.75] / 1.00 |
| shift | 0 | 1e6・100・A0 | 8.5e-4 [4.1] / 0.99 | 0.026 [3.4] / 1.00 |
| shift | 1/2 | 1e6・100・A0 | 7.7e-5 [0.37] / 0.98 | 0.012 [1.6] / 1.00 |
| shift | 0 | 1e6・31.6・B0 | 1.8e-3 [8.6] / 0.94 | 0.041 [5.3] / 0.99 |

- **物理的なモードの損失は、全状態の最悪よりずっと小さい**（単位時間あたり 1〜9、全状態では 150〜4000）。全状態の最悪を決めていたのは、格子規模の入力。
- 物理的なモードでは、制約付きと shift はほぼ同じ。shift の改善（ノート85）は、最悪の格子規模の入力の増幅に効くもので、通常の移流の精度は変えない。
- 随伴補正は、小さな CFL の物理的なモードの損失も 1/10〜1/50 にする。

## 4. 入力と出力の両側に追加の基底（`enriched_loss`）
### 定式化（ユーザー）
セル平均の演算子 A（`(Av)_i = ∫_{K_i}ρv/m_i`）、再構築 R（`AR = I`）、界面とともに動く関数 b に対して `ψ = (I − RA)b`。

- `Aψ = 0`：セル平均を変えない。
- `range(R, ψ) = range(R, b)`。
- 一様な並進で `b^{n+1} = 𝒰b^n` とし、古い空間と新しい空間の両方に足す（追加の自由度も移流する）。最悪の損失は、拡大した入力の全体で測る。

b は界面から 1 セルの幅のテント型を 3 種類：軽い相の側だけ、重い相の側だけ、両相にまたがる（連続）。

### 結果（shift、N = 48、最悪の 1 ステップの損失）
| 密度比・ζ・界面 | CFL | 追加なし | 軽い相のテント | 重い相のテント | 両相のテント |
| --- | --- | --- | --- | --- | --- |
| 1・1・A0 | 0.01 | 0.036 | 0.037 | 0.036 | 0.060 |
| 1・1・A0 | 0.37 | 0.909 | 0.913 | 0.907 | 0.984 |
| 1e3・10・A0 | 0.01 | 0.883 | 0.919 | 0.883 | 0.883 |
| 1e6・100・A0 | 0.01 | 0.991 | 0.995 | 0.991 | 0.991 |
| 1e6・31.6・B0 | 0.01 | 0.944 | 0.943 | 0.946 | 0.946 |

- **どのテント型も、最悪の損失を下げない**（軽い相のテントと両相のテントは、かえって上げる場合がある）。追加した自由度そのものが、次の失われやすいモードになる（ユーザーの指摘どおり）。
- 出力側だけのオラクル（ノート85：1 個で 0.03）との差は、追加の基底の移流の問題。**簡単なテント型の内部モーメントには根拠がない。** オラクルの残差の POD から基底を作る案（ユーザーの提案）は、まだ試していない。

## 5. 直接の高次 Remap・Galerkin・随伴補正（`run3`、shift、密度比 1e3）
| | 直接の Remap `M₁⁻¹C_g` | Galerkin `G₁⁻¹C` | 随伴補正 |
| --- | --- | --- | --- |
| phases、t = 0.137：N = 16 … 256 | 9.8e-4 … 2.2e-9 | 6.0e-4 … 8.4e-10 | 4.6e-4 … 6.6e-10 |
| 次数（N = 128 → 256）：t = 0.05 / 0.1 / 0.137 | 4.15 / 5.68 / 3.98 | 4.74 / 4.80 / 4.55 | 4.62 / 5.07 / 4.54 |
| E(t)/E(0) − 1（N = 16 … 256） | +9.4e-7 … +2.1e-12（増える） | −1.3e-9 … 1e-14 | −7.7e-10 … 1e-14 |
| 長時間（N = 64、t = 0.25 / 0.5 / 1）：誤差、密度比 1e3 | 7.1e-7 / 1.2e-6 / **2.0e-6**（増える） | 4.3e-7 / 4.7e-7 / 4.8e-7 | 3.4e-7 / 3.6e-7 / 3.9e-7 |
| 同、E(1)/E(0) − 1 | **+1.7e-8** | 5e-14 | −2e-16 |
| 同、密度比 1e6 の誤差（t = 1） | 2.0e-6 | 4.8e-7 | 3.9e-7 |
| 1 ステップの ‖T‖∞ の最大（N = 64、t = 1、1e3 / 1e6） | 10.8 / 7.7 | 10.9 / 11.7 | 11.4 / 17.2 |
| 滑らかなデータの max|u| の増加（全条件） | ≤ 1.9% | ≤ 1.9% | ≤ 1.9% |
| 格子規模に近いデータ（`grid`、N = 64、t = 0.137）のエネルギーの損失 | **15%** | 4.5% | 0.36% |

- **3 方式とも 4 次。** 誤差は随伴補正 < Galerkin < 直接の Remap（約 2〜3 倍の差）。
- **直接の Remap はエネルギーが増える**（わずかだが、格子とともに減る）。長時間で誤差が時間とともに増える。
- **直接の Remap がもっとも散逸が大きい**（格子規模に近いデータで 15%、Galerkin の 3 倍）。
- 直接の Remap は線形の解が要らない（GPU に向く）ので、実用の候補として残す。高密度比のせん断層で安定かどうかが判断の分かれ目（二次元で確かめる）。

## 次（ユーザーの再編した計画）
- 一次元の研究はここで区切る。内部モーメント（POD の基底）は、二次元で必要性が見えたときに戻る。
- **二次元の厳密な斜めの平らな界面の並進**（周期格子）を始める。比べるのは、直接の Remap・Galerkin・随伴補正（shift、内部モーメントなし）。
  - 二次元では、切断領域の積分、界面の向き、複数の界面の近接が新しく現れる。
  - 再構築は、セルごとの多次元の多項式の制約付き（shift）の適合に一般化する。
- その後、円形界面の並進、厳密な輸送写像の変形流、実際の PLIC の順。
