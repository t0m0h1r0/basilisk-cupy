# 59 フェーズ3（2）：論文の振動液滴（14b）、上昇気泡（14c）、Rayleigh–Taylor（14d）

## 条件（`cases/phase3_drop_bubble.py`、論文の 14 章の条件）
- **振動液滴：** [0, 0.02]² m、周期、水の楕円 a = 5.5 mm、b = 4.5 mm（D₀ = 0.1）、空気の中、2 周期（T_RL = 0.10546 s）。変形量 D = (a − b)/(a + b) の半径は、中心を通る軸上の相 1 の積分の半分から求める（VOF の体積率でも厳密。ψ = ½ の交点の線形補間は VOF で最大 h/2 ずれ、ψ の二次モーメントは R/ε ≈ 5 の拡散で初期値が 0.0755 になる）。CLS の初期値は 0.0979（拡散したプロファイルの O(ε²κ) のずれ）、VOF は 0.0993。D(t) = D₀ e^{βt} cos(ωt + φ) を当てはめる。基準は 2 次元の Rayleigh–Lamb の ω₀ = 59.578 s⁻¹。
- **上昇気泡：** [0, 0.01] × [0, 0.02] m、x 周期・y 壁、半径 2.5 mm の空気の泡、(5, 5) mm、g = 9.81、0.06 s まで（論文は 0.03 s までを掲載し、0.04 s 以降の破綻を報告）。泡（1 − ψ）の重心・速度・変形量を見る。
- CLS の方式は、ξ-SDF の再初期化を 10 ステップごとに入れる（ノート57）。解法の許容値は、体積の相対変化 1e-8。
- 論文の振動液滴は NS を解いていない（線形の Rayleigh–Lamb モードをチャートで積分、`force_admissible=0`、ノート10）。比べられるのは、厳密解（周波数）と方式の間だけである。

- **周波数は、どの方式も 3% 以内で Rayleigh–Lamb に合う**（N = 64 で CLS −1.4〜−0.5%、VOF −1.1%）。測り方を交点から積分に替えても、β と ω の変化は 0.05 s⁻¹・0.1% 以内。
- **CLS は、再初期化を入れても振幅が増える**（β > 0）。最大速度は VOF の 3〜8 倍で、格子を細かくするとかえって大きくなる。
- 閉じた界面（曲率が大きい）では、10 ステップごとの ξ-SDF では安定化が足りない（3 節）。

| 64 | 再初期化なし | — | — | — | — | **0.023 s で発散** |
| 64 | VOF | 6.999 mm | 0.0666 m/s | 0.0836 | 0.270 | 破綻せず |
| 論文（32 × 64、α = 2） | | 7.350 mm | 0.0957 m/s | | 0.343 | 0.04 s 以降に破綻 |

- **再初期化を入れると、論文が破綻を報告した 0.04 s を越えて、0.06 s まで破綻しない。** 再初期化なしでは 0.039 s（N = 32）で発散し、論文の報告とほぼ同じ時刻になる。論文の「t ≃ 0.04 s 以降の形状の破綻（未解決）」は、再初期化の不足による不安定（ノート57 と同じ機構）と見られる（確認したのは、再初期化なしで同じ時刻に発散することまで）。
- **本移植の CLS と VOF は、重心が 1% 以内で一致**（N = 64 で 7.03 と 7.00 mm）。
- **論文の値は、本移植より上昇が約 17% 大きい**（上昇距離 2.35 mm 対 2.0 mm）。原因は未確認（格子：論文は α = 2 の界面適合格子、本移植は一様格子）。
- **論文の値は、それ自体で整合しない：** (7.350 − 5)/0.03 = 0.078 m/s で、論文の「平均上昇速度 0.0957 m/s」と合わない。平均上昇速度の定義が書かれていない。

## 3. 振動液滴の再初期化の頻度と方法（TwoPhaseIMEX + ab2）
| 方式 | N = 32：β / ω の誤差 / 最大速度 | N = 64：β / ω の誤差 / 最大速度 |
| --- | --- | --- |
| ξ-SDF 10 ステップごと | +0.80 / −2.58% / 0.101 | +1.60 / −1.42% / 0.281 |
| ξ-SDF 5 | +0.40 / −1.17% / 0.090 | −0.95 / −1.83% / 0.151 |
| ξ-SDF 1 | −0.65 / +0.33% / 0.164 | −1.20 / −0.92% / 0.246 |
| 圧縮・拡散 10 | −4.15 / −14.17% / 0.035 | −2.05 / −10.17% / 0.034 |
| **ξ-SDF 10 + 高さ関数の曲率（fd2）** | **−0.45 / −5.17% / 0.037** | **−0.70 / −3.42% / 0.034** |
| 参考：VOF | +0.05 / −1.75% / 0.033 | 0.00 / −1.08% / 0.035 |

- **曲率を高さ関数に替えると、増幅が止まり、最大速度が VOF と同じ水準（0.034）に下がる。** ノート54 の「再初期化が入れる凹凸を、ψ の CCD 曲率が増幅する」が、閉じた界面での増幅の原因と考えられる（曲率の方法だけを替えて止まった、という意味での確認）。
- ただし周波数の誤差は −3.4%（N = 64）で、ψ の曲率（−1.4%）や VOF（−1.1%）より大きい。
- 再初期化を頻繁にすると減衰に転じるが、最大速度（寄生流）は大きくなる。圧縮・拡散は、周波数を 10〜15% ずらす。
- 2 次元の n = 2 のモードの粘性による減衰は、β ≈ −2n(n−1)ν/R² ≈ −0.16 s⁻¹ と見積もれる（2 次元版の見積もりで、厳密解とは照合していない）。高さ関数の形の −0.45〜−0.70 は、その 3〜4 倍。

## 4. Rayleigh–Taylor（14d、GPU、128 × 512、T = 7）
水（1000、1e-3）が上、シリコーン油（950、5e-3）が下、σ = 0.04、g = 9.81、y₀ = 1、A₀ = 0.01、m = 1、壁。振幅は界面の高さ（列の積分）の第 1 Fourier 係数。静止から始めた線形解 A₀ cosh(γt) を、A < 3A₀（t < 約 1.05）で当てはめた。

| 方式 | γ | 法線モード 1.754 に対して | 体積 | ステップ数 / 時間（GPU） |
| --- | --- | --- | --- | --- |
| TwoPhaseIMEX + ab2 + ξ-SDF 10 | 1.731 | −1.3% | 拡散した質量 5e-15 | 2735 / 118 秒 |
| TwoPhaseIMEX（既定）+ ξ-SDF 10（交点の振幅） | 1.724 | −1.7% | 拡散した質量 5e-15、鋭い体積 +2.3e-3 | 2692 / 112 秒 |
| Basilisk 型の VOF | 1.721 | −1.9% | 1e-7 | 2286 / 377 秒 |
| TwoPhaseIMEX（既定）、再初期化なし | t = 5.79 で発散 | | | 2053 / 92 秒 |

- **線形の成長率は、両方式とも理論と 2% 以内で合う。** 論文の基準 γ = 1.78 は、表面張力と粘性を含まず 1.3% 高い（ノート10）。論文は当てはめの値を示していない。
- **非線形の段階（t = 7）は、界面が巻き込んで混ざるので、振幅の指標（交点でも列の積分でも）は意味を失う。** 図の下段の形を見ると、両方式ともマッシュルームが崩れて混ざり合っている（細部は異なる）。
- 再初期化なしでは、RT も t = 5.79 で発散する。

## 論文の主張の判定
| ベンチマーク | 論文の主張 | 判定 | 根拠 |
| --- | --- | --- | --- |
| 振動液滴（14b） | Rayleigh–Lamb に一致（振幅誤差 2.5e-10） | 比較不能（論文は NS を解いていない） | NS では、周波数は 3% 以内で合う。CLS は再初期化 + ψ の曲率では振幅が増える。高さ関数の曲率で止まる |
| 上昇気泡（14c） | 0.03 s まで妥当、0.04 s 以降は形状が破綻（未解決） | 破綻の原因を特定（再初期化の不足と見られる） | 再初期化なしで 0.039 s に発散、ξ-SDF の再初期化で 0.06 s まで破綻せず。上昇は本移植（CLS と VOF が 1% で一致）より論文が約 17% 大きく、論文の平均上昇速度は自身の重心と整合しない |
| RT（14d） | 線形成長と整合、マッシュルームの形成、体積保存 | 線形成長は成立 | γ = 1.721〜1.731（理論 1.754 の −1.3〜−1.9%）。再初期化なしでは t = 5.79 で発散 |
