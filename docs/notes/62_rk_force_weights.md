# 62 IMEX-RK の段の表面張力の重みと、論文の実装の再現性（PR #73）

## 定式化と理論的根拠
### IMEX-RK の段の力の重み（1 節）
IMEX-RK の段 i は次のとおり：

```
u_i = uⁿ + Δt Σ_j A^E_ij f(u_j) + Δt Σ_j A^I_ij g(u_j),   c_i = Σ_j A^I_ij
```

（f は陽的、g は陰的。）表面張力のジャンプと圧力は、射影を通じて陰的な部分 g に入る。

- 段 i で、その段の力 a_i を刻み c_iΔt の射影でそのまま全量入れると、段の区間の力の積分を `c_i Δt a_i` で近似することになる。
- 時間に線形な力 `a(t) = a₀ + a′t` に対して、正しい積分は `Δt Σ_j A^I_ij a(c_jΔt)`。両者の差は次のとおり：

  ```
  a′Δt² (Σ_j A^I_ij c_j − c_i²) = a′Δt² (c_i²/2 − c_i²) ≠ 0
  ```

  （2 次の段の条件 `Σ_j A^I_ij c_j = c_i²/2` を使った。）各段に O(Δt²) の誤差が入るので、大域の誤差は O(Δt)。これが 1 次の刻み依存の正体。

- `force_weights="scheme"` は `a_eff,i = Σ_j A^I_ij a_j / c_i` を入れる。積分が `Δt Σ_j A^I_ij a_j` となり、表の次数の条件をそのまま受け継ぐ。最後の組み立ての b^I も同じ理由。
- BDF は 1 段なので、力の時刻が陰的な部分の時刻と自動的に一致し、もともと整合する。

### 2 節
論文の実装を動かした再現性の記録で、理論的な主張は含まない。

### 振動液滴の線形モード（3 節）
線形化した非圧縮の Navier–Stokes 方程式で、時間依存を e^{st} とする。速度を `u = ∇φ + ∇×(ψ e_z)` と分けると、次が成り立つ：

- φ は調和関数（Δφ = 0）で、圧力 `p = −ρ s φ` を担う。
- ψ は `(Δ − s/ν) ψ = 0` を満たす。

角度のモード n では、次の形になる：

- φ は rⁿ（内側）と r⁻ⁿ（外側）。
- ψ は変形 Bessel 関数 Iₙ(mr)（内側、原点で有界）と Kₙ(mr)（外側、無限遠で減衰）。
- `m² = s/ν`。

未知数は 4 個（A、B、C、D）、r = R の条件も 4 個。行列式が 0 になる s が固有値。

- **非粘性の極限**：2 次元の円柱で `ω² = σ n(n² − 1) / (R³ (ρ₁ + ρ₂))`。R = σ = ρ₁ = 1、ρ₂ → 0、n = 2 で √6。
- **弱い粘性の減衰**：境界層の寄与を無視した散逸の見積もり `β = 2n(n − 1)ν/R²`。

表の値は、この 2 つの極限と 1% 以内で一致した。行列式の解の正しさの確認になっている。

## 1. IMEX-RK の 1 次の刻み依存の原因（`TwoPhaseIMEXRK(force_weights=...)`）
ノート52 で、2 次・3 次の ARS の表がどれも、二相の毛管波で 1 次の刻み依存を示した（−5.3〜−5.8% → −11.9%）。多段法の CN 系（ノート51 の 3 節）と同じ形だった。

- **見立て：** 段 i では、ψ_i の界面で作ったジャンプの力 a_i を、刻み c_i Δt の射影でそのまま全量入れている。段の区間 [0, c_i Δt] で力を一定とみなすことになり、時間に対して 1 次である。
- **直し方：** 段の力を陰的な重みで混ぜる。a_eff,i = Σ_j A^I_ij a_j / c_i（ARS の表では A^I_i0 = 0 なので段 0 は使わない）。最後の組み立てでは b^I で混ぜる。`force_weights="scheme"`（既定は従来どおり `"stage"`）。

等密度の毛管波（16 点）の減衰の誤差、刻み 1/1・1/2・1/4（%）：

| 表 | stage（現行） | scheme |
| --- | --- | --- |
| ars222 | −5.84 / −9.28 / −11.00 | **−12.55 / −12.63 / −12.68** |
| ars343 | −5.41 / −9.12 / −10.93 | **−12.12 / −12.48 / −12.60** |

- **見立ては確かめられた。** 重み付けで 1 次の刻み依存が消え、極限（約 −12.7%）に既定の刻みから近い。ars343 に残る小さな依存（0.36 → 0.12 ポイント）は、ほぼ 2 次。
- 多段法の CN 系と合わせて、「表面張力のジャンプ（と圧力）は、陰的な部分と同じ時刻の重みで入れる」が、IMEX の時間積分に共通する規則になる。BDF は γ = (1) なので、もともと整合していた。

## 2. 論文の実装（TwoPhaseFlow、コミット be5419e、2026-06-01）は 14 章の設定で動かない
論文の実装を、本移植とは別の仮想環境（numpy、scipy、cupy 14.2）で、論文の設定ファイルのまま流した（`experiment/run.py --config ...`）。

| 設定 | 結果 |
| --- | --- |
| `ch14_rising_bubble` | 最初のステップで停止：`pressure_velocity runtime admission failed: ph_runtime_exchange:coupled_midpoint_exchange_open`（圧力・運動エネルギーの交換の残差 2.6e-8 が受理の閾値を超える） |
| `ch14_oscillating_droplet` | 同じ理由で最初のステップで停止 |
| `variants/ch14_capillary_pcg_fuccd_t1`（論文 14a の設定） | 最初のステップで停止：`g14:g12:split_ppe_hfe_source:pressure_source_endpoint_adjoint_work_not_bound` |
| `ch14_rayleigh_taylor` | 同じ理由で最初のステップで停止 |
| `ch14_static_droplet` | 計算は進む（短い時間を与えたため、図の作成で停止しただけ） |

- 論文の実装の現在の版は、14 章の 4 ベンチマークのどれも、自身の設定で動かない。どれも計算が発散したのではなく、実装に組み込まれた「受理の判定」が満たされずに止まっている。
- 論文の数値は、これより前の版で作られたと考えられる。論文のコードとの直接の比較には、論文の結果を作った版を特定する必要がある（未実施）。

## 3. 振動液滴の粘性つきの線形モード（`cases/two_fluid_modes.drop_mode`）
2 次元の円柱の液滴（モード n、内側 ρ₁・μ₁、外側 ρ₂・μ₂）について、内側を φ = A rⁿ、ψ = B Iₙ(m₁r)、外側を φ = C r⁻ⁿ、ψ = D Kₙ(m₂r)（m_k² = s/ν_k）とした。r = R で、速度の 2 成分と接線応力の連続、法線応力のジャンプ σ(n² − 1)η/R² を課し、行列式の零点を Newton 法で求める（Bessel 関数は mpmath、列ごとに尺度をそろえる）。

| 検証 | 結果 |
| --- | --- |
| 真空に近い外側、ν = 1e-3 / 1e-4（R = σ = ρ = 1、n = 2） | β = −0.003956 / −0.0004025、弱減衰の見積もり 2n(n − 1)ν/R² = 0.004 / 0.0004 と 1% 以内。ω = 2.4493（非粘性 √6 = 2.4495） |
| 論文の振動液滴（水–空気、R = √(ab)） | **β = −0.179 s⁻¹、ω = 59.555 s⁻¹**（非粘性 59.578） |

ノート59 の振動液滴の減衰の評価は、この値を基準に直した（高さ関数の曲率の CLS は物理の 2.5〜3.9 倍、VOF は減衰不足）。
