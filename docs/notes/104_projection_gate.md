## 定式化と理論的根拠
### A. エネルギー内積の射影（ユーザー）
発散を `B = D_f I`（I は再構築の面の値、D_f は面の差）、エネルギーを移流の Gram G_A とする。

```
Π = I − G⁻¹Bᵀ(BG⁻¹Bᵀ)⁺B
```

これは任意の B について G 内積の直交射影で、`ΠᵀGΠ ⪯ G` が成り立つ。面の補間が非対称でも、発散と圧力勾配を互いに随伴として作れば、エネルギーは増えない。

- 監修 #117 の「非対称な面の補間ではエネルギーの安定性が失われる」に対し、ユーザーはこの構成で反論した。行列で確かめた（1 節）。
- `G1 = m` なので、Π は総運動量 `1ᵀGu` を保つ。

### B. checkerboard の零空間（監修 #117）
周期 PCCD の面の値の記号 `Î_PCCD(θ)`（面を原点とする）は実数で、θ = π で 0 になる。そのため：

- B の零空間に checkerboard が入る（偽の発散 0 の速度）。
- Schur 補行列 `L = BG⁻¹Bᵀ` の零空間にも入る（圧力を制御できない）。

### C. 高階差分の補正（ユーザー）
```
v_f = v_f^PCCD + α/32 δ⁴(q_f − q_{f−1}),   Î_α(θ) = Î_PCCD(θ) + iα sin⁵(θ/2)
|Î_α|² = Î_PCCD² + α² sin¹⁰(θ/2)
```

- 滑らかな場では補正は O(h⁵)。
- 格子の尺度のモードには強く効く。
- 6 セルの局所の式（q_{f−3}〜q_{f+2}）である。

Schur の比 `min L̂(θ)/|θ|²`（h = ρ = 1）で評価する。

- 一次元：`L̂ = |2 sin(θ/2) Î_α|² / ĝ(θ)`。
- 二次元：`L̂ = Σ_d |2 sin(θ_d/2) Î_α(θ_d)|² / (ĝ(θx)ĝ(θy))`。

### D. 射影の精度（二次元・単相）
G は両成分で同じスカラーなので、`Π = I − b^H b / |b|²` になる。ここで `b = 2i(s_x Î(θx), s_y Î(θy))`、`s = sin(θ/2)`。厳密な b は `i(θx, θy)` である。

発散 0 の平面波の厳密なセル平均は変わらないはずで、勾配の平面波は消えるはずである。その誤差は、b の方向の誤差で決まる。

### E. 二相：y の層（界面が格子に平行、x は Fourier）
θx ごとに N × N の Schur 補行列を作る：

```
L(θx) = [ |b_x|² G_y⁻¹ + B_y G_y⁻¹ B_yᵀ ] / (ĝ_x h³),   B_y = D_y (I_y + α C_y)
```

- G_y、I_y は、部分セルの相分離 PCCD（SplitBlend、ノート97）の Gram と面の値である。
- 参照は 2 次の変数密度の Laplacian：`L₂ = [4 sin²(θx/2) M⁻¹ + D_y M_f⁻¹ D_yᵀ]/h³`。M はセルの質量、M_f は面の点の密度 × h（層では面の流束に厳密）。
- (L, L₂) の一般化固有値の最小・最大を測る。最小が 0 に近いと、圧力を制御できない偽のモードがある。

補正 C_y の 2 通り：

- **cross**：全ての面に入れる（ステンシルが界面をまたぐ）。
- **run**：6 セルのステンシルに混合セルを含む面では 0 にする。

## 1. 単相・周期
### Schur の比 `L̂/|θ|²`（各方向 2049 点で走査）
| α | 一次元 最小 / 最大 | 二次元 最小 / 最大 | 二次元：MAC の記号 `4 sin²` との比 |
| --- | --- | --- | --- |
| 0 | 0 / 1.000 | 0 / 1.000 | 0〜1.000 |
| 1.0 | 0.328 / 1.000 | 0.265 / 1.000 | 0.654〜1.177 |
| 1.1 | 0.397 / 1.000 | 0.321 / 1.000 | 0.787〜1.257 |
| **1.2** | **0.472** / 1.000 | **0.382** / 1.000 | 0.823〜1.355 |
| 1.3 | 0.554 / 1.000 | 0.448 / 1.000 | 0.835〜1.477 |
| 1.5 | 0.737 / 1.000 | 0.583 / 1.000 | 0.853〜1.822 |
| MAC（参考） | 0.405 | 0.405 | — |

- **ユーザーの独立の計算の値（0.328 / 0.265 … 0.737 / 0.583）と全桁で一致した。**
- 最小を与える波数は、α ≤ 1.3 では (π, π)。
- 行列（N = 32）の L の固有値は、記号と 9e-15 で一致した。

### 行列の構造（N = 32、h = 1）
| α | B の零空間 | L の零空間 | Π² − Π | BΠ | ΠᵀGΠ − G の最大の固有値 | 運動量 | Π u は定数か |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 0 | **2**（定数 + checkerboard） | **2** | 2e-15 | 2e-15 | −4e-16 | 9e-16 | **いいえ**（ばらつき 0.033） |
| 1.2 | 1（定数） | 1 | 3e-15 | 3e-15 | 1e-16 | 4e-16 | はい（7e-15） |

- 一次元では、発散 0 の速度は定数だけである。α = 0 では checkerboard が射影を素通りする。α = 1.2 では、Π は運動量の平均に一致する定数を返す。
- **非対称な補正でも射影はエネルギーを増やさない**（ユーザーの主張どおり）。

### 射影の精度（二次元・単相、方向について最大の誤差、発散 0 の波 / 勾配の波）
| α | \|θ\| = 0.4 | 0.2 | 0.1 | 0.05 | 次数 |
| --- | --- | --- | --- | --- | --- |
| 0 | 1.0e-7 | 1.5e-9 | 2.3e-11 | 3.6e-13 | 6 |
| 1.2 | 8.7e-5 | 2.8e-6 | 8.7e-8 | 2.7e-9 | **5** |

- **補正は射影の精度を 6 次から 5 次に落とし、定数は約 900 倍になる**（|θ| = 0.4、1 波長 16 セル）。4 次の目標は満たすが、無視できる大きさではない。
- 発散 0 の波と勾配の波の誤差は同じ（2 × 2 の直交射影なので、b の方向の誤差だけで決まる）。

## 2. 二相：y の層（N = 32・64、混合セルの重い相の割合 c = 0.5、0.01、0.99）
| 密度比 | α = 0（零空間 B_y / L の偽の 0） | α = 1.2・cross（一般化固有値の最小 / 最大） | α = 1.2・run |
| --- | --- | --- | --- |
| 1 | 3 / 3（c = 0.01・0.99 で 2 / 2） | **9.3e-3〜9.8e-3** / 4.2〜5.4 | 零空間 3、L の偽の 0 が 2 |
| 1e3 | 3 / 3 | **2.8e-5〜3.7e-4** / 29〜31 | 同上 |
| 1e6 | 3 / 3〜5 | **2.8e-8〜3.9e-7** / 2.4e4〜2.9e4 | 同上 |

- **偽の零空間の原因**：部分セルの相分離 PCCD では、面の値が混合セルの平均に依存しない。混合セルに対応する I_y の列は 1e-15 以下（N = 32・64、密度比 1e3・1e6）。面の値は純相の列の端の多項式（の延長）で決まるからである（ノート97 の部分セルの構成）。
  - そのため、混合セルごとに、B_y の零空間に偽の発散 0 の速度（混合セルの値だけを動かすモード）ができる。L にも同じ数の偽の 0 ができる。
  - c = 0.01・0.99 で 1 つ減るのは、混合セルが列に編入された（SplitBlend）ため。
- **cross**（補正が界面をまたぐ）：零空間は消えるが、最小の固有値は密度比に反比例して小さくなる（1 → 1e3 → 1e6 で 9e-3 → 3e-5 → 3e-8）。最大は密度比に比例して大きくなる。そのため、(L, L₂) の条件数は密度比 1e6 で約 1e12 になる。
  - 最小のモード（θx = 0）の最大の位置は、混合セルから 3 セルの所にある。
  - N = 32 と 64 で値はほとんど変わらない。格子を細かくしても改善しない、格子の尺度のモードである。
- **run**（界面の近くでは補正しない）：偽の零空間がそのまま残る。
- 面の値の片側の跳び：c = 0.01（密度比 1）、c = 0.99（密度比 1e3・1e6）で 2.7〜2.8（単位のデータに対して）。編入した混合セルと隣の列の多項式が、面で一致しない。この面の流束は一意に決まらない。この表では片側の値の平均を使った。

## 3. 補足：x 方向の体積平均と、区間の移動度による比較（ユーザーのレビュー）
- **x 方向の面の流束**：層の混合セルを通る x 方向の流束は、セルの y 方向の体積平均 `V q`（V は再構築の体積平均）で作るべきである。
  - 質量加重の平均との差 `max|V − I|` は、密度比 1 で 3e-15、1e3 で 0.52、1e6 で 0.52（N = 32）。小さくない。
  - ただし、Schur 補行列の一般化固有値の最小・最大は、質量加重と体積平均で 3 桁まで同じだった。最小・最大を与えるのは θx = 0（x の項がない）の y 方向のモードだからである。
- **比較の Laplacian の移動度**：
  - x（層に平行）は、セルの中の `1/ρ` の平均とした。
  - y（層をまたぐ、直列）は、隣の圧力の点の間の `h/∫ρ` とした。

| 密度比 | α = 0：零空間 / 最大（点の密度 → 区間） | α = 1.2・cross：最小（どちらの比較でも同じ） / 最大（点 → 区間） |
| --- | --- | --- |
| 1 | 3 / 4.2 → 4.2 | 9.3e-3 / 5.4 → 5.4 |
| 1e3 | 3 / 4.2 → 1.35e3（N = 32）、573（N = 64） | 2.8e-5 / 30 → 1.7e3（N = 32）、720（N = 64） |
| 1e6 | 3 / 4.2 → 1.34e6、5.7e5 | 2.8e-8 / 2.6e4 → 1.7e6、7.2e5 |

（c = 0.5。c = 0.01 も同じ傾向。混合セルの速度の自由度による**厳密な零空間**（α = 0）と、比較の演算子に対する**条件数の悪化**（α = 1.2 の最小・最大）は分けて読む。）

- **厳密な零空間**（混合セルごとに 1 つ）は、比較の演算子によらない。
- **最小の固有値**（α = 1.2、1/密度比）も、比較の演算子によらない。最小のモードは混合セルから 3 セルの所の y 方向のモードで、両方の比較が一致する所にある。
- **最大の固有値**は比較の演算子に強く依存する。区間の移動度に対しては α = 0 でも密度比に比例して大きく、N に反比例する。セル平均の L は、界面をまたぐ面で、物理的な直列の移動度より大きな移動度を持つ（点の密度に近い振る舞い）。そのため、ノート104 の「条件数 1e12」は、点の密度の比較での値である。区間の移動度に対しては、さらに大きい（最大 1.7e6 / 最小 2.8e-8 ≈ 6e13）。

- **界面をまたぐ高階差分の局所誤差**（ユーザーの指示による補足、導出）：速度は界面で連続でも、勾配は跳ぶ（`[μu'] = 0`、μ が跳べば `[u'] ≠ 0`）。折れ目を持つ関数のセル平均に差分を k 回当てると、折れ目の近くでは `δ^k q = O(h [u'])` になる（滑らかな場合の O(h^k) ではない）。そのため、ステンシルが界面をまたぐ面では、補正 `α/32 δ⁴(q_f − q_{f−1})` は O(h) の局所誤差を面の値に加える。cross の形は、零空間の問題とは別に、精度の面でも二相には向かない（数値での確認はしていない）。

## まとめ
- **単相**：ユーザーの高階差分の補正（α = 1.2）は checkerboard を除き、Schur の比の最小は 0.472（一次元）/ 0.382（二次元）（ユーザーの値と一致）。射影は G 内積で直交で、エネルギーを増やさず、運動量を保つ。代償は、射影の精度が 6 次から 5 次に落ち、定数が約 900 倍になること。
- **二相（相分離 PCCD + 部分セル）では、セル平均の射影は成立しない**：
  - 面の値が混合セルの平均に依存しないので、混合セルごとに偽の零空間が残る。
  - 補正を界面の両側にまたがせると零空間は消えるが、L は密度比に比例して悪条件になる（密度比 1e6 で条件数約 1e12）。
  - 界面の近くで補正を切ると、零空間が残る。
- **判定**：「セル平均だけを状態変数とし、相分離 PCCD の面の値で発散を作る」射影は、二相ではこのままでは成立しない。混合セルの平均が面の流束に入る構成が必要である。

## 未検証・次（ユーザーの判断が必要）
状態変数・射影の候補（ユーザーの表に、この結果を加える）：

| 候補 | 単相 | 二相の見込み |
| --- | --- | --- |
| 通常の PCCD 射影 | 零空間あり | 零空間が混合セルの分も増える |
| 高階差分の補正 | 成立（5 次） | 混合セルが面に入らない問題は残る。界面をまたぐと密度比に比例する悪条件 |
| MAC 型（面の速度を状態に） | 構成上、零空間なし（2 次の記号 0.405） | 混合セルの平均の問題が生じない。高次化と、移流・再構築との整合は未検討 |
| 圧力安定化・粗い圧力空間 | 未検討 | 未検討 |

- 混合セルの平均を面の値に入れる部分セルの変形（例：u_Γ を介した面の値の補正）。移流の再構築（ノート97）にも影響する。
- 斜めの界面（Gate 1-B）では、混合セルが連続するので、この問題はさらに大きくなる見込み。
- 圧力勾配の精度、密度・圧力の跳びとの整合、求解の費用（G⁻¹ の入れ子）は、方式が決まってから測る。
