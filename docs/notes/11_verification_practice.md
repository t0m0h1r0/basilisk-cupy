# 11 検証のときの注意

- 対称性で誤差項が打ち消し合う問題（kx = ky の Taylor–Green など）だけで次数を判断しない。ψ = sin(ax) sin(by)（a ≠ b）を併用する。
- 時間発展の検証より先に、静的な検証をする（演算子単体の次数、厳密解を射影したときの変化量）。
- 最大ノルムの次数は壁セルで決まることが多い。内部だけの次数も併せて見る。
- 新旧の比較は、同じスクリプト・同じ条件で、別のワークツリーに取り出した旧版と並べて測る。
- 反復の許容値が丸め誤差の床（|b|·ε）に近いと、反復回数が偶然で決まる（N = 256 の欠陥補正で 23 対 128）。
- 論文の式は、導出の前提（点値か平均値か、どの演算子を合成したか）まで確かめる。
- Basilisk の参照値と合わないときは、Basilisk をミラーのソースから手元でビルドし（gcc と make のみ）、同じ時点の場を全桁で出力させてセルごとに比べる。許容値・緩和の順序・定数（π = 3.14159265358979）を合わせると、1ステップ目は丸め誤差の精度で一致する（12 を参照）。
- 反復解法の許容値が緩い比較では、反復の経路（緩和の順序、許容値の定義）まで同じでないと結果は一致しない。
