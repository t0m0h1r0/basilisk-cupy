# 05 時間刻み

高精度ソルバーの目的の一つは時間刻みを大きくすること。そのための検討。

- EXT2（IMEX-BDF2 の陽的部分）は虚軸上に安定域がない。非散逸の FCCD/CCD 対流は粘性に頼って安定しているだけ。
- 高次の演算子ほどスペクトルが広い：max|λh| = 1.000（fd2 流束）、1.378（FCCD 流束、03 の修正後 1.608）、2.126（CCD D1）。
- IMEX-RK ARS(3,4,3) を導入：陽的部分は RK4 と同じ安定域（虚軸 2.83、実軸 −2.79）、陰的部分は L 安定な SDIRK（γ = 0.4359）。段ごとに IPC で射影し、最後に1回余分に射影する。
- **面状態**（`face_native=True`）：射影済みの面速度を状態にし、セルは R_h u_f とする。近似射影の O(dt·h^p) の交差項が消える（同じ N で、誤差が時間刻みによらなくなる）。
- **陰的ハイパー粘性**：UCCD6 の実軸の制約（σ ω₂(π)⁸ CFL ≤ 4/3）を外し、粘性の欠陥補正の中で一緒に解く。前処理は高速対角化。
- 実測（README）：粘性 TG、N = 64、t = 0.5：BDF2 CFL 0.2 で 2.1e-6・6.9 s ↔ IMEX-RK 面状態 CFL 2 で 1.5e-6・3.3 s。蓋付きキャビティ：陽的ハイパー粘性 CFL 0.07・130 s ↔ 陰的・面状態 CFL 2・7 s。

## 定式化と理論的根拠
- **EXT2 は虚軸上に安定域がない**：SBDF2 の陽的な部分を純虚数の固有値 iω にかけると、`|ζ| − 1 ≈ (3/4)(ωΔt)⁴ > 0`（ノート70 で導出）。どんな刻みでも増幅する。非散逸の対流（中心型、記号が純虚数）は、粘性の減衰が増幅を上回る範囲でだけ安定。
- **高次の演算子ほどスペクトルが広い**：陽的な刻みの上限は `|λ|_max Δt ≤（方式の虚軸の限界）`。CCD の D1 の記号の最大 2.126（kh の最大値付近）は、fd2 の 1.0 の約 2 倍で、同じ CFL 数でも 2 倍厳しい。
- **ARS(3,4,3) の陽的な部分**：安定関数が RK4 と同じなので、虚軸の限界 2√2 = 2.83、実軸 −2.79。
- **面状態で交差項が消える理由**：近似射影の誤差は、セル中心の速度を面に補間し直す（作り直す）ことで毎ステップ入る（ノート47）。射影済みの面の速度を状態にすると、作り直しがなくなり、その交差項が消える。セルの速度は `R_h u_f` で表示用に作るだけ。
