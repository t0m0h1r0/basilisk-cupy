## 結論の要約
- **現象を再現した**（監修の表と同じ桁）：面に揃った帯・正方形を一様流で運ぶと、密度比 1000・1e6 で max|u − U| が 3e-2〜0.3 に育つ。円い液滴では育たない。
- **原因は、運動量の VOF 輸送の中の独立な 2 つの欠陥**で、どちらも「セルに残る運動量と質量の不一致」を軽い相の質量で割ることで密度比倍に増幅し、射影が界面の両側の速度の差に戻して帰還が閉じる（射影を外すと育たない：8e-14）。
  - **D1**：上流のセルで相が「無い」（cᵢ ≤ 1e-10、丸めで負を含む）とき、体積の流束はあるのに運動量の流束を 0 にする。運動量は clamp した f で作るのに、輸送は clamp しない f で行う。→ CFL < 0.5 でも 1e-5 の水準。
  - **D2**：相が一部しか満たさない上流のセルの勾配の項。そのセルから相のほぼ全部が出ていくと、勾配の項の分の運動量が残り、残った小さい質量で割られる：`u_T' − u_T = −ρ₁(c − δ)(1 − C)g/2 / (ρ₁δ + ρ₂(1 − δ))`（**1 回の掃過で丸めまで一致**）。利得は δ → 0 で密度比/8。**面に揃った界面を CFL 0.5 の直下で運ぶと、2 ステップごとにこの条件になる**（自動の Δt は 0.5 に下から近づく）。固定の CFL 0.4999 で発散（3.4e2）、0.5 ちょうどでは丸めの種が無く 0。
- **両方を直すと**（`cases/` のフック。D1：clamp しない f と `ρ_lin`、相が無いセルの面の値を混合の値に。D2：部分的なセルの勾配の項を 0 に）、**監修の全ての配置（19 行）と `break_stability.py` の全ての形状（2000 ステップ、密度比 1e3・1e6）で max|u − U| ≤ 1.2e-9**。残りは圧力の許容誤差に比例（1e-13 で 2.4e-13）。どちらか一方だけでは直らない。
- 界面の無い計算はビット一致（単相の結果はそのまま）。渦の中の液滴で総運動量は丸めの水準（8e-13）で安定。**ただし D2 は界面のセルの面の値を 1 次にするので解を変える**（格子の差の約 1/4〜1/3。この配置は漸近の範囲になく、精度の次数への影響は未検証）。
- 元の方式は、**密度比 1e6 の薄い膜でも 4.1e-2 まで育つ**（ノート114 で判定できなかった条件。修正後 1.2e-9）。
- ライブラリは変えていない。扱い（修正を基準ソルバーに入れるか、自由流の要件の範囲を限るか）は B の判断を求める（最後の節）。

## 定式化と理論的根拠
### A. 設定
`TwoPhase(conserving=True)`（源の項なし、`conserving.h` と同じ）。各ステップで相ごとの運動量 `q₁ = clamp(f)ρ₁u`、`q₂ = (1 − clamp(f))ρ₂u` を作り、VOF の濃度として f と同じ体積の流束で運び（`vof.h`）、`u = (q₁ + q₂)/ρ(f)`（ρ は clamp した f の一次式）で速度に戻す。濃度 `t/c` の面の値は、上流のセルの濃度 + 勾配の項 `s(1 − C)/2·g`（C はその面の CFL 数、g は `vof_concentration_gradient`：c ≥ CMIN = 1/2 のセルだけ。隣が CMIN 未満なら片側の差）。上流のセルの相の体積率 `cᵢ ≤ 1e-10` なら、その相の運動量の流束を 0 にする（`vof.h` の `if (ci > 1e-10)`）。

一様流 U では、厳密解も、丸めの無い数値解も `u ≡ U` である（全ての濃度が ρₖU、勾配が 0）。誤差は丸め（と圧力の許容誤差）から始まり、以下の 2 つの欠陥が密度比倍に増幅し、射影が界面の両側に戻す。

### B. 欠陥 D2：部分的なセルの勾配の項（導出。1 回の掃過について厳密）
セル T の下流側の幅 c を重い相が占め（上流は軽い相）、重い相の速度が T とその下流で `u_{T+k} = u_T + gk` とする。T の重い相の勾配は片側の差 `ρ₁g`（c ≥ CMIN）。CFL 数 C の掃過で、T から出る重い相の体積は `c − δ`（`δ = max(c − C, 0)`）、その面の値は `ρ₁(u_T + (1 − C)g/2)`。T に残る運動量と質量は

```
q_T' = ρ₁ c u_T − ρ₁(c − δ)(u_T + (1 − C)g/2) + （軽い相：流入も流出も u_T）
m_T' = ρ₁ δ + ρ₂ (1 − δ)
⇒ u_T' − u_T = − ρ₁ (c − δ)(1 − C) g / 2 / (ρ₁ δ + ρ₂ (1 − δ))                 (D2)
```

勾配の項は「出ていく重い相の速度」を変えるが「出ていく質量」は変えないので、その分の運動量 `ρ₁(c − δ)(1 − C)g/2` がセルに残り、残った小さい質量で割られる。増幅率 `(D2)/g` は δ → 0（c が C の直上）で `(ρ₁/ρ₂)c(1 − C)/2 ≈ 密度比/8` に近づく（証明：式から直接。δ = 0 で分母が ρ₂）。

**面に揃った界面を CFL 0.5 の直下で運ぶと、この条件を 2 ステップごとに満たす**：界面は 1 ステップに C ≈ 1/2 − ε 進むので、界面のセルの体積率は 1/2 + O(ε)（≥ CMIN、勾配あり）と O(ε) を交互に取り、前者のセルから重い相のほぼ全部（残り δ = 2εk）が次の掃過で出ていく。C がちょうど 1/2（固定の Δt）なら丸めの種が無く誤差は 0 のまま。円い液滴・斜めの帯では、c が C の直上に来るセルが続かない（D2 の増幅が時々しか起きない）。CFL を自動で決めると Δt は 0.5 に下から近づく（`(previous + 0.1 dt)/1.1`）ので、監修の構成（600 ステップ）はちょうど危ない側に入る。

**修正**：相が一部しか満たさないセル（0 < cₖ < 1）では勾配の項を 0 にする（その相の濃度は一定値で再構成）。このとき出ていく相の運動量は `ρₖ u_T ×（出ていく体積）` で、質量と一致する。純相のセル（cₖ = 1）は変えない。界面の無い計算は変わらない（ビット一致、5 節）。

### C. 欠陥 D1：相が「無い」セルと clamp（機構の記述。局所の式は切り出していない）
1. **閾値**：上流のセルの体積率 cᵢ が 1e-10 以下（0 に近い正の値、または丸めで負）でも、f の流束 `cf·u`（cu ≤ 0 なら cf = cu）は 0 でない。運動量の流束だけが 0 になり、受け取るセルで「質量は変わるが運動量は変わらない」不一致が生じる。
2. **clamp**：運動量は `clamp(f)` で作るが、輸送するのは clamp しない f で、速度に戻す密度も clamp する。f が [0, 1] の外に 1e-9 ほど出たセル（膨張の項 `cc·div u` は圧力の許容誤差の分だけ 0 でない）では、運動量と質量が別の f を見る。

どちらも不一致の大きさは `ρ₁ × (1e-9〜1e-12 の体積)` で、軽い相を含むセルの質量で割ると密度比倍の速度の誤差になる（見立て。1 回の掃過の式は作っていない：負の f は clamp した世界ではほとんど打ち消し合い、増幅は「受け取るセルが正の微小な重い相を持つ」配置でだけ起きる。その配置を 1 掃過で作れなかった）。**証拠は 3 節の切り分け**：1 と 2 のどちらか一方だけを直しても残り、両方で消える。

**修正**：(i) 運動量を clamp しない f で作り、速度は `u = (q₁ + q₂)/ρ_lin(f)`（`ρ_lin(f) = fρ₁ + (1 − f)ρ₂`、下限 `min(ρ₁, ρ₂)/2`。この計算では下限に達しない）で戻す。運動量のゴーストセルも同じ f で作る。(ii) 上流のセルで相が無い（cᵢ ≤ 1e-10）ときは、面の値をそのセルの混合の速度 `ρₖ(q₁ + q₂)/ρ_lin(f)` とし、運動量の流束を `面の値 × 同じ体積の流束` にする（0 にしない）。流束の形なので保存は保たれる。一様流では全ての面の値が ρₖU になり、`u ≡ U` が丸めまで保たれる（f の値によらない）。

### D. 測定（結果の前に固定したもの、後から足したもの）
- 固定したもの：監修の合格の条件（#162）「選んだ扱いで、面に揃った帯と正方形の液滴（CFL の上限、密度比 1000・1e6）の max|u − U| が円い液滴と同じ水準になる（またはその水準を要件として明記する）」。監修の配置（`audit/aligned/aligned_base.py`）をそのまま使う。
- 後から足したもの（原因の特定の途中で）：固定の Δt での CFL の走査、圧力の射影を外した計算（2 節）、D1 の 2 つの部品の切り分け、監修の `break_stability.py` の形状での 2000 ステップ、渦の中の液滴での修正の影響。

- 保存は全ての形で丸めの水準（要件 1e-9）。D1 は円い界面ではほとんど何も変えない（max\|u\| が 15 桁まで同じ）。
- **D2 は解を変える**（界面のセルの面の値が 1 次の再構成になる）：max\|u\| が 2%（N = 64）・0.4%（N = 128）変わる。格子の細分化の差との比較：

- 方式の差（RMS）は格子の差の約 1/4〜1/3。ただし**どちらも細分化でほとんど減らない**（粘性の無い密度比 1000 の渦で、界面に沿う速度の不連続があり、漸近の範囲にない）。**D2 が二相の精度の次数をどれだけ下げるかは、この配置では判定できない（未検証）**。速度の最大の差 0.2〜0.3 は界面の上の点である（f の差 0.07〜0.3 も界面の位置のずれ）。

## まとめ
| 欠陥 | どこで | 何が起きるか | 修正（フック） | 効果 |
| --- | --- | --- | --- | --- |
| D1 | 相が無い（cᵢ ≤ 1e-10）上流のセル、f が [0, 1] の外のセル | 体積は動くが運動量は動かない／運動量と密度が別の f を見る | clamp しない f と `ρ_lin`、相が無いセルの面の値を混合の値に | CFL < 0.5 の 1e-5 → 2e-10 |

## 自己点検（試験が成立しやすい条件に寄っていないか）
- 監修の配置をそのまま使い、元の方式の値が監修の表と一致することを確かめた。修正の効果を見る配置を後から選んではいない（1 節は監修の全ての行、4 節は監修の `break_stability.py` の全ての形状）。
- 修正の形は、原因の特定の途中で 6 通り試した（相が無いセルの面の値だけ、clamp しない形だけ、両方、f の clamp、幾何的な勾配の項 `conserving_geometric`、部分的なセルの勾配の項を 0）。f の clamp は効かず、幾何的な勾配の項は D2 に効く（帯、密度比 1000 で 5.6e-5）が D1 と組み合わせても 1e-5 が残った（試行の段階の測定で、表と試験には入れていない）。記録したのは最小の 2 つの組み合わせである。
- 一様流の試験は、全ての面の値が ρₖU になる修正には成立しやすい。修正が解を変える大きさは 5 節で測ったが、精度の次数への影響は判定できていない（上）。
- 固定の Δt の 0.25・0.5 の 0 は丸めの種が無いだけで、安定性の証拠ではない。

## 検証済みと未検証
- 検証済み（数値）：現象の再現（監修の表と一致）。D1 と D2 が独立で両方が要ること（切り分け）。式 (D2) が 1 回の掃過で丸めまで一致。射影を外すと育たないこと。修正後に全ての配置・形状で ≤ 1.2e-9、残りが許容誤差に比例すること。界面の無い計算でビット一致。渦の中の液滴で保存（≤ 8e-13）と安定。
- 証明：式 (D2)（1 回の掃過、仮定は 3 節の配置）。修正後の一様流の保存（全ての面の値が ρₖU、流束の形）は構成から明らか。
- 未検証：D1 の 1 回の掃過の式（機構の記述のみ）。D2 の修正が二相の精度の次数に与える影響（渦の中の液滴は漸近の範囲にない）。射影を含む 1 ステップの増幅率（ノート114 の 3 節のような写像の解析）。壁のある場合。C 版の Basilisk での修正の確認。f のはみ出し（1e-7）の原因と、`ρ_lin` の下限に達する条件（密度比 1e6 で余裕は約 3 倍）。ノート115〜117 の結果（源の項・帯で切る形）との組み合わせ。
