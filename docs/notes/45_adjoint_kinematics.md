# 45. 補正済みの運動学と GFM のエネルギー整合性：差を測ってから補正を判断する

44 の帯の補正（鋭い運動学）は毛管波の減衰不足を解消したが、エネルギー交換の吸収（+3.5〜+9.9%）と、静止液滴の寄生流の遅い減衰が残った。
いきなり力を作り直すのではなく、まず運動学の作用素とその転置を組み立て、GFM との差を測った。

**結論：**
- GFM（鋭い界面）に整合するエネルギーを基準にすると、既定の輸送の減衰不足は、運動学と GFM の非随伴性でほぼ説明できる。
- 帯の補正の後に残る非随伴性は小さく（−2%、減衰不足の向き）、残る減衰しすぎ（+4%）の原因ではない。そのため、力を随伴に作り直す補正は必要ない（むしろ逆効果）。
- 44 の「吸収と減衰しすぎは同じ向き」という記述は、因果を示していなかった。訂正する。

## 定式化と理論的根拠
### 随伴の力の恒等式
ψ を固定すると、輸送は面の速度について線形で `ψ̇ = −T u_f`。表面エネルギー E(ψ)、`g = ∂E/∂ψ` とすると：

```
dE/dt = gᵀ ψ̇ = −gᵀ T u_f = −Σ_f u_f (Tᵀg)_f
```

`F_adj = Tᵀg / V_f` とおけば `Σ_f u_f F_adj V_f + dE/dt = 0`（測定 1.4e-14）。

### 食い違いの仕事から減衰の変化を予測する式
実際の力は F_GFM。運動エネルギー K と表面エネルギー E の和の変化は、次のとおり：

```
d(K + E)/dt = −D + Σ_f u_f (F_GFM − F_adj) V_f = −D + B(u, η)
```

（−D は粘性の散逸。）B は、力が運動学の転置でないことによるエネルギーの湧き出し。

モード `u = Re(û e^{iωt})` で周期平均すると、`⟨B⟩ = ½ B(Re û)`（η と同じ位相の速度の成分）。90° ずれた成分は往復するだけで、平均に残らない（周波数に効く）。減衰率の変化は `δγ = −⟨B⟩ / (2⟨K + E⟩)`。本文 2 節の予測はこの式。

### 基準のエネルギーの選び方
GFM の力は、鋭い界面の跳び `σκ(η)` を面に入れる。これに整合するエネルギーは、界面の長さ `E = σL(η) ≈ ½σΣ(η_x)²Δx`（線形）。帯の面積 `σA_h(ψ)` は CSF 型の力（ノート43）に整合するエネルギーで、GFM には整合しない。基準を誤ると、勾配の成分（圧力に吸収される）まで食い違いに数え、予測が大きく外れる（−53.8%）。

### 静止平衡性とエネルギー整合性が別の条件であること
エネルギー整合は、すべての u_f について `u_fᵀF + Ė = 0`（力の向きの条件）。静止平衡は、`F − G_f p = 0` となる p が存在する（F が勾配の成分だけを持つ）こと。一方は他方を含意しない。

## 1. 作用素と半離散の恒等式
- ψ を固定すれば、輸送は面速度について線形で、ψ̇ = −T(ψ)uf と書ける（クリッピングと質量補正は除く）。面ごとの単位ベクトルを当てて組み立てた（N = 32 で 1024 × 1984、壁面は除外）。帯の補正も、ψ を固定すれば uf について線形である。
- 表面エネルギーを E、g = ∂E/∂ψ とすると、F_adj = Tᵀg/V_f は Σ uf F_adj V_f + dE/dt = 0 を満たす。乱数の uf で確かめた（輸送：和 1.4e-14、補正：−2.8e-14）。

## 2. どのエネルギーを基準にするか
| 基準のエネルギー | 運動学 | 食い違いからの減衰の予測（N = 32 / 64） | 実測（固有値、厳密な曲率、Δt） |
| --- | --- | --- | --- |
| 帯の面積 σA_h(ψ) | 輸送 | −53.8% / −38.0% | −16.6% / −4.7% |
| 帯の面積 σA_h(ψ) | 帯の補正 | −10.2% / −9.0% | +7.7% / +5.6% |
| **鋭い界面 σL(η)** | 輸送 | **−19.7% / −5.8%** | −16.6% / −4.7% |
| **鋭い界面 σL(η)** | 帯の補正 | **−2.2% / −1.6%** | +7.7% / +5.6% |

- 予測の求め方：
  - 食い違いの仕事 B(u, η) = Σ uf(F_GFM − F_adj)V_f の周期平均は、η と同じ位相の速度（実部）で ½B(Re û) になる。
  - δγ = −⟨B⟩/(2E)（E は運動エネルギーの平均の 2 倍）とした。
  - η と 90° ずれた位相の速度（虚部）での食い違いは往復の成分で、減衰ではなく周波数に効く。
- **帯の面積は GFM のエネルギーではない。** 周波数側の食い違いも +59%（輸送、N = 32）と大きく、実測の周波数誤差（−3.4%）と合わない。ΔF = F_adj − F_GFM はノルムで F_GFM の 437 倍あるが、ほとんどが勾配成分（圧力に吸収される）で、発散ゼロ成分は 0.28（輸送）、0.21（補正）である。
- **鋭い界面のエネルギー**を使った（E = ½σΣ(η_x)²Δx、η は ψ = ½ の交点の高さ、g は交点の高さの ψ による微分 C を通して σ(−η'')Δx）。
  - これは厳密な曲率の GFM のジャンプと整合する。
  - 既定の輸送の減衰不足（−16.6% / −4.7%）は、非随伴性からの予測（−19.7% / −5.8%）でほぼ説明できる。

## 3. 補正後に残る減衰しすぎ
- 帯の補正の後、非随伴性からの予測は −2.2% / −1.6%（減衰不足の向き）しかない。実測の +7.7% / +5.6% は、エネルギー交換からは来ていない。
- 時間刻みを変えた（厳密な曲率、N = 32）：

> 追記（46）：Δt/64 まで測ると、外挿値は約 +3.2%（下の +4.0% は漸近域に入る前の 3 点からの値）。

| Δt / Δt₀ | 1 | ½ | ¼ | 外挿（→ 0） |
| --- | --- | --- | --- | --- |
| 減衰誤差 | +7.7% | +6.4% | +5.2% | 約 +4.0% |

- 半分は時間刻みの誤差である。半離散の残り（約 +4%）は、41 の鋭い運動学の残り（+3.8%）と同じで、運動学・エネルギー交換以外（粘性と射影の部分）に由来すると考えられる（未帰属）。
- ψ 曲率での時間積分（44：+3.4%）は、厳密な曲率の固有値（+7.7%）より小さい。ψ 曲率の誤差が一部を打ち消している。

## 4. 静止液滴（静止平衡性は別の条件）
- エネルギー整合性（uᵀF + Ė = 0）と静止平衡性（F − Gp = 0）は別の条件である。
- GFM の力は変えていないので、静止平衡（GFM の力の発散ゼロ成分は |ΠF|/|F| = 8.1e-4、N = 32）は同じである。
- 1 ステップの Jacobian（静止液滴、密度比 1、K = 0）の、最も遅いモードの |λ| を比べた：

| N | 輸送 | 帯の補正 |
| --- | --- | --- |
| 32 | 0.99957 | 0.99933 |
| 64 | 0.99575 | 0.99489 |

- 補正の方が、最も遅いモードの減衰はむしろ速い。44 で見た、時間積分での max|u| の遅い減衰は、線形化した平衡のまわりのモードでは説明できない（非線形の効果、または最大値ノルムによる可能性。未解明）。

## 結論と判断
| 問い | 答え |
| --- | --- |
| 随伴性の破れはエネルギー誤差を説明するか | 既定の輸送の減衰不足は、ほぼ説明する（鋭い界面のエネルギーで） |
| 補正後の減衰しすぎの原因か | いいえ（予測 −2% に対して実測 +8%） |
| 力の最小限の補正は必要か | 不要。非随伴性は小さく、補正すると減衰しすぎを広げる向き |
| 静止液滴の寄生流の遅い減衰 | 線形化した主要モードは遅くない。原因は未解明 |
| 残る +4%（半離散）+ 時間刻みの +3.7% | 粘性・射影の部分と時間分割。次に帰属させる |

- 既定値は変えていない（試作は `cases/` の中だけ）。
- 次の候補：残る減衰しすぎを、粘性と射影の部分に帰属させる（離散分散関係で、粘性の時間積分と射影を一つずつ差し替える）。その後、P0-4（密度で重み付けした圧力射影）。
