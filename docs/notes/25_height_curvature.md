# 25 ψ の高さ関数による曲率（CCD と2次差分）（PR #39）

## 方法（`cls.curvature(method="heights", heights_method="ccd" | "fd2")`）
- ψ の勾配が軸 a 方向に大きいセルで、同じ行の各列の高さ η を求める。
- **高さ（既定 `heights="crossing"`）：** セルを中心とする幅 2m+1（m = 4）の窓の中にある、ただ1つの ψ = ½ の交差の位置。
  - 交差は、φ_map = ε ln(ψ/(1−ψ)) の4セルを通る3次ラグランジュ補間の根で求める。
- **比較用（`heights="sum"`）：** 列の和 Σψ·Δ を高さにする（窓 m = 15、両端の ψ が 1e-3 以下 / 1−1e-3 以上）。
- **微分：** 高さが定義される列の連なりごとに、接線方向の CCD を1回解く（`ccd`）か、中心差分をとる（`fd2`、Basilisk と同じ）。
  - CCD の連なりの両端 `trim = 2` セルは使わない。
- κ = s η″/(1+η′²)^{3/2}。どの連なりにも入らない帯内のセルは、ψ を直接微分した曲率で埋める。

## 正確な円（R = 0.2）：交差での κR − 1（GFM のジャンプと同じ θ 補間）
| N | 64 | 128 | 256 |
| --- | --- | --- | --- |
| ψ を直接微分（rms / max） | 9.6e-4 / 1.7e-3 | 3.5e-4 / 5.2e-4 | 2.3e-4 / 4.3e-4 |
| 列の和の高さ＋2次差分（m = 15） | 8.8e-3 / 6.6e-2 | 1.5e-2 / 3.0e-2 | 4.0e-3 / 6.1e-3 |
| 交差の高さ＋2次差分 | 1.3e-3 / 1.8e-3 | 3.3e-4 / 4.4e-4 | 8.2e-5 / 1.1e-4 |
| 交差の高さ＋CCD（端を除く） | 2.4e-3 / 7.8e-3 | 1.7e-4 / 6.8e-4 | 2.4e-5 / 7.8e-5 |

- **列の和の高さ：** 曲がった界面では、拡散したプロファイルが列方向に非対称になり、和の位置が ψ = ½ からずれる（傾きの大きい列で 0.01h〜0.17h）。O((ε/R)²) のモデル誤差で、使えない。
- **交差の高さ＋CCD：** N とともに収束し（rms で N = 128→256 が 1/7）、N = 256 では ψ を直接微分した曲率（O(h⁻¹) で頭打ち、14）の 1/9。
- **粗い格子：** 連なりが短く、最大誤差は ψ の直接微分より大きい（N = 64 で 7.8e-3）。
- **移流後**（補正した発散＋6次の面値で並進、t = 1）：どの方式も 5e-3〜2e-2 で同程度。移流の誤差が支配的。

## 毛管波（GFM、補正した発散＋6次の面値、相対 RMS 誤差）
| 1波長の点数 | 8 | 16 | 32 | 64 |
| --- | --- | --- | --- | --- |
| ψ を直接微分 | 0.188 | 0.0639 | 0.0109 | 0.00209 |
| 交差の高さ＋2次差分 | 0.187 | 0.0549 | 0.0120 | 0.00440 |
| 交差の高さ＋CCD（端を除く） | 0.183 | 0.0496 | 0.0100 | 0.00478 |
| 交差の高さ＋CCD（端も使う） | 1.17 | 0.886 | 0.165 | 0.188 |
| VOF（Basilisk） | 0.139 | 0.0242 | 0.0064 | 0.0023 |

- 連なりの端（ここでは壁）まで CCD の値を使うと崩れる。t = 0 の曲率は壁の列で 2% ずれる程度（−0.4012、正しくは −0.3929）なので、端の閉じ方による陽的な毛管ループの不安定と考えられる（未確認）。
- 端を除くと 8〜32 点で最良だが、64 点では ψ を直接微分した方が良い。

## 静止液滴（GFM、密度比 100、N = 64、800 ステップ）
| 曲率 | 係数 √(5/12) | 係数 1（tension.h のまま） | 安定の境目 |
| --- | --- | --- | --- |
| ψ を直接微分 | 安定、3.3e-8 | 不安定 | 0.95〜1.0（N = 128：0.91〜0.95） |
| 交差の高さ＋2次差分 | 安定、2.5e-10 | 安定、1.1e-11 | 約 1.4（N = 128：1.2〜1.4） |
| 交差の高さ＋CCD | 寄生流が減衰しない（5e-5） | 不安定 | — |

- **2次差分の高さ：** 寄生流が 1e-11 まで減衰し、境目は VOF（1.2〜1.4）や ψ の2次差分の曲率（20）と同じ水準。同じ高さから曲率を求めるので、界面に沿って曲率がそろいやすいと考えられる。
- **CCD の高さ：** 格子規模の波に硬く（9.6/h²）、連なりの端の扱いもあり、静止液滴では良くない。

## 結論
- 「高さ関数を CCD で微分」は、正確なプロファイルでは最も高精度で、N とともに収束する。ψ の直接微分のような頭打ちはない。
- しかし実際の流れでは利点が限られる。
  - 移流後は、移流の誤差が支配的。
  - 毛管波では粗い格子だけ良い。
  - 静止液滴では寄生流が減衰しない。
  - 連なりの端の CCD は不安定のもとになる。
- 2次差分の高さ（交差位置から）は、静止液滴の平衡と安定性で最も良い。
- 既定は論文どおり ψ の直接微分のまま。
