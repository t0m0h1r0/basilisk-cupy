# 37. layered 形の CCD 粘性で、エネルギーが増える原因

33 の「粘性のみの減衰試験」では、layered 形（D1∘D1、論文の 3 層の字義どおりの合成）で射影した白色雑音の運動エネルギーが 40 ステップで 7.8 倍に増えた（N = 64）。
既定の split 形では起きない。対称部 S、演算子のスペクトル、後退 Euler、defect correction（DC）、射影、境界条件の順に切り分けた。
スクリプトは `cases/layered_energy.py`、図は `docs/figures/layered_energy.png`。

## 定式化と理論的根拠
- **周期でエネルギーが増えない理由**：周期の CCD の D1 は巡回行列で、反対称（`D1ᵀ = −D1`）。そのため `D1·D1 = −D1ᵀD1` は対称で半負定値。`A = (I − κL)⁻¹` は ‖A‖₂ ≤ 1。
- **壁で増えうる理由**：layered 形の `D1_ext·D1_dir` は、2 つの層の閉包が違うので、`D1_ext ≠ −D1_dirᵀ`。対称部 `(L + Lᵀ)/2` が正の固有値を持てば、ある方向で `d/dt|u|² = 2uᵀLu > 0`。1 ステップでも ‖A‖ > 1 になりうる。SBP 型の `−D1_dirᵀD1_dir` は構成から半負定値。
- **欠陥的な零固有値で k のべきで増える理由**：零固有値がジョルダン塊（大きさ m）を持つと、A の対応する部分は `I + N`（N は冪零、N^m = 0）の形で、`A^k = Σ_{j<m} C(k, j) N^j`。そのノルムは `k^{m−1}` のように多項式的に増える。固有値の大きさ（ρ(A) ≈ 1.0008）では説明できない増大（k = 40 → 80 で 6.2 倍）は、この形と整合する。

## 方法
- 演算子 L_H を、`CCDStress` に単位ベクトルを与えて列ごとに組み立てた（2N² 元）。μ = 1、密度 1、L = h² L_H。
- 粘性の 1 ステップは A = (I − κL)⁻¹。κ = μΔt/h² = 0.426 で、33 の試験の N = 64 の値。
- P は CenteredNS の近似射影を、同じく列ごとに組み立てたもの（`cases/operator_commutator.py` の `Ops.P`）。
- エネルギーは、白色雑音（乱数の種 0）に A を k 回掛けたときの |x_k|²/|x_0|²。

## 1. 1 次元（`ccd_matrices` の行列）
layered 形の同じ軸の項は、D1_ext · D1_dir である。
- D1_dir：層 A。速度の Dirichlet 条件で閉じる。
- D1_ext：層 C。応力の壁の値を使わず、外挿で閉じる。

| n | 演算子 | max Re λ | 対称部の最大固有値 | ‖A‖₂ | 零空間 L / L² | 40 ステップ後の E/E0 |
| --- | --- | --- | --- | --- | --- | --- |
| 32 | 周期 D1·D1 | 7e-16 | −6e-16 | 1.000 | 2 / 2 | 0.108 |
| 32 | 壁 D1_ext·D1_dir（layered） | 7e-16 | **+1.79** | **1.367** | 1 / 1 | 0.362 |
| 32 | 壁 D2_dir（split） | −9.6e-3 | −9.6e-3 | 0.996 | 0 / 0 | 0.042 |
| 32 | 壁 −D1_dirᵀ D1_dir | −4.7e-3 | −4.7e-3 | 0.998 | 0 / 0 | 0.043 |

- 対称部の最大固有値は、n = 16 / 32 / 64 で +2.14 / +1.79 / +1.78、‖A‖₂ は 1.55 / 1.37 / 1.34 である。h² でまとめた量なので、格子を細かくしても消えない。
- 周期境界では、CCD の D1 は反対称（巡回行列）なので、D1·D1 = −D1ᵀD1 は対称で半負定値になる。エネルギーは増えない。格子規模のモード（記号 0）は減衰せず残る（零空間が 2）。
- 壁では、層 A と層 C で閉じ方が違う。そのため D1_ext·D1_dir は対称でなく、対称部に正の固有値がある。1 ステップでエネルギーが増えうる（‖A‖ > 1）。
- それでも 1 次元では、40 ステップ後には減っている（0.19〜0.36）。零固有値は単純で、ジョルダン塊はない。
- 同じ D1_dir から作る −D1_dirᵀ D1_dir（SBP 型の随伴の閉じ方）は、半負定値で増えない。

## 2. 2 次元（N = 16）
| 境界 | 形 | max Re λ | 対称部の最大固有値 | ‖L − Lᵀ‖/‖L‖ | 零空間 L / L² | ‖A‖₂ | ρ(A) | E/E0：k = 1、40、80 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 周期 | split | 2e-14 | 7e-15 | 8e-16 | 2 / 2 | 1.000 | 1.00000 | 0.123、1.3e-3、1.2e-3 |
| 周期 | layered | 7e-15 | 1e-14 | 3e-15 | 8 / 8 | 1.000 | 1.00000 | 0.180、1.9e-2、1.8e-2 |
| 壁 | split | −7.7e-2 | −5.5e-2 | 0.38 | 0 / 0 | 0.972 | 0.96820 | 0.115、1.6e-4、1.1e-5 |
| 壁 | layered | **+2.0e-3** | **+12.7** | **1.0** | **4 / 5** | **8.73** | **1.00084** | **1.21、2.1e4、1.3e5** |

- 壁の layered 形では、L と L² で零空間の次元が違う（4 と 5）。零固有値が欠陥的で、ジョルダン塊を持つ。そのため、A を掛けるたびにエネルギーが k のべきで増える（k = 40 → 80 で 6.2 倍）。
- 固有値の実部はほぼ 0 で、N = 16 で +2.0e-3、N = 32 で +1.8e-11。ρ(A) = 1.00084 で 80 ステップ回しても 1.14 倍にしかならないので、固有値の不安定では説明できない。増大の主因は、非正規性と欠陥的な零固有値である。
- 同じ成分の項だけ（交差項を除く）でも、‖A‖ = 7.06、80 ステップで 1.2e3 倍に増える（初期値は射影した雑音）。零空間は 4 / 4。交差項が加わって、ジョルダン塊ができる。
- 周期境界では、layered 形も対称で（‖L − Lᵀ‖/‖L‖ = 3e-15）、増えない。零空間 8 は減衰しない格子規模のモードで、エネルギーは 1.8e-2 で止まる。

## 3. 射影と DC
| 壁、N = 16 | ‖M‖₂ | ρ(M) | E/E0：k = 1、40、80 |
| --- | --- | --- | --- |
| split、M = A | 0.972 | 0.96820 | 0.115、1.6e-4、1.1e-5 |
| split、M = PA | 0.972 | 0.96820 | 0.092、2.2e-4、1.5e-5 |
| layered、M = A | 8.73 | 1.00084 | 1.21、2.1e4、1.3e5 |
| layered、M = PA | 6.33 | **1.04794** | 1.21、4.2e4、1.9e6 |

- 射影は増大の原因ではない。射影を入れる前の A だけで、すでに増える。
- ただし、射影を掛けると ρ が 1.00084 → 1.048 になり、増大は速まる（80 ステップで 1.3e5 → 1.9e6）。減衰しない中立のモードが、射影との組み合わせで固有値の不安定に変わる。
- DC：実際の時間発展（`viscous_decay`、N = 64）では、粘性の解法の警告は 0 件だった。許容 1e-10 に対して雑音の振幅は 3e-5 なので、各ステップの DC は A_H の解に収束している。増大は DC の不足ではなく、A_H の不動点そのものの性質である。

## 4. 実際の時間発展（`viscous_decay`）
| N | 形 | E/E0：1、10、20、40 ステップ |
| --- | --- | --- |
| 16 | layered | 0.62、3.7、67、2.5e3 |
| 32 | layered | 0.57、0.93、3.9、84 |
| 64 | layered | 0.53、0.23、1.5、**7.8**（33 の値） |
| 16 / 32 / 64 | split | 40 ステップで 1.5e-3 / 1.6e-3 / 1.2e-3 |

- 行列の解析（N = 16、2.1e4 倍。初期値と κ は異なる）と同じ傾向で、粗い格子ほど速く増える。
- 粗い格子ほど速いのは、壁の行（閉じ方の行）が全体に占める割合が 1/N で増えるためと考えられる（推測）。

## 結論
- ×7.8 の原因は、壁での閉じ方の不一致である。層 A は Dirichlet、層 C は外挿で閉じるので、D1∘D1 は対称でなくなる。
  - その結果、対称部に正の固有値ができ（2 次元 N = 16 で +12.7/h²）、‖(I − κL)⁻¹‖ = 8.7 になる。
  - さらに、D1 の格子規模の零モード（減衰しないモード）がジョルダン塊でつながり、エネルギーが k のべきで増える。
- 後退 Euler の固有値（ρ(A) − 1 = 8e-4）、DC、射影は原因でない。射影は増大を速める（ρ(PA) = 1.048）。
- 周期境界では同じ layered 形でも増えない。境界条件が決め手である。
- 既定の split 形は、壁でも対称部が負（−5.5e-2/h²）で、‖A‖ < 1。単調に減衰する。既定は変えない。
- layered 形を使うなら、層 C を層 A の随伴（−D1_dirᵀ）で閉じる SBP 型にすれば、半負定値になる（1 次元で確認）。ただし、格子規模のモードは減衰しない（周期の場合と同じ）。2 次元への実装と精度の確認はしていない。
