# 46. 帯の補正後に残る減衰しすぎの帰属：時間離散化・粘性の空間離散化・射影

45 で、帯の補正（44）の後に残る減衰しすぎ（N = 32、×1、厳密な曲率で +7.7%）は、エネルギー交換の非随伴性からは来ていないと分かった。
ここでは、それを時間離散化、粘性の空間離散化、圧力射影と時間分割、その交互作用に帰属させた。

- スクリプト：`cases/capwave_jacobian.py`（`ns_kw=` で CenteredNS の設定を渡し、固有ベクトルも返すようにした）、`cases/residual_attribution_figures.py`
- 図：`docs/figures/residual_attribution.png`
- 共通の条件：離散分散関係（1 ステップの Jacobian を cos/sin の部分空間に制限）、厳密な線形曲率、帯の補正の運動学、解法の許容 1e-14。

## 1. 比較したケース
| ケース | 粘性 | 圧力・時間分割 |
| --- | --- | --- |
| A | 現行（Basilisk の fd2、後退 Euler） | 現行（粘性 → 表面張力 → 射影の分割。粘性は前ステップの圧力勾配を使う） |
| B | 現行 | 現行。Δt を 1/64 まで細かくして外挿 |
| C | CCD（split 形、06） | 現行 |
| D | 現行 | 連成反復を収束させたもの（36：粘性・表面張力・射影を同時に満たす、上限 40 回、許容 1e-13） |
| E | CCD | 連成反復を収束させたもの |

- D の「厳密な鞍点解」は、ここでは連成反復の収束解で代用した。連成反復は、その離散系で、粘性・GFM の力・射影の不動点を求める。コロケート格子で、セル中心の速度が近似射影であることは D でも残る。これはこの実装の構造そのものなので、ここでは要因として分けていない。

## 2. 時間刻み（B）
| Δt/Δt₀ | 1 | ½ | ¼ | ⅛ | 1/16 | 1/32 | 1/64 | 外挿（→ 0） |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| A（fd2） | +7.72% | +6.36% | +5.19% | +4.35% | +3.83% | +3.54% | +3.39% | **+3.2%** |
| C（CCD） | +4.43% | +3.58% | +2.80% | +2.16% | +1.72% | +1.45% | +1.30% | **+1.1%** |

- A の差分は 1.36 / 1.17 / 0.84 / 0.52 / 0.29 / 0.15 で、隣り合う差の比は 0.86 / 0.72 / 0.62 / 0.56 / 0.53。局所的な次数は 0.2 から 0.9 へ上がり、Δt/16 以降で 1 次の漸近域に入る。外挿は、最後の 3 点を等比で延ばしたもの。Δt/4 までの 3 点からの外挿（45 の約 +4.0%）は、漸近域に入っていなかった。
- **同じモードを追っていること：** 固有ベクトルの Δt/16 との重なり |v·v₁₆|/(|v||v₁₆|) は、Δt：0.9950、½：0.9979、¼：0.99942、⅛：0.99992。
- 周波数の誤差は、A で −0.0〜−0.2%、C で −1.1% で、ほとんど Δt によらない。

## 3. 反実仮想の比較と交互作用
変化は減衰誤差のポイントで表す。Δ_μ = C − A、Δ_Π = D − A、交互作用 Δ_μΠ = E − C − D + A。

| 条件 | A | Δ_μ（fd2 → CCD） | Δ_Π（分割を消す） | Δ_μΠ |
| --- | --- | --- | --- | --- |
| N = 32、Δt | +7.72% | −3.29 | −0.10 | +0.00 |
| N = 32、Δt/4 | +5.19% | −2.39 | −0.01 | +0.00 |
| N = 64、Δt | +5.55% | −2.58 | −0.10 | +0.00 |

- **時間分割（粘性 → 射影の順序と、遅れた圧力）は効かない**（−0.1 ポイント以下）。連成反復で不動点まで解いても、減衰はほとんど変わらない。
- **粘性の空間離散化は効く**（−2.4〜−3.3 ポイント）。
- 交互作用はない。粘性を良くする効果と、射影・分割を変える効果は独立である。
- 31 と 41 の「粘性の次数は効かない」は、運動学の誤差（−16%）に隠れていたためで、運動学を直した後は粘性の次数が効く。

## 4. 帰属（N = 32、×1、A の Δt で +7.7%）
| 成分 | 大きさ |
| --- | --- |
| 時間離散化（fd2 で +7.7% → +3.2%） | +4.5 ポイント |
| 粘性の空間離散化（Δt → 0 で fd2 +3.2% → CCD +1.1%） | +2.1 ポイント |
| 残り（CCD、Δt → 0） | +1.1% |
| 時間分割・射影の分割 | 0.1 ポイント以下 |

- 時間離散化の 4.5 ポイントは、分割の順序ではなく、時間積分そのもの（後退 Euler の粘性と、陽的な表面張力の組み合わせの 1 次の誤差）による。分割を消した D でも同じだけ残る。
- 残る +1.1% は、帰属させていない。近似射影、面の補間、CLS の残り、のいずれか。

## 結論と次の段
- 帯の補正の後に残る減衰しすぎは、時間離散化（約 60%）と、fd2 の粘性の空間離散化（約 30%）でほぼ説明できる。時間分割と射影の分割は効かない。
- 既定の粘性（Basilisk の fd2）から CCD にすると、半離散で +3.2% → +1.1%、既定の刻みで +7.7% → +4.4%。
- 時間の 1 次誤差を下げるには、時間積分の次数を上げる（粘性と表面張力の陰的な 2 次の連成など、Case C）。分割の順序を変えるだけでは効かない。
- 密度比 1 での残差なので、P0-4（密度で重み付けした圧力射影）とは独立の課題である。
- 既定値は変えていない。
