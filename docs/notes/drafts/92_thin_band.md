## 定式化と理論的根拠
### A. 跳びの原因
各セルの区分多項式の適合は、最も近い界面の足 x_Γ を中心とする窓（半径 5.5 セル）を使い、その界面の折れだけを基底に持つ。

帯の真ん中（両方の界面から等距離）では、界面の位置が少し動くだけで最も近い界面が入れ替わる。そのとき、窓の中心とヒンジが不連続に変わる。

- 帯の中の関数（片側の折れだけを持つ関数の類）は、どちらの適合でも厳密に再現される。窓が他方の界面に届かない限り、厳密な再現の試験では跳びは見えない（45°、N = 24 で、どちらも 5e-13）。
- しかし、一般のデータに対する写像（演算子）は二つの適合で異なり、入れ替わりで跳ぶ。

### B. 両側の適合の混合（"pair"）
2 つの界面への距離を |s₁| ≤ |s₂| とし、`t = (|s₂| − |s₁|)/h` とする。最も近い界面の適合 R₁ と、もう一方の界面の適合 R₂ を

```
R = (1 − w) R₁ + w R₂,   w = ½ (1 − smooth(t/δ))      （δ = 1 セル）
```

で混ぜる。

- **連続性**：t = 0（等距離）で w = ½。入れ替わりで R₁ と R₂ が入れ替わっても、R は変わらない。t ≥ δ では w = 0 で、元の適合に戻る。
- **構造**：各適合は、セルの質量平均と定数を保つ（shift）。重みの和は 1 なので、混合も保つ。
- **厳密さ**：混ぜる前の各適合が、その関数の類で厳密なら、混合も厳密である。
- 単一の多項式との混合（λ）は、各界面の距離でそれぞれ行う。

### C. 両方の折れを持つ適合（"two"、比較のため）
`P₀ + max(d₁, 0)P₁ + max(d₂, 0)P₂`（35 係数）を、セルの中心を中心とする窓（半径 6.5）で適合する。2 つ目の界面の距離で、通常の適合と混ぜる（5.5〜6.5 セル）。

窓の中心がセルに固定されるので、入れ替わりで窓は跳ばない。ただし、折れの成分の階数が不足する（N = 24 の 45° の帯で、20 列のうち 12〜19）。階数の変化で、別の跳びが起こりうる（ノート88 の窓の議論と同じ）。
