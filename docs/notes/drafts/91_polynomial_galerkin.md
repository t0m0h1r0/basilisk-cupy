二次元では、質量で尺度を合わせた条件数が小さい（ノート87〜89 で 3.6 以下）ので、少ない次数で足りる見込み。ここでは、近似しても構造（エネルギー、自由流、総運動量）を厳密に保つ条件を導き、円の並進（ノート89）で測った。

## 定式化と理論的根拠
### A. 近似の形とエネルギー
`A = M^{−1/2} G₁ M^{−1/2}`（対称正定値）、`v = M^{−1/2} C u` とする。多項式 p による近似は次の形：

```
T_p = M^{−1/2} p(A) M^{−1/2} C
```

厳密な写像は `p(λ) = 1/λ`。

- **近似の写像のエネルギー**：`‖T_p u‖²_{G₁} = vᵀ p(A) A p(A) v`。
- **厳密な写像のエネルギー**：`vᵀ A⁻¹ v = uᵀ CᵀG₁⁻¹C u ≤ ‖u‖²_{G₀}`（ノート87 D 節の Schur 補行列）。

よって、A のスペクトルの上で `λ p(λ)² ≤ 1/λ`、すなわち

```
|λ p(λ)| ≤ 1   ⇔   0 ≤ r(λ) ≤ 2,   r(λ) = 1 − λ p(λ)（残差の多項式、r(0) = 1）
```

が成り立てば、`‖T_p u‖_{G₁} ≤ ‖u‖_{G₀}`（エネルギーは増えない）。

- 普通の Chebyshev の残差の多項式は、区間の上で −δ まで下がる（r < 0）。そのため、エネルギーが (1 + δ)² 倍まで増えうる。
- **r = q²**（q は r と同じ形の残差の多項式）にすれば、`r ≥ 0` が自動的に成り立つ。`|q| ≤ √2` をスペクトルの上で保てばよい。
- 実装は、0 から始めた Richardson の掃引（`x ← x + (1/λ_i) M⁻¹(Cu − G₁x)`、残差の多項式 `Π(1 − λ/λ_i) = q`）を、同じ節点で 2 回繰り返すこと。2 回目の初期値の誤差は `−q(A)A⁻¹b` なので、最後の誤差は `q²(A)A⁻¹b`。

### B. 自由流と総運動量
`G₁1 = m`（1 の分割と、同じ積分点）なので、`A (M^{1/2}1) = M^{−1/2}G₁1 = M^{1/2}1`。つまり、`M^{1/2}1` は A の固有値 1 の固有ベクトルである。

- **自由流**：`T_p 1 = M^{−1/2}p(A)M^{−1/2}C1 = M^{−1/2}p(A)A M^{1/2}1 = M^{−1/2}(1 − r(A))M^{1/2}1`。`r(1) = 0` なら `T_p1 = 1`。
- **総運動量**：A は対称なので、`(M^{1/2}1)ᵀ r(A) = r(1)(M^{1/2}1)ᵀ = 0`。そのため `1ᵀG₁T_p u = 1ᵀCu`。

**q に λ = 1 の根を置けば**（`q(λ) = (1 − λ)Π_j(1 − λ/λ_j)`）、多項式近似でも自由流と総運動量は厳密になる。

### C. スペクトルの区間 [1, b]
- **下端は 1**：shift は各セルの再構築の質量平均をセルの値に保つ（`∫_{K_i}ρP = m_i v_i`）。Cauchy–Schwarz の不等式で、各セルで `∫_{K_i}ρP² ≥ m_i v_i²`。和をとって `vᵀG₁v ≥ vᵀMv`、すなわち `G₁ ⪰ M`、`λ_min(A) ≥ 1`。定数で等号（B 節の固有ベクトル）。
  - 厳密には、G₁ は共通の分割の積分点で組み立てるので、セルの自分の積分点での平均の条件とは積分の誤差 ε だけずれる。正の重みの Cauchy–Schwarz（`Σ_q w_qρP² ≥ (Σ w_qρP)²/Σ w_qρ`）から、`λ_min ≥ 1 − O(ε)`。
  - 測定：N = 24 で `λ_min = 1 + 8e-15`、N = 48 で `1 + 3e-12`。
  - 下端はエネルギーの保証には効かない（[0, 1] では q ∈ [0, 1]）。精度（Chebyshev の区間）にだけ効く。
- **上端 b**：Gershgorin の上界 `max_i Σ_j |A_ij|`（厳密）。`|q| ≤ √2` をスペクトル全体で保証するには、上端の上界が厳密である必要がある。
- **節点**：残りの k − 1 個の根は、[1, b] の Chebyshev の根。q の次数は k で、2 回の掃引で G₁ との積が 2k 回。
- **誤差の見積もり**：Chebyshev の残差は `δ_k ≈ 2((√κ − 1)/(√κ + 1))^{k−1}`（κ = b）。r = q² の誤差はおよそ δ_k²。
