## 定式化と理論的根拠
### A. 流れと写像
```
u = (A sin(2πy) cos(πt/T), 0),   Φ_t(X, Y) = (X + S(t) sin 2πY, Y),   S(t) = (AT/π) sin(πt/T)
```

- **面積の保存**：Φ_t は面積を保つ（ヤコビアンは 1）。
- **流れの反転**：t = T/2 で変形が最大（S = AT/π）になり、t = T で元に戻る。
- **界面**：時刻 t の界面は、円 |X − c| = R₀ の像。
- **古い点**：時刻 t₀ から t₁ への 1 ステップでは、新しい点 x の古い点は `(x − ΔS sin 2πy, y)`（`ΔS = S(t₁) − S(t₀)`）。
- **時間の誤差はない**：写像が厳密なので、誤差は各ステップの射影（再構築と Galerkin の射影）だけから出る。

設定は A = 1、T = 0.5、R₀ = 1/4、中心 (0.5, 0.5)、密度比 1000、CFL 0.37。t = 0.125（T/4）と 0.25（T/2、S = 0.159）で測る（途中の時刻でも判断する、という以前の方針どおり）。

運ぶ関数は、ノート89 の q を写像で運んだもの：`q(x, t) = q₀(Φ_t^{−1}(x))`。

### B. 共通の分割
新しいセル K_i と、動いた古いセル Φ(K_j) の共通部分を、新しい時刻の界面で相ごとに切る。

- せん断は y を変えないので、古いセルは同じ行の 3 個だけである（CFL < 1 で `|ΔS| < h`）。
- その縦の面は曲線 `x = jh + ΔS sin 2πy` になる。

積分は、y を外、x を内にする。y を固定すると、分割の境界はすべて閉じた形の x の位置で与えられる：

- セルの面 x₀、x₁
- 動いた古い面 `jh + ΔS sin 2πy`
- 界面の 2 点 `c_x + S sin 2πy ∓ √(R₀² − (y − c_y)²)`

y の範囲は、次の点で分ける：

- 二つの境界が交わる点。根を探す前に、差の関数の極値（差分商の零点）で区間を分け、極値の両側の近い 2 根を取りこぼさないようにする。
- 界面の接点 `c_y ± R₀`。

各小区間で、y は近い方の接点 y_t から `y = y_t ± u²` と置いて u で Gauss 12 点、x は各区間で Gauss 6 点。

`√(R₀² − (y − c_y)²) = u√(2R₀ − u²)` は u で滑らかなので、接点のすぐ手前で終わる小区間（近くの根で区切られた場合）でも正確に積分できる（ノート89 D 節の円の積分の弱点を除いた）。

測定：
- 面積（全体と重い相）の誤差は、S = 0〜0.24、中心を格子からずらした場合も含め、N = 24〜48 で 1e-16〜2e-14。
- 置き換えの前（cos の写像）は最大 6e-7。接点で `R₀² − (y − c_y)²` が −1e-17 に丸められて NaN になり、根を取りこぼした例もあった。許容幅を入れて直した。

エネルギーの非増加は、同じ積分点と正の重みから代数的に出る（ノート87 D 節）。分割が曲がっていても変わらない。

### C. ヒンジ
時刻 t の界面は、円の像である。厳密な距離は閉じた形では得られないが、定義関数

```
φ(x) = |Φ_t^{−1}(x) − c| − R₀
```

は界面の近くで滑らかで、`∇φ ≠ 0` である。

ノート89 B 節の Hadamard の補題は、距離でなくても、`∇φ ≠ 0` の滑らかな定義関数なら同じく成り立つ：`q_out − q_in = φ g`。

- **A（定義関数）**：`max(φ/(h|∇φ(x_Γ)|), 0)`。
  - 足での勾配の大きさで割るのは、足の近くで距離と同じ尺度にするため。定数倍は P₁ に吸収されるので、近似の空間は変わらない。
- **C（二次）**：足での曲線の曲率 κ を使い、`ξ + (κh/2)η²`。
  - κ は、媒介変数の曲線 `P(θ) = (c_x + R₀ cos θ + S sin 2πy(θ), c_y + R₀ sin θ)` の `(x'y'' − y'x'')/|P'|³` から求める。
- **B（接線）**：足での接線。

足は、曲線を 720 点で調べたあと、黄金分割で精密にした最も近い点である。

### D. 体積率だけからのヒンジ（P1-2 の D の実用版、円の並進で測る）
実際の手法では、厳密な界面はなく、体積率 F しかない。C（接触放物線）の放物線を、体積率の高さ関数から作る。

- **向き**：界面のセル（I, J）の 3×3 の F の中心差分で決める。|∂_y F| ≥ |∂_x F| なら縦の高さ、そうでなければ横の高さ。
- **高さ**：縦の高さは、3 列の 7 セルの和 `H_k = Σ_{j=−3}^{3} F(I+k, J+j)`、k = −1, 0, 1。重い相が下なら、列の界面の高さの平均は `y_k = (J − 3)h + H_k h`。上なら `(J + 4)h − H_k h`。
- **放物線**：`Y(x) = a + h(bξ + cξ²)`（`ξ = (x − x_I)/h`）を、3 列の平均に合わせる。
  - 列の平均は `∫_{k−1/2}^{k+1/2} ξ² dξ = k² + 1/12` なので：
    ```
    c = (y₁ − 2y₀ + y₋₁)/(2h),   b = (y₁ − y₋₁)/(2h),   a = y₀ − c h/12
    ```
  - 放物線の界面なら厳密である。
- **ヒンジ**：定義関数 `± (y − Y(x))/(h√(1 + Y'²))`（軽い相の側を正）。足は、セルの中心から放物線への最も近い点（ξ の Newton）。
- **誤差の見積もり（証明はしていない）**：滑らかな界面 Y(x) の 3 次の項 dξ³ は、列の平均では `d(k³ + k/4)` になり、b に入る。放物線の誤差は `d(ξ³ − 5ξ/4)` で、ξ = 0（ステンシルの中心）では 0 になる。
  - そのため、中心の近くの位置の誤差は物理的に O(h⁴)（セル単位で O(h³)）と見込む。
  - 窓の中（|ξ| が 5 程度）では、接触放物線と同じく O(h³)（セル単位で O(h²)）。
- **他は厳密なまま**：界面のセルの選び方（足を含むセル）、切り替えの距離、相の分割（密度）は、厳密な幾何のままにした。ヒンジの違いだけを分けるためである。体積率と PLIC で相の分割も作るのは P2。
