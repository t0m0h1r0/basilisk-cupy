# 22 静止液滴の可視化：Basilisk との比較（PR #37）

## 条件
- R = 0.25、σ = 1、μ = 0.1、ρ = 1（液滴）/ 0.1（外）、64 × 64、四方が壁、t = 0.2。
- Basilisk は `tools/basilisk/static_drop.c` をローカルでビルドして実行し、場を書き出す。
- 本実装は `cases/static_drop_compare.py`：
  - VOF 版は Basilisk の CPU 版と同じ逐次緩和で計算する。
  - CLS は CSF と GFM（時間刻み係数は既定の √(5/12)）。
- 図：`docs/figures/static_drop_compare.png`（密度・速度・圧力）、`static_drop_compare_lines.png`（寄生流の時間変化、中心を通る圧力）。

## 測定（t = 0.2）
| | ステップ数 | 寄生流の最大値 | 圧力ジャンプ |
| --- | --- | --- | --- |
| Basilisk（C） | 255 | 5.31e-7 | 4.0116 |
| 本実装 VOF | 255 | 5.31e-7 | 4.0116 |
| CLS＋CSF | 390 | 4.27e-4 | 4.0212 |
| CLS＋GFM | 390 | 7.47e-7 | 4.0030 |

- **VOF 版と Basilisk の差：** 速度で最大 2.5e-10、圧力で 5.1e-9。図では見分けがつかない。
  - 寄生流の時間変化の曲線もほぼ重なる。
  - 寄生流の模様は、上下左右と斜めの8方向に放射状。
- **CLS＋CSF：** 寄生流は 3〜4e-4 で横ばいのまま減衰しない。圧力は界面の幅（約7セル）にわたってなだらかに変化する。
- **CLS＋GFM：** 圧力は界面で階段状に跳ぶ。寄生流は Basilisk と同程度で減衰するが、界面の階段状の折れ目に集中する（21 の不安定モードと同じ場所の形）。
