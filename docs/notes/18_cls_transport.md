# 18 ψ 移流の精度：面差分の補正（PR #33）

## 定式化と理論的根拠
### D_f の誤差 h²/24 ∂³(ψu)
面の点の流束 F の単純な差は、セル中心で次のとおり：

```
(F_{i+1/2} − F_{i−1/2})/h = ∂_x F + (h²/24) ∂_x³F + O(h⁴)
```

点の値の ψ を運ぶなら、`h²/24 ∂³F` が 2 次の誤差として残る。

### ψ = ½ の遅れ −h²/(48ε²) の導出
一様な速度 u では、誤差の項は `−(h²/24) u ψ‴`。界面（ψ = ½）の移動の速さの誤差は `(h²/24) u ψ‴/ψ′`。tanh の分布 `ψ = ½(1 + tanh(x/2ε))` では、x = 0 で次のとおり：

```
ψ′ = 1/(4ε),   ψ‴ = −1/(8ε³),   ψ‴/ψ′ = −1/(2ε²)
```

相対的な遅れは `(h²/24)(1/(2ε²)) = h²/(48ε²)`。ε = 1.5h で `1/(48 × 2.25) = 0.926%`（本文の 0.93%）。ε ∝ h なので、N によらない。

### 補正から ψ u_xxx を外す理由
`∂³(ψu)` の展開のうち `ψ u_xxx` の項を入れると、射影後の u_f は単純な差で発散 0 なので、ψ ≡ 1 の領域で `−(h²/24)u_xxx` の湧き出しが生じる。外した項の誤差 `h²/24 ∂(ψ u_xx)` は u の滑らかさだけで決まり、ε に比例して大きくならない（1/ε² の増幅がない）。

### 6 次の面値が補正と組み合わせたときだけ効く理由
誤差は、面値の誤差（4 次 → 6 次）と D_f の誤差（2 次）の和。D_f の 2 次の誤差が支配している間は、面値を良くしても見えない。補正で D_f を 4 次にすると、面値の 4 次の誤差が見えるようになり、6 次の面値の効果が出る。

## 見つけたこと
- 論文（06b）の CLS 移流は、FCCD の面値 P_f ψ（4次）に面速度を掛け、その単純な差 D_f をとる。
- D_f は面の点値に対して2次で、h²/24·∂³(ψu) の誤差が残る（ccd.py の div_f で補正している項）。
- ε = 1.5h では ψ の幅が常に3セルなので、この誤差は N によらず ψ′ の一定割合になる。ψ = ½ では −h²ψ‴/(24ψ′) = −h²/(48ε²) = −0.93%。
- その結果、界面は移動距離の約 0.9% ずつ遅れ、N を上げても減らない。重心は保存形なので正しく動く（ψ = ½ だけが遅れる）。
- 17 で見た移流後の界面のばらつき・歪みの主因はこれだった。

| 確かめたこと（帯 \|x\| < 0.2 を1周、N = 64） | ψ = ½ の遅れ |
| --- | --- |
| 論文どおり（N = 32 / 64 / 128） | 7.0e-3 / 5.9e-3 / 4.7e-3 |
| 6次の面値（`FCCDFaceComplex(order=6)`）のみ | 5.9e-3（変わらない） |

## 補正（`CLSInterface(..., divergence="fccd")`）
- 面のフラックスを ψ_f u_f − (h²/24)(ψ_xx u + 2ψ_x u_x) にする。
  - 微分は ψ_f と u_f の面の列に沿った CCD（div_f の face_flux と同じ演算子）。速度が一様なら face_flux と一致する。
- ∂³(ψu) のうち ψ u_xxx の項は入れない。
  - 射影後の u_f は単純な D_f で発散ゼロなので、この項を入れると ψ ≡ 1 の領域に O(h²) の湧き出しが生じる。
  - 外した項の誤差 h²/24·∂(ψu_xx) は速度の滑らかさだけで決まり、ε に比例して大きくならない。
- 壁の面では補正をゼロにする。
- 保存形のままなので、質量は丸め誤差まで保たれる。
- 既定は論文どおりの `"plain"`。
