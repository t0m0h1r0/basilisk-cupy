## 定式化と理論的根拠
### A. 層の二相と可換な再構築
密度は y だけに依存する（重い相 ρ = 1 が [a, b)、軽い相 1/r がその外、周期）。法線方向（y）の面の値 f_j（面 j はセル j の下）に対し：

```
d_i = (f_{i+1} − f_i)/h,   R_F f = f_i + ∫ R_C d
```

R_C が体積平均を保てば `∂_y R_F = R_C D` で、面の値も再現する（ノート107 の 3.6 節）。接線の速度 u は、y 方向には同じ R_C で再構築される（可換性のため）。

| 候補 | R_C（セルの値の再構築） | 役割 |
| --- | --- | --- |
| A | 区分定数（法線速度は区分線形） | 低次の MAC の再構築 |
| B | 単相の PCCD（界面の扱いなし、ノート105） | 悪条件の再現 |
| D0 | 切断セルで、重い相の部分は隣の純粋な重いセルの値（なければ 0）。軽い相の部分は、セルの体積平均を満たす定数 | 密度適合型・低次 |
| D0m | D0 と同じ形で、体積平均を満たす側を「移動度（長さ / 密度）の大きい相」にする。他方の相は隣の純粋なセルの値 | 密度適合型・低次（D0 の薄い軽い相の修正） |
| D1 | 切断セルで `d_i (1/ρ)/⟨1/ρ⟩`（変化を軽い相に置く） | 密度適合型・低次 |
| M | 再構築なし。基準の内積そのもの（下の M_t、M_n）を質量とする集中型の MAC | 基準の内積の物理的な確認（3 節だけ） |

- A・D0・D0m・D1 は、体積平均の再現と面の値の再現が 2e-16（構成上）。
- **定数の再現**：A・B・D0・D0m は R_F・R_C とも丸めの水準。**D1 の R_C は定数を再現しない**（誤差は最大 1e6）。切断セルで、定数のデータを `(1/ρ)/⟨1/ρ⟩` に写すからである。そのため、D1 は接線成分の自由流を保てず、T1-D の条件 3 を満たさない。

- **D0 の薄い軽い相の問題と D0m**（この段階の途中で見つけた）：D0 は、軽い相が体積平均の拘束を埋める。軽い相の厚さが `(1 − c) ≪ 1/r` のとき、隣の重いセルのデータに対する軽い相の振幅は `c/(1 − c)` で、エネルギー `ρ_L c²/(1 − c)` が限りなく大きくなる。D0m は、移動度の大きい相 X が拘束を埋める。このとき、X のエネルギーは `ρ_X ℓ_Y²/ℓ_X ≤ 2M_t`、隣の Y のセルのデータへの寄与は `≤ ρ_Y ℓ_Y` で、どちらも有界である（導出。`ℓ_Y/ρ_Y ≤ ℓ_X/ρ_X` を使う）。
  - D0m の切り替え（移動度が等しい所）は不連続である。界面の移動での連続性には、混合が要る（未実装）。

### B. 基準の内積（結果を見る前に固定、ユーザーの規則）
| 方向 | 基準 |
| --- | --- |
| 法線 | `M_n = diag(∫_{双対セル} ρ)`（直列の移動度 `h/∫ρ`） |
| 接線 | `M_t = diag(h/⟨1/ρ⟩)`（並列の移動度） |
| Schur | `L_ref = B M_n⁻¹ Bᵀ`（θx = 0） |

追加の比較（判定には使わない）：`M_pt = diag(ρ(面の点) h)`。

**基準によらない量**（この段階で加えた）：対角でスケールした行列 `D^{−1/2} G D^{−1/2}`、`D^{−1/2} L D^{−1/2}`（D は自分の対角）の条件数。基準の内積の選び方に依存しない。

### C. ユーザーの不可能性定理（2026-11-27）のレビュー
- **主張**：R_C を共有する成分分離型のテンソル積の再構築で、接線の上界 `G_C ⪯ C diag(H_i)`（H は調和平均の密度）が密度比によらず成り立てば、`1/2 < c < 1` の切断セルの上の軽い面 j について `λ_min(G_F, M_n) ≤ [2(1 − c) + 2C(H_i + 1)] / [r(c − 1/2) + (3/2 − c)] = O(1/r)`。
- **開発側の確認（導出）**：
  1. 単位の面のデータ e_j について `v' = R_C D e_j` で、D e_j は 2 つのセルだけ ±1。よって `∫ρ|v'|² ≤ C(H_i + 1)`。
  2. 重い相の部分は、同じ相の面（v = 0）から積分する。重みつきの Cauchy–Schwarz `|v(y)|² ≤ (∫ρ|v'|²)(∫ dy/ρ)` で、ρ = r の区間では `ρ|v|² ≤ (距離)·∫ρ|v'|²`。密度比が打ち消し、重い相のエネルギーは O(C) になる。
  3. 軽い相の部分は、軽い面（v = 1）から積分して `2(1 − c) + O(C)`。
  4. 分母の M_n は、双対セルの重い相の質量 `r(c − 1/2)` を含む。
- 証明に誤りは見つからなかった。数値とも合う（1 節：D0・D1 の最小固有値の傾きが −1.00）。
- **この証明が言っていること（補足）**：ρ の重みつきの勾配のエネルギーが有界な連続の再構築では、重い相は「重い面」に固定される。一方、M_n は双対セル [y_j − h/2, y_j + h/2] の重い部分の質量を、軽い面 j に割り当てる。M_n に一致するのは、双対セルの上で区分定数（セルの中心で不連続）の速度である。定理は、この 2 つの割り当てが `c > 1/2` で両立しないことを示している。

## 2. どちらの割り当てが物理的に正しいか：厳密解のある射影の試験
基準の内積との同値と、対角でスケールした条件数は、結論が食い違う。そこで、基準の選び方によらない物理的な試験を加えた。

- **問題**：`w = (0, cos 2πy) e^{ikx}`（k = 2πm）の、密度加重の Helmholtz 射影 `u = w − ∇p/ρ`、`∇·u = 0`。層ごとに `p = ρA sin 2πy + αe^{ky} + βe^{−ky}` で、界面で p と p'/ρ が連続（4 × 4 の連立）。厳密解である（差分で確かめた：方程式の残差 2e-7（差分の打ち切り）、界面の跳び 6e-12）。
- 射影後の接線速度 `u = −ikp/ρ` は界面で跳ぶ（圧力の勾配は軽い相を r 倍加速する）。`∂_y v = −∂_x u` も 1/ρ に比例して跳ぶ。
- **離散**：厳密な面の平均を入力し、`Π = I − G⁻¹Bᴴ(BG⁻¹Bᴴ)⁻¹B` を掛け、厳密な射影後の面の平均と比べる。x は Fourier の記号。

## まとめ
- **再現**：ユーザーの漏れの表（全桁）、A・B・D の Gram と Schur の値、D の傾き ±1.00。不可能性定理の証明に誤りは見つからなかった。
- **#132 の判定（指定の基準 M_n・M_t に対して）**：T1-A・B・C・D の全てが不成立。合格の条件を満たす候補はない。
- **新しい観察（判定を変えるものではない。ユーザーの判断の材料）**：
  1. D0m の不成立は、基準 M_n との対角の食い違いによる。基準によらない条件数は、Gram が法線 3.0・接線 3.7、Schur も L_ref と同程度で、密度比・薄片によらない。B の悪条件は本質的である。
  2. 厳密解のある射影では、D0m は密度比によらず収束する（RMS で約 2 次）。基準の内積の組 (M_t, M_n) そのもので作った MAC は、定理の範囲（c > 1/2）で O(1) の誤差になる。
  3. したがって、「(M_t, M_n) の両方への一様な同値」は、正確な射影のための条件としては強すぎる可能性がある。c > 1/2 では、この 2 つの基準は互いに整合していない。

## 未検証・次（ユーザーの判断が必要）
