# 73 検証の拡充（1）：寄生流の標準の試験 `spurious.c`（PR #82）

Basilisk の検証ケースを、適合格子を外して一様な格子で C 版と走らせ、本移植と突き合わせる（`tools/basilisk/*_uniform.c`）。1 つ目は Popinet (2009) の寄生流の試験。

## 定式化と理論的根拠
### 静止液滴の釣り合いと寄生流
連続系の静止液滴は、Laplace の圧力の跳び `[p] = σκ`（κ = 1/R、二次元）で釣り合い、u = 0 が厳密解。

離散系（tension.h）では、表面張力は面の加速度として `a_F = α_F σ κ_F (∇f)_F` を入れる。κ_F は面の両側のセルの曲率の平均、(∇f)_F は圧力の勾配と同じ面の差分。いわゆる釣り合いのとれた力（balanced-force）の形。

- κ が界面のセルで一定（κ₀）なら、`p = σκ₀ f + 定数` で `(∇p)_F = σκ₀(∇f)_F` が面ごとに厳密に成り立ち、u = 0 が離散系でも定常解になる。
- 高さ関数の曲率は、円の VOF の場では一定にならない（曲率の誤差、表の 4 列目）。その不釣り合いが寄生流を起こす。

### 寄生流が丸め誤差まで減る理由
流れは f を動かし、界面の形が変わる。Popinet (2009) の議論によれば、系は「離散的な曲率が一定になる形」に緩和する。そこでは上の釣り合いが厳密に成り立ち、流れは粘性で指数的に減衰して丸め誤差（1e-14）まで落ちる。

表の「形の誤差」は、初期の円からこの離散的な平衡の形までのずれ。速度の尺度は capillary の速度 `√(σ/(ρD))`、緩和は粘性の時間 `D²/μ` で起きる。両者の比は Laplace 数 La で決まるので、La が小さい（粘性が強い）ほど、時刻の上限で減衰しきっていない値が残りやすい。La = 120 の 5.0e-8 対 1.1e-8 の差は、この減衰の途中の違いとみられる（緩和の方式の違い、未確認）。

### 一様な格子どうしで比べる理由
形の誤差は界面の近くの格子の解像度で決まる。適合格子の基準値（`spurious.ref`）は、界面の近くを細かくした格子での値なので、一様な格子とは格子そのものが違う。比べるべきは同じ一様な格子の C 版。

## 設定（`src/test/spurious.c`）
直径 0.8 の液滴の四分の一を [0, 1]² に置き（原点が中心、対称境界）、密度 1、表面張力 1、粘性は Laplace 数 `La = σρD/μ²` から。移流なし（`stokes = true`）で、粘性の時間 `D²/μ` まで、または f の変化が 1 ステップに `DC` 未満になるまで回す。書き出すのは、寄生流の最大 `max|u| √D`、初期の形からの f のずれ（平均・RMS・最大）、曲率の最大誤差。

C 版は `tools/basilisk/spurious_uniform.c`（`adapt` のイベントを外しただけ、Jacobi の緩和）、本移植は `cases/spurious_compare.py`（`CenteredNS` + VOF + tension.h、両相の密度と粘性を等しく）。
