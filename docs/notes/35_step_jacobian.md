# 35 1ステップの Jacobian の固有値解析と密度比100で連成反復が効かない原因

## ねらい
34（#48）で、表面張力・粘性・射影の連成反復 K = 1 を入れた。等密度では、粘性が安定化に働くようになった。一方、密度比 100 では改善しなかった。

このノートでは、1ステップ全体の Jacobian の固有値を計算する。それを実測した安定の境目と突き合わせ、密度比 100 で K = 1 が効かない原因を特定する。

条件は全体を通して次のとおり。

- 静止液滴：R = 0.25、σ = 1、μ₁ = μ₂ = 0.1、ρ₁ = 1。
- 壁で囲んだ [−½, ½]²、CLS、GFM ジャンプ。
- 刻みは tension.h の上限 √(ρ_m h³/(πσ)) の f 倍。

## 方法（`cases/step_jacobian.py`）
**状態**

- 1ステップで次へ持ち越す量をすべて並べる：q = (ψ, u_x, u_y, uf_x, uf_y, p, g_x, g_y)。
- `StepMap.F(q)` は、刻みを固定して q から1ステップ進める。

**基準状態**

- 基準状態 q₀ は、安定な刻み（0.5 倍）で 300 ステップ進めた液滴。
- 基準状態からのずれ |F(q₀) − q₀| は約 1e-5。

**Jacobian と固有値**

- Jacobian は行列を作らず、中心差分 (F(q₀ + εv) − F(q₀ − εv))/2ε で作用させる。
- 固有値は Arnoldi 法で求める。開始ベクトルにべき乗法を 20 回かけ、40〜60 次元の部分空間を使う。

**中立な方向の除去**

固有値 1 の中立な方向を、射影で毎回取り除く。

- p の定数（ゲージ自由度）
- ψ の総量（保存量）

**摂動幅**

- 最初は ‖εv‖ = 1e-7（ベクトル全体のノルム）とした。成分あたりでは 1e-9 程度で、線形ソルバーの残差より小さかった。
- そのため、安定な刻みでも |λ| = 1.4〜1.8 と誤った値が出た。
- 成分あたり約 1e-5 に上げ、ソルバーの許容誤差を 1e-14 にした。
- 1e-7〜1e-3 の範囲では、|Jv|/|v| は 1297.4〜1299.0 で変わらない。

**検証（N = 16、密な Jacobian）**

| ケース | 密な Jacobian | Arnoldi |
| --- | --- | --- |
| 比 1、K = 0、1.6 倍 | −1.7786, −1.7753, −1.7749, −1.7733 | 4 つとも一致 |
| 比 1、K = 0、1.0 倍 | 1.0000 が並ぶ（中立に近いモード） | 1.0001 |

## 実測した境目との一致（N = 32）
実測は、初期液滴から 800 ステップ進め、後半の max|u| の成長率で判定した。ソルバーの許容誤差は 1e-14。

| | 実測：安定 / 不安定 | Jacobian の \|λ₁\|（arg/π） |
| --- | --- | --- |
| 比 100、K = 0 | 1.019 / 1.075 | 1.0000 / 1.0787（1） |
| 比 100、K = 1 | 1.244 / 1.3 | 0.9987 / 1.0072（−0.21） |
| 比 100、K = 2 | 2.0 / 2.144 | 0.998 / 1.070（1） |
| 比 1、K = 0 | 1.188 / 1.244 | 0.9997 / 1.039（1） |
| 比 1、K = 1 | 2.2 / 2.256 | 0.999 / 1.022（1） |
| 比 1、K = 2 | 2.031 / 2.1 | 0.9991 / —（2.4 で 1.64） |
| 比 100、収束（K ≤ 16、反復の変化 < 1e-10） | 1.8 / 1.9 | K = 8：0.9999 / 1.168（1） |
| 比 1、収束 | 2.05 / 2.1 | K = 8：0.9994 / 1.069（1） |

8 ケースすべてで、|λ₁| = 1 を横切る位置が実測の区間に入る。

最初の実測はソルバーの許容誤差 1e-8 で行い、そのうち 3 ケースで境目が 3〜7% ずれた。ずれの原因は、|u| ≈ 1e-7 の残差雑音で成長率が見えなかったことである。

- 比 100、K = 2：2.144 倍で、tol 1e-8 では安定に見え、1e-14 では不安定。
- 比 1、K = 2：2.031 倍で、tol 1e-8 では成長率 +0.0067/step と出て、1e-14 では安定。

境目を測るときは、許容誤差を十分小さくする必要がある。

## 二種類の不安定モード
図：`docs/figures/step_jacobian.png`、`docs/figures/step_jacobian_modes.png`。

| モード | 出るケース | 固有値 | 場所 |
| --- | --- | --- | --- |
| 陽的な毛管モード | K = 0 全般、K ≥ 2 | 負の実数（arg = π）、1ステップごとに符号が反転 | 界面が格子と平行な部分（上下左右）に局在 |
| 振動モード | 密度比 100 の K = 1 | 複素（arg ≈ ±0.21π、約 9.5 ステップ周期） | 界面が格子に斜め（45°）の部分に局在、圧力が界面のセルで鋸歯状 |

振動モードは、多くの固有値が |λ| = 1.18〜1.19 に集まった帯として現れる。

K を変えたときの先頭の Ritz 値（比 100、1.6 倍）：

| K | 1 | 2 | 3 | 4 | 8 |
| --- | --- | --- | --- | --- | --- |
| \|λ₁\|（arg/π） | 1.189（±0.22） | 0.9989（0.001） | 0.9987（0） | 0.9995（0） | 0.9996（0） |
| 振動モードの帯 | 1.18〜1.19 | なし | なし | なし | なし |

- 比 1 の K = 1 は 0.9996（0）で、振動モードは出ない。
- 比 10 の K = 1 では、同じ帯が 0.949（±0.25π）に減衰した形で現れる。
- 比 1000 の K = 1 では 1.222（±0.215π）。

## 原因：遅れた圧力が粘性を通って射影で消えない
K = 1 の反復は次のように進む。

1. 新しい加速度 a（GFM ジャンプ）と前のステップの圧力 p から g = face_to_cell(a − α∇p) を作る。
2. u_adv + Δt g に粘性 B = (I − Δt/ρ L)⁻¹ をかけ、Δt g を引き戻す。
3. 射影する。

圧力が δp だけ遅れていると、2 の後の速度には (B − I)Δt face_to_cell(α∇δp) が残る。

- 粘性がなければ、これは 0 になる。
- 粘性があると、勾配の形が崩れ、射影 P でも取り除けない。
- 新しい a と古い p は釣り合っていない。その差 α∇δp は、気相（α = 1/ρ が大きい）では密度比に比例して大きい。

これを確かめるため、残る量を直接測った（`cases/operator_commutator.py`）。

- 遅れた圧力として q = x² − y²（l = 2 モードの圧力）をとる。
- 測る量は |P(B − I)Δt α∇q| / |Δt ∇q|。

| | N = 32 | N = 64 | K = 1、1.6 倍の \|λ₁\| |
| --- | --- | --- | --- |
| A：密度比 1、μ 比 1 | 0.039 | 0.031 | 0.9996（安定） |
| 密度比 10 | 0.70 | 0.50 | 0.949 の振動モード（安定） |
| B：密度比 100、μ 比 1 | 8.06 | 6.37 | 1.189（不安定） |
| C：密度比 100、ν 比 1（μ₂ = 0.001） | 2.76 | 2.69 | 1.093（不安定、実測も 138 ステップで発散） |
| D：密度比 1、μ 比 100 | 0.0026 | 0.0015 | 0.9992（安定、実測も安定） |
| E：密度比 1000、μ 比 1 | 46.5 | 59.3 | 1.222（不安定） |

- 残る量は、密度比 1 → 1000 でほぼ比例して増える。
- 振動モードが出るかどうか、およびその |λ| の大小の順序は、この量の大小と一致する。
- 粘性比だけを 100 にした D では、残る量は小さく、安定。
- 動粘性をそろえた C でも、密度比 100 では不安定。

効いているのは粘性比ではない。気相の α を通じて大きくなる、遅れた圧力勾配である。

**仮説の棄却（交換子）**

最初は、滑らかなランダム速度場での交換子 |PB − BP|/|u| を候補にした。

| ケース | 交換子（N = 32） |
| --- | --- |
| A | 3.6e-4 |
| B | 0.52 |
| C | 0.043 |
| D | 7.1e-3 |
| E | 1.04 |

しかし C は交換子が小さいのに不安定である。交換子だけでは説明できず、この仮説は退けた。

また、セル上で P を2回かけたときの差 |PPu − Pu|/|Pu| は 0.017〜0.034 で、密度比にほとんどよらない。補間の不整合は主因ではない。

**ステップ内の外側反復の収束**

Phase 1 で測ったステップ内の外側反復の収束率（1回あたり）は次のとおり。

| 密度比 | 1 | 10 | 100 | 1000 |
| --- | --- | --- | --- | --- |
| 収束率 | 0.375 | 0.409 | 0.424 | 0.458 |

- 収束率は密度比にほとんどよらない。
- 違うのは最初の残差の大きさ（1回目の |Δg| は比 100 で約 10 倍）で、上の残る量と同じ傾向である。
- K = 2 でこの残差が十分小さくなり、振動モードは消える。

## 根本対策：反復を残差で止める（`coupled_tolerance`）
`CenteredNS(coupled_iterations=K_max, coupled_tolerance=tol)` を追加した。

- 2回目以降の反復で Δt max|g_{k+1} − g_k| < tol になったら、反復を打ち切る。
- 1回目の変化は前のステップとの差なので、判定に使わない。
- 人工粘性は加えていない。既定は None で、従来どおり K 回反復する。

効果（N = 32、K_max = 16、tol = 1e-10、800 ステップ）：

| | 境目 | 平均反復回数（安定なとき） |
| --- | --- | --- |
| 比 100 | 1.8〜1.9（K = 1：1.244〜1.3、K = 0：1.019〜1.075） | 3.5 |
| 比 1 | 2.05〜2.1 | 3.2 |

- 反復を収束させると、振動モードは消える。
- 残る境目は、陽的な毛管モード（arg = π）で決まる。
- 密度比 100 の不利は、比 1 に対して約 1 割に縮まる。

**K = 2 の境目が収束時より高い点**

- 比 100 の K = 2 は 2.0〜2.144 で、収束時の 1.8〜1.9 より高い。
- 途中で止めた反復が、陽的な毛管モードに余分な減衰を与えるためと見られる。
- この余分な減衰は、仕組みとして保証されたものではない。実測でも、K = 2 は比 1 では 2.031〜2.1 で、K = 1 の 2.2〜2.256 より低い。

N = 64 での確認（密度比 100、μ = 0.1、800 ステップ、ソルバー 1e-14）：

| f | 1.0 | 1.1 | 1.2 | 1.4 | 1.6 | 1.8 | 2.0 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| K = 1 | 不安定（308 ステップで発散） | 不安定 | | | | | |
| K = 2 | | | 安定 | 安定 | 安定 | 安定 | 安定 |
| 収束（K ≤ 16、1e-10）：結果 / 平均反復回数 | | | 安定 / 4.8 | 安定 / 4.5 | 安定 / 4.3 | 安定 / 4.2 | 不安定 |

- 比 100 の境目は、K = 1 の 1.0 未満（34 では 0.80〜1.03）から、収束させると 1.8〜2.0 に上がる。
- 比 1 では、収束させると 2.0 倍まで安定（平均反復回数 3.4〜3.6）。
- N = 32 と同じく、K = 2 は収束時より高い刻みまで安定（2.0 倍でも安定）。

## 過去の結果との関係
- **33・34（#47・#48）：** 比 1 で K = 0 の境目が粘性で下がり、K ≥ 1 で上がる。これは、陽的な毛管モード（arg = π）の固有値の位置として再現した。
- **34 の「密度比 100 で K = 1 が改善しない」：** 上の振動モードによる。毛管ループの時間分割の問題ではなく、外側反復が収束していないことが原因である。
- **35・36（#35・#36、時間刻み係数とその N 依存）：** 今回は N = 16・32 のみで、N 依存の再確認はしていない。
  - 比 100、K = 1、1.6 倍は、N = 16 では安定（密な Jacobian で 1.0011 までの中立に近いモードのみ）、N = 32 では不安定。境目が N とともに下がる傾向とは合う。
- **41（#41、半陰的化）：** 今回の解析には含めていない。

## 残り
- layered 形の粘性のみの減衰で、エネルギーが ×7.8 に増える件（33）は、別の課題として扱う。
- 境目の N 依存を、Jacobian で調べる。
- 渦層の扱い（B）は、この結果を受けてから進める。
