## 定式化と理論的根拠
### A. 短い列の縮退（SplitShort）
相分離 PCCD（ノート97）の列は、陽的な端の式のために純相のセルが 5 個以上必要で、それより短いと例外になる。二次元で方向ごとに PCCD を当てると、曲線の界面では全ての長さの列が現れる（監修 #116）。

ユーザーの方針：情報が足りない列に 5 次を要求しない。保存性・有界性・幾何学的な連続性を優先する。

| 純相のセル数 n | 再構築 |
| --- | --- |
| n ≥ 5 | PCCD の列（従来どおり） |
| 1 ≤ n ≤ 4 | 列の n 個のセル平均を全て満たす、次数 n − 1 の単一の多項式（保存型、次数 n − 1 まで厳密） |
| n = 0（面をまたぐ薄膜：混合セルが 2 つ隣り合い、その相の純相がない） | 膜の速度は 2 つの界面の値 u₁、u₂ の間で線形。各混合セルの他方の相は部分セルの形 `P_ext + (u_Γ − P_ext(σ))b(t)`。u₁、u₂ は 2 つの混合セルの質量加重の平均から（2 × 2 の線形の連立） |

- 全ての場合で、各セルの質量加重の平均は構成上データに一致する（最後の shift を含む）。
- SplitBlend（ノート95・97）の編入と組み合わせる。界面が面を横切るとき、混合セルは重み w で隣の列に編入され、列の長さ n の形と n + 1 の形が w で混ざる。そのため、列の長さの切り替え（4 ↔ 5 の PCCD への切り替えを含む）は、界面の位置について連続になる見込みである（2 節で測った）。
- 1 セルの列は定数（1 次）である。薄膜（n = 0）は界面の値を使う線形なので、1 セルの列より誤差が小さい（1 節）。列の多項式に隣の界面の値も使えば、短い列の次数を上げられる見込みがある（未実装）。

### B. 二次元の全粘性応力（x は Fourier、y は二相の再構築）
θx ごとに 2N × 2N の行列である（ユーザーの V6-3a）。

```
K_uu = 2a_xB_y + b_xA_y,   K_vv = a_xB_y + 2b_xA_y,   K_uv = c_xW_y
A_y = ∫μY'Y'ᵀ,  B_y = ∫μYYᵀ,  W_y = ∫μY'Yᵀ   （Y は最小粘性エネルギー再構築の y の基底）
G_C = b_x diag(G_ν, G_ν),   G_D = g_A,x diag(G_A,y, G_A,y)
```

- `(u_y + v_x)² ≤ 2u_y² + 2v_x²` から `K ⪯ 2 diag(a_xB_y + b_xA_y, 同)`。
- そのため、`λ_max(K, G_D) ≤ (2/g_A,x)(a_x λ(B_y, G_A,y) + b_x λ(A_y, G_A,y))`（ユーザーの上界）。
- 確認（密度比 1、粘度一定、N = 16、θx = 0.7）：
  - 2N 個の減衰率は、2 × 2 の Fourier の記号（ノート102）を θy = 2πm/N で並べたものと 1.9e-15 で一致した。
  - A_y は一次元の K_ν と 2.6e-15 で一致した。
  - G_ν はコンパクトな形と 7.6e-16 で一致した。

## 1. 短い列（N = 32、軽い相の純相が n セル、両端の混合セルの軽い相の割合 (f₁, f₂)）
### 定義されるか、と誤差（相対の最大誤差。軽い相の中 / 重い相の中、折れ目のある u = sin 2πx + 膜の中の放物線）
| n | ノート97（従来） | SplitShort：軽い相 | 重い相（密度比 1 / 1e3 / 1e6） |
| --- | --- | --- | --- |
| 0 | 例外は出ないが壊れている（軽い相の誤差 0.19〜0.47：延長の多項式がない） | 2.4e-4〜1.1e-2 | 7.5e-3 / 1.3e-4 / 5e-5 |
| 1 | **未定義** | 0.08〜0.10 | 8.6e-2 / 8.1e-4 / 6e-5 |
| 2 | **未定義** | 1.4e-3〜9.8e-3 | 5.0e-3 / 6e-5 / 6e-5 |
| 3 | **未定義** | 1.4e-3〜2.0e-3 | 5.7e-4 / 6e-5 / 6e-5 |
| 4 | **未定義** | 1.8e-4〜4.0e-4 | 1.4e-4 / 6e-5 / 6e-5 |
| 5〜8 | 定義（3e-5〜8e-5） | 同じ | 同じ（4e-5〜7e-5） |

（(f₁, f₂) = (0.4, 0.7)、(0.15, 0.2)、(0.9, 0.85) の最大。滑らかな u（sin 2πx + 0.3 cos 2πx）でも同じ傾向。）

- **平均の保存**：全ての場合で 9e-16 以下。
- **密度比 1e3 以上では、短い列は重い相の精度にほとんど影響しない**（軽い相の質量が小さいので、混合セルの u_Γ が重い相で決まる）。密度比 1 では、短い列の低い次数が混合セルを通して重い相に広がる（n = 1 で 8.6e-2）。
- 軽い相の誤差は、列が 1 セル増えるごとにおよそ 1 桁下がる。n ≥ 5 で PCCD の水準になる。

### Gram の最大固有値（M で正規化）
| (f₁, f₂) | n = 0〜4（SplitShort） | n = 5 | n = 8 |
| --- | --- | --- | --- |
| (0.4, 0.7) | 9.7〜10.7 | 13.0〜15.0 | 10.7〜11.3 |
| (0.15, 0.2) | 13.3〜13.5 | 13.4〜13.5 | 13.4〜13.5 |
| (0.9, 0.85) | 5.1〜10.9 | **22.0〜22.5** | 14.2〜15.1 |

- **短い列の縮退は Gram を大きくしない**。最大は n = 5 の PCCD（22.5、密度比 1e6）で、監修の測定（5 セルで 33.2、別の混合セルの割合）と同じく、PCCD の列の端の式で決まる。
- n = 0〜4 の低い次数の多項式は、n = 5 の PCCD より条件がよい。

## 2. 界面の移動での連続性（軽い相の厚さを 0.3 → 6.7 セルまで連続に動かす、200 点）
| 密度比 | ノート97（従来） | SplitShort + SplitBlend |
| --- | --- | --- |
| 1 / 1e3 / 1e6：未定義の位置 | 127 / 124 / 124（200 点中） | **0** |
| 最大の変化率 `max\|R(ℓ + ε) − R(ℓ)\|/ε` | 6.9 / 8.0 / 6.7（定義される所で） | **0.60 / 0.39 / 0.27** |

- 跳びがあれば、変化率は 1/ε = 1e7 の桁になる。全ての位置で O(1) なので、**列の長さの切り替え（0 → 1 → … → 6、4 ↔ 5 を含む）で跳びはない**（ε = 1e-7 の差分での判定）。

## 3. 二次元の D の剛性（N = 32、λ_max × h²/ν_max、θx について最大）
| 物性 | 密度比 1・1e3・1e6 の通常の条件 | 動粘度一定の薄片 |
| --- | --- | --- |
| C（二次元） | 29.3〜30.6 | 51.3（1e6、c = 0.01） |
| D（二次元） | 24.8〜29.2 | **176**（1e3、c = 0.01）、**569**（1e6、c = 0.01）、**2045**（1e6、c = 1e-4） |
| D（一次元、θx = 0 の y 方向） | 7.7〜10.4 | 44.9、232、**479** |
| ユーザーの上界（D） | 34.4〜41.0、全て成立 | 220、688、2510、全て成立 |

- **最大は全て θx = π**（x 方向の格子の尺度）。二次元の D は一次元の約 3〜4.3 倍になる。
  - x 方向の粘性の行列は、最小エネルギー再構築の記号 b_x を使う。質量は PCCD の Gram g_A,x を使う。その比 `2b_x(π)/g_A,x(π)` が掛かるためと考えられる（測った比は約 4.3）。
  - C では、同じ b_x が両方に現れるので打ち消し、二次元でも約 30 である。
- **監修 #120 (d) の懸念（接線方向の B_y を通して G_ν の悪条件が戻る）は現れなかった**：
  - `λ(B_y, G_A,y) h²/ν` は全ての条件で 0.1 以下。
  - 剛性は法線方向の A_y（一次元と同じ項）で決まる。
  - G_ν の悪条件（粘度一定・1e6 で λ(G_ν, M) = 3.3 万〜7.1 万）は、D には効かない。
- 動粘度一定の薄片の悪化（一次元 479、ノート100）は、二次元で約 4.3 倍の 2045 になる。陰的な粘性の求解を前提にすれば、現段階では許容する（ユーザーの判断、ノート101）。ただし、D の改良は状態変数の決定まで保留する。

## まとめ
- **短い列（#116）**：SplitShort（1〜4 セルは次数 n − 1 の列の多項式、0 セルは界面の値の間の線形）で、純相 0〜8 セルの全てで次のことが成り立った：
  - 方式が定義され、平均を保つ。
  - Gram ≤ 22.5（最大は n = 5 の PCCD の端）。
  - 界面の移動で連続。
  - 密度比 1e3 以上では重い相の精度を落とさない。
- **二次元の D の剛性（#120 (d)）**：通常の条件では 25〜29（C と同程度）。動粘度一定の薄片では一次元の約 4.3 倍（2045）。B_y による悪化はない。

## 未検証・次
- 短い列の輸送（Floquet・長時間）での安定性。今回は静的な再構築だけ。
- 1 つのセルの中に界面が 2 つある配置（3 つの部分を持つ混合セル）。今回の n = 0 は面をまたぐ薄膜だけ。
- 隣の界面の値を使って、短い列の次数を上げること。
- 斜めの界面・円での、セル中心型（A・B）と MAC 型（C・D）の再構築の比較（Gate 1-B の本体）。
