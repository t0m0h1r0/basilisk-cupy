# 24 ACLS の再初期化（PR #38）

## 定式化と理論的根拠
### 2008 の形の平衡と、離散的に釣り合わない理由
`H_ε(φ) = 1/(1 + e^{−φ/ε})` は `ε ∂_φ H_ε = H_ε(1 − H_ε)` を満たす。平らな界面（|∇φ| = 1）では `ε∇ψ·n = ψ(1 − ψ)` で、流束 `(ε∇ψ·n − ψ(1 − ψ))n` は連続系で 0（平衡）。

離散系では、面の 2 点差分 `ε(ψ_R − ψ_L)/h` と、面の `ψ(1 − ψ)`（非線形）の評価が、O(h²) だけずれる。流束は 0 にならず、表の `8.1e-4`（h によらず同じ値：h² のずれを h で割った発散の後に h を掛けた量）が残る。

### 2017 の形が離散的に厳密に釣り合う理由
`φ_map = ε ln(ψ/(1 − ψ))` は、ψ が厳密な H_ε(φ) なら `φ_map = φ`（逆関数）。平らな界面では φ は一次関数なので、2 点差分は `∇φ_map·n = 1` を丸め誤差まで厳密に与える。流束 `ψ(1 − ψ)(|∇φ_map·n| − 1)n` は離散的に 0（表の 1e-16）。どの向きでも成り立つのは、一次関数の差分が向きによらず厳密なため。

### 2017 の実効的な拡散係数と、刻みを 1/4 にする理由
ψ を `H_ε(φ) + δψ` と摂動すると、`δφ_map = ε δψ / (ψ(1 − ψ))` なので、流束は次のとおり：

```
ψ(1 − ψ) ∂_n δφ_map ≈ ε ∂_n δψ
```

ε の拡散と同じ形。ただし面の ψ(1 − ψ) とセルの値が一致しない急なセルでは、比 `ψ(1 − ψ)_面 / ψ(1 − ψ)_セル` が 1 を超え、実効的な拡散係数が ε を超える。陽的な擬似時間の安定条件 `dτ ≤ h²/(2D_eff)` が厳しくなる。そのため、刻みを 1/4 にした（N = 128 で 1 倍では発散）。

### φ_map を CCD で微分すると発散する理由
`dφ_map/dψ = ε/(ψ(1 − ψ))` は、飽和に近いセル（ψ → 0、1）で発散する。そこでの ψ の小さな乱れが φ_map で大きく増幅される。CCD は区間全体の連立なので、その増幅された乱れを界面の近くの微分に運ぶ（1 セルあたり 0.455 倍、ノート75）。局所の差分なら、影響はそのセルの近くに留まる。

## 実装（`cls.reinitialize(n_steps, method="acls2008" | "acls2017")`）
- **2008（Desjardins, Moureau & Pitsch）：** ∂τψ = ∇·[(ε∇ψ·n − ψ(1−ψ)) n]。
- **2017（Chiodi & Desjardins）：** ∂τψ = ∇·[ψ(1−ψ)(|∇φ_map·n| − 1) n]。
  - φ_map = ε ln(ψ/(1−ψ))。ψ(1−ψ) = 1/(4cosh²(φ_map/2ε))（面の φ_map で評価）。
  - ψ ではなく、平らな界面で1次関数になる φ_map を微分する。
- **法線 n：** 作り直した距離関数から求める。ACLS の FMM の代わりに、ψ = ½ の交差を結ぶ折れ線までの距離（13 の `distance="segments"`）を使い、1回の呼び出しにつき1度だけ計算する。n はその中心差分。
- **離散化：** 保存形の FV。面の法線方向の微分は2点差分、接線方向は両セルの中心差分の平均、n は両セルの平均を正規化したもの。壁では流束ゼロ。
- **後処理：** clipping と段階 B の質量補正（圧縮・拡散と同じ）。
- **擬似時間刻み：** 圧縮・拡散の dτ に `ACLS_DTAU_FACTOR`（2008：1、2017：1/4）を掛ける。
  - 2017 は 1 倍では N = 128 の並進で発散した。急なセルでは、面の ψ(1−ψ) がセルの値を上回り、実効的な拡散係数が ε を超えるため。
- 比較の基準「圧縮・拡散」は、これまでの FCCD 版の Olsson–Kreiss（等方拡散、法線は ψ の CCD 勾配）。

## 平らな界面での釣り合い
正確な H_ε プロファイル（傾き 0 / 0.3 / π/4 rad）での max|∇·F|·h（N = 64。2008 は N = 32〜128 で同じ値、2017 は 4e-16〜2e-15）：

| | 0 | 0.3 | π/4 |
| --- | --- | --- | --- |
| 2008 | 8.1e-4 | 7.1e-4 | 1.9e-3 |
| 2017 | 3.7e-16 | 5.6e-16 | 9.3e-16 |

2017 は、平らな界面ならどの向きでも離散的に厳密に釣り合う。

## 静止した円（直径 20 セル）に1擬似ステップの再初期化を繰り返す
ψ の最大変化 / 曲率の最大誤差（|φ| < ε）：

| 回数 | 10 | 100 | 1000 |
| --- | --- | --- | --- |
| 圧縮・拡散（N = 64） | 2.1e-4 / 0.002 | 2.9e-4 / 0.003 | 1.1e-3 / 0.018 |
| ACLS 2008（N = 64） | 1.6e-3 / 0.011 | 6.4e-3 / 0.056 | 3.2e-2 / 0.53 |
| ACLS 2017（N = 64、刻み 1/4） | 1.4e-4 / 0.001 | 3.2e-4 / 0.001 | 1.1e-3 / 0.031 |

- N = 128（同じ直径 20 セル）でもほぼ同じ値。
- **2008：** 論文が問題にした、再初期化の繰り返しによる変形が出る。
- **2017：** 変形が 1/30 に減る。ただし擬似時間の合計は他の 1/4 で、それでも FCCD の圧縮・拡散と同程度。
- **法線の影響：** 正確な法線、折れ線距離、ψ の CCD 勾配のどれを使っても、結果はほとんど変わらない。

- 毛管波は、移流に補正した発散と6次の面値を使った条件。
- どの再初期化も毛管波を悪くする（振幅 0.01 は 0.16〜0.3Δ しかない）。
- ACLS は圧縮・拡散より害が小さいが、21 の不安定（境目が N とともに下がる）は消せない。

## FCCD で φ_map を微分すると発散する
2017 の φ_map の微分を FCCD/CCD にすると、N = 64 では静止円の崩れが最小になった（1000 回で 9.0e-4）。しかし N = 128 では 700 回前後で発散した（打ち切りを 1e-12 → 1e-3 に変えると、かえって早く発散する）。

- φ_map は飽和に近いセルで ψ の乱れを 1/(ψ(1−ψ)) 倍に増幅する。CCD は大域的に結合しているので、その乱れが界面付近の微分に届く。
- そのため 2017 の離散化は局所の差分に限る（実装は2点差分と中心差分のみ）。

## 結論
- 2017 の再定式化は、平らな界面で厳密に釣り合い、2008 の変形をなくす。その点は文献の主張どおり。
- ただし、この比較では、FCCD で解く等方拡散の圧縮・拡散（今の方式）を上回る場面はなかった。
  - 移流と曲率では同程度か劣る。
  - 細い糸は大きく削る。
  - 21 の不安定を消すのは圧縮・拡散だけ。
- ACLS が有利なのは、毎ステップ再初期化したときの毛管波（悪化が小さい）だけだった。
