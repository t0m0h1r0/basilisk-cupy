# 33 毛管ループの連成安定性と粘性のみの減衰試験（PR #47）

## 定式化と理論的根拠
### Jury の条件の導出
2×2 の増幅行列 A の特性多項式 `λ² − tr λ + det = 0` の根が単位円の中にある条件は、次の 3 つ（Jury）：

```
|det| ≤ 1,   1 − tr + det ≥ 0,   1 + tr + det ≥ 0
```

実装の順序の `A = [[1, 1], [−ab, b − a]]` では、`tr = 1 + b − a`、`det = b − a(1 − b)`。

- `1 − tr + det = ab ≥ 0`（常に成立）。
- `1 + tr + det = 2(1 + b) − a(2 − b) ≥ 0` → `a ≤ 2(1 + b)/(2 − b)`。
- `det ≥ −1` → `a ≤ (1 + b)/(1 − b)`。

本文の `a ≤ min(2(1+b)/(2−b), (1+b)/(1−b))`。b = 1/(1 + D) を入れると表の値（D = 0 で ωΔt ≤ 2、D → ∞ で 1）になる。

### layered 形が格子規模の雑音を減衰させない理由
CCD の 1 階微分の記号は kh = π で 0（中心型の差分）。D1∘D1 の記号も 0 なので、格子規模の成分に粘性が効かない。split 形の D2 の記号は 9.6（厳密 π² = 9.87）で、強く減衰させる。layered 形で雑音が増えた理由（減衰しないだけでなく増える）は、ノート37 の壁の閉包の非対称性と欠陥的な零固有値による。

## 背景
外部の意見（貼り付け）は、「粘性 → 表面張力」の順の簡略モデルで、安定条件 a ≤ 2(1+b) を導いた（a = (ωΔt)²、b = 1/(1+dΔt)）。粘性を強めると安定限界が下がる（#35）ことの説明候補になる、という指摘だった。これを実装の順序に合わせて確かめた。

## 実装の順序のモデル（`cases/coupled_stability.py`）
CenteredNS（vof_first）の1ステップを、振幅 η と速度 v（dt 単位）の線形モデルにした。

1. η′ = η + v（界面を前のステップの速度で動かす）。
2. 予測段で、前のステップの g（η の力と圧力）を足して粘性を解き、g を引き戻す。
3. 新しい力 F(η′) を射影で入れる。

まとめると v′ = b(v + F(η)) − F(η) + F(η′)、F = −ω²η。増幅行列は [[1, 1], [−ab, b − a]] で、Jury の条件から a ≤ min(2(1+b)/(2−b), (1+b)/(1−b)) となる。

| D = dΔt | 実装の順序 | 粘性 → 力（意見のモデル） | 力も含めて粘性を陰的に |
| --- | --- | --- | --- |
| 0 | ωΔt ≤ 2.000 | 2.000 | 2.000 |
| 1 | 1.414 | 1.732 | 2.449 |
| 10 | 1.069 | 1.477 | 4.899 |
| ∞ | 1 | √2 | ∞（a ≤ 4 + 2D） |

- 意見のモデルの式は正しい（Jury の条件で確認）。
- 実装の順序では、粘性で安定限界が 2 → 1 とさらに大きく下がる。g の中の古い力は粘性で減衰するが、新しい力は減衰しないので、力の「差分」が増幅されるため。
- 力を粘性と一緒に陰的に扱えば、粘性は安定化の側に働く。
- ψ を運ぶ速度だけを 1/(1+θa) で平滑化すると（27 を模したもの）、θ = 1 で上限（ωΔt = 20 で打ち切り）まで安定。27 が効いた理由を定性的に説明する。

## 実際のソルバーとの照合（静止液滴、GFM、等密度、N = 64、600 ステップ、二分法）
| μ | 0 | 0.003 | 0.01 | 0.03 | 0.1 | 0.3 | 1.0 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 安定の境目（tension.h の上限の何倍か） | 1.60〜1.65 | 1.50〜1.55 | 1.40〜1.45 | 1.30〜1.35 | 1.15〜1.20 | 1.05〜1.10 | 1.00〜1.05 |
| μ = 0 との比 | 1 | 0.94 | 0.88 | 0.82 | 0.72 | 0.66 | 0.63 |

- 粘性を強めるほど境目が単調に下がり、一定値に近づく。モデルの振る舞いと定性的に一致する。
- 定量的には合わない。
  - 比は 0.63 で止まる（モデルは 0.5）。
  - モデルの D に読み替えると、μ に比例しない。
  - 1つの数のモデルでは、モードの空間構造（粘性の効き方の分布、密度、離散的な慣性）を表せない。

## 粘性のみの減衰試験
界面を止め、表面張力を切り、密度と粘性の分布を固定して、同じ初期速度を各演算子で減衰させた（N = 64、μ = 0.1、刻み 1.04e-3）。

| 初期速度 | 2次差分（Basilisk） | CCD split（既定） | CCD layered（D1∘D1） |
| --- | --- | --- | --- |
| 静止液滴の 30 ステップ後の寄生流：40 ステップ後の E/E0 | 0.115 | 0.115 | 0.110 |
| 射影した白色雑音：1 ステップ後 / 40 ステップ後 | 0.487 / 1.18e-3 | 0.402 / 1.21e-3 | 0.526 / **7.8（増大）** |

- 静止液滴の寄生流は大きなスケールの成分が主で、演算子の差は出ない。
- 格子規模の雑音では、layered 形は減衰せず、むしろ増大する。CCD の D1 は格子規模で記号がゼロ（−h²×シンボル：厳密値 9.87、2次差分 4、split 形の D2 9.60、layered 形 0）。外部の意見が挙げた Chamarthi et al. の指摘と同じ。
- 既定の split 形（06）は問題ない。粘性演算子の高波数での減衰は、いまの不安定の原因ではない。

## 結論
- #35 の「粘性を強めると安定限界が下がる」は、粘性演算子ではなく、粘性と表面張力の時間分割の順序で説明できる（定性的）。
- 力を粘性と一緒に陰的に扱う順序なら、粘性は安定化に働く（モデル）。実装で確かめるのが次の段。
