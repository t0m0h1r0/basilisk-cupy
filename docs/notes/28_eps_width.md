# 28 界面幅 ε/h を広げる（PR #42）

## 定式化と理論的根拠
### 界面幅の取り引き
曲率などの誤差を、2 つの項の和と見る：

```
e(ε) ≈ C₁ (h/ε)^p + C₂ (ε/R)²
```

- 第 1 項は、分布（幅 ε）を格子で微分する打ち切り誤差。演算子の次数 p で決まる。
- 第 2 項は、拡散した分布そのものが曲がった界面で鋭い界面からずれるモデル誤差（ノート54・25 の `ε²κ` 型）。

- ε = 1.5h では第 1 項が h によらない定数（h/ε 一定）で、曲率は h とともに収束しない（ノート14 の O(h⁻¹)）。
- ε を広げると第 1 項が `(h/ε)^p` で下がる。ACLS の釣り合いの誤差が `(h/ε)⁵` 程度で下がったこと（1.5 → 4 で 1/90）は、p ≈ 5 と整合する（`(1.5/4)⁵ ≈ 1/134`）。
- R/ε が小さいと第 2 項が効き、逆効果になる。N = 32（R = 6.4h）で ε/h ≥ 3 の誤差が O(0.1) になったことと整合する。

最適な ε は、2 つの項の釣り合いで決まり、R/h が大きいほど広く取れる。目安 R/ε ≳ 10〜20 は、測定からの経験的な値（定数 C₁、C₂ は求めていない）。

### ε に依存しないもの
毛管波の誤差は、界面の運動学（ノート41：面の間隔 h で決まる重み）で決まり、ε によらない。格子規模の毛管波の不安定（ノート21）も、輸送の散逸のなさによるので、ε を変えても直らない。

## 問い
ε = 1.5h では遷移層が3セルしかなく、CCD/FCCD の高次精度が頭打ちになっていた（14、18、26）。ε/h を 2・3・4 に広げると良くなるか。

- `CLSInterface.from_level_set(..., eps=...)` に加え、`capillary_wave.run`、`reversed_cls.run`、`capillary_dt_scan.growth` に `eps_factor` を追加した。
- 移流は補正した発散＋6次の面値（18）。
- 図：`docs/figures/eps_width.png`（`cases/eps_figures.py`）。

## 分かったこと
- **効く所：** ε を広げると、CCD/FCCD の高次精度が効き始める。
  - ACLS の釣り合いの誤差は ε/h にほぼ (h/ε)⁵ で下がる（1.5 → 4 で 1/90）。
  - 正確なプロファイルの曲率は、ε/h ≥ 3 で 1e-5〜1e-6 になり、ε/h = 1.5 の O(h⁻¹) の増加もなくなる（N = 128 で 1/200〜1/1200）。
  - 移流の誤差も下がる（N = 128 の ψ L1 で 1/26）。
- **効かない所：** 界面幅が液滴の半径に比べて無視できないと逆効果。
  - N = 32（R = 6.4h）では ε/h = 3 以上で曲率の誤差が O(0.1)。
  - 静止円を繰り返し再初期化したときの崩れも ε とともに増える（R/ε が小さいほど、平衡の形が tanh からずれる）。
  - 目安は R/ε ≳ 10〜20。
- **ε に依存しないもの：**
  - 毛管波の誤差（どの ε/h でも 0.064 前後、16 点）。誤差のもとは界面幅ではない。
  - 格子規模の毛管波の不安定（21）。これは 27 の半陰的化で抑える。
- **反転渦：** 細い糸が ε と競合するので、N = 128 では ε を広げるほど悪くなる。

## 結論
- 界面の解像度（R/ε）に余裕がある問題では、ε/h = 2〜3 にすると、曲率・移流・再初期化の精度が1〜3桁良くなる。
- 細い構造や粗い格子では、ε/h = 1.5（論文の値）の方が良い。
- 既定は論文どおり 1.5 のまま。
