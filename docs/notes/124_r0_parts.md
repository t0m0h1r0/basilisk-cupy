## 定式化と理論的根拠
### A. 構成の引数（`conf`、全ての部品に共通）
`conserving`（既定 True）、`filtered`（False）、`face_density`（"smooth"：two-phase.h、"mean"：`TwoPhaseVOFJump` の算術平均のセルの係数、ノート115）、`viscosity_mean`（"arithmetic"：two-phase.h、"harmonic"：面の粘性 `1/(c/μ₁ + (1 − c)/μ₂)`、ノート121）、`fixes`（PR #192 の `conserving_consistent=True`・`conserving_slope_limit=3.0`）、`project_start`（最初の面の速度の射影）、`tolerance`。

### B. 共通の出力
- 離散の発散 `h max|∇·u_f| / U_ref`（start の後の t = 0 を含む、計算の全体の最大）。
- 誤差の場の L1・L2・L∞ を、全体・界面の帯（参照の界面までの法線の距離が 2.5h 以内のセルの中心）・純相の内部に分ける（`split`）。

### C. 二層 Couette・Poiseuille の厳密な定常解（導出）
流路 0 ≤ y ≤ 1、x に周期、壁は粘着（Couette は上の壁が U で動く）。相 1（μ₁）が y < y_i。定常で `(μu')' = 0`（Couette）、`(μu')' = −F`（Poiseuille、体積あたりの一様な力。面の加速度 `F·α_f`）。界面で u と μu' が連続。
- Couette：`τ = U/(y_i/μ₁ + (1 − y_i)/μ₂)`、各層で u は一次。
- Poiseuille：`μu' = C − Fy`、`u(0) = u(1) = 0` から `C = F b/a`（`a = y_i/μ₁ + (1 − y_i)/μ₂`、`b = (y_i²/2)/μ₁ + ((1 − y_i²)/2)/μ₂`）。
- セル平均は、界面で区切った 3 点の Gauss（二次の区分の多項式に厳密）。界面の位置は `y_i = 0.5 + offset·h`（offset 0：面の上、0.3：セルの中）。静止から始め、t_end の場と t = 0.9 t_end の場の差を「定常さ」として出す。

### D. 毛管波の 10 周期の参照
監修の `audit/pr177/capwave_exact.py`（二層・有限の深さ・滑りの壁の線形化 Navier–Stokes の Laplace 変換）を物差しにして、t ≤ 4.1 で評価した。**監修の de Hoog の逆変換（次数 24）は t ≈ 3 から解を失う**（t = 3 で 1.2e-7、正しくは −1.13e-3）ので、**Talbot の方法**で評価した（t = 3・4 で de Hoog の次数 48 と 1e-14 まで一致。t ≤ 1.2 では監修の表と 4.5e-17 まで一致）。
