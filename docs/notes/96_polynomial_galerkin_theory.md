# 96 多項式近似 Galerkin の一般理論：行列とベクトルの積だけで、エネルギーの非増加・自由流・総運動量を厳密に保つ条件（PCCD にも適用できる。実装は保留）

ユーザーの提案（GPU 向けの候補）は、Galerkin の写像 `T = G₁⁻¹C` の連立方程式を解かず、質量の対角 M で前処理した多項式で近似することだった。ここでは、近似しても構造を厳密に保つ条件を、再構築の方法によらない形で書く。

- 最小二乗 Galerkin（ノート87〜90）の試作で導いた。
- ノート91 以降の PCCD–Galerkin、および密度適合型 PCCD（shift を使う形）にも、そのまま当てはまる。
- **実装は保留**（ユーザーの判断、2026-11-27）。試作のコードと測定は、凍結した枝にある（索引の「保留中の研究」）。

## 定式化と理論的根拠
### 前提
次の 3 つを仮定する。

1. **共通の積分点**：G₀、G₁、C を、新旧の基底の共通の分割の上の、同じ積分点と正の重み `w_q ρ(q)` から作る。`G₀ = B₀ᵀWB₀`、`G₁ = B₁ᵀWB₁`、`C = B₁ᵀWB₀`。
   - このとき `[[G₀, Cᵀ], [C, G₁]] ⪰ 0` なので `CᵀG₁⁻¹C ⪯ G₀` となり、厳密な Galerkin のエネルギーは増えない（ノート87 D 節）。
2. **1 の分割**：一様なデータの再構築は一様（`Σ_j φ_j = 1`）。そのため `G₁1 = m`（質量）、`C1 = m`。
3. **平均の保存（shift）**：各セルの再構築の質量加重平均が、そのセルのデータに一致する（`∫_{K_i}ρ u_h = m_i ū_i`）。

### A. 近似の形とエネルギーの条件
`A = M^{−1/2}G₁M^{−1/2}`（対称正定値）、`v = M^{−1/2}Cu`。多項式 p による近似を

```
T_p = M^{−1/2} p(A) M^{−1/2} C          （厳密な写像は p(λ) = 1/λ）
```

とすると、`‖T_p u‖²_{G₁} = vᵀp(A)Ap(A)v`、厳密な写像では `vᵀA⁻¹v = uᵀCᵀG₁⁻¹Cu ≤ ‖u‖²_{G₀}`。

したがって、A のスペクトルの上で `λp(λ)² ≤ 1/λ`、すなわち

```
|λp(λ)| ≤ 1   ⇔   0 ≤ r(λ) ≤ 2,      r(λ) = 1 − λp(λ)（残差の多項式、r(0) = 1）
```

なら `‖T_p u‖_{G₁} ≤ ‖u‖_{G₀}`。**有限の反復で止めても、エネルギーは増えない**（ユーザーのノート91 への指摘「有限の残差で止めると証明が使えない」への答え）。

- 普通の Chebyshev の残差は区間の上で負になる（r = −δ）ので、エネルギーが (1 + δ)² 倍まで増えうる。
- **r = q²**（q は残差の多項式）なら `r ≥ 0` が自動的に成り立つ。スペクトル全体で `|q| ≤ √2` を保てばよい。
- 実装は、0 から始めた Richardson の掃引 `x ← x + (1/λ_i)M⁻¹(Cu − G₁x)`（残差の多項式 `Π(1 − λ/λ_i) = q`）を、同じ節点で 2 回繰り返すこと。2 回目の初期の誤差は `−q(A)A⁻¹b` なので、最後の誤差は `q²(A)A⁻¹b` になる。

### B. 自由流と総運動量
前提 2 から `A(M^{1/2}1) = M^{−1/2}G₁1 = M^{1/2}1`。つまり `M^{1/2}1` は A の固有値 1 の固有ベクトルである。

- **自由流**：`T_p1 = M^{−1/2}(1 − r(A))M^{1/2}1`。`r(1) = 0` なら `T_p1 = 1`。
- **総運動量**：A は対称なので `(M^{1/2}1)ᵀr(A) = r(1)(M^{1/2}1)ᵀ = 0`、すなわち `1ᵀG₁T_pu = 1ᵀCu`。

**q が λ = 1 に根を持てば**（`q(λ) = (1 − λ)Π_j(1 − λ/λ_j)`）、自由流と総運動量は多項式近似でも厳密である。

### C. スペクトルの区間 [1, b]
- **下端 1**：前提 3 と Cauchy–Schwarz から、各セルで `∫_{K_i}ρu_h² ≥ m_iū_i²`。和をとって `G₁ ⪰ M`、`λ_min(A) ≥ 1`（定数で等号）。
  - G₁ の積分点がセル自身の積分点と違う場合は、正の重みの Cauchy–Schwarz から `λ_min ≥ 1 − O(ε)`（ε は積分の誤差）。
  - 下端はエネルギーの保証には効かない（[0, 1] では q ∈ [0, 1]）。効くのは精度（Chebyshev の区間）だけである。
  - ユーザーの一般化（相分離 PCCD、ノート95 で検証中）：`R = J_c + (I − P_c)R̃` の形の再構築では `G = M + R̃*(I − P_c)R̃` なので、下端 1 は構成上成り立ち、上端は R̃ の大きさで決まる。
- **上端 b**：Gershgorin の上界 `max_i Σ_j |A_ij|`。`|q| ≤ √2` をスペクトル全体で保証するには、厳密な上界が必要である。
- **節点**：q の残りの k − 1 個の根を [1, b] の Chebyshev の根にとる。G₁ との積は 2 回の掃引で 2k 回。
- **誤差の見積もり**：Chebyshev の残差 `δ_k ≈ 2ρ^{k−1}`、`ρ = (√b − 1)/(√b + 1)`。r = q² の誤差はおよそ δ_k²。

### D. PCCD への当てはめ
単相の PCCD（ノート91）は、前提 1〜3 を満たす（平均を保つ Hermite、1 の分割、同じ積分点の G と C）。

| N | spec(G/M) | Gershgorin の上界 b |
| --- | --- | --- |
| 32 | [1.000000, 1.528315] | 1.7111 |
| 64 | [1.000000, 1.530715] | 1.7111 |
| 128 | [1.000000, 1.532019] | 1.7111 |

- b = 1.711 なら ρ = 0.133。
  - k = 6（G₁ との積 12 回）で r ≈ 7e-9。
  - k = 8（16 回）で r ≈ 2e-12。
- G は CCD の逆行列を含むので密行列である（ノート91 の 4 節）。各積 G₁x は「CCD の解法 → 局所の積分 → 随伴の CCD の解法」で、行列を作らずに計算する。
- 二相の場合の上端は、再構築の設計（密度適合型 PCCD、ノート95 で検証中）で決まる。条件数を密度比によらず 10 程度に抑えるのが当面の目標（ユーザー）で、そのとき k ≈ 10 で r ≈ 1e-9 の見込み（見積もり）。
