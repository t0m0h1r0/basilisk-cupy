# 29 毛管波の誤差の原因（PR #43）

## 定式化と理論的根拠
- **渦層の厚さ**：振動 ω₀ の界面の接線速度に対する粘性の境界層は `δ = √(2ν/ω₀)`（Stokes 層）。ν = 0.0183、ω₀ = 11.1 で δ ≈ 0.057。
- **粘性ゼロでの渦シート**：非粘性の線形の毛管波では、界面の上下で接線速度が逆向きで、界面は渦シート（接線速度の跳び）。数値散逸がなければ、その格子規模の成分が減衰せずに残り、長い時間で増幅しうる（Kelvin–Helmholtz 型）。CLS の中心型の輸送は散逸が小さく（0.6%/周期）、VOF の幾何学的な輸送は散逸がある（2.9%/周期）。
- **収束次数の違い**：VOF の幾何学的な輸送の散逸は 1 次の誤差なので、減衰率のずれも 1 次で縮む。CLS は 2 次で縮む。粗い格子で VOF が正確に見えるのは、符号の逆の 2 つの誤差（散逸の過剰と、渦層・運動学の不足）の打ち消し。
- **解釈の訂正（ノート41）**：この節の「渦層を解像できず粘性散逸が過小」は、ノート41 で「界面の運動学（交点が ±h の平均の速度で動く）」と訂正された。運動学の誤差も `−½M₂/δ²`、つまり (h/δ)² で決まるので、この節の δ/h による整理はそのまま成り立つ。

## 問い
CLS＋GFM（補正した発散＋6次の面値）の毛管波の誤差は、1波長 16 / 32 点で 0.0639 / 0.0109 と、VOF（0.0243 / 0.0064）より大きい。界面幅（28）でも曲率（17、25）でも決まっていなかった。

## 方法
振幅のピークから周期と1周期あたりの減衰率を読み、Prosperetti の解（周期 3.457、減衰率 0.692、ω₀t 単位）と比べる（`cases/capwave_damping.py`）。

## 測定
| 1波長の点数 | 16 | 32 | 64 |
| --- | --- | --- | --- |
| VOF：誤差 / 周期 / 減衰率 | 0.0243 / 3.490 / 0.6831 | 0.0064 / 3.470 / 0.6858 | 0.0023 |
| CLS：誤差 / 周期 / 減衰率 | 0.0639 / 3.565 / 0.7247 | 0.0109 / 3.470 / 0.6992 | 0.0021 |

- 主な差は減衰。VOF はわずかに減衰しすぎ、CLS は減衰が足りない。
- CLS の減衰率のずれは +0.033 → +0.0073（16 → 32 点、2次で収束）、VOF は −0.0089 → −0.0062（1次）。64 点では CLS の方が誤差が小さい。

原因でなかったもの（1波長 16 / 32 点、誤差・周期・減衰率がほぼ変わらない）：

| 変えた点 | 誤差 |
| --- | --- |
| 振幅を φ_map の3次補間で読む（t = 0 の 1.3% の過小評価をなくす） | 0.0694 / 0.0133（かえって悪い） |
| 質量補正なし、clipping なし | 0.0639 / 0.0109（同じ） |
| 時間刻みを 1/4〜1/5 | 0.0666 / 0.0117 |
| ジャンプ位置 θ を φ_map の線形補間で | 0.0636 / 0.0104 |
| 曲率を界面のフーリエ級数から求めた正確な値に | 0.0800 / 0.0284（減衰率 0.7231） |
| 曲率を高さ関数（2次差分 / CCD）に | 0.0549 / 0.0120、0.0496 / 0.0100（減衰率 0.73） |
| 界面幅 ε/h = 2〜4（28） | 0.064〜0.065 / 0.0106〜0.0108 |

粘性ゼロ（μ = 0、物理的な減衰なし）、16 点：

| | 1周期あたりの減衰率 |
| --- | --- |
| VOF | 0.9712（数値散逸 2.9%/周期） |
| CLS | 0.9941（0.6%/周期） |

- 粘性ゼロ・32 点では、CLS は t ≈ 20 から振幅が増えて発散する（半陰的表面張力 θ = 1・4 でも同じ）。
- 界面の上下で接線速度が反転する渦シートが、散逸なしでは保てないため。VOF は数値散逸で減衰させる。

## 解釈
- 粘性があるとき、界面には厚さ δ = √(2ν/ω₀) ≈ 0.057 の渦層ができる（ν = 0.0183、ω₀ = 11.1）。
- 格子幅は 1波長 16 / 32 / 64 点で h = 0.0625 / 0.031 / 0.016、δ/h = 0.9 / 1.8 / 3.7。
- 粗い格子ではこの層を解像できず、速度勾配が過小になって粘性散逸も過小になる。これが CLS の減衰不足（2次で収束）と考えられる。
- VOF は、幾何的な移流の数値散逸（粘性ゼロで 2.9%/周期）がこれを打ち消すので、粗い格子でも Prosperetti の解に近く見える（1次で収束）。
- この解釈は、δ/h の見積もり、粘性ゼロでの渦シート、収束次数の違いと整合する。ただし、渦層の解像度を直接変えて確かめてはいない。

## 結論
- 毛管波で CLS が VOF に劣って見えるのは、CLS の誤りではない。
- 粗い格子では渦層が解像できない NS の誤差が、CLS では打ち消されずに現れる。VOF では移流の数値散逸がそれを偶然打ち消している。
- CLS は2次で収束し、64 点で VOF を上回る。
