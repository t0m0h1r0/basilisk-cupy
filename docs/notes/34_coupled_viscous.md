# 34 表面張力・粘性・射影の連成反復（PR #48）

## 定式化と理論的根拠
### 連成反復の線形モデルの安定条件 a ≤ 4 + 2D
反復が収束すると、モデルは `η′ = η + v`、`v′ = b(v + F(η′))`、`F = −ω²η`、`b = 1/(1 + D)`。増幅行列は：

```
A = [[1, 1], [−ab, b(1 − a)]],   tr = 1 + b − ab,   det = b
```

（a = (ωΔt)²。）Jury の条件（ノート33）：

- `|det| = b ≤ 1`（常に成立）。
- `1 − tr + det = ab ≥ 0`（常に成立）。
- `1 + tr + det = 2 + 2b − ab ≥ 0` → `a ≤ 2(1 + b)/b = 4 + 2D`。

粘性（D が大きい）ほど限界が上がる。力を粘性と同じ陰的な段に入れると、粘性が力の振動も減衰させるため。μ = 0（D = 0）では a ≤ 4、つまり ωΔt ≤ 2 で、K = 0 と同じ。

### 立ち上がりの過渡
最初は圧力 p = 0 で釣り合っていない。外側反復は 1 回ごとに残差を約 c 倍（測定で約 1/10）に縮めるので、K 回で `c^K` 倍。K = 1 の 1 ステップ目の寄生流 2.7e-3 が K = 2、3 で 1 桁ずつ下がったのは、この縮小と一致する。

## ねらい
33 の線形モデルは、次の2点を予測した。

- CenteredNS の時間分割（予測段で前のステップの力に粘性をかけて引き戻し、新しい力は射影で入れる）では、粘性を強めると安定限界が ωΔt = 2 → 1 に下がる。
- 力を粘性と一緒に陰的に扱えば、粘性は安定化に働く（a ≤ 4 + 2dΔt）。

これを実装で確かめる。

## 実装（`CenteredNS(..., coupled_iterations=K)`）
- 新しいステップの加速度 a（移動した界面の GFM ジャンプなど）を、粘性より先に計算する。
- K 回の外側反復を行う。
  1. g = face_to_cell(a − α∇p)（最新の圧力で）。
  2. (I − Δt/ρ L)w = u_adv + Δt g を解く。
  3. u = w − Δt g、uf = interp(u) + Δt a として射影し、g を更新する。
- 収束すると (I − Δt/ρ L)u^{n+1} = u_adv + Δt(a − α∇p^{n+1})、∇·u^{n+1} = 0 になる（粘性・新しい力・圧力・非圧縮条件の連成）。
- 静止液滴で a と ∇p が釣り合っていれば、u = 0 のまま（釣り合いを壊さない）。#46 の滑らかな圧力の形とも併用できる（a の中身を変えないため）。
- 界面が先に動く（vof_first）ので、モデルは η′ = η + v、v′ = b(v + F(η′))。これは「力も含めて粘性を陰的に」と同じ安定条件になる（33 のモデルで確認）。
- 既定は K = 0（Basilisk の分割）。

## 測定
安定の境目（静止液滴、GFM、等密度、N = 64、600 ステップ、二分法、tension.h の上限の何倍か）：

| μ | 0 | 0.01 | 0.1 | 1.0 |
| --- | --- | --- | --- | --- |
| K = 0（33） | 1.60〜1.65 | 1.40〜1.45 | 1.15〜1.20 | 1.00〜1.05 |
| K = 1 | 1.44〜1.66 | 1.66〜1.88 | 2.09〜2.31 | 2.53〜2.75 |

- 予測どおり、粘性を強めると境目が上がるようになった。μ = 0 では K によらず同程度（モデルでも D = 0 では差がない）。
- K = 2 でも μ = 0.1 の境目は 2.09〜2.31（K = 1 と同じ）。
- N = 128、μ = 0.1、K = 1：2.15〜2.38（N = 64 と同程度。K = 0 では N とともに下がっていた、20・21）。
- **密度比 100**（ρ₂ = 0.01、N = 64、μ = 0.1、K = 1）：0.80〜1.03 で改善しない（K = 0 は 0.95〜1.00）。原因は未解明（セルの密度 ρ(ψ) と面の GFM 係数の違い、気相の大きな動粘性などが候補）。

精度（K = 0 → K = 1）：

| | K = 0 | K = 1 |
| --- | --- | --- |
| 静止液滴 N = 64、刻み 1 倍、10 ステップ：ジャンプ / 寄生流 | 4.00269 / 4.87e-5 | 4.00281 / 4.19e-5 |
| 毛管波（32 点、刻み √(5/12)）：誤差 / 減衰率の誤差 / 周期の誤差 | 0.0109 / −2.26% / +0.45% | 0.0108 / −2.29% / +0.45% |
| 毛管波、K = 1、刻み 2 倍 / 4 倍 | — | 0.0105 / 0.0105 |

- 精度は変わらない。
- K = 1 なら刻みを 4 倍にしても毛管波は同じ精度で、ステップ数が 1483 → 739、計算時間が 30 → 19 秒になる。出力時刻の間隔で刻みが決まるため、2倍と4倍は同じステップ数。

**立ち上がりの過渡：** 1 ステップ目の寄生流（刻み 1.6 倍、μ = 0.1）は、K = 0 / 1 / 2 / 3 で 8.8e-6 / 2.7e-3 / 2.5e-4 / 3.0e-5。
- 最初は圧力が釣り合っていない（p = 0）ので、K = 1 では反復が収束しきらない。反復1回ごとに約 1/10 に減る。
- その後は減衰する（K = 1 で 400 ステップ後 1.4e-8）。
