# 43. 波数分割型 CCD 残差補正の検討（2）：輸送と表面張力の随伴化

42 で減衰項 γQᵀMQ を検証した後の指摘を受けて、提案の P0「界面輸送と表面張力の随伴化（構造保存）」を検討した。
**エネルギー交換の整合性（随伴性）は、毛管波の精度の決め手ではなかった。** 決め手は、運動学と力の両方が渦層の厚さ δ より狭く界面に局在していること（鋭さ）である。

- スクリプト：`cases/adjoint_tension.py`（随伴型の表面張力）、`cases/capwave_jacobian.py`（`tension="adjoint"`、`force_weights=True`）、`cases/adjoint_tension_figures.py`
- 図：`docs/figures/adjoint_tension.png`

## 1. 随伴型の表面張力（ψ∇μ 型）
- **構成：**
  - plain の CLS 輸送は ψ̇ = −D_f(ψ_f uf) = −T(ψ)·uf で、uf について線形である。
  - 離散面積を A = Σ|Gψ|·V とする（G は CCD の 1 階微分）。μ = σ(∂A/∂ψ)/V とおく。
  - 面の力を F_f = −ψ_f(μ_R − μ_L)/Δ（壁面は 0）とすると、D_f の総和の部分積分から、任意の uf について Σ uf·F·V_f = −dE/dt が成り立つ。
- **確認：** 任意の面速度で、dE/dt = 94.652、力の仕事 = −94.652、和は 1.4e-14 だった。離散面積は 2.0484（厳密 2.0493）。
- **毛管波（法線モードから開始、時間積分。随伴型は |∇ψ| の線形化が遠方で滑らかでなく、縮約した Jacobian の残差が 0.3 で使えないため）：**

| N、粘性 | GFM（plain 輸送） | 随伴型 ψ∇μ |
| --- | --- | --- |
| 32、×1 | 減衰 −20.7%、周波数 −5.0% | 減衰 **−63.9%**、周波数 **−32.8%** |
| 32、×0.5 | | −85.1%、−33.3% |
| 32、×2 | | −45.4%、−32.8% |
| 64、×1 | −6.2%、−1.5% | −33.1%、−17.6% |
| 64、×2 | | −24.2%、−15.7% |

- エネルギーは厳密に整合するが、精度は大きく悪い。周波数の誤差は εk にほぼ比例する（εk = 0.59 / 0.29 で −33% / −18%）。#52 の CSF（−65%、周期 −33%）と同じ傾向で、力が幅 ε の帯に広がることによる。
- 連続系でいえば、ψ∇μ の勾配部分は圧力に吸収され、残りは σκ∇ψ（CSF）になる。随伴化しても、拡散界面の誤差は消えない。

## 2. 随伴の組を幅 h で作る（CLS の重みの運動学 + 同じ重みの GFM）
41 の CLS の運動学の重み w_f（界面の面で 0.57、±h で 0.23）で界面を動かし、GFM のジャンプも同じ重みで面に分配した。この組は随伴（エネルギー整合）である。

| δ/h | CLS の重みの運動学 + 鋭い GFM | 同じ重みで分配した GFM（随伴の組） |
| --- | --- | --- |
| 0.65 | −28.9% | −39.3% |
| 0.92 | −16.8% | −25.9% |
| 1.30 | −9.5% | −15.8% |
| 1.83 | −5.0% | −10.2% |

- 随伴の組にすると、かえって悪くなる。

## 3. まとめ：結合の幅
N = 32、×1（δ/h = 0.92）の減衰誤差：

| 運動学 | 力 | 結合の幅 | 随伴か | 減衰誤差 |
| --- | --- | --- | --- | --- |
| 鋭い（η での補間） | 鋭い GFM | 0 | はい | **+3.8%** |
| CLS の重み | 鋭い GFM | ~h（運動学のみ） | いいえ | −16.8% |
| CLS の重み | 同じ重みの GFM | ~h | はい | −25.9% |
| CLS の輸送 | ψ∇μ | ~ε | はい | −63.9% |

- **理論：** 運動学と力が幅 w の核で界面に結合すると、それは厚さ w の拡散界面の毛管波になる。渦層の v は界面に幅 δ の山を持つ（41）ので、w ≳ δ ではその山がならされ、エネルギーが整合していても減衰と周波数がずれる。
- 鋭い運動学（η での線形補間）と、θ で重み付けした GFM（その転置）は、それ自体が随伴の組である。「随伴かつ鋭い」組が、精度とエネルギー整合を両立する。
- 提案の構造保存の考え（f = T_hᵀ ∂E/∂φ）は、T_h を鋭い運動学に取れば、この組と一致する。

## 結論
- 随伴化は、エネルギー交換を厳密にするが、それだけでは毛管波の精度は改善しない。ψ∇μ 型（−63.9%）、幅 h の随伴の組（−25.9%）は、どちらも既定（−16.4%）より悪い。
- 改善には、運動学と力をともに鋭くする必要がある（+3.8%）。CLS で実装するなら、界面の速度を η で補間して法線方向に延長した速度で ψ を動かす（速度の延長）と GFM の組になる。質量保存は段階 B で閉じる。
- 既定値は変えていない（試作は `cases/` の中だけ）。

## 残り
