## 定式化と理論的根拠
### A. D の誤差の方程式（ユーザー）
C と D に同じ初期値 q₀（厳密なセル平均）を与える。そのため、初期値の射影の差はない。差 `e = q_D − q_C` は次を満たす：

```
G_A ė + K_ν e = (G_ν − G_A) q̇_C
```

右辺 `r = (G_ν − G_A)q̇_C` が誤差の源である。

固有値（Rayleigh 商 `qᵀK_νq/qᵀG_Aq`）では局所の誤差が内積で打ち消されうるので、固有値が 4 次でも速度の最大誤差は 3 次程度になりうる。そのため、固有値、時間発展、質量加重 L² 誤差、最大誤差を分けて見る。

### B. 壁の境界（ユーザー）
面は f = 0 … N（N + 1 個）。壁の面の ψ は片側だけ。部分積分で、厳密に次が成り立つ：

```
q₀ − u_L = ∫ψ₀τ/μ,   u_R − q_{N−1} = ∫ψ_Nτ/μ   →   Hτ = D_b q + b,   b = (−u_L, 0, …, 0, u_R)
```

M の内積の方式（A）では、`M q̇ = −D_bᵀτ + F` から、収支は次のとおり：

```
d/dt Σmq = τ_N − τ₀ + ΣF
d/dt(½qᵀMq) = −τᵀH₄τ + u_Rτ_N − u_Lτ₀ + q·F      （τ = H₄⁻¹(D_bq + b)）
```

右辺の壁の項は、壁がする仕事である。動く壁の Couette ではエネルギーが供給されるので、「エネルギーが増えない」ではなく、収支そのものを確かめる。

最小粘性エネルギーの形（C）は、壁の値を満たす再構築（`τ = H⁻¹(D_bq + b)`）で、固定した壁では `G_ν q̇ = −K_νq + F`、`K_ν = D_bᵀH⁻¹D_b`。

### C. 力の種類と厳密さ（重要）
定常では `τ' = −f`。

- **加速度の力**（f = ρg、重力の型）：応力は質量座標で線形。最小粘性エネルギーの応力の再構築（質量座標で線形）で厳密。
- **体積力**（f = 一定、圧力勾配の型）：応力は x について線形。密度が跳ぶ混合セルでは、質量座標で折れるので厳密ではない。
- 非定常の Stokes（`τ' = −λρu`）は、加速度の型で 4 次。
- 圧力の射影（P2）では、圧力勾配は体積力の型で働く。粘性の演算子と圧力の勾配の接続で、この点が効く。

## まとめ
- **粘性の方式**：統合の主候補は D、参照解法は C（ユーザーの判断）。H₃、射影 E、DG 型は保留。
- **D の精度の低下の原因**：相分離 PCCD の列の端の式（大半の条件）と、混合セルの補正（粘度だけが跳ぶ条件）。本当の単相 PCCD では D と C は同じ精度。
- **壁**：`Hτ = D_bq + b` で、運動量とエネルギー（壁の仕事を含む）の収支は厳密。Couette は厳密。最小粘性エネルギーの形は、加速度の力の Poiseuille で厳密、壁のある非定常 Stokes で 4 次。
- ~~**注意**：体積力（圧力勾配の型）の Poiseuille は、密度が跳ぶと 2〜3 次。圧力の射影との接続（P2）で、応力の再構築を質量座標で線形とすることの限界になる。~~ 訂正：限界ではない。外力の整合した離散化で厳密（ノート102）、始動流でも 4 次（ノート103）。
- **D の剛性 479**（動粘度一定の極端な場合）は、陰的な粘性の求解を前提に、現段階では許容する（ユーザー）。

## 次（ユーザーの順序）
1. **二次元化（格子に平行な界面）**：厳密な界面で、PCCD–Galerkin の移流と D の粘性を、同じ Gram の行列で組み合わせる。
   - 粘性の小ステップでは界面を固定し、移流の小ステップで Gram を更新する分割（Strang）にする。各写像がエネルギーを増やさなければ、組み合わせも増やさない。
   - 全粘性応力テンソル、混合微分、接線・法線方向の応力の接続を確かめる（一次元のスカラーの粘性を各方向に当てるだけで十分とは仮定しない）。
2. 壁の PCCD の端（D の壁の場合）。
3. 圧力の射影（体積力の型の応力の扱い、C 節）。
