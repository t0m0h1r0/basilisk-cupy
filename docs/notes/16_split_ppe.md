# 16 分相 PPE と圧力ジャンプ（GFM）（PR #31）

## 方法
論文の圧力ジャンプ型閉包（09b1、09b3）を、Basilisk の2次の FV 射影に入れた。`TwoPhaseCLS(..., pressure_jump=True)`。

- 界面は、各面で ψ = 1/2 となる位置。セル中心間の線分上の割合 θ = (ψ_L − ½)/(ψ_L − ψ_R)。
- **ジャンプ補正付き面勾配：** G_Γ(p; j) = Gp − B(j)、B(j) = j (H_R − H_L)/Δ、H = [ψ > ½]。
  - j = σκ（＋換算重力 [ρ]G·x）。両隣のセル値を θ で線形補間して交差位置での値にする。
  - 実装は面の加速度 α_f B(j) として入れる。これは iforce.h の f を鋭い H に替えた形と同じ。
  - その結果、射影・速度補正・セル中心の勾配のすべてが同じ G_Γ を使う（論文の式 affine_pressure_history_faces と同じ面空間で閉じる）。
- **分相（相ごとに定数密度）：**
  - 相の内部の面では α_f = 1/ρ_k。
  - 界面で切れる面では、[α ∂ₙp] = 0 から決まる GFM の係数 α_f = 1/(θρ_L + (1−θ)ρ_R)。
  - この演算子を1回マルチグリッドで解くことは、2つの定数密度の問題をジャンプ条件でつないで解くことと同じ。
- **HFE は不要：** HFE は論文の CCD ステンシルが界面をまたぐのを防ぐためのもの。ここでは面の2点ステンシルしか使わず、ジャンプは B(j) で既知になるので出番がない。
- セルの密度（運動量、粘性）と面の粘性は ψ のまま。
- 論文の毛管補正量の鞍点系、欠陥補正（DC）、FCCD による高次化は今回は入れていない。

## 静止液滴（R = 0.25、σ = 1、μ = 0.1、10 ステップ）
圧力ジャンプ / 寄生流の最大値：

| N | 32 | 64 | 128 |
| --- | --- | --- | --- |
| CSF（15） | 4.3014 / 3.6e-4 | 4.0230 / 3.2e-4 | 3.9410 / 1.7e-4 |
| GFM | 4.0091 / 3.3e-4 | 4.0027 / 4.9e-5 | 4.0010 / 8.6e-6 |

- GFM のジャンプは 4 に収束し（およそ2次）、寄生流はおよそ h^2.5 で減る。
- **長時間（N = 64）：** 400 ステップで寄生流は 1.1e-8 まで減衰する（CSF 2.4e-4、VOF 6.1e-8）。密度比 10 でも 1.6e-7。
- **密度比 1000（ρ₂ = 0.001）：** 100 ステップまでは 1.2e-5 だが、tension.h の時間刻み上限 √(ρ_m Δ³/(πσ))（ρ_m は両相の平均）では 400 ステップで発散した（2.7）。
  - dt を半分にすると安定で、800 ステップで 1.6e-7。
  - 気相側に寄った切断面では α_f が 1/ρ_g に近くなり、ρ_m で見積もった上限では足りない。
  - セルの密度も鋭く（H で）すると、かえって不安定になる（200 ステップで 3.6e-2）。
- 密度比 100 は 400 ステップで 8.7e-4（増加中）。
