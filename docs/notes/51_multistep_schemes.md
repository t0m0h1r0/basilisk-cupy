# 51 時間積分の差し替え（1）：多段法の IMEX と界面の輸送（PR #66）

## ねらい
時間積分を差し替えて比べられるようにする（ユーザーの要望：陽的・陰的それぞれ複数、Runge–Kutta を含む）。二段に分ける。

- **第一段**
  - 本 PR：多段法（係数の表で作れるもの）、界面の輸送の速度、ψ の積分法。
  - 次の PR：二相の IMEX-RK。
- **第二段：** 界面を含めた連成反復、回転形 IPC、ARK と誤差推定による刻みの自動調整。

既定は論文どおり（SBDF2 = BDF2 + EXT2、ψ は u_f^n の凍結で TVD-RK3）のままとする。

## 構成
### 係数（`basilisk_cupy/time/schemes.py`）
多段法の IMEX は、次の形で一つにまとめた。

    Σ_j α_j u^{n+1−j} = Δt [ Σ_j β_j E^{n−j} + Σ_j γ_j V^{n+1−j} ]

ここで E は陽的な項（対流）、V は陰的な項（粘性）である。係数は毎ステップ、実際の時刻の点から Lagrange 多項式で計算する。そのため、可変の刻みでも正確である。

| 族 | 種類 | 係数 |
| --- | --- | --- |
| `bdf1`〜`bdf4` | 陰的 | α：時刻 n+1 での補間多項式の微分、γ = (1) |
| `am2`〜`am4` | 陰的 | α = (1, −1)、γ：補間多項式の区間での積分（`am2` = Crank–Nicolson） |
| `theta<値>` | 陰的 | γ = (θ, 1 − θ)（`theta1` = 後退 Euler） |
| `ext1`〜`ext4` | 陽的 | 時刻 n+1 への外挿（BDF の相方） |
| `ab1`〜`ab4` | 陽的 | Adams–Bashforth（AM・θ の相方） |
| `mcnab2` | 組 | 修正 CNAB2（Ascher–Ruuth–Wetton 1995）：γ = (9/16, 3/8, 1/16)、β = (3/2, −1/2)。刻みは一定のみ |
| `cnlf` | 組 | Crank–Nicolson leap-frog：α = (½, 0, −½)、β = (1)、γ = (½, 0, ½)。刻みは一定のみ |

- 名前付きの組：`sbdf1`〜`sbdf4`、`cnab2`。任意の組 `("am3", "ab3")` なども指定できる。
- 族の合わない組（`bdf2` + `ab2` など）も許すが、1 次になる。
- **立ち上がり：** 履歴が足りないときは次数を自動的に下げる。
  - `sbdf3` は 1 ステップ目が `sbdf1`、2 ステップ目が `sbdf2`。
  - `cnab2` の 1 ステップ目は V^n がないので後退 Euler。
  - `mcnab2` は V^{n−1} がそろうまで `cnab2`。
- ψ の陽的 Runge–Kutta の表：`euler`、`ssprk2`、`ssprk3`、`heun3`、`rk4`。

### 時間積分器（`basilisk_cupy/time/imex_multistep.py`）
`IMEXMultistepNS`：上の式を α₀ で割り、σ = Δt/α₀、τ = σγ₀ とする。

    (I − τV) u* = Σ_{j≥1} (−α_j/α₀) u^{n+1−j} + σ ( Σ β_j E^{n−j} + Σ_{j≥1} γ_j V^{n+1−j} + g^n )

その後、`IMEXBDF2NS` と同じ増分射影を、射影の刻み σ で行う（圧力は陰的な時刻の Lagrange 乗数）。

- `sbdf2` は `IMEXBDF2NS` と 1e-12 以内で一致する（CFL による可変の刻みを含む）。
- 過去の粘性項 V^k は、解いた予測子から V^k = (u*_k − rhs_k)/τ_k として保存する（`IMEXRKNS` の段と同じ扱い）。射影後の u^k ではなく u* に粘性の演算子を作用させたものになる。
- 陽的な対流の安定限界は、族によらず EXT2 の値を使っている（族ごとの限界は未適用）。

### 二相（`TwoPhaseIMEX`）
| 引数 | 値 |
| --- | --- |
| `scheme` | 上の任意の多段法（既定 `"sbdf2"`） |
| `transport` | `"frozen"`（u_f^n、論文。旧名 `"projected"`）、`"ab2"` / `"ab3"`（Adams–Bashforth の区間平均、可変の刻み対応）、`"pc"`（予測子・修正子：u_f^n で 1 回進めて u_f^{n+1} を予測し、状態を戻して ½(u_f^n + u_f^{n+1}) で進め直す。費用は 2 倍） |
| `psi_integrator` | `"ssprk3"`（論文の TVD-RK3）、`"ssprk2"`、`"heun3"`、`"rk4"`、`"euler"`（各段の値を [0, 1] に切り詰める） |

## 1. 単相の実効次数（`cases/time_order.py`）
周期の単位正方形、fd2、μ = 0.05、二つのモード（kx ≠ ky）の初期の速度、t = 0.2、自己収束（1280 ステップを基準）。刻みを半分にするごとの次数：

| 方式 | N = 16、NS | N = 16、Stokes | N = 64、Stokes | N = 64、NS |
| --- | --- | --- | --- | --- |
| sbdf1 | 0.99 / 1.01 / 1.04 | 0.99 / 1.01 / 1.04 | — | 0.99 / 1.01 / 1.04 |
| sbdf2 | 1.70 / 1.02 / 0.86 | 2.18 / 1.78 / 1.36 | 2.31 / 2.07 / 2.02 | 2.41 / 2.25 / 2.34 |
| sbdf3 | 2.07 / 2.04 / 1.64 | 1.90 / 1.94 / 1.94 | 1.91 / 1.97 / 1.99 | 1.92 / 1.99 / 2.03 |
| sbdf4 | 2.04 / 2.10 / 1.69 | 1.91 / 1.93 / 1.93 | — | 1.93 / 1.97 / 2.01 |
| cnab2 | 1.79 / 1.48 / 0.99 | 1.88 / 1.89 / 1.76 | 1.92 / 1.95 / 1.98 | 1.95 / 2.02 / 2.11 |
| mcnab2 | 1.63 / 1.15 / 0.86 | 1.85 / 1.84 / 1.44 | 1.91 / 1.95 / 1.97 | 1.96 / 2.06 / 2.18 |
| cnlf | 1.77 / 1.18 / 0.82 | 2.01 / 1.78 / 1.46 | — | 2.09 / 2.13 / 2.26 |
| am3 + ab3 | 2.06 / 1.65 / 1.31 | 1.90 / 1.92 / 1.91 | — | 1.94 / 2.00 / 2.07 |
| theta0.6 + ab2 | 1.17 / 1.12 / 1.10 | 1.14 / 1.09 / 1.09 | — | 1.14 / 1.10 / 1.09 |

- **N = 16 で次数が 1 に落ちる原因：** kx ≠ ky の初期場は、セル中心の離散発散が厳密に 0 ではない（Taylor–Green の kx = ky では 0 になる）。近似射影が毎ステップその一部を取り除くので、O(Δt h²) の交差項が残る（`imex_bdf2.py` の説明と同じ）。N = 64 では h² が 1/16 になり、Stokes でも NS でも 2 次に戻った。**kx = ky の検証ではこの劣化は見えない。**
- **3 次以上の方式も 2 次止まり：** 増分圧力補正（IPC）の分割誤差は O(Δt²) である（Guermond–Minev–Shen 2006）。SBDF3 の誤差は SBDF2 の約 6.5 倍で、高次の BDF は IPC と組むとかえって悪い（N = 64、Stokes、80 ステップで 4.2e-5 対 6.1e-6）。
- θ = 0.6 は 1 次（理論どおり）。
- 費用：N = 16 の全 50 条件が 28 コアで 23 秒。
