# 19 高密度比での表面張力の時間刻み（PR #34）

## 現象
- 静止液滴（R = 0.25、σ = 1、両相の μ = 0.1、N = 64）を GFM で解くと、密度比 100・1000 では寄生流が指数的に増えて発散した（16）。
- 時間刻みは tension.h の √(ρ_m Δ³/(πσ))（ρ_m は両相の平均）。

## 切り分け（N = 64、400〜500 ステップ）
| 条件 | 密度比 100 | 密度比 1000 |
| --- | --- | --- |
| VOF（Basilisk そのもの） | 減衰（1.6e-10） | 減衰（2.7e-10） |
| CLS＋GFM | 増大（2.2e-2） | 発散（5.6e-1） |
| CLS＋GFM、界面の移流を止める | 一定（1.9e-4） | 一定（1.9e-4） |
| CLS＋GFM、μ = 0.01 または 0、あるいは両相の ν をそろえる | 安定 | 安定 |
| CLS＋GFM、曲率を2次差分で求める | 安定（1.4 倍の刻みでは不安定ぎみ） | 安定（1.4 倍では増大） |
| CLS＋GFM、刻みを 0.9 倍 / 0.8 倍 / 0.7 倍 | 安定 | 安定 |
| N = 32（刻み 1 倍） | 安定 | 安定 |

- 界面を止めると安定するので、原因は「界面の移動 → 曲率 → 圧力ジャンプ → 速度」という陽的な毛管のループ。
- 曲率を2次差分に替えると安定するので、CCD 曲率の硬さが原因。
- 粘性を小さくすると安定する理由は未解明。

## 理由
- 格子規模の波（kh = π）に対する2階微分の応答は、2次差分で 4/Δ²、CCD（Chu–Fan）で 48/(5Δ²) = 9.6/Δ²（厳密値 π² = 9.87 に近い）。
  - CCD の第2式は f′ = 0 のとき f″(1 + ¼) = −12/Δ² になるので 9.6。
- tension.h と論文（07d の式 dt_sigma）の上限は同じ式 √((ρ_l + ρ_g)Δ³/(2πσ))。
  - 2次差分の曲率なら、最も硬いモードに対して √(9.87/4) ≈ 1.6 倍の余裕がある。
  - CCD 曲率では余裕がほとんどなく、測定でも臨界は 0.9〜1.0 倍の間だった（N = 64、密度比 100・1000）。
- 2次差分と同じ余裕を取り戻す係数は √(4/9.6) = √(5/12) ≈ 0.645。

## 実装
- `TwoPhaseCLS(..., capillary_dt_factor=CCD_CAPILLARY_DT_FACTOR)` で、tension.h の上限に √(5/12) を掛ける。
- 既定は √(5/12)。15〜18 の測定は tension.h の上限（係数 1）で行ったもので、そのテストは係数 1 を明示している。

## 測定（係数 √(5/12)、GFM、寄生流の最大値）
| N | 密度比 1 | 10 | 100 | 1000 |
| --- | --- | --- | --- | --- |
| 32（t = 0.4） | 6.1e-6 | 9.4e-7 | 4.4e-7 | 1.3e-7 |
| 64（t = 0.4） | 1.1e-7 | 1.3e-8 | 3.2e-8 | 3.9e-8 |
| 128（t = 0.15） | — | — | 1.2e-6（減少中） | 5.4e-7（減少中） |

- どの密度比でも寄生流は減衰した。
- 計算量は 1.55 倍（ステップ数 524 → 805）。
- CSF（ψ の拡散界面）は係数を掛けても、密度比 100・1000 で 1e-2 程度の突発的な増大が残る（未解明）。

検証は 20：曲率の硬さの比は支持されたが、境目の絶対値は N・粘性・密度比に依存する。
