# 17 移流後の ψ 曲率：誤差の出どころ（PR #32）

## 定式化と理論的根拠
- **界面の位置の格子規模のばらつきが曲率を収束させない理由**：位置のばらつき a が h によらず一定（2e-4）なら、曲率の誤差は `a(π/h)²`（ノート76）で、h とともに増える。表の曲率の誤差の増加（0.394 → 0.805）と同じ向き。
- **再初期化で収束する理由**：圧縮・拡散の拡散項は、界面に沿った格子規模の乱れを減衰させる（等方拡散、ノート26）。毎ステップかけると、ばらつきが h の高いべきで小さく保たれ、曲率が収束する。
- **毛管波の誤差が曲率で決まらない理由**：理想的な曲率に替えても良くならなかったので、誤差は他の部分（ノート18 で移流の D_f の誤差、ノート41 で運動学）から来る。

## 問い
移流後の ψ 曲率は収束しない（14）。また毛管波（GFM）は VOF の 2〜6 倍の誤差だった（16）。曲率の求め方を変えれば改善するか。

## 結論
- 誤差の出どころは曲率の式ではなく、移流された界面そのもの。
- 圧縮・拡散型の再初期化を毎ステップかけると、曲率は収束する（2〜3次）。ただし細い糸状の界面は削られる。
- 毛管波（GFM）の誤差は曲率では決まっていない。理想的な曲率に替えても良くならない。

- 理想的な曲率でも改善しないので、毛管波の誤差は曲率ではない。
- 再初期化をかけるとむしろ悪化する。振幅 0.01 は 1波長 32 点で 0.16Δ しかなく、再初期化による界面のわずかな移動が効く。
- 振幅の測り方（交差の最大値 → 交差のフーリエ係数）を変えても同じ（0.217 / 0.0955 / 0.0282 / 0.0130）。
- t = 0 の振幅は、交差の線形補間のために 0.00982 / 0.00983 / 0.00987 / 0.01001 になる（1.5% 小さい）。
- 残る候補は ψ の移流（界面位置のばらつき 2e-4 は振幅の 2%）。ε を広げると 32 点でわずかに良くなる。
