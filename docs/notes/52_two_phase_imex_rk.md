# 52 時間積分の差し替え（2）：二相の IMEX Runge–Kutta（PR #67）

## 構成
### 表（`basilisk_cupy/time/imex_rk.py`）
ARS 型（第 1 段は陽的だけ、陰的部分の対角は一つの γ）の表を、既存の (3,4,3)・(4,4,3) に加えた。

| 表 | 陰的部分 | 次数 | 陽的部分の虚軸 / 実軸の安定限界 | stiffly accurate（陽 / 陰） |
| --- | --- | --- | --- | --- |
| `ars111` | 後退 Euler（陽的部分は前進 Euler） | 1 | 0 / 2.0 | ✓ / ✓ |
| `ars121` | 陰的中点則 | 2（陰的部分） | 0 / 2.0 | ✗ / ✗ |
| `ars222` | L 安定 SDIRK2（γ = 1 − 1/√2） | 2 | 0 / 2.0 | ✓ / ✓ |
| `ars233` | SDIRK3（γ = (3 + √3)/6） | 3 | 1.732 / 2.512 | ✗ / ✗ |
| `ars343` | L 安定 SDIRK3 | 3 | 2.828 / 2.785 | ✗ / ✓ |
| `ars443` | L 安定 | 3 | 1.569 / 2.142 | ✓ / ✓ |

- 安定限界は `axis_limits` で安定関数から測った（(3,4,3)・(4,4,3) は既存の値と一致）。
- 陰的部分が stiffly accurate でない表のために、最後を u^n + Δt Σ_j (b_E,j C_j + b_I,j V_j) として、p^n から射影し直す一般の形を加えた。
- 虚軸上に安定域のない表（`ars111`、`ars121`、`ars222`）では、`IMEXBDF2NS` の EXT2 と同じく、対流の刻みの制限を掛けない（散逸のない対流は粘性で安定に保つ）。以前は Δt = 0 を返していた。
- Pareschi–Russo の IMEX-SSP は第 1 段が陰的で、ARS 型の構造に収まらないため入れていない（第二段の ARK と一緒に扱う）。

### 二相（`basilisk_cupy/time/two_phase_imex_rk.py`）
`TwoPhaseIMEXRK` では、ψ を同じ表の陽的な成分として段ごとに進める。多段法の `TwoPhaseIMEX` が、ψ を 1 ステップに 1 回、凍結した速度で運ぶのとはこの点が違う。段 i の処理：

1. ψ_i = ψ^n + Δt Σ_j AE_ij R(ψ_j, u_f,j) を [0, 1] に切り詰める。R は CLS の流束 −D_f(ψ u_f)。
2. ψ_i から物性（ρ、α、μ）を作る。
3. 粘性を陰的に解く。
4. ψ_i の界面でジャンプの面加速度を作る。
5. 刻み c_i Δt で IPC の射影を行う。

最後に ψ^{n+1} = ψ^n + Δt Σ b_E,j R_j とし、質量を閉じる。陽的部分が stiffly accurate な表では、最後の段の界面がそのまま ψ^{n+1} になる。

80 ステップでの誤差（N = 64）：

| 表 | NS | Stokes |
| --- | --- | --- |
| ars222 | 5.4e-6 | 5.3e-6 |
| ars233 | 3.3e-6 | 2.7e-7 |
| ars343 | 3.1e-6 | 8.2e-8 |
| ars443 | 3.9e-6 | 7.4e-8 |

- **Stokes では 3 次の表が 3 次になる（N = 64）。** 各段で射影するので、多段法の SBDF3（IPC の分割誤差で 2 次止まり、ノート51）とは違って、増分圧力補正の O(Δt²) の分割誤差に縛られない。
- **対流があると、誤差が約 3e-6 で止まる。** Stokes では 7e-8 まで下がるので、床は対流の項に関係している。候補は、対流と近似射影の交差項（kx ≠ ky の初期場はセル中心の離散発散が 0 でなく、近似射影が毎回その一部を取り除く。N = 16 では Stokes でも 1 次に落ちる）だが、切り分けはしていない。2 次の表（ars121、ars222）の誤差は床より大きいので、この範囲では 2 次のまま。
- 意味：この組み合わせでは、対流のある流れで 3 次の時間積分は誤差を 3e-6 より下げない。Stokes 型の問題（粘性・表面張力が支配的な毛管波など）では、3 次の効果が出うる。

## 2. 二相（`cases/time_schemes.py --schemes ars...`、毛管波 24 条件と安定限界 12 条件、111 分）
条件は多段法（ノート51 の 2 節）と同じ：毛管波は等密度・16 点・一定の刻み STEP/d、静止液滴は N = 32、600 ステップ、安定限界は tension.h の刻みの倍率。

| ars111 | −14.91 / −12.52 / −12.74 / −12.76 | 1.09 / 0.92 |
| ars121 | −5.39 / −9.13 / −10.94 / −11.85 | 1.41 / 1.19 |
| ars222 | −5.84 / −9.28 / −11.00 / −11.89 | 1.00 / **0.60** |

| ars443 | −5.25 / −9.06 / −10.90 / −11.84 | **1.68 / 1.41** |

（周期の誤差は、すべて +3.6〜+3.8%。）

- **2 次・3 次の表は、どれも 1 次の刻み依存を示す**（変化は 3.7 / 1.8 / 0.9 ポイントと半分ずつ）。極限は多段法と同じ約 −12.7%。ψ を段ごとに進めても消えないので、段の中でのジャンプと圧力の時刻の扱いに原因があると見られる（多段法の CN 系と同じ形。未確認）。
- **安定限界は ars443 が最も高い**（1.68 / 1.41。多段法の最良の sbdf3 は 1.54 / 1.30）。
- **ars222 は密度比 1000 で 0.60 倍しかなく、既定の刻み（0.645 倍）でも不安定になる。** 二相で使うときは刻みを下げる必要がある。
- 費用：段の数だけ射影と粘性の解法が増えるので、1 ステップは多段法の 2〜4 倍。
