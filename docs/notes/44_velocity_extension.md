# 44. 鋭い界面運動学（帯の速度補正）＋ GFM

> **追記（45）：** 下の「残る減衰しすぎはこの吸収と同じ向き」「随伴でないことに関係すると考えられる」は、因果を示していなかった。GFM に整合する鋭い界面のエネルギーで測ると、補正後の非随伴性は −2% と小さく、減衰しすぎ（+8%、厳密な曲率の固有値）の原因ではない。そのうち半分は時間刻みによる。

41・43 で、毛管波の減衰不足の主因は CLS の輸送が界面を ±h の範囲で平均した速度で動かすこと、決め手は運動学と力の鋭さだと分かった。
ここでは、CLS で鋭い運動学を実現する方法を `cases/` に独立実装し（本体の CLS 輸送は変えていない）、毛管波と副作用を測った。

- スクリプト：`cases/velocity_extension.py`（`attach(cls)` で `cls.advect` を差し替える）、`cases/velocity_extension_checks.py`、`cases/velocity_extension_figures.py`
- 図：`docs/figures/velocity_extension.png`

## 1. 試した方式と、捨てたもの
| 方式 | 毛管波（N = 32、×1） | 一様な並進（N = 32 / 64、ψ の L1） | 判定 |
| --- | --- | --- | --- |
| 最寄りの交点の V_n を延長し、−D_f(ψ_f w) + ψD_f w で輸送 | −0.9% | 3.4e-2 / 4.8e-2（既定 6.0e-3 / 5.0e-3） | 捨てる |
| 足の点 x − φn での V_n を延長（同じ面の形） | −1.0% | 4.1e-2 / 5.5e-2 | 捨てる |
| 同、−w·∇ψ（CCD の勾配） | −0.8% | 1.1e-1 / 1.0e-1 | 捨てる |
| 帯の補正、保存形（D_f(ψ_f(uf + δ))） | +12.7% | 6.0e-3 / 5.0e-3 | 捨てる（圧縮項 −ψ∇·δ が交点を動かす） |
| 帯の補正、セルで作って面へ平均 | +11.9% | 6.0e-3 | 捨てる（面→セル→面の平均が v の尖りの 2 階差分を足す） |
| **帯の補正、面の上で作り、圧縮なしで運ぶ（採用した試作）** | **+3.4%** | **6.0e-3 / 5.0e-3（一致）** | |

- **延長速度で ψ 全体を運ぶ方式は、界面から離れた所で失敗する。** 法線 n は中心で特異になり、ψ が飽和しない所では不定である（R/ε = 3.2）。延長速度 V·n はそこで不連続になり、非保存形の中心差分がそれを拾う。誤差は N とともに増える。
- **採用した方式：** 保存形の輸送はそのまま uf で行い、界面付近の帯の中だけ、面の法線速度を界面での値に置き換える補正 δ を加える。
  - 面 a の上で δ = χ(V − u·n)n_a とする。V は面の位置からの足の点 x_f − φn での n·u（双線形補間）。u·n は面の値と、他方の成分の 4 面の平均から作る。χ = exp(−(φ/4ε)⁴)。
  - ψ_t = −D_f(ψ_f uf) − [D_f(ψ_f δ) − ψ D_f δ] とする。補正の部分は、圧縮なしの非保存形で運ぶ。質量は段階 B で閉じる。
  - 速度が帯の中で一様なら δ = 0 で、既定と完全に一致する（一様な並進で差 1e-12 未満、テスト）。速度が帯の中で急に変わる所（渦層）でだけ働く。

## 2. 毛管波（法線モードから開始、移流あり、ψ 曲率）
| N、粘性 | δ/h | 既定（CLS の輸送） | 帯の補正 |
| --- | --- | --- | --- |
| 32、×0.5 | 0.65 | −27.8%（周波数 −4.1%） | −2.3%（+0.7%） |
| 32、×1 | 0.92 | −16.4%（−3.4%） | +3.4%（+0.5%） |
| 32、×2 | 1.30 | −9.1%（−3.0%） | +3.2%（−0.1%） |
| 64、×0.5 | 1.30 | −7.4% | +5.7%（+0.8%） |
| 64、×1 | 1.83 | −3.8%（−0.6%） | +3.5%（+0.3%） |
| 64、×2 | 2.59 | −2.0%（−0.6%） | +1.7%（0.0%） |
| 128、×1 | 3.66 | +0.5%（−0.1%） | +2.0%（0.0%） |

- 鋭い基準（41：固有値で +3.8%、−1.1%）とほぼ同じ水準になった。周波数は、すべての N で既定より良い。
- 残る減衰しすぎ（+2〜+6%）は N とともにゆっくり下がる（×1 で +3.4 / +3.5 / +2.0%）。N = 128 では既定（+0.5%）の方が良い。
- **エネルギー交換：** 力の仕事 − 表面エネルギーの変化（38 の分解、減衰率に対する割合）は、既定の −13.2%（注入）から、+9.9%（N = 32）、+3.5%（N = 64）の吸収に変わる。補正した運動学と GFM の力は厳密な随伴ではない。残る減衰しすぎは、この吸収と同じ向きである。

## 3. 副作用
| 試験 | 既定 | 帯の補正 |
| --- | --- | --- |
| 一様な並進（周期、N = 32 / 64、ψ の L1） | 6.00e-3 / 5.04e-3 | 同じ |
| 変形流（reversed、sharp L1、N = 64 / 128） | 0.0306 / 0.0139 | **0.0278 / 0.0084** |
| 変形流の質量 | 2e-15 / 8e-15 | 9e-15 / 8e-15 |
| 静止液滴のジャンプ（N = 32 / 64） | 4.0101 / 4.0030 | 同じ |
| 静止液滴の寄生流、400 ステップ後（N = 32 / 64、密度比 1） | 1.8e-7 / 6.8e-7 | 2.1e-6 / 6.3e-6 |
| 同、密度比 100 | 8.8e-9 / 4.4e-7 | 1.3e-7 / 4.8e-6 |

- 変形流では、界面の形の誤差が改善した（N = 128 で 0.0139 → 0.0084）。
- 静止液滴の寄生流は、減衰が約 10 倍遅い。ただし減衰はしている。

## 合格条件との対照（暫定の研究目標）
| 指標 | 結果 |
| --- | --- |
| 毛管波の減衰誤差：+3.8% の鋭い基準に近づく | 達成（+3.4% / +3.5% / +2.0%） |
| 周波数の誤差：−1.1% 程度 | 達成（+0.5% / +0.3% / 0.0%） |
| エネルギー交換：半離散の恒等式が丸め誤差 | **未達**（+3.5〜+9.9% の吸収。随伴ではない） |
| 体積保存：悪化しない | 達成（段階 B で 1e-15） |
| 静止液滴：寄生流・ジャンプの悪化なし | ジャンプは達成。寄生流の減衰は約 10 倍遅い（**未達**） |
| 格子収束：N = 32/64/128 で改善傾向 | 周波数は達成。減衰はゆっくり（+3.4 → +2.0%）で、N = 128 では既定の方が良い |

## 結論と次の段
- 帯の補正により、粗い格子（δ/h ≲ 2）の毛管波の減衰不足は解消した（N = 32、×1：−16.4% → +3.4%）。周波数と変形流も改善した。
- 未達は、エネルギー交換の厳密な整合と、静止液滴の寄生流の減衰の遅さである。どちらも、補正した運動学と GFM の力が随伴でないことに関係すると考えられる（未確認）。
- 本体への反映は、これらを詰めてから判断する。
- 次の候補：GFM の力を、補正した運動学の転置（足の点の補間の転置）として作り、半離散の恒等式を満たす組にする。その後、密度で重み付けした圧力射影（P0-4）。
