# 54 再初期化の二つの閉鎖（λ_Γ、ε_eff）と、再初期化が曲率に入れる雑音（PR #68）

## 定式化と理論的根拠
### λ_Γ が一意に決まらない理由
セルの数で数える体積 `V_Γ,h(λ) = Σ [φ_i + λ > 0] dV` は、λ について階段関数（φ_i + λ の符号が変わるときだけ跳ぶ）。`V_Γ,h(λ) = V₀` の解は区間になるか、存在しない。連続な形 `Σ clip(½ + (φ+λ)/h, 0, 1) dV` は λ の連続な単調関数なので、二分法で一意に解ける。

### 幅で質量を合わせる問題の条件が、平らな界面で悪い理由
プロファイル `H_ε(φ) = 1/(1 + e^{−φ/ε})` の拡散した質量を、界面からの距離 φ と、界面に沿った座標で書く。面積要素は `(1 + κφ) dφ dl`（κ は曲率、φ の 1 次まで）。

`H_ε(φ) − H(φ)` は φ の奇関数なので、`∫(H_ε − H) dφ = 0`。曲率の項からだけ次が残る：

```
∫ φ (H_ε − H) dφ = −2 ∫₀^∞ φ/(1 + e^{φ/ε}) dφ = −(π²/6) ε²

M(ε) = M₀ − (π²/6) ε² ∫ κ dl + O(ε³),   dM/dε = −(π²/3) ε ∫ κ dl
```

- **平らな界面**（κ ≈ 0）：dM/dε ≈ 0 で、幅は質量をほとんど動かさない。わずかな質量のずれを幅で合わせようとすると、幅が大きく振れる（ε_eff が探索範囲の端 4 倍・1/4 に張り付く）。
- **閉じた界面**：`∫κ dl = 2π`（二次元）で dM/dε ≠ 0 なので、条件は穏当（液滴で ε_eff/ε = 1.02）。

本文 1 節の「dM/dε は曲率に比例」の導出。

### 再初期化の小さな凹凸が、曲率を大きく狂わせる理由
ノート76 の桁の見積もり `δκ ~ π² δψ / h` と同じ機構。ψ の格子規模の変化 δψ = 2.8e-2（N = 32）は、`δκ ~ 10 × 0.028 × 32 ≈ 9` を生む。真の曲率 4 の 2 倍程度で、表の曲率の幅（−6.35〜18.0）と同じ桁。

## ねらい
論文 11b1 第2段（05 章の式 ridge_eikonal_sharp_volume_shift、ridge_eikonal_diffuse_mass_width）の再初期化を確かめる。手順は二つの閉鎖からなる。

1. 符号付き距離 φ_sdf を一様にずらして（λ_Γ）、鋭い界面の体積 V_Γ,h を閉じる。
2. プロファイルの幅 ε_eff を変えて、拡散した質量 M_ψ,h を閉じる。

本移植の既定の ξ-SDF は、一様なずらしで拡散した質量だけを閉じる（ノート13）。

## 論文の記述の問題
- **λ_Γ が一意に決まらない：** V_Γ,h は「閾値化相体積」で、セルの数で決まる。そのため、一様なずらしに対して階段関数になり、λ_Γ が区間で決まってしまう。本実装では、連続な形 V(φ) = Σ clip(½ + φ/h, 0, 1) dV に置き換えた（`CLSInterface.sharp_volume`）。
- **記述の食い違い：** 05a の末尾は「標準アルゴリズムでは、段階 F が φ 空間の一様シフトで液相体積を閉じる」と書き、05 章（ずらしで体積、幅で質量）と食い違う。

## 実装
`reinitialize(method="xi_sdf_vw")`（既定は変えない）：

1. ξ-SDF の距離を作る。
2. λ_Γ を二分法で求め、V を合わせる。
3. Σ H_ε_eff(φ + λ_Γ) dV = M を、ε_eff ∈ [ε/4, 4ε] の二分法で解く。符号が変わらないときは、残差が最小の幅を使う。
4. `reinit_info` に λ_Γ、ε_eff/ε、二つの残差を記録する。

- それでも再初期化を入れると、どの形でもジャンプが +12〜14% ずれ、寄生流は 100〜1000 倍になる。

### 原因：再初期化が入れる小さな凹凸を、ψ の CCD 曲率が増幅する
流れを止めた液滴（N = 32）に、ξ-SDF を 1 回だけかけた。

| ψ | 最大 \|Δψ\| | 帯（0.3 < ψ < 0.7）の κ：平均 / 最小 / 最大 |
| --- | --- | --- |
| 初期（正確なプロファイル） | — | 3.97 / 3.48 / 4.60 |
| ξ-SDF（点） | 2.8e-2 | 3.59 / −6.35 / 18.0 |
| ξ-SDF（折れ線） | 1.9e-3 | 3.90 / 1.84 / 6.01 |

- ψ の変化は小さいのに、ψ の 2 階の CCD 微分から作る曲率は、その凹凸を大きく増幅する（点の距離では、曲率の幅が 1.1 から 24 に広がる）。
- 当初の見立て「点集合までの距離（斜めの界面で最大 √2 倍、ノート13）が原因」は否定した。折れ線までの距離でも、流れの中のジャンプは 4.54 だった。
- 意味：論文の標準経路の「ψ の CCD 曲率」と「Ridge–Eikonal の再初期化」は、組み合わせると曲率の精度を損なう。再初期化は ψ を作り直すが、曲率に必要な滑らかさ（2 階微分）までは保たない。

## 論文の主張の判定（ノート10 に追加）
| 主張 | 判定 | 根拠 |
| --- | --- | --- |
| 二つのスカラー制約で、物理界面の位置とプロファイルの質量を分けて閉じる（05） | 不成立（平らに近い界面）／条件付き（閉じた界面） | 平らに近い界面で幅の問題の条件が悪く、ε_eff が範囲の端に張り付く。毛管波の振幅に段差が入り、RMS 誤差が 1.1〜2.4 倍になる |
| 標準経路は再初期化つきで安定に動く（11b1） | 条件付き | 再初期化は ψ の CCD 曲率に雑音を入れ、静止液滴のジャンプを +13% ずらす |
