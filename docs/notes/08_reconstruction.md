# 08 R_h（面 → セル）のコンパクト版（PR #15）

- 面状態ではセル値が R_h u_f なので、R_h の誤差がセル値の床になる。FCCD の face_to_cell は4次。
- 広い Lagrange ステンシル（6点）ではなく、CCD 的に作った：
  - 軸方向の面の並びを節点の列とみなし、その上で CCD を解いて面のジェット (f, f′, f″) を得る。
  - セル値は両側2面のジェットによる5次のエルミート中点：(f_L+f_R)/2 + (5h/32)(f′_L − f′_R) + (h²/64)(f″_L + f″_R)。6次。
- 壁の行は節点 0〜2 に収めた（f″ 3次、f′ 4次 → R_h は壁で5次）。節点 3 まで使えば壁でも6次になるが、NS の結果は変わらなかった（自由すべり箱 TG、N = 64 で 6.8e-8 と同じ）ので採らなかった。
- 単体の精度（N = 128）：周期 3.0e-13（6点 Lagrange は 6.8e-11）。

## 定式化と理論的根拠
- **5 次の Hermite の中点の値**：ノート04 と同じ式（両側の面のジェット (f, f′, f″) からの中点の値）。次数 5 の多項式を厳密に再現するので 6 次（ノート04 で数値でも確認）。
- **面状態で R_h の誤差がセル値の床になる理由**：セル値は `R_h u_f` で作るので、`R_h` の打ち切り誤差がそのままセル値の誤差に加わる。u_f が高次でも、R_h が 4 次ならセル値は 4 次で止まる。
- **壁で 5 次で十分な理由**：ノート01 の論法（境界の 1 層の誤差は h で薄まる）。NS の結果が変わらなかったことで確認した。
