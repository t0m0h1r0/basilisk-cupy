# 69 CLS の粘性の解のセル密度の既定を "sharp" に（PR #79）

ノート68 で、CLS の振動液滴の過大な減衰（物理の約 3.9 倍）は、陰的な粘性の解のぼやけたセル密度 ρ(ψ) から来ることが分かった。`cell_density="sharp"`（ψ > 1/2 で ρ1、それ以外で ρ2）にすると、N = 64 で液滴の減衰は 0.84 倍、毛管波・液滴の周波数の誤差は VOF 並み（−1.26% / −1.38%）になる。これを受けて、既定を `"sharp"` に変えた（2026-11-26、ユーザーの判断）。

- 変更：`TwoPhaseCLS(cell_density="sharp")`（`CenteredNS` + CLS の経路にも効く）、`TwoPhaseIMEX`・`TwoPhaseIMEXRK`（`_attach_two_phase`）。
- 旧来の振る舞いは `cell_density="diffuse"` で得られる。

## 定式化と理論的根拠
既定を変えた理由はノート68 の機構（粘性の解のセル密度）による。この変更で生じた 2 つの影響の理由：

- **静止液滴の寄生流が増える**：静止では、寄生流は曲率の誤差による力の不釣り合いで駆動され、粘性で減衰する。鋭い ρ では、界面の空気側のセルが本来の軽い密度で加速されるので、同じ不釣り合いの力に対する速度の応答が大きくなる（加速度 ∝ 1/ρ）。そのため寄生流の最大が増える方向に働く（増え方 1.1〜2.9 倍の定量的な予測はしていない）。
- **連成反復の収束が遅くなる**：外側の反復の縮小率は、反復の写像の係数の変化に対する感度で決まる。鋭い ρ はセルごとに密度比 1000 で跳ぶので、反復の 1 回で界面のセルの値が大きく変わり、縮小率が 1 に近づく（36 → 96 回）。縮小率の解析はしていない。

## 影響：静止液滴の寄生流はやや増える
密度比 1 では値は変わらない（鋭い密度とぼやけた密度が一致する）。密度比 1000 の静止液滴（R = 0.25、σ = 1、μ = 0.1、N = 32）：

| テスト | ジャンプ（`"diffuse"` → `"sharp"`） | 寄生流の最大 |
| --- | --- | --- |
| `TwoPhaseIMEX`、t = 0.1（`test_two_phase_imex.py`） | 4.01030 → 4.01075 | 6.76e-4 → 7.22e-4（終わり 1.17e-4 → 1.76e-4） |
| `TwoPhaseIMEXRK` ars222、40 ステップ | 4.00888 → 4.00933 | 3.90e-4 → 7.74e-4 |
| `TwoPhaseIMEXRK` ars343、40 ステップ | 4.00967 → 4.01126 | 2.24e-4 → 3.62e-4 |
| phase-ccd、40 ステップ（`test_phase_ccd.py`） | 4.00238 → 4.00183 | 8.88e-5 → 2.59e-4 |

- 静止液滴の寄生流は 1.1〜2.9 倍に増える。動く界面の精度（ノート68：周波数の誤差 1/3、液滴の減衰が物理どおり）との取り引き。

## 影響：連成反復（`CenteredNS(coupled_iterations=K)`、ノート36）の収束が遅くなる
比 100 の液滴（N = 16）の 1 ステップ、変化が 1e-10 になるまで：`"diffuse"` 36 回、`"sharp"` 96 回（2.7 倍）。60 回では収束しない（変化 3.2e-8）。鋭い密度は係数がなめらかでないので、外側の反復の縮小率が悪い。

## テストの扱い
- 標準の経路の静止液滴（上の表の 4 件）：基準値を新しい既定の値に更新し、旧来の値を docstring に残した。
- 研究のための測定（連成反復 `cases/coupled_residuals.py`、ステップのヤコビアン `cases/step_jacobian.py`、演算子の交換子 `cases/operator_commutator.py`、論文の毛管波の体積の許容 `test_paper_capillary_wave_volume_tolerance`）：測定の目的はセル密度ではないので、`cell_density="diffuse"` を明示して、記録された数値を保った。
