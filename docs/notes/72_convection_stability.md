# 72 二相流の対流の扱いと安定性：BCG、UCCD、運動量保存形（PR #82）

UCCD6・FUCCD₄（論文の対流）は風上の散逸を含むので、安定化に使えるかを、二相流で検証した。比べたのは、Basilisk の VOF（BCG の移流）、運動量保存形の VOF（`conserving.h`、ノート71）、IMEX 上の VOF の中心差分・UCCD6・FUCCD₄（`cases/convection_stability.py`）。

## 1. Rayleigh–Taylor（`rt.c` の設定、縮約重力、t = 1）
| 構成 | N = 64、μ | N = 64、μ/10 | N = 128、μ | N = 128、μ/10 |
| --- | --- | --- | --- | --- |
| Basilisk の VOF（BCG） | 13.18 / 8.1 | 15.08 / 8.2 | 13.04 / 6.2 | 17.02 / 6.5 |
| 運動量保存形 | 12.75 / 7.2 | 14.22 / 7.5 | 12.62 / 6.6 | 14.60 / 9.9 |
| IMEX、中心差分 | 13.12 / 7.4 | 18.54 / 10.3 | 13.03 / 7.7 | 16.39 / 12.1 |
| IMEX、UCCD6 | 13.53 / 7.9 | 18.96 / 8.4 | 12.98 / 6.8 | **t = 0.97 で発散** |
| IMEX、FUCCD₄ | 13.76 / 8.7 | 15.23 / 7.3 | 13.23 / 7.7 | 17.11 / 13.4 |

（t = 1 の運動エネルギー / 最大速度。μ = 0.00313。）

- 発散したのは UCCD6 だけ。最大速度は、左の壁から 2 セル目の界面のセルで育った（x = −1.953、f = 0.03〜0.77）。UCCD6 の超粘性の壁の閉包の負の固有値（ノート02：壁で増幅）と合うが、界面との組み合わせで初めて表に出ている。
- RT は重力で運動エネルギーが増え続けるので、安定性の判定には向かない。

## 2. 外力のない二相のせん断層（`--shear`）
周期の [0, 1]²、重い帯（0.25 < y < 0.75）を軽い流体が挟み、帯の上下の界面に沿って tanh のせん断層（δ = 1/30）と小さな縦の摂動。重力・表面張力・粘性なし。**運動エネルギーは物理的には増えない。** 運動エネルギーの最大（初期値に対する倍率）：

| 構成 | 密度比 10、N = 64 | N = 128 | 密度比 100、N = 64 | N = 128 |
| --- | --- | --- | --- | --- |
| **運動量保存形** | **1.0000** | **1.0000** | **1.0000** | **1.0000** |
| 運動量保存形 + CCD の勾配（3 節） | 1.0002 | 1.0000 | 1.0017 | 1.0023 |
| Basilisk の VOF（BCG） | 1.10 | 1.08 | 1.15 | 1.13 |
| IMEX、FUCCD₄ | 1.11 | 1.05 | 発散（t = 1.99） | 発散（t = 1.47） |
| IMEX、UCCD6 | 1.13 | 1.17 | 1.81 | 発散（t = 1.59） |
| IMEX、中心差分 | 1.45 | 1.61 | 発散（t = 1.39） | 発散（t = 0.93） |

- **UCCD6・FUCCD₄ の風上の散逸は、中心差分よりエネルギーの増加を抑え、発散を遅らせる。しかし密度比 100 では、N = 128 で 3 方式とも発散する。**
- **運動量保存形だけが、4 条件ともエネルギーを増やさない。** BCG（非保存形）は 1 割ほど増やすが、発散はしない。
- 時間積分を SBDF3（陽的な部分が、純虚数の固有値を ωΔt < 0.6 で減衰させる。SBDF2 は常に増幅）に替えても、中心差分のエネルギーの増加は変わらない（密度比 10、N = 64：1.45 → 1.46）。**不安定の主因は時間積分ではなく、密度の跳びをまたいで速度を（運動量としてではなく）運ぶこと**とみられる。

| 時間積分（N = 64） | 中心差分、密度比 10 | 密度比 100 | UCCD6、密度比 10 | 密度比 100 |
| --- | --- | --- | --- | --- |
| SBDF2（既定） | 1.45 | 発散（t = 1.39） | 1.13 | 1.81 |
| SBDF3 | 1.46 | 発散（t = 1.40） | 発散（t = 0.16、下の不具合） | 発散（t = 0.15、同） |
| CNLF | 発散（t = 1.20） | 発散（t = 1.04） | 1.22 | 発散（t = 1.97） |

| 多段法（陽的な部分を純虚数の固有値 iω にかけた 1 ステップの増幅） | ωΔt = 0.25 | 0.5 | 0.8 |
| --- | --- | --- | --- |
| SBDF2（既定） | +3.4e-3 | +6.7e-2 | +0.31 |
| CNAB2 | +1.1e-3 | +2.7e-2 | +0.26 |
| SBDF3 | −2.8e-3 | −4.8e-2 | +0.32 |
| SBDF4 | −3.8e-4 | −1.7e-2 | +0.45 |
| CNLF | 0 | 0 | 0 |

### 見つけた不具合：UCCD6・FUCCD₄ の刻みの上限が SBDF2 に固定されていた
超粘性の陽的な刻みの上限は、EXT2/BDF2 の実軸の限界 4/3 で書かれていた（`EXT2_REAL_LIMIT`）。ほかの多段法の陽的な部分の実軸の限界（一定の刻み、`schemes.explicit_real_limit`）は：

| 多段法 | SBDF1 | SBDF2 | SBDF3 | SBDF4 | CNAB2・MCNAB2 | CNLF |
| --- | --- | --- | --- | --- | --- | --- |
| 実軸の限界 rΔt | 2 | 4/3 | 20/21 | 0.711 | 1 | 0（減衰の項に不安定） |

SBDF3 では上限が 1.4 倍長すぎ、せん断層が始めてすぐ発散した。修正：`IMEXMultistepNS` が上限を `explicit_real_limit(scheme) / (4/3)` 倍にし、CNLF と散逸を持つ陽的な対流の組み合わせはエラーにする。SBDF2 の刻みは変わらない。修正後の UCCD6 + SBDF3（N = 64）は t = 2 まで走る：密度比 10 で 1.12、密度比 100 で 1.45（SBDF2 では 1.13 / 1.81）。

## 3. 運動量保存形に CCD の精度を足す（`TwoPhase(conserving_gradient="ccd")`）
VOF の濃度の流束 `f + s min(1, 1 − s un) g/2`（風上のセルからの BCG 型の予測）の勾配 g を、vof.h の中心差分から、相ごとの CCD に替えた：線ごとに、その相が占めるセル（c ≥ 1/2）の並びを切り出し、端を外挿の閉包にして CCD で微分する（6 セル未満の並びは vof.h のまま）。濃度は相の中でなめらかなので、CCD は界面をまたがない。

精度（論文の毛管波・振動液滴、水–空気、`cases/vof_imex_dynamics.py --variants centered-vof centered-conserving centered-conserving-ccd`）：

| 構成 | 毛管波 N = 32：β 倍率 / ω の誤差 | N = 64 | 液滴 N = 32：ω の誤差 | N = 64 |
| --- | --- | --- | --- | --- |
| Basilisk の VOF（BCG） | 2.49 倍 / −3.98% | 1.31 倍 / −1.33% | −1.71% | −1.04% |
| 運動量保存形 | 1.62 倍 / −4.21% | 1.12 倍 / −1.41% | −1.46% | −1.04% |
| 運動量保存形 + CCD の勾配 | 1.31 倍 / −4.17% | 1.06 倍 / −1.41% | −1.46% | −1.04% |

- 周波数はほぼ同じ。毛管波の減衰は、運動量保存形で物理に近づき、CCD の勾配でさらに近づく。
- 振幅の小さい問題なので、対流の精度の差は出にくい。対流の効く問題での精度の比較は TBD。

## 4. BCG に CCD の微分を入れる（試作、`cases/ccd_bcg.py`）
BCG の面の値 `u + (h/2)(1 − c) u′`（c は CFL 数）の u′ を、3 点の中心差分から CCD に替えた（`ccd`）。さらに CCD の u″ で 2 次の項 `(h²/8)(1 − c)² u″` を加えた版（`ccd2`、一次元の線形移流なら特性線に沿ったテイラー展開を O(h³) まで取る）も試した。ライブラリは変えず、試作の側から BCG の勾配を差し替える。

非粘性の Taylor–Green（周期、t = 0.5）の u の最大誤差：

| 方式 | N = 16 | 32 | 64 | 次数 |
| --- | --- | --- | --- | --- |
| BCG | 6.47e-2 | 1.08e-2 | 1.60e-3 | 2.58、2.75 |
| `ccd` | 5.86e-2 | 9.90e-3 | 1.45e-3 | 2.57、2.77 |
| `ccd2` | 5.37e-2 | 9.31e-3 | 1.51e-3 | 2.53、2.62 |

精度はほぼ変わらない。Taylor–Green の誤差は、移流の面の値ではなく、近似射影や時間積分で決まっている。

外力のない二相のせん断層（2 節と同じ、Basilisk の VOF の経路）の運動エネルギーの最大：

| 方式 | 密度比 10、N = 64 | N = 128 | 密度比 100、N = 64 | N = 128 |
| --- | --- | --- | --- | --- |
| BCG | 1.10 | 1.08 | 1.15 | 1.13 |
| `ccd` | 1.05 | 1.03 | 1.085 | **1.25** |
| `ccd2` | 5.5 | 発散（t = 1.82） | 発散（t = 1.42） | 発散（t = 1.21） |

- 勾配だけを CCD に替える `ccd` は、3 条件で BCG より運動エネルギーの増加を 4〜6 割小さくする。**ただし密度比 100、N = 128 では逆に 1.25 倍（BCG 1.13 倍）に増やす。** 一様に BCG より良いとは言えず、密度比が大きく解像の細かいところで悪くなる原因は未調査。
- **2 次の項を加える `ccd2` は不安定で、不採用。** 一次元の線形移流では正しい展開だが、界面や速度の急変部で u″ が大きく、外挿が行き過ぎる。

## まとめ
- 二相流の安定性を決めるのは、上流差分の散逸よりも**運動量の保存**。運動量保存形の VOF だけが、密度比 100 でも運動エネルギーを増やさない。
- UCCD6・FUCCD₄ の風上の散逸は、中心差分の不安定を遅らせるが、密度比 100 では止められない。時間積分（SBDF3・CNLF）を替えても直らない。
- CCD を運動量保存形の勾配に入れる形（3 節）は、安定性を損なわずに精度を上げる（毛管波の減衰が 1.12 → 1.06 倍、せん断層のエネルギーの増加は最大 0.2%）。**いまの候補はこれ。** → **ノート75 で取り下げ**：並進する液滴で格子を細かくすると誤差が増え、原因の界面のセルを外すと毛管波の改善も消える。
- CCD を BCG の勾配に入れる形（4 節）は、条件によって良くも悪くもなる（密度比 100、N = 128 で悪化）。2 次の項（u″）の外挿は不安定で入れない。
