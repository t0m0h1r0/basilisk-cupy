## 定式化と理論的根拠
### A. 試験の設定
- 単相（体積分率は全域で一定）、周期の [0, 1]²、定常の Taylor–Green `u = (sin 2πx cos 2πy, −cos 2πx sin 2πy)`、`p = (cos 4πx + cos 4πy)/4`（圧力の加速度 `g = −∇p = (π sin 4πx, π sin 4πy)`）。Euler 方程式の定常解である。
- 面の速度は、頂点の流れ関数の差から作る（面の平均として厳密で、離散的に発散 0）。
- 輸送は、ライブラリの VOF の濃度の輸送（`vof_advection`、ノート77）をそのまま使う。掃過の順序は、ステップの番号の偶奇で x→y と y→x を交互にする。

### B. 1 ステップの局所誤差の式
`A = −u∂_x`、`B = −v∂_y`、`d = ∂_x u = −∂_y v` とする。

| 候補 | 主要項 | 掃過の順序の反転 |
| --- | --- | --- |
| 方向分割の交換子 + 凍結した膨張の項（ユーザーの導出、ノート111 の 3 節） | `e_xy = +(Δt²/2)([B, A] + d(A + B))q` | 符号が変わる（奇成分） |
| 面の値の半ステップの予測に源の項が無い（補足、下の導出） | `e = +(Δt²/2) u·∇S`（S は源の項。運動量では S = g） | 変わらない（偶成分） |

**源の項の導出（補足）**：`∂_t q + ∇·(uq) = S`（u は定常・発散 0、S は定常）の厳密な 1 ステップは `q + Δt(−∇·(uq) + S) + (Δt²/2)(−∇·(u q_t))`、`q_t = −∇·(uq) + S`。輸送だけを 2 次で行い、その後に ΔtS を足す方式は、`−(Δt²/2)∇·(uS)` の項を持たない。差は `+(Δt²/2)∇·(uS) = (Δt²/2) u·∇S`。面の値に `(Δt/2)S` を足せば（BCG の予測と同じ）、流束がこの項を運ぶ。

### C. 偶成分と奇成分（ユーザー）
同じ厳密な初期値から、x→y と y→x を 1 ステップずつ行う。`e_even = (e_xy + e_yx)/2`、`e_odd = (e_xy − e_yx)/2`。

- 奇成分は、交互の掃過で（時間刻みが一定なら）打ち消し合う。
- 偶成分は残る。空間の打ち切り誤差も偶成分に入るので、固定の格子で時間刻みを変えて、Δt² に比例する部分を分ける。

### D. 移植版のゴーストセル（この段階で見つけた）
`TwoPhase` の保存形は、運動量の場 `q = (1 − f)ρu` のゴーストセルを、f と u のゴーストセルから作る（`_MomentumField.fill_ghosts`。Basilisk の `boundary_q1_x` の移植）。u はステップの開始時の速度である。

- 1 回目の掃過の後、q の内部の値は変わるが、ゴーストセルは開始時の u から作り直される。**周期境界では、2 回目の掃過のゴーストセルが古い値のまま**になる（正しくは、掃過後の q の周期の像）。
- 影響は、2 回目の掃過の方向の境界の 2 セルに出る（1 節）。内部のセルでは、単独の輸送と丸めまで一致する。
- C 版の Basilisk では、周期境界は格子の側で処理される。同じ不具合があるかは、この環境に Basilisk の C のビルドが無く、未確認である。

## 2. 1 ステップの誤差の分離（厳密な初期値から 1 ステップ、RMS）

| N・CFL | 奇成分 / Δt² | 式との差（奇成分に対する比） | 交換子だけの式との差 | 偶成分 |
| --- | --- | --- | --- | --- |
| 64・0.4 | 5.222 | 4.0% | 96% | 1.96e-5 |
| 64・0.05 | 5.229 | 0.8% | 96% | 4.30e-6 |
| 128・0.4 | 5.231 | 1.9% | 96% | 2.26e-6 |
| 256・0.4 | 5.233 | 1.0% | 96% | 2.77e-7 |
| 256・0.05 | 5.234 | 0.13% | 96% | 6.39e-8 |

- **奇成分は Δt² に正確に比例し（係数 5.22〜5.23）、ユーザーの式 `(Δt²/2)([B, A] + d(A + B))q` と一致する**（相関 0.9992〜1.0000、差は Δt と h を小さくすると 0.1% まで減る）。
- **交換子だけの式では合わない**（差 96%）。凍結した膨張の項 `d(A + B)q` が必要である。
- 偶成分は、CFL を固定して格子を倍にすると約 1/8 になる（空間の打ち切り誤差 ∝ Δt h²）。Δt² に比例する偶成分は見えない。

### x 方向の運動量（輸送の後に、厳密な圧力の加速度 Δt g を足す。厳密解は定常）
| 面の値の源の項 | N・CFL | 偶成分 / Δt² | 予測 `(Δt²/2) u·∇g` との差（比） | 奇成分 / Δt² |
| --- | --- | --- | --- | --- |
| なし | 64・0.4 | 6.999 | 5.8% | 3.481 |
| なし | 128・0.4 | 6.984 | 2.9% | 3.487 |
| なし | 256・0.4 | 6.980 | 1.4% | 3.489 |
| なし | 256・0.05 | 7.001 | 1.4% | 3.489 |
| あり | 64・0.4 | 0.437 | — | 3.478 |
| あり | 128・0.4 | 0.216 | — | 3.487 |
| あり | 256・0.4 | 0.108 | — | 3.489 |

- **源の項が無いと、偶成分に O(Δt²) の局所誤差がある（係数 7.0）。予測の式と 1.4〜5.8% で一致する**（相関 0.998〜0.9999）。
- 面の値に源の項を入れると、偶成分は 1/16〜1/65 になる。残りは `h Δt²` に比例する（係数が格子を倍にすると半分。CFL を固定すれば `h³`）。
- 奇成分（係数 3.49）は、源の項によらない。

## 3. 大域の誤差（厳密な速度と厳密な g を与えた輸送だけ、x 方向の運動量、max）
| 面の値の源の項・掃過 | N = 64：CFL 0.4 / 0.2 / 0.1 / 0.05（t = 0.25） | N = 128：同 | 判定 |
| --- | --- | --- | --- |
| なし・交互 | 1.95e-2 / 9.80e-3 / 4.96e-3 / 2.55e-3 | 9.72e-3 / 4.87e-3 / 2.44e-3 / 1.23e-3 | **時間 1 次**（CFL・格子のどちらを半分にしても半分） |
| あり・交互 | 1.09e-3 / 5.97e-4 / 3.32e-4 / 2.09e-4 | 2.75e-4 / 1.47e-4 / 7.77e-5 / 4.22e-5 | **2 次**（CFL を固定して格子を倍で 1/4） |
| あり・順序を固定 | 1.06e-2 / 5.27e-3 / 2.60e-3 / 1.27e-3 | 5.23e-3 / 2.61e-3 | 時間 1 次（奇成分が打ち消されない） |

- t = 0.5・CFL 0.5 でも、源の項あり・交互は N = 32 / 64 / 128 で 6.46e-3 / 1.55e-3 / 3.83e-4（2 次）。
- スカラーの輸送（交互）は、RMS で N = 64 → 128 が 2.3e-3 → 6.0e-4（CFL 0.4、2 次）。固定の格子で CFL を小さくすると誤差は増える（空間誤差が CFL に依存する方式のため。時間誤差ではない）。

**ここまでの結論**：厳密な速度と厳密な g の下では、「面の値の源の項」と「交互の掃過」で、保存形の輸送は 2 次になる。ユーザーの指摘のとおり、方向分割と膨張の項（奇成分）は、交互の掃過で打ち消されている。持続する時間 1 次は、偶成分（源の項）から来る。

## まとめ
- **時間 1 次の原因は 2 つ**である。
  1. **面の値の半ステップの予測に圧力の源の項が無い**（偶成分の局所誤差 `(Δt²/2) u·∇g`。式と実測が 1.4〜5.8% で一致）。支配的な原因。
  2. **移植版の運動量のゴーストセルが、周期境界で 2 回目の掃過のときに古い**（境界の 2 セルに局在）。源の項を足した後に残っていた 1 次の誤差。
- **方向分割と凍結した膨張の項は原因ではない**。ユーザーの式のとおり奇成分で、交互の掃過で打ち消される（順序を固定すると 1 次に戻る）。
- 両方を直すと、単相の Taylor–Green で保存形は約 2.8 次になり、非保存形と同じ精度になる。**中点法・RK2 に進まずに、半ステップの予測の最小の修正で 2 次になった**（単相・定常の流れで）。

## 未検証・次（ユーザーの判断が必要な点を含む）
- **ライブラリの修正**：`_MomentumField.fill_ghosts` を、周期の方向ではその場自身の周期の像にする。ライブラリ本体の変更なので、ユーザーの了承の後に行う（全ての試験を実行する）。C 版の Basilisk に同じ不具合があるかは未確認。
- **非定常の流れ**（運ぶ面の速度の時間のレベル、`conserving_predict`）：定常の Taylor–Green では判定できない。減衰する Taylor–Green や非対称な流れで測る（ノート111 の P0-6）。
- **粘性の源の項**：面の値の予測に粘性の加速度も要るはずである（未測定）。
- **高密度比での源の項の陽的な帰還の不安定**（ノート77：密度比 1000 で 1 ステップに約 1.8 倍）。単相で 2 次になっても、そのまま二相には入れない（ユーザー）。帰還の増幅率の解析と、安定な形（例：源の項の陰的な扱い、制限）は R0-P1 の残りの課題である。
- 収束の規約による読み（10 点以上の格子、時間刻みの固定と CFL の固定の両方）は、修正の形が決まってから行う。ここでは 3〜4 点である。
- 界面のある場合（密度比 1 の受動的な液滴、ノート77 の 3 節）での確認。
