# 03 面の発散 D_f（PR #17）

## 問題
- 素の面差分 (F_R − F_L)/h を点値に使うと F_x + (h²/24)F_xxx となり、**2次**。
- 標準の Taylor–Green（kx = ky）では u_xxx + v_yyy = 0 で、この項が消える。これまで4次に見えていたのはこのため。
- ψ = sin(ax) sin(by)（a ≠ b）も Navier–Stokes の厳密解。これで測ると、FCCD の NS は面状態・セル状態とも2次だった。
- 射影が D_f u_f = 0 を課すので、厳密解の面値を O(h²) 動かしていた（N = 64 で 4.8e-4）。

## 修正
- 流束を F̂ = F − (h²/24)∂ₙₙF に補正してから差分する（`face_flux`）。∂ₙₙF は面の並び上の CCD。
  - FCCD の面勾配の双対。4次で、ステンシルは広がらない。
  - 両項とも差分の形なので保存形のまま。射影後、各セルで D_f F̂ = 0 が厳密に成り立つ。
  - ただし壁面の F̂ は 0 にならない。VOF・トレーサーには `wall_free_flux`（下）を使う。
  - 写像格子では h_ξ/J_c で割る（セル幅だと O(h²) が入る）。
- `div_f(flux, periodic=...)`：壁の行のために軸ごとの周期フラグを受け取る。

## 効果とコスト
- Taylor–Green a ≠ b、面状態、N = 64：7.84e-4 → 8.49e-6（2次 → 3.9次）。
- 蓋付きキャビティ E(1.1) は細格子の値へ早く近づく（BDF2 の N = 128 と 256 の差：6.2e-5 → 3.7e-5）。
- FCCD 中央流束の max|λh| 1.378 → 1.608。面状態の非粘性 TG は CFL 2.0 まで同精度、2.5 で破綻（旧 3）。
- FUCCD4 の μ₄(π) 4954.5 → 6936.3（EXT2 での CFL 上限 0.27 → 0.19）。

## 自由すべり箱でも確認（壁あり、a ≠ b）
- ψ = sin(πx) sin(2πy) は自由すべりの単位箱での厳密解。N = 16 / 32 / 64：素の D_f 4.10e-3 / 1.09e-3 / 2.78e-4（2次）、補正あり 5.95e-4 / 5.09e-5 / 1.93e-6（4.7次）。
- a = b では素の D_f のほうが小さい（N = 64 で 6.5e-8 対 2.1e-7）。誤差が打ち消し合うためで、一般の流れでは補正が正しい。
- 壁面だけ補正しない（F̂_wall = u_n）と、壁セルの誤差が O(h) になり 2.7次に落ちる（1.63e-5）。不採用。

## 壁面の補正流束と `wall_free_flux`（PR #22）
- 不透過壁（u_n = 0）でも F̂_wall = −(h²/24)∂ₙₙu_n は 0 でない。no-slip 壁では ∂ₙₙu_n = −∂ₜ∂ₙu_t（接線方向の微分）なので、壁全体での積分は 0 だが各点では 0 でない。
- 蓋付きキャビティの射影後（N = 32 / 64 / 128）：壁面の max|F̂| 6.2e-2 / 4.2e-2 / 4.5e-2（角の特異性で N を増やしても減らない）、壁を通る正味は 1e-16 以下。
- VOF でそのまま使うと、壁で局所的な出入りが起きる（壁際のトレーサーを200ステップ運ぶと全体量が 9.9e-5 変わる）。
- 採用：Φ = F̂ + curl ψ（`FCCDFaceComplex.wall_free_flux`、2次元）。
  - ψ は節点の離散流れ関数。境界では壁面流束の累積和、内部へは Coons 補間（計算座標）で滑らかに広げる。
  - curl なので D_f は変わらない（差 1e-18）。壁面の Φ は厳密に 0。チャネルの各壁の正味も丸め誤差の精度で 0。
  - 内部での変化 Φ − F̂ は O(h²)：5.6e-4 / 1.4e-4 / 3.5e-5（N = 32 / 64 / 128）。壁際1層だけに付け替えると O(h)（4.6e-3 / 2.3e-3 / 1.1e-3）。
  - トレーサーの全体量の変化：F̂ 9.9e-5 → Φ 2.2e-16。
  - 写像格子では体積流束（面速度 × 接線方向のセル寸法 h/J）で curl を取る。
  - NS・射影は変えない（VOF 用の流束を後から作るだけ）。fd2 では u_f をそのまま返す。
- 不採用：(iii) 接線方向平均 ū（D_f ū が O(h⁴) で厳密に 0 でない）、(iv) 4次 FV への全面移行（変更が大きい）。
- 残り：3次元（ψ がベクトルポテンシャルになる）。M4 を2次元で始めるなら不要。
