## 結論の要約
- **選ぶ形：D1 + D2 の限定の適用（`d1+d2lim`）**。面ごとに、上流のセルから出ていく相の体積 out と、そのセルに残る自分の質量から、ノート118 の式 (D2) の利得 `ρₖ·out·(1 − |C|)/2 ÷ (ρₖ(cₖ − out) + ρₒ(1 − cₖ))` を計算し、1 を超える面だけ勾配の項を 0 にする。
- B の合格の条件（結果の前に固定）：

| 形 | a 自由流・安定（25 条件の最大） | b 精度（元の方式との比の最大、2 つの基準 × 3 ノルム × 7 格子） | c 保存（運動量 / 質量） | d 界面なし |
| --- | --- | --- | --- | --- |
| D1 だけ | **不合格**（2.0e3） | 1.000 | 8e-13 / 8e-13 | 一致 |
| D1 + D2 全面 | 1.3e-9 | **3.54（不合格）** | 5e-13 / 5e-13 | 一致 |
| **D1 + D2 限定** | **1.3e-9** | **1.000** | **8e-13 / 8e-13** | **一致** |

- **b の合格は自明に近い（自己点検）**：b は密度比 1 の試験で、限定の適用は密度比 1 では利得が 1 を超えない（最大 1/4、C 節）ので一度も切らず、元の方式と全桁一致する。密度比のある流れでの精度は厳密解が無く、b では測れない。記録として、密度比 1000 の渦の中の液滴で場を比べると、**限定の適用は元の方式と 1e-15 で一致する**（一度も切らない。全面の適用は 1.3〜1.9e-2、格子の差の約 1/4）。切ったのは、面に揃った帯を CFL の上限で運ぶ計算だけ（部分的なセルの面の 4%）。
- D1 の確認（B の指示）：f の [0, 1] からのはみ出しは最大 3e-7（元の方式でも 2e-7）で、**VOF の側の性質**（厳密に一様な面の速度では 1e-14 以下、ソルバーの面の速度〔一様流からのずれ 1e-11〕で 5e-8 の跳び。圧力の許容誤差によらない）。`ρ_lin` の下限（`min(ρ₁, ρ₂)/2`、密度比 1e6 で f < −5e-7 に相当）までの余裕は**約 1.7 倍しかない**（密度比 1e6 の自由流）。渦の中の液滴では下限に近づかない。`ρ_lin` と物性の（clamp した）密度の差は ρ₂ の 3e-10 以下。

## 定式化と理論的根拠
### A. 4 つの形
ノート118 の記号。上流のセル（相 k の体積率 cₖ）、面の CFL 数 C、相 k が占める掃過領域の割合 cfₖ、出ていく相 k の体積 `out = cfₖ|C|`。
1. **D1 だけ**：対照。
2. **D1 + D2 全面**：0 < cₖ < 1 の全ての上流のセルで勾配の項を 0（ノート118）。
3. **D1 + D2 限定**：式 (D2) は、勾配の項の運動量のうち、出ていった質量に対応しない分がセルに残り、残った質量で割られることを示す。その利得を面ごとに

```
Γ = ρₖ · out · (1 − |C|)/2  ÷  ( ρₖ (cₖ − out) + ρₒ (1 − cₖ) )
```

と見積もり（分母は、そのセルが自分の中身から残す質量。流入は数えないので、式 (D2) の分母より小さく、Γ は大きめ）、**Γ > 1 の面だけ勾配の項を 0** にする。閾値 1 は「勾配の項 1 単位あたりの速度の乱れが、勾配そのものより大きくならない」ことに対応する（安定性の厳密な条件ではない：仮定つき）。
4. **D1 + 幾何学的なモーメント**：ノート77 の `VOFTracer(geometric=True)`。勾配の項を、相の掃過領域の重心と、セルの中の相の重心の差で掛ける。相の全量が出ていくと 2 つの重心が一致し、勾配の項が消える（構成から）。

### B. 限定の適用が密度比 1 で切らないこと（証明）
ρₖ = ρₒ = ρ では `Γ = out(1 − |C|)/2 / (1 − out)`。out ≤ |C| ≤ 1/2（`vof.h` の CFL の上限）なので Γ ≤ (1/2)(1/2)/2 / (1/2) = 1/4 < 1。よって密度比 1 では一度も切らず、b の試験（密度比 1）では元の方式とビット一致する。**b は限定の適用の精度を、密度比のある流れでは何も保証しない。**

### C. 軽い相では切らないこと
相 k が軽い相（ρₖ ≪ ρₒ）なら、分母の ρₒ(1 − cₖ) が支配して Γ ≪ 1。切るのは、重い相が出ていって、残りが軽くなるセルだけ（式 (D2) の機構そのもの）。

### D. 測定（結果の前に固定したもの、後から足したもの）
- 固定（B、#162）：a〜d の条件と閾値（b は 1.2 倍）、分岐（a・c・d を満たすもののうち b が最良）、規模（方式 3・4 の形は 1 つずつ）。限定の適用の閾値（Γ > 1）と、分母の取り方（流入を数えない）は、測定の前に決めた。形は 1 つしか試していない。
- 後から足した記録：密度比 1000 の渦での場の差、切った面の数、f のはみ出しの出どころの確認。

## まとめ
- B の分岐（a・c・d を満たすもののうち b が最良）に当てはめると **D1 + D2 限定**。幾何学的な形は b で不合格（1.57 倍）、全面の適用も不合格（3.54 倍）。
- 限定の適用が切るのは、面に揃った界面を CFL の上限で運ぶような、重い相のほぼ全部が出ていくセルだけで、試した滑らかな流れ（渦の中の液滴）では一度も切らない。

## 自己点検（試験が成立しやすい条件に寄っていないか）
- **b は限定の適用に有利**（B 節：密度比 1 では切らないことが証明できる）。限定の適用が切る流れ（面に揃った界面の高密度比の流れ）での精度は測っていない。厳密解のある高密度比の流れ（層状の二層せん断流、A-4・C-3）で測るべきである。
- 閾値 Γ > 1 は 1 つだけ試した。閾値を下げると切る面が増える（精度は全面の適用に近づく）。閾値を上げた場合に自由流が保たれる範囲は測っていない（式 (D2) から、利得が 1 を超えて繰り返すと育つので、上げすぎれば育つはず：未検証）。
- 幾何学的な形の形は、ノート77 の実装をそのまま使った（B の指示）。改良はしていない。
- 自由流の試験は一様流で、全ての面の値が ρₖU になる形に成立しやすい（ノート118 と同じ）。非一様な流れでの安定は渦の中の液滴だけ。

## 検証済みと未検証
- 証明：限定の適用が密度比 1 で切らない（B 節）、軽い相では Γ ≪ 1（C 節、定性的）。
- 数値で確認：a〜d の表、切った面の数、渦での場の差、はみ出しの出どころ（VOF の側であること）。
- 未検証：限定の適用が切る流れでの精度、閾値への依存、はみ出しの機構、密度比 1e7 以上での `ρ_lin` の下限、壁のある場合、ノート117 の源の項・E1〜E3 との組み合わせ（A-3）。

## B に求める判断
1. 採否：D1 + D2 限定を、A-3（組み合わせの検証）とライブラリへの導入の候補とする。
2. `ρ_lin` の下限の余裕が密度比 1e6 で約 1.7 倍しかない。ライブラリに入れるときは、(i) 下限に達したセルを数えて警告する、(ii) 下限を `min(ρ₁, ρ₂)·10⁻³` 程度に下げる（一致は崩れるが負の密度は避ける）、のどちらかを提案する。A の推奨は (i)。
3. 限定の適用の精度の確認は、A-4 の層状の二層せん断流（厳密解あり）で行う。
