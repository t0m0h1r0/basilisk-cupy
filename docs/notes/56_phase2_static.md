# 56 フェーズ2：静止液滴の三者比較（密度比 1〜1000）

## 定式化と理論的根拠
- **基準のジャンプ**：二次元の静止液滴は Laplace の式 `[p] = σκ = σ/R = 1/0.25 = 4`。速度 0 が厳密解で、表の「ジャンプの誤差」はこの値からの相対誤差。
- **ジャンプの誤差が密度比によらない理由**：静止の釣り合いでは、ジャンプは曲率の平均で決まり（ノート63）、密度は加速度の大きさ（寄生流の応答）にしか入らない。そのため、ジャンプの誤差は密度比にほとんど依存しない。寄生流の履歴の最大は密度比で少し変わる。
- **VOF の寄生流の初期の大きさ**：Basilisk の `fraction()` の初期化は、曲率に O(1) の誤差を残す（ノート66 で導出）。最初の数ステップの 1e-2 はこの初期の不釣り合いから来る。その後は離散的な平衡の形へ緩和して減衰する（ノート73）。
- **CLS の終わりの寄生流が 1e-8 で止まる理由**：CLS は、再初期化なしでも輸送で ψ の分布が少しずつ変わり、曲率の不釣り合いが新たに入り続ける（ノート76 の CLS の節）。離散的な平衡に落ち着かない。この説明は、ノート76 の輸送だけの測定からの類推で、静止液滴で直接は確かめていない。
- **体積**：CLS は保存形の流束と質量の閉鎖で丸め誤差。VOF は Poisson の許容誤差の分だけ面の速度の発散が残る（ノート67）ので、1e-8 の水準。

## 条件（`cases/phase2_static.py`）
- R = 0.25、単位正方形、壁、σ = 1、μ = 0.1（両相）、ρ₁ = 1（内）、ρ₂ = 1/比、t = 1 まで。
- 解法の許容値は 1e-8。各方式の既定の刻みを使う（VOF は tension.h の上限、CLS は × √(5/12)）。
- 24 条件を並列に実行した。

## わかったこと
- **すべての方式・密度比（1〜1000）で、t = 1 まで安定。**
- **ジャンプの精度：** CLS/GFM の誤差は VOF の 3.5〜3.9 倍小さい（N = 32 で 0.26% 対 0.90%、N = 64 で 0.075% 対 0.29%）。次数は 1.8 と 1.6。密度比にはほとんど依存しない。
- **寄生流：**
  - 履歴の最大は、CLS/GFM が VOF の 25〜90 倍小さい（VOF は最初の数ステップで 1e-2 に達する）。
  - 最後まで流した後の値は、VOF の方が小さい（1e-10 以下まで減衰。CLS/GFM は 1e-8 前後で止まる）。
- **体積：** CLS は 1e-14（丸め誤差）。VOF は 1e-8（解法の許容値の水準）。
- **二つの時間積分（centered と imex）の差は小さい：** ジャンプで 1.5e-4（N = 32）・1e-5（N = 64）以下、寄生流の履歴の最大で 4〜7%。静止状態は時間積分の違いにほとんど影響されない（ノート50 と同じ）。
