# 70 IMEX 上の VOF の毛管の刻み：tension.h の上限の √(5/12) 倍に（PR #80）

## 1. 症状：N = 128 の静止液滴が崩れる
IMEX 上の VOF（`TwoPhaseIMEX(interface="vof" / "vof-gfm")`、tension.h の曲率）の静止液滴（R = 0.25、σ = 1、μ = 0.1、密度比 1000、厳密な初期化、t = 0.5、`cases/vof_static_curvature.py`、GPU）は、N = 64 では安定だが、N = 128 で崩れた（CSF：1825 ステップで最大速度 4.2、GFM：544 ステップで 51）。同じ設定の Basilisk の VOF（`CenteredNS`、`cases/phase2_static.py`）は、同じ刻み（1825 ステップ）で安定（ジャンプの誤差 +2.5e-3、最大速度 3.6e-3）。

## 2. 原因：SBDF2 の陽的な表面張力
刻みの上限を変えた（N = 128、CSF、tension.h の曲率）：

| 刻み（tension.h の上限 2.76e-4 に対して） | ジャンプの誤差 | 最大速度 | t = 0.5 の速度 |
| --- | --- | --- | --- |
| 1.0 | 崩れる | 4.16 | — |
| 0.8（2.2e-4） | +1.82e-3 | 9.4e-4 | 1.4e-4（減りが遅い） |
| 0.65（1.78e-4） | +1.87e-3 | 1.4e-3 | 8.4e-6 |
| 0.48（1.3e-4） | +1.88e-3 | 1.6e-4 | 3.0e-7 |

表面張力は、振動（純虚数の固有値 iω）として働く。SBDF2 の陽的な部分（EXT2）を `z' = iω z` にかけた特性多項式 `3z² − (4 + 4iωΔt) z + (1 + 2iωΔt) = 0` の根は、ωΔt が約 0.001 を超えると単位円の外に出る。1 ステップの増幅は ωΔt のほぼ 4 乗：

| ωΔt | 0.25 | 0.5 | 0.75 | 1.0 | 1.5 |
| --- | --- | --- | --- | --- | --- |
| max \|z\| − 1 | 3.4e-3 | 6.7e-2 | 0.26 | 0.53 | 1.13 |

tension.h の上限 `sqrt(ρ Δ³/(π σ))` は、格子スケールの毛管波で ωΔt がおよそ 1 になるように決まっている。Basilisk の分割（速度を先に、界面を後に進める）はこの刻みで安定だが、SBDF2 では 1 ステップに 5 割ほど増幅し、陰的な粘性の減衰が抑えきれないと崩れる（N = 64 では抑えきれていた）。刻みを 0.65 倍にすると ωΔt ≈ 0.65 で、増幅は約 0.17 に下がる。

## 3. 修正
IMEX の経路の VOF（`_attach_vof`）では、tension.h の曲率でも毛管の刻みを √(5/12) ≈ 0.645 倍にした（`TwoPhase._curvature_dt_factor`）。CCD の曲率（ノート66 で同じ係数を入れた）とは重ねない（CCD の曲率はこの刻みで N = 128 でも安定：ジャンプの誤差 −3.9e-5）。Basilisk の `CenteredNS` の VOF は変えない。

## 4. 影響
- 静止液滴（N = 32、t = 0.1、`tests/test_two_phase_imex.py`）：ステップ数は 42 / 56 → 60 / 81。ジャンプは 5 桁目まで同じ（例：CSF、密度比 1000 で 4.04111 → 4.04123）、寄生流の最大もほぼ同じ。
- 動く界面（ノート64〜67 の値は旧来の刻み、`cases/vof_imex_dynamics.py --variants imex-vof-ab2-fd2v imex-vof-gfm-fd2v imex-vof-gfm-fd2v+pccd`）：ほとんど変わらない。

| 構成 | 毛管波 N = 32：β 倍率 / ω の誤差 | N = 64 | 液滴 N = 32：ω の誤差 | N = 64 |
| --- | --- | --- | --- | --- |
| CSF | 2.05 倍 / −3.98%（同じ） | 1.18 倍 / −1.33%（同じ） | −1.54%（同じ） | −1.04%（同じ） |
| GFM | 0.25 倍 / −4.91%（同じ） | 0.44 倍 / −1.44%（0.37 倍 / −1.44%） | −2.38%（同じ） | −1.04%（同じ） |
| GFM + phase-ccd | 0.12 倍 / −1.63%（同じ） | 0.44 倍 / −0.37%（0.50 倍 / −0.48%） | −0.71%（−0.63%） | +0.04%（−0.04%） |

  （括弧は旧来の刻みの値。）ステップ数は増える（毛管波 N = 64 で 1012 → 1512、液滴 N = 64 で 1007 → 1410）が、周波数・減衰はほぼ同じで、旧来の刻みでも時間の誤差は小さかった。
- N = 128 の静止液滴（新しい既定、GPU）：CSF はジャンプの誤差 +1.88e-3、最大速度 1.1e-3、t = 0.5 で 9.3e-7。GFM は +1.87e-3、1.1e-3、t = 0.5 で 2.6e-4（安定だが、CSF より寄生流の減りが遅い）。2821 ステップ。

（刻みの比較の測定は、PR #79 の `cases/vof_static_curvature.py` の `run(..., DT=...)` による。）
