# 79 P0-4a の訂正と、再構築による相似変換（P0-4b-1・P0-4b-2）

ノート78 の P0-4a（「pair4 は変密度でも 4 次」）は誤りだった。ユーザーが独立に計算し、t = 1（1 周期後）だけで判定していたため、途中の誤差が相殺されて 4 次に見えていたことを指摘した。こちらでも再現した。あわせて、ユーザーの提案した、セル平均を点値に戻してから歪対称な輸送を行う方式（相似変換 `R⁻¹AR`）を検証した。

## 1. P0-4a の訂正（`python -m cases.energy_transport --semi`）
半離散（RK4、CFL 0.02）の最大誤差を途中の時刻でも測り、厳密解を半離散の演算子に代入した局所残差（厳密な面の流束から）も測った。pair4、N = 16 / 32 / 64 / 128 / 256：

| 試験 | t = 0.25 | t = 0.5 | t = 1 | 局所残差 |
| --- | --- | --- | --- | --- |
| 一定の密度・速度 | 1.19e-3 … 1.90e-8（4.00） | 2.38e-3 … 3.80e-8（4.00） | 4.77e-3 … 7.60e-8（4.00） | 4.83e-3 … 7.60e-8（4.00） |
| 密度の波（速度一定、F = ρU が変わる） | 2.64e-3 … 4.77e-8（4.00） | 5.33e-3 … 9.53e-8（4.00） | 1.07e-2 … 1.91e-7（4.00） | 1.04e-2 … 1.91e-7（4.00） |
| **定常な変密度・変速度** | 1.84e-2 / 3.07e-3 / 7.00e-4 / 1.71e-4 / 4.25e-5（**2.01**） | 2.93e-2 / 4.25e-3 / 8.71e-4 / 2.06e-4 / 5.09e-5（**2.02**） | 1.73e-2 / 9.59e-4 / 5.81e-5 / 3.63e-6 / 2.27e-7（4.00） | 9.55e-2 / 2.10e-2 / 5.05e-3 / 1.25e-3 / 3.12e-4（**2.00**） |

（括弧は N = 128 → 256 の次数。ユーザーの値と一致。）

- **pair4 は、速度一定の密度の波では全時刻で 4 次、定常な変密度・変速度では一般の時刻で 2 次。** t = 1 の 4 次は、周期の終わりでの誤差の相殺。ノート78 の P0-4a の結論はこう訂正する。
- ユーザーの解釈：質量で重み付けたセル平均は `q̄_ρ = q + h²/24 (q″ + 2 ρ′q′/ρ) + O(h⁴)` で、変密度では `h²/12 · ρ′q′/ρ` が出る。セル平均と点値の違いを扱わない限り、ステンシルを 4 次にしても 4 次にならない。

## 2. 変形と逆変形での相似変換（P0-4b-1、`--reconstructed`）
ノート78 の変形と逆変形の厳密解。x 方向に Fourier 変換し、時間は厳密に積分（輸送する変数では行が結合しない）。t = 1/2 の最大誤差：

| 方式 | N = 16 | 32 | 64 | 128 | 256 | 次数 |
| --- | --- | --- | --- | --- | --- | --- |
| A：セル平均に pair4、行の平均の速度 | 1.49e-2 | 3.90e-3 | 9.87e-4 | 2.47e-4 | 6.19e-5 | 2.00 |
| B：v = R q̄ に pair4（`R = I − h²/24 Δ_h`）、行の平均の速度 | 1.05e-2 | 2.56e-3 | 6.33e-4 | 1.58e-4 | 3.94e-5 | 2.00 |
| **C：v = R q̄ に pair4、行の中心の点の速度** | 1.52e-3 | 1.11e-4 | 7.24e-6 | 4.58e-7 | **2.87e-8** | **4.00** |

（B・C は `E_R = ½ h² |R q̄|²` を 2.2e-16 で保存。ユーザーの表と全桁一致。）

- **エネルギーの定義を変える（B）だけでは足りず、移流の速度も点値と整合させる（C）と、高次のエネルギーの保存と 4 次が両立する**（N = 256 で A の約 1/2,160）。

## 3. 変密度への拡張（P0-4b-2、`--reconstructed-semi`）
一次元で、ユーザーの提案どおり密度と運動量を別々に再構築：`ρ* = R ρ̄`、`(ρq)* = R (ρq)̄`、`q* = (ρq)*/ρ*`（`R = I − δ²/24`）。点値を分割形（歪対称）で運ぶ：

```
ρ* q*_t = −½ [F* D q* + D(F* q*) − q* D F*]     （D は 4 次の中心差分、F* はセルの中心の点の質量の流束）
```

`ρ*_t = R ρ̄_t`（厳密な面の流束から）、`(ρq)̄ = R⁻¹ (ρq)*` で戻す。最大誤差（N = 16 … 256、括弧は次数）：

| 試験 | t = 0.25 | t = 0.5 | t = 1 |
| --- | --- | --- | --- |
| 一定 | 1.19e-3 … 1.90e-8（4.00） | 2.38e-3 … 3.80e-8（4.00） | 4.77e-3 … 7.60e-8（4.00） |
| 密度の波 | 5.88e-3 … 1.02e-7（4.00） | 1.16e-2 … 2.03e-7（4.00） | 2.25e-2 … 4.06e-7（4.00） |
| **定常な変密度・変速度** | 1.19e-2 … **2.36e-7（4.00）** | 2.05e-2 … 3.67e-7（4.00） | 1.56e-2 … 2.27e-7（4.00） |

- **3 つの試験すべてで、全時刻 4 次。** pair4 が 2 次だった定常な変密度・変速度で、t = 0.25、N = 256 の誤差が 1/180。

保存（t = 1 の、全運動量の相対的なずれ / `E* = ½ Σ h ρ* q*²` の相対的なずれ、N = 16 / 32 / 64 / 128）：

| 試験 | ずれ |
| --- | --- |
| 一定 | 1.6e-16/2.6e-12、2.6e-17/8.1e-14、2.4e-17/1.9e-15、2.5e-16/0 |
| 定常な変密度・変速度 | 1.1e-16/2.6e-12、1.2e-17/8.1e-14、7.3e-17/3.4e-15、1.5e-16/8.9e-16 |
| **密度の波** | **2.6e-9/2.0e-5**、5.9e-10/8.7e-8、2.9e-12/3.4e-10、1.2e-14/1.4e-12 |

- 質量の流束が変わらない場合は、運動量は丸め誤差、E* は RK4 の時間の誤差だけ（刻みとともに減る）。半離散では厳密に保存。
- **質量の流束が空間・時間で変わる場合（密度の波）は、保存が厳密でない**（N = 16 で E* が 2e-5）。分割形の輸送がエネルギーを保つには、離散的な連続の式 `ρ*_t = −D F*` が厳密に成り立つ必要があるが、`ρ*_t = R ρ̄_t`（面の流束から）と `D F*`（中心の点の流束から）は O(h⁴) しか一致しない。時間で変わる質量行列と再構築演算子の整合（ユーザーの注意）が残る課題。

## 4. 連続の式を構成で満たす：密度も点の空間で運ぶ（`--point-space`）
ρ* と (ρq)* をどちらも点の空間で運ぶ：`ρ*_t = −D F*`（`F* = ρ* U*`、U* はセルの中心の点の速度）、q* は 3 節の分割形。離散的な連続の式が構成で厳密に成り立つので、半離散で `E* = ½ h Σ ρ* q*²` は厳密に保存。セル平均は `R⁻¹` で戻す（R は和を保つので、全質量・全運動量も保存）。最大誤差の次数（N = 64 → 128）と t = 1 のずれ（N = 16 / 32 / 64 / 128）：

| 試験 | t = 0.25 | 0.5 | 1 | 質量 / 運動量 / E* のずれ |
| --- | --- | --- | --- | --- |
| 一定 | 4.00 | 4.00 | 4.00 | 0/4e-16/3e-12、0/7e-17/8e-14、0/1e-16/2e-15、0/8e-17/0 |
| **密度の波** | **3.99** | **3.99** | **3.99** | **4e-16/3e-16/3e-11、2e-16/7e-16/4e-14、0/2e-16/2e-15、1e-16/3e-16/1e-15** |
| 定常な変密度・変速度 | 3.98 | 3.99 | 3.99 | 4e-16/3e-16/3e-12、4e-16/5e-16/8e-14、4e-16/3e-16/4e-15、6e-16/3e-16/2e-16 |

（誤差の値は 3 節とほぼ同じ：密度の波 N = 128、t = 0.25 で 1.64e-6、定常な変密度・変速度 3.78e-6。）

- **密度の波でも、質量・運動量は丸め誤差、E* は RK4 の時間の誤差だけ（刻みとともに減る）で、全時刻 4 次。** 3 節で残った保存の破れ（N = 16 で E* 2e-5）が消えた。
- 代償：セル平均の質量は `R⁻¹ρ*` で、幾何学的な（VOF の）質量の更新とは一致しない。二相流では、ここが質量分布の共分散を使うエネルギー `E₄^Γ`（ユーザーの提案）の出番になる。

## まとめ
- ノート78 の P0-4a は訂正：pair4 は変速度では 2 次。
- ユーザーの相似変換（点値の空間で歪対称な輸送、セル平均に戻す）は、一定の密度の多次元の変形で 4 次と高次のエネルギーの厳密な保存を両立し、変密度に拡張しても全時刻 4 次。
- 変密度で厳密に保存するには、再構築した密度と質量の流束の間で離散的な連続の式を厳密に満たす構成が要る。密度も点の空間で同じ歪対称な演算子で運べば、なめらかな変密度で 4 次と質量・運動量・エネルギーの厳密な保存が両立する（4 節）。残るのは、これを VOF の幾何学的な質量の更新と一致させること。

## 次
- 点の空間で運ぶ密度と、VOF の幾何学的な質量の更新（セル平均）の整合。
- 二相流（不連続な密度）では R が正値を保たないので、ユーザーの提案する、PLIC と相の密度から求める質量分布の共分散 Σ_i を使ったエネルギー `E₄^Γ`。
