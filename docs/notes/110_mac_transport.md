## 定式化と理論的根拠
### A. 問題（ユーザーの試験の案）
層の二相（密度が y だけに依存、周期、N = 32）で、界面を厳密な写像 `y = x + Δ` で並進させる。速度の 1 成分を同じ写像で運ぶ（`ρ^{n+1}(y) = ρ^n(y − Δ)`）。

- 2 つの成分を別々に扱う：**接線**（セルのデータ、再構築 R_C）と**法線**（面のデータ、R_F）。再構築はノート108 の低次の形（A、D0m、D0b）。
- 制御体積はノート109 の 3 通り（dual、phase、blend）。重み χ_i は各時刻の界面の位置で決まる。

### B. 質量・運動量の移管（ノート107 の 5.5 節、ユーザー）
厳密な輸送の測度 π を使って：

```
m_ij = ∫ ρ^n(x) χ_i^n(x) χ_j^{n+1}(x + Δ) dx,   p_ij = ∫ ρ^n(x) χ_i^n(x) χ_j^{n+1}(x + Δ) u^n(x) dx
```

- 制御体積が領域を分割するので `Σ_j m_ij = m_i^n`、`Σ_i m_ij = m_j^{n+1}`（恒等式）。
- `p⋆_j = Σ_i p_ij` は、運んだ再構築の、新しい制御体積の中の厳密な運動量である。移動度の切り替えで所属が変わることによる移管を含む。
- 積分は、新旧の界面・セルの面・双対セルの境界の全てで区間を分け、Gauss 8 点で行う（低次の再構築では厳密）。

### C. 2 つの更新
| 更新 | 式 | 構成上の性質 |
| --- | --- | --- |
| Galerkin | `G^{n+1} f = C f^n`、`C = ∫ρ^{n+1} R^{n+1}ᵀ (R^n f)∘Φ⁻¹` | エネルギー非増加（定理 4）。局所の運動量は課さない |
| 運動量 Remap | `P⋆^{n+1} f = p⋆` | 局所の運動量が厳密。エネルギーは `1/σ_min²` でしか抑えられない（ノート107 の 5.6 節） |

- 両方とも、再構築が定数を再現すれば自由流を保つ（Galerkin は定理 4、Remap は `P⋆1 = m` と `p⋆ = U m` から）。
- `σ(Q⋆) = 1`（等長）のとき、再構築空間は制御体積の上の区分定数に一致し、Galerkin の射影と Remap は同じ演算子になる（導出）。D0m の接線成分 + 相別の制御体積がこの場合である（ノート109 の C 節）。

### D. 測る量
- 1 ステップの最悪のエネルギー増幅：`λ_max(Tᵀ G^{n+1} T, G^n)`。
- 多ステップの積の最悪の増幅（開始からの最大）：増幅が積み重なるかを見る。
- Galerkin の局所の運動量のずれ：`‖M⋆^{−1/2}(P⋆ T_gal − P̃) G^{−1/2}‖`（P̃ は運んだ再構築の運動量。任意の入力に対する最悪の、質量とエネルギーで正規化したずれ）。
- 滑らかな場（`sin 2πy + 0.3`）のエネルギーと総運動量。

## 1. 質量の移管と自由流（全ての組・シナリオ・密度比 1 / 1e3 / 1e6）
- **`m_ij` の行和・列和は、1e-15 で制御体積の質量に一致した**。切り替えで 1 つの制御体積の質量が **9.1e11 倍**変わる場合（密度比 1e6、接線、r² に対応）を含む。
- **自由流**：D0m・phase では Galerkin も Remap も 3e-15 以下、D0b では 2e-14 以下。旧来の双対セルでは、悪条件のために緩む（D0m・dual の Remap で 2e-9、A・dual で 1e-10〜3e-10）。
- **総運動量**：2e-13 以下（D0m・dual の Remap だけ 5e-9）。

## まとめ
- **質量の移管**：共通の輸送の測度による `m_ij`・`p_ij` で、所属の切り替え（質量の比 r²）を含めて、質量の収支・自由流・総運動量が丸めの水準で成り立つ。硬い切り替えそのものは、保存の妨げにならなかった。
- **保存とエネルギーの両立**：
  - 再構築空間が制御体積の上の区分定数に一致する成分（D0m の接線、σ = 1）では、両立する。
  - そうでない成分（法線、σ = 0.71〜0.79）では、両立しない。運動量 Remap の最悪の増幅は 1.3 以下で、多ステップで積み重ならなかった。Galerkin は運動量が 0.4（正規化）ずれる。
- **旧来の双対セルは、密度適合型の再構築と組むと輸送で破綻する**。相別の制御体積を主候補とする判断（ユーザー）を、輸送でも支持する結果である。

## 未検証・次（ユーザーの判断が必要な点を含む）
- **法線成分をどうするか**（S8 の本体）。候補：
  1. 運動量 Remap を採り、有界な増幅（1.3）を許す。完全離散のエネルギーの安定性は別に示す必要がある。
  2. 法線の再構築空間を、制御体積の運動量と等長になるように変える（補助モーメント、または相の区間の半分ずつの平均。下界 √(3/4)、ノート107 の 5.6 節）。可換性との両立は未検討。
  3. 保存型の流束 + エネルギーに整合した補正。
- この試験は、一次元・低次・厳密な一様の並進・N = 32 だけである。一般の流れ、数値の界面の輸送（PLIC）、二次元、高次（D5m は σ = 0.09〜0.11 で、最悪の増幅の上界は約 110）は未検証。
- 連続で、かつ頑健な組（D0b の代わり）。硬い切り替えの D0m で保存が成り立つので、連続化の必要性そのもの（時間精度への影響、定理 6）を測る必要がある。
- 極端に薄い軽い相での最大の速度と時間刻みへの依存（ユーザーの試験の 4 つ目）は、切り替えの近くの 2 つのシナリオで間接に見ただけである。
