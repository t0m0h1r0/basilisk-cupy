# 02 UCCD6 ハイパー粘性の負の固有値（判断：このまま）

- (D2)⁴ は「1つ目の D2 が場の境界条件、外側3つが外挿」という合成。コンパクトな壁クロージャでは、壁に負の固有値が1つ出る。
  - Dirichlet −1.66/h⁸、Neumann −0.020/h⁸（N によらない）。最大は 8493.5/h⁸。
- 増幅率に直すと 1.7σ|u|/h（σ = 1e-3 で 1.7e-3|u|/h）。旧クロージャで移流そのものが持っていた 0.096|u|/h の約 1/56。
- 非負にする案（不採用）：
  - 4つすべてを場の境界条件で作る → 壁で1次
  - (E B)ᵀ(E B) と対称化する → 壁で3次（現状 4次）
- 判断（Tomo さん）：このままでよい。
- 教訓：外挿のクロージャを含む演算子の合成は、スペクトルの性質を保証しない（→ 04 で D2∘D2 を避けた理由）。

## 定式化と理論的根拠
- **負の固有値が増幅率 1.7σ|u|/h になる理由**：UCCD6 の超粘性の項は `σ|u|h⁷ ∂⁸` の形（`(D2)⁴` を h⁷ で掛ける）。壁の負の固有値 `−1.66/h⁸` を持つモードでは、`σ|u|h⁷ × 1.66/h⁸ = 1.66 σ|u|/h` の速さで増える。σ = 1e-3 で 1.7e-3|u|/h。
- **合成でスペクトルの性質が保証されない理由**：各段の D2 が半負定値でも、外挿の閉包を含む段の積は一般に対称でない（ノート37 の layered 形と同じ）。積の固有値は、各段の固有値の積にはならない。
- **非負にする案の次数**：`(EB)ᵀ(EB)` の形は構成から半正定値（エネルギーの減少が保証される）。その代わり、転置が壁の行の精度を 1 次下げる（本文の 3 次）。
