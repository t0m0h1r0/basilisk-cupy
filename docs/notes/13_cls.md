# 13 CLS（保存型レベルセット）への差し替え（PR #27）

TwoPhaseFlow の界面手法の1段目。VOF（Basilisk 互換のベースライン）と同じ速度場で比べる。

## 移植した内容（`interface/cls.py`）
- ψ = H_ε(Φ) = (1 + tanh(Φ/2ε))/2（Φ は液相で正の符号付き距離。論文の ψ = H_ε(−φ) と同じ）、ε = 1.5Δ（TwoPhaseFlow の `epsilon_factor`）。逆写像は artanh の前に ψ を [10⁻⁶, 1 − 10⁻⁶] に制限。
- 段階 A：保存形移流。TVD-RK3、流束 (P_f ψ)u_f（P_f は FCCD の面値、中心型4次）、素の面差分 D_f、各段で [0, 1] にクリップ（TwoPhaseFlow の `fccd_flux` モードと同じ構成）。
- 段階 B：質量補正。重み w = 4ψ(1−ψ) で界面帯だけを補正し、クリップ。
- 再初期化（暫定）：Olsson–Kreiss の圧縮・拡散の式を、セル中心の有限体積の保存形で陽的に解く（面流束 ψ(1−ψ)n − ε∇ψ、法線は CCD 勾配、擬似時間刻みは TwoPhaseFlow の `compute_dtau`）。

## 論文と実装の食い違い
- 論文（5b 節）は再初期化の標準を Ridge–Eikonal とし、圧縮・拡散型は「連続レベルの平衡の定義」としてのみ使い、離散では「非採用」とする。実装の既定は圧縮・拡散型の分割スキーム（`reinit_method = "split"`：圧縮は散逸付き CCD の前進 Euler、拡散は CN-ADI、4 擬似ステップ、節点格子）。
- 実装の再初期化の頻度の既定は 0（設定しなければ行わない）。
- ψ の移流の発散は素の D_f（点値に対して2次。03 の D_f の問題と同じ）。

## 測定
反転渦（Basilisk reversed.c の速度、T = 15）、sharp 誤差 = |(ψ > 1/2) − 体積率| の平均：

| N | CLS（再初期化なし） | CLS（10 ステップごと） | CLS（50 ステップごと） | CLS（毎ステップ） | VOF |
| --- | --- | --- | --- | --- | --- |
| 32 | 0.0707 | 0.0707 | 0.0924 | 0.171 | 0.0606 |
| 64 | 0.0306 | 0.0306 | 0.0460 | 0.139 | 0.0099 |
| 128 | 0.0139 | 0.0080 | 0.0171 | — | 0.0014 |

周期領域での円の並進（速度 (1, 0.5)、t = 1）：

| N | CLS の ψ の L1 誤差 | CLS の sharp 誤差 | VOF |
| --- | --- | --- | --- |
| 32 | 6.0e-3 | 1.17e-2 | 1.52e-3 |
| 64 | 5.4e-3 | 7.0e-3 | 3.40e-4 |
| 128 | 4.3e-3 | 4.3e-3 | 8.66e-5 |

- 質量（∫ψ）は全条件で 1e-13 以下で保存。ψ は常に [0, 1]。
- 静止した円に再初期化を 100 回かけても ψ = 1/2 の等値線は動かない（N = 64 で sharp 誤差 4.997e-3 のまま）。
- CLS は滑らかな並進でも約1次。ε ∝ Δ なのでプロファイルは常に約3セルの幅で、中心型の面値の振動を各段のクリップで切るため、界面が少しずつずれる。VOF は並進で約 2.2 次、反転渦で約 2.7 次。
- 毎ステップの再初期化は、強く引き伸ばされた細い帯を圧縮・拡散が崩すため、かえって悪化する。

## 次の段
Ridge–Eikonal（段階 D）で再初期化を差し替え、ψ 曲率、分相 PPE＋HFE/GFM と進む。二相 NS への組み込み（ψ による物性、表面張力）は ψ 曲率の段で行う。
