## 定式化と理論的根拠
### A. 体積力の整合した離散化（ユーザー）
最小粘性エネルギーの応力は、セルの質量座標について線形 `τ_h = (1 − s_i)τ_{i−1} + s_iτ_i` である。体積力 f（圧力勾配の型）の定常では `τ' = −f` なので、密度が跳ぶ混合セルでは表せない（ノート101）。

外力による局所の応力の補正を加える：

```
τ_b,i(x) = −∫_{x_i}^x f + s_i(x)F_i,   F_i = ∫_{K_i} f      （セルの両端で 0）
τ_h = (1 − s_i)τ_{i−1} + s_iτ_i + τ_b,i,   d_f = ∫ψ_f τ_b/μ,   Hτ = D_bq + b − d
```

離散の外力は `F + D_bᵀH⁻¹d` になる。これは、最小粘性エネルギー再構築を試験関数にした Galerkin の外力 `R_ν*f` に一致する（ユーザー）。

- 外力なし、加速度の力（f = ρg、τ_b = 0）、密度が一定の体積力では d = 0。既存の結果は変わらない。
- H、K_ν、G_A は変えない。
- D 方式で、移流の再構築 R_A と外力の仕事を厳密に整合させること（`R_A*f`）と、圧力の勾配との整合は、まだ確立していない。

### B. 二次元の全粘性応力テンソル（ユーザー、V6-1）
速度の 2 成分を、一次元の最小粘性エネルギー再構築のテンソル積 X(x)Y(y) で表す。粘性の行列は、`K = ∫2μ B_εᵀB_ε`（`ε = (∇u + ∇uᵀ)/2`）で構成上、対称・半正定値になる。

単相・周期では、各方向が巡回行列なので、波数 (θx, θy) ごとの 2×2 の記号になる。一次元の記号を `b = ∫|X|²`、`a = ∫|X'|²`、`c = ∫X̄X'` とすると：

```
K = μ [[2a_xb_y + b_xa_y, c_x c̄_y], [c̄_x c_y, a_xb_y + 2b_xa_y]],   G_C = b_xb_y I,   G_D = h² g_A(θx) g_A(θy) I
```

- 一次元の X は解析的に書ける。セル [0, h] で `X = 1 + τ_{−1}(w_l − h/3) + τ_0(w_r − h/6)`、`w_l = h(s − s²/2)`、`w_r = hs²/2`、`X' = (1 − s)τ_{−1} + sτ_0`。
- G_D の g_A は、周期 PCCD の Gram の記号（ノート91）。
- 厳密な減衰率は、発散 0 のモードで μ|k|²、回転 0 のモードで 2μ|k|²（`∇·τ = μ(Δu + ∇∇·u)`）。回転 0 のモードの値は、混合微分の項（c_x c̄_y）に依存する。

### C. 格子に平行な界面（V6-2）
密度と粘度が y だけに変わるとき、x によらないモード（θx = 0）では `a_x = c_x = 0`、`b_x = h` になる。二次元の演算子は、y 方向の一次元の演算子に代数的に一致する。そのため、x によらない流れ（二層せん断流）については、一次元の結果（ノート100・101）がそのまま当てはまる。

### D. Galilean boost 付きの二層 Stokes（ユーザー、V6-4）
`u = (w(y − Ut)e^{−λt}, U)`、ρ と μ も速度 U で移動する。周期で表面張力が 0 なら、これは非圧縮の二相 Navier–Stokes の厳密解である。x によらないので、テンソル積の離散化では y の一次元の問題に厳密に帰着する（C 節）。

1 ステップ：
1. 粘性の半ステップ（界面を固定、`G_A^n q̇ = −K_ν^n q` を一般化固有値で厳密に積分）
2. PCCD–Galerkin の移流（共通の分割、`G_A^n → G_A^{n+1}`）
3. 粘性の半ステップ（`G_A^{n+1}`、`K_ν^{n+1}`）

- 各写像は、その Gram のエネルギーを増やさない（粘性は散逸、移流は Galerkin）。
- 移流の G₁（ステップ n）と、次のステップの G₀ は、同じ形状の Gram を異なる分割で積分したもので、差は ε_G。ε_G = 0 なら、全体のエネルギーは増えない（ユーザー）。
- 時間で厳密に積分した粘性の半ステップなので、時間の誤差は分割だけから出る。

## まとめ
- **体積力**：外力を最小粘性エネルギー再構築に整合させた離散化（`F + D_bᵀH⁻¹d`）で、体積力の Poiseuille が全ての物性で厳密になった。
- **二次元の粘性**：テンソル積の最小エネルギー再構築による全粘性応力テンソル（`K = ∫2μB_εᵀB_ε`）は、単相で C・D とも 4 次、等方的、混合微分も正しい。
- **統合**：PCCD–Galerkin の移流と D の粘性を同じ Gram で Strang に組み合わせると、エネルギーは増えず、運動量を保ち、2.3〜3.8 次で収束する。分割の誤差は無視できる。
