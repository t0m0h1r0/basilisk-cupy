# 50 論文の標準経路を一つの組み合わせに：`TwoPhaseIMEX`（PR #65）

## ねらい
論文 11b1 の 7 段の時間刻みを、既存の部品で一つの組み合わせとして組み立てる。既定の `CenteredNS` は変えず、別のクラス `TwoPhaseIMEX`（`basilisk_cupy/time/two_phase_imex.py`）として追加した。
中身は `IMEXBDF2NS` に `TwoPhaseCLS` をフックでつないだもの。両者は同じ段（stage）の名前を使うので、新しく書いたのは組み立てと診断量だけである。

## 1. 静止液滴（R = 0.25、σ = 1、μ = 0.1、壁、t = 0.5）
CenteredNS + CLS/GFM と同じ CLS・GFM・粘性の解法で、時間積分だけを変えた。ジャンプ / 終わりの最大速度 / 最大速度の履歴の最大：

| N | 密度比 | CenteredNS | TwoPhaseIMEX（u_f^n） | TwoPhaseIMEX（AB2） |
| --- | --- | --- | --- | --- |
| 32 | 1 | 4.01046 / 1.3e-6 / 3.5e-4 | 4.01030 / 2.6e-6 / 3.7e-4 | 4.01030 / 2.7e-6 / 3.7e-4 |
| 32 | 1000 | 4.01066 / 5.5e-8 / 6.4e-4 | 4.01051 / 5.3e-8 / 6.8e-4 | 4.01051 / 5.7e-8 / 6.7e-4 |
| 64 | 1 | 4.00301 / 5.8e-8 / 5.5e-5 | 4.00300 / 4.3e-8 / 5.7e-5 | 4.00301 / 4.4e-8 / 5.6e-5 |
| 64 | 1000 | 4.00302 / 3.3e-8 / 9.0e-5 | 4.00301 / 3.9e-9 / 9.4e-5 | 4.00301 / 4.1e-9 / 9.3e-5 |

- 密度比 1 / 10 / 100 / 1000 のすべてで安定。質量の変化は 1e-14 以下（刻みは tension.h の上限 × √(5/12)）。
- ジャンプは約 1.8 次で 4 に近づく（N = 32 → 64 で誤差 0.0103 → 0.0030）。
- 三つの時間積分の差は、ジャンプで 2e-4 以下。静止状態は時間積分の違いにほとんど影響されない。
- 費用（GPU、一つずつ実行）：N = 64、密度比 1000 で CenteredNS 37 秒、TwoPhaseIMEX 40 秒（1004 ステップ）。

## 2. 毛管波（capwave.c、等密度）
Prosperetti の解との RMS 誤差 / 減衰率の誤差（最初の 5 周期）/ 周期の誤差：

| 1 波長の点数 | CenteredNS | TwoPhaseIMEX（u_f^n、論文） | TwoPhaseIMEX（AB2） |
| --- | --- | --- | --- |
| 8 | 0.1866 / −28.7% / +15.6% | 0.2032 / −36.0% / +15.4% | 0.1907 / −30.1% / +15.4% |
| 16 | 0.0709 / −12.0% / +3.6% | 0.0827 / −18.8% / +3.6% | 0.0723 / −12.0% / +3.6% |
| 32 | 0.0158 / −3.1% / +0.84% | 0.0203 / −6.3% / +0.65% | 0.0164 / −2.8% / +0.84% |

- 対流の方式（中心、FUCCD₄、UCCD6）による差は、RMS 誤差で 3e-4 以下だった（振幅 0.01 では対流がほぼ効かない）。

### 刻みの依存（16 点、刻みの上限を 1/d に）
| d | 1 | 2 | 4 | 8 | 16 | 32 |
| --- | --- | --- | --- | --- | --- | --- |
| CenteredNS | −12.02% | −12.28% | −12.50% | −12.53% | −12.54% | −12.56% |
| IMEX（u_f^n） | −18.77% | −15.87% | −14.35% | −13.57% | −13.18% | −12.99% |
| IMEX（AB2） | −12.04% | −12.51% | −12.67% | −12.73% | −12.76% | −12.78% |

- **論文どおりの輸送（u_f^n）は時間 1 次。** 刻みを半分にするたびの変化は 2.90 / 1.52 / 0.78 / 0.39 / 0.19 ポイントで、ちょうど半分ずつ縮む。
- **AB2 にすると 1 次の誤差が消える。** 変化は 0.47 / 0.16 / 0.06 / 0.03 / 0.02 ポイントで、すべての方式が同じ極限（約 −12.7〜−12.8%）に向かう。
- 因果の確認：運動量・射影・曲率は同じで、ψ を運ぶ速度だけを変えて 1 次の誤差が消えた。原因は第1段の輸送である。
- **当初の仮説（CenteredNS の 1 次の時間誤差が減衰を足し、打ち消している）は否定された。** CenteredNS は刻みにほとんど依存しない（−12.0 → −12.6%）。
- 既定の刻みでは、論文どおりの輸送のずれ（−18.8% − (−12.7%) ≈ −6 ポイント）が、CLS の運動学による減衰不足（41）に**上乗せ**される。
- 極限の −12.7% は、16 点で CLS の運動学が生む半離散の減衰不足（41・49）であり、時間積分では直らない。

### 論文との関係（ノート10 に追加）
- 11b1 は第1段で ψ を「前ステップの射影後の面速度 u_f^n」で TVD-RK3 により進める。TwoPhaseFlow の実装も、現在の状態の面速度（なければ節点速度）を使う（`ns_pipeline.py` の `_transport.advance(_with_face_velocity)`）。
- 速度を 1 ステップ凍結して運ぶのは、運動学 dx/dt = u について陽的 Euler と同じで、時間 1 次である。TVD-RK3 の 3 次は、速度を凍結した輸送方程式についての次数にすぎない。
- 論文 13d の V7 は二相の実効次数 1.59 を「毛管圧力ジャンプ / FCCD 射影の界面帯の低正則性」に帰している。本実装の測定では、より単純な 1 次の原因が第1段にある。論文の経路で 1.59 がどちらによるかは未確認。
