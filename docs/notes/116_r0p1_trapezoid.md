## 結論の要約
- **候補 1（引き戻さない形そのまま。最初のステップを通常の射影で始める＝初期値を射影で作る）：条件 4 で不合格**。連続するステップの g の差は、定常の Taylor–Green で N = 32 → 256 に対して 56% → 107% と、**格子を細かくするほど増える**（源の項なしの形は 5.3% → 0.9%）。条件 1〜3 は満たす（液滴・気泡・斜めの帯、密度比 1e3・1e6、1000 ステップで増幅なし。総運動量 2e-13。単相の誤差は N = 32〜256 で 4.6e-3 → 3.2e-5）。
- **候補 2（半ステップの力積を、直前の 2 ステップの圧力の平均から、現在の面の係数で作る）：条件 1 で不合格**。振動は抑えられる（10% → 1.7%、源の項なしの約 2 倍で、格子とともに減る）、単相の精度は最良（N = 256 で 1.4e-5）、総運動量も保存する（3e-13）。しかし**密度比 1000 で不安定に戻る**（成長率 1.7〜2.9、3 つの形状とも。密度比 1e6 では 9〜42）。
- **理由（導出、B 節）**：振動を減衰させるには、力積に 1 ステップ前の情報を混ぜる必要がある。1 ステップ前の**圧力**を現在の密度で使うと、重い相が抜けたセルに、重い相の大きさの圧力勾配が軽い密度で掛かる（ノート114 の「力の形」と同じ機構）。1 ステップ前の**加速度**を使えば有界だが、力の総和が 0 でなくなり、運動量を保存しない（ノート114 の「加速度の形」と同じ）。**遅れた情報を、保存し、かつ有界に使う局所的な方法は、この 2 つの間には無い**（仮定つきの主張）。
- **判定**：B が決めた上限（候補 2 つ）の中で、案 1 は**不合格**。条件 5（粘性の段との両立）は、どちらの候補も先に不合格になったので測っていない。次の分岐（保存型の中点法・RK2、または界面の近くだけ時間中心化を切る）は B の判断。

## 定式化と理論的根拠
### A. 引き戻さない形と、その振動（ノート114 の B 節の続き）
輸送の前に `u ← u + (Δt/2)Kⁿ` を足し、何も引かない。射影は残りを与える：`uⁿ⁺¹ = T(uⁿ + (Δt/2)Kⁿ) + Δt g̃ⁿ⁺¹`。圧力の力積の合計は `(Δt/2)Kⁿ + Δt g̃ⁿ⁺¹` で、時間 2 次の整合には `Kⁿ + 2g̃ⁿ⁺¹ → 2g⋆`（g⋆ は真の加速度）が要る。`Hⁿ⁺¹ := 2g̃ⁿ⁺¹` と書くと、発散 0 の条件から（P は勾配の成分への射影、輸送の作用は O(Δt) なので省く）

```
Hⁿ⁺¹ = 2g⋆ − P Kⁿ
```

- **候補 1**：`Kⁿ = Hⁿ`。`Hⁿ⁺¹ − g⋆ = −P(Hⁿ − g⋆)`。固有値 −1：**減衰しない 2Δt の振動**（圧力の Crank–Nicolson の既知の性質）。ずれ `Hⁿ − g⋆` は、毎ステップの打ち切り誤差で励起され続ける。
- **候補 2**：`Kⁿ = (Hⁿ + Hⁿ⁻¹)/2`。`eⁿ⁺¹ = −(eⁿ + eⁿ⁻¹)/2`、特性方程式 `r² + r/2 + 1/2 = 0`、`|r| = 1/√2`：**減衰する**。不動点は `H = g⋆` で、整合は保たれる。

### B. 候補 2 の作り方と、保存・安定の両立の問題
- `(Hⁿ + Hⁿ⁻¹)/2` を加速度のまま平均すると、`Hⁿ⁻¹` は時刻 n − 1 の密度で作った加速度なので、力の総和 `Σρⁿ Hⁿ⁻¹` が 0 にならない（運動量を保存しない。ノート114 の加速度の形と同じ理由で、採らない）。
- そこで、**圧力（ポテンシャル）を平均してから**、現在の面の係数 αⁿ とセルへの平均で加速度にした：`Kⁿ = −avg_f(αⁿ_f ∇(Φⁿ + Φⁿ⁻¹)/2)`、`Φ = 2p`（最初のステップだけ `Φ = p`）。面の密度が算術平均なら `Σρⁿ Kⁿ = 0` で、保存する（ノート115 の恒等式）。
- **不安定になる理由**：重い相が時刻 n − 1 から n の間に抜けたセルでは、`∇pⁿ⁻¹` は重い相を加速する大きさ（`ρ₁ a`）のままで、それを現在の軽い密度で割ると `(ρ₁/ρ₂) a` になる。ノート114 の式 (F) の `m_out/m'` と同じ因子である。
- まとめると、遅れた情報の使い方は「力（圧力）として使う → 保存するが、抜けたセルで密度比の増幅」「加速度として使う → 有界だが、保存しない」のどちらかになる。両立させるには、遅れた力積を質量と一緒に運ぶ（運動量の一部として輸送する）ような、局所的でない扱いが要ると考えられる（未検証。最小の修正の範囲を超える）。

### C. 合格の条件（B が結果の前に固定、PR #155 のコメント）
| # | 条件 |
| --- | --- |
| 1 | 安定：密度比 1000 と 1e6 で、液滴・気泡・斜めの帯に増幅が無い |
| 2 | 保存：圧力を含む総運動量の正規化した誤差 1e-9 以下（渦の中の液滴） |
| 3 | 単相の精度：#141 の合格の条件（`O(h² + hΔt + Δt²)`）を保つ |
| 4 | 圧力の振動：連続するステップの g の差が、源の項なしの形と同じ水準（数 %）で、格子を細かくしても増えない |
| 5 | 粘性の段と両立する |

1 つでも満たさなければ不合格として記録し、作り込まない。測り方（A が先に決めた）：条件 1 は一様流 (1, 0.37) の中の 3 つの形状、N = 32・64、1000 ステップ、max\|u − U\| が 1e-3 に達したら不安定（ノート114 と同じ）。条件 3・4 は定常の Taylor–Green、CFL 0.5、t = 0.5、N = 32〜256 の 7 格子（g の差は最後の 2 ステップの相対差）。条件 2 はノート114 の渦の中の液滴（t = 0.25、N = 32・64）。

- 正直な記録：候補 2 は、全ケースを流す前に N = 32 の予備の実行で、単相の振動が減ることと、密度比 1000 で不安定なことを見ている。候補の作り方は、その後で変えていない。

## 自己点検
- 条件 3 は固定の CFL での傾きだけで、#153 の読み方（場の差による Δt の係数）では測っていない。不合格の理由には関わらない。
- 安定の判定は一様流の中の 3 つの形状、1000 ステップまで。
- 「遅れた情報を保存しつつ有界に使う局所的な方法は無い」は、2 つの作り方（力として・加速度として）についての主張で、一般の証明は無い。振動を抑える別の系統（例：射影の側で圧力の増分を解く形、振動する成分だけを取り出して除く形）は、上限（2 つ）の外で、試していない。
- 候補 1 の振動が速度の誤差に現れていないのは、定常の単相の流れでの結果である。
